The sealed source audit checker passes 68 payloads, 51 complete selected
bindings, 12 frozen/indexed transfers and 26 ordered callback roster entries.
Root read the report, roster and the complete critical property, pres-shell,
weak-reference entry, canceled-link and SVG-notification/reflow definitions.
This is a source/effect review, not a completed native noninterference proof.

A live-source join matches 50 of 51 complete selected definitions. The only
difference is the committed containing-block-size field/initializer in
CachedBAxisMeasurement::Key. Its exact delta is retained; it adds a LogicalSize
value and does not introduce an owning frame field. This comparison is separate
from the producer's frozen-versus-indexed comparison and its three differences.

The native protocol now has explicit obligations for synchronous SVG observer
callbacks before the first primary-bit read; property descriptor destructors
inside NotifyDestroyingFrame before the second; and final destruction callbacks
after pointer clearing. Generic properties and WebRender releases are not
classified as harmless numeric-cache deletion. The managed refresh cancellation
branch calls its action immediately, but aWasCanceled makes the link action
return before LeaveLink; reference-release effects remain open.
