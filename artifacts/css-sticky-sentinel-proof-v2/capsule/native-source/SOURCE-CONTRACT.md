## Representability and encoding

The native nscoord is signed32, while its conventional nscoord_MAX and NS_AUTOOFFSET equal 1073741823. Low/high finite sticky endpoints are -536870911 and 536870912. Original offsets are optional raw [top,right,bottom,left] values; raw AUTO means absent on that side. A semantic optional-inset interpretation additionally requires that no explicit numeric inset encodes as AUTO. This capsule does not establish that producer guarantee. Values numerically equal to finite sticky endpoints do not establish inactivity.

All supplied coordinates, extents and exact origin-plus-extent sums must fit signed32. Rectangle far methods actually use Saturate, not undefined raw addition: on this domain the faithful saturation facade equals mathematical addition. Outside that domain saturation remains real native behavior, but this capsule rejects the case and proves nothing about it. Every executed canonical translation subtraction and continuation/frame addition is separately checked for signed32 representation, including old-code paths. Point arithmetic facades use ordinary int32 operators and UBSan checks those evaluated runs. The supplied rectangles can have negative extents for contradictory constraints; negative extents do not assert physical browser geometry.

## Geometry and property providers

The full real ComputeStickyLimits and ComputeStickyOffsets bodies are retained in PROVIDERS.json but not executed. The limits facade faithfully selects current versus ignore space, checks the first-continuation precondition, observes original-offset presence, and returns the native initialized finite rectangles if the property is missing. Otherwise it returns admitted rectangles. On present properties, inactive sides must keep the finite endpoint, each active current edge must equal its ignore-space edge plus scroll position, and containment must be space-invariant. All reached geometry calls require an available provider.

These conditions do not derive containing blocks, padding, frame unions, margins, effective insets, writing modes, transformations or geometry after ancestor motion. Supplied limits must equal the actual provider result at the particular call, after any earlier ancestor updates. The parent/child cases therefore exercise dispatch/order and per-call consumers under that premise, not a derivation of ancestor-dependent layout. All upstream evaluated intermediates and frame invariants remain separate premises. The repair still calls the real limits provider for all-auto or missing-offset cases.

GetProperty supplies stable optional normal/offset properties during a call. The exact real normal getter uses the current position if the normal property is absent. Reflow recomputation is an explicit admitted optional-offset transition. A missing normal in PositionContinuations returns before geometry; missing offsets in direct DoComputePosition still cause geometry and normal/property observations. The corpus includes missing-normal cases whose geometry provider is deliberately unavailable, as well as rejected reached-provider failures. No reentrancy, deletion or property mutation occurs except the explicit recomputation and position updates.

## Oracle, roster and mutations

The expected positional oracle independently forms per-axis effective interval bounds. Inactive bounds use mathematical signed32 extremes; active near uses min(stickNear,containFar), active far uses max(stickFar,containNear). It projects the original normal into a nonempty interval; a contradictory interval returns its far bound, matching the required ordered behavior. It is not generated from the extracted C++ assignments. Expected traces are a separate explicit caller/lifecycle interpretation. Agreement is finite compiled calibration, not a theorem of source equivalence.

The closed 856 cases include all 16 masks and seven entry actions across six normal patterns; missing offsets/normals; nested ancestor and continuation dispatch; property installation/removal on reflow; both-axis explicit endpoint collisions; contradictory intervals; signed32 normal boundaries; and sticky/container fallback. The seven mutants respectively restore all clamps, guard only all-auto, infer activity from numeric endpoints, swap activation masks, treat auto-as-zero effective insets as active, restore finite clamps for a missing property, and reverse the two clamp orders. The effective-inset mutant deliberately models erased auto provenance; it is not a full effective-inset producer implementation.

The driver accepts an internal integer protocol generated only after exact JSON roster/schema validation; it is not a general external parser. The schema checks and 20 negative controls are bounded input gates, not a proof of complete malformed-input rejection. No arbitrary mutation history, browser reachability, global sticky layout, scroll ranges, compositor/timeline behavior or all-CSS correctness follows. In particular GetScrollRanges' numeric sentinel tests and timeline explicit-edge assertions remain outside this repair.
