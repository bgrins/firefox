Installs no tests and preserves accepted zoom fix139, the parked prototypes, recovery snapshots, index semantics and flags, nested repository, and unrelated working bodies. The current compiled baseline has 775 completed assertions; expected test failures remain observations.

It reuses the existing guarded write, control publication and rollback helpers. Three additional signed ledger successors are checked against both their preserved v24 preimages and current epoch/HEAD; the original two research-ledger rules are unchanged. This does not weaken the original recovery inventory.

Invoke with isolated Python and the FILES.json SHA followed by the exact epoch SHA in POLICY.json. Root owns execution. After successful installation, the compatible existing build command is:

```
python3 -I -S -B artifacts/css-registered-number-native-runtime-v1/build.py provider-default-candidate-build-1
```

That helper runs mach build binaries -j2, owns process cleanup, preserves source/index state and publishes the actual build epoch and result. No build or native installation was performed while preparing this package.

Preparation checks authenticate references and Python syntax. The saved-evidence test checks one actual baseline and rejects 14 in-memory corruptions; live process, application-metadata and Git succession probes are mocked there. It is not a live preflight or rollback simulation. Existing ownership/rollback helpers are reused, not newly proven.
