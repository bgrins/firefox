# Focused overflow retiming regression gate

Run34 existing flex fragmentation tests plus the336-observation candidate WPT before and after only the standalone native patch. Existing cases cover container fragmentation, overflow children with borders, floats, relative/absolute positioning, vertical writing modes, external resize and eight crash regressions. Searchfox path/query discovery selected these tests. Existing metadata stays unchanged; paired raw statuses distinguish preexisting failures from candidate regressions. All tests must finish, their identities must match, and inputs/source/binary pins must remain stable during each run. Restore source and build and remove the temporary new WPT after testing. This gate does not close unexercised skip branches or full formal refinement.
