# Min/max relative infinity: independent audit

Strongest lead: with `font-size: 0`, `left: min(-1px, infinity * 1em)` should compute to `0px`; current source predicts `-1px`. The symmetric max expression predicts `1px` instead of `0px`. Reversing operands does not change the issue. This is source-based evidence, supported by root-reported exploratory System Firefox observations, not an authenticated current-branch browser result.

[CSS Values 4](https://drafts.csswg.org/css-values-4/#calc-ieee) makes zero times infinity NaN, propagates NaN through operations, and normalizes it only at the top-level calculation. [Simplification](https://drafts.csswg.org/css-values-4/#calc-simplification) requires enough information to compute or compare operands. At zero font size the relative operand becomes NaN; coefficient ordering before resolving that context is insufficient.

In `CalcNode::simplify_and_sort_direct_children`, MinMax selects a leaf using `compare`, with no relative-infinity guard. Specified `Leaf::compare` compares opposite coefficient signs before resolving length units. It therefore discards the infinite em operand. Same-unit comparisons can also discard it. `canonical_value` returns None for unresolved relative lengths. The existing Clamp branch already uses the combination of an infinite coefficient and unavailable canonical value to prevent unsafe finite folds. The MinMax resolver explicitly propagates resolved NaN before its numeric comparison.

The proposed pre-comparison guard is sound as a conservative change: defer MinMax when any leaf has an infinite `unitless_value()` and no `canonical_value()`. Preserve all children and type checks; do not replace unresolved infinity with NaN at parse time. The guard can defer harmless all-infinite or singleton cases too, and may change specified serialization. It is not a claim that every serialization or performance characteristic remains identical. No implementation was written or compiled by this review.

The root fixture has exactly 18 unique callbacks: eight target expressions and ten controls. All expected 0→16→0 font arrays were independently reviewed. The four nested same-unit targets add 1px outside min/max, making lost NaN visible as erroneous 1px rather than an indistinguishable zero. Finite operands, absolute infinities, clamp, same-sign mixed units, an em calibration and direct NaN provide controls. Relative-position `left` permits negative values and avoids nonnegative-property clamping. Runtime style writes and computed-style reads are intentional test observations. No specified-serialization oracle is asserted. The falsifiable next step is an authenticated original/candidate run of these exact bytes plus prior math regressions, with all originally passing signatures preserved; the original result must be observed rather than assumed.
