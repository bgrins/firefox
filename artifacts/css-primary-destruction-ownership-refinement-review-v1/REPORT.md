## Substantive correction

The first pair of predecessor witnesses described a nonempty ordinary item array with no owned buffer that the old executor could still erase successfully. `ArrayShape` now excludes this at every table/line/item level, while admitting both shared-empty storage and allocated empty buffers. Local `Represented` additionally requires the selected release plan, address uniqueness and actual role-correct allocation cells.

The second pair described two individually valid owners sharing a cache root: cleaning one frees the other's cache while leaving its frame/primary coherence intact. `OwnersSeparated` now compares release addresses across all distinct live modeled owners. `other_allocations_survive` uses that pre-state separation and the executor's actual erasure relation; it does not simply assert the desired postcondition. `other_frame_was_present` excludes invented post-state frames. The selected table becomes empty, other owners retain their table and allocation claims, and `world_after_cleanup` derives representation/separation after execution. Completeness then supplies a successful subsequent cleanup of another owner.

The executor remains the inherited detach-then-role-check/free recursion. No native runtime role check or error return is implied by its Option result. The theorem is about the selected phase; it does not model arbitrary callbacks between releases.

The final nested fixture addresses the early nonvacuity request: a full two-owner World and Coherent relation coexist with nested shared/line/item allocations, repeated/dangling raw references and an allocated-empty item buffer. Actual modeled cleanup preserves the other owner/cache, preserves primary coherence, and frees the selected cache and empty buffer. This jointly inhabits the new invariants and demonstrates their lifetime limit.

## Independent boundary challenges

1. **Capacity is external.** The same heap has a valid nested World under roomy capacity and fails under zero capacity. No field in `Cell.allocation role` selects which capacity is the native one. Header/payload decoding remains a separate obligation.
2. **Raw references need not be live.** The full nested World plus Coherent contains raw reference999 while heap999 is absent. The selected destructor ignores these values; later dereference safety does not follow.
3. **World does not imply primary coherence.** A lone frame with empty owned storage satisfies World while its true primary bit disagrees with the absent content pointer. Coherent remains an independent input to the inherited preservation theorem.
4. **Foreign properties are excluded, not handled.** A table containing `.foreign` cannot be Represented. Thus quantification over all modeled frame cells is not proof that every real frame property's owner is included in the projection.
5. **Role checking already rules out cross-role aliasing in a complete represented heap.** Two role-correct releases with unequal roles cannot share an address in the same heap. The producer's role-sensitive-separation counterexample usefully discriminates the standalone SeparatePlans relation, but is not itself an inhabited bad World under the unchanged allocation premises. Same-role cross-owner aliasing remains the substantive additional separation requirement.
6. **Address reuse has no generation identity.** Writing a new item-cache allocation into the freed address gives the same modeled cell value as the former cache. This is a representational limitation, not proof that a captured native pointer becomes valid again.

These clarify explicit admissions rather than refute the producer theorems.

## Native correspondence limits

Retained source supports ordinary nsTArray property/line/item storage, a shared empty header, allocated empty-buffer release, detachment by moving the table, and selected scalar/member destruction. A FlexItem array is not an array of bare pointers: the raw-reference projection omits its value fields, whose destructor behavior remains in the selected-provider contract. Array files retain their indexed-discovery revision, distinct from explicitly frozen flex/frame sources.

`Capacity : Address → Nat` does not decode a native header or prove allocated byte extent, alignment, element-size multiplication, pointer provenance or machine bounds. Addresses are abstract bases without generations. `World` covers the selected-descriptor world, not unseen external owners, every native property or arbitrary installation/transfer paths. Address inequality is not a native byte-range nonoverlap proof. Global native ownership needs a complete projection and installation history.

Cleanup preservation cannot bridge all native notifications before/between the primary-bit reads, allocator callbacks, newly installed properties, final frame destruction or capture/callback/use timing. Owner survival and coherence remain weaker than captured-cache survival. The accepted result strengthens a necessary selected-phase invariant without silently closing those original obligations.
