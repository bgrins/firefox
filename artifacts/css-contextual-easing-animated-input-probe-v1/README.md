This is one unexecuted tentative WPT probe for contextual keyframe easing when an ancestor's animated font size changes. It proposes no native change and establishes no new browser bug. Run it against the same baseline and contextual-easing candidate used for the completed comparison before changing the guard.

The completed combined Gecko pair already covers 315 callbacks, all 41 repairs, and 296 preserved control/ending signatures. Its inherited-font callback explicitly says “without animating that input.” The isolated full Servo checks passed under the documented missing-docs warning policy. Neither result covers this animation-driven input. The movement ownership plan is a different, unexecuted same-root move boundary.

The candidate's `MatchMethods::needs_animations_update` requests contextual regeneration only outside animation-only traversal. Gecko's existing `process_animations` returns earlier for an animation-only traversal with old values. Removing just the new condition therefore would not establish a Gecko fix. The unvisited cascade dependency recorder can observe context without proving that CSS keyframes are regenerated. Searchfox traversal excerpts also distinguish animation-only descendant dirtiness; they do not establish that this probe necessarily avoids every subsequent ordinary traversal.

[CSS Animations processing](https://drafts.csswg.org/css-animations-2/#keyframe-processing) derives the keyframe timing function from the declaration's computed value; its [script ownership rule](https://drafts.csswg.org/css-animations-2/#animations) makes a successful setKeyframes override persistent. [CSS Values em units](https://drafts.csswg.org/css-values-4/#font-relative-lengths) use the element's computed font size. [Web Animations](https://drafts.csswg.org/web-animations-1/#computing-property-values) resolves dependent property values in the target's computed context and [applies animation results through the cascade](https://drafts.csswg.org/web-animations-1/#applying-the-composited-result). These support the proposed inherited-font oracle. Keyframe easing is metadata, so the general property-value algorithm alone is not a proof of native easing acquisition. This is deliberately tentative. It avoids same-element font animation/self-dependency: the driver affects only an ancestor, and the child animates only opacity.

The page registers three callbacks: normal inherited-font mutation as an acquisition control; ancestor font animation as the discriminating case; and the same animated input after successful literal steps(5) setKeyframes as an ownership control. Each uses one stable shadow root, one keyframes rule/name, one target/CSSAnimation/KeyframeEffect, and paused time 750 ms. CSS easing steps(calc(1em / 8px), end) should sample 0.5 at 16 px and 2/3 at 24 px; the script override remains 0.6. Three independent literal-reference animations calibrate those values. No var(), part, slot, root move, or competing keyframe names occurs, so known declaring-root bug 1458189 and WithVariables bug 1710735 are outside the oracle.

All four input samples (16→24→16→24) are collected before assertions. In the animated case only the existing ancestor driver's currentTime changes during that sequence. Computed-style/getAnimations reads and two rendering frames are allowed; there are no author style writes during these four samples. A final unrelated outline-color mutation requests an ordinary restyle at the same 24 px input. The failure diagnostic retains all opacity/font/identity/frame snapshots, including this last sample, rather than stopping at the first stale observation. Normal-control runs are separate sequential promise tests, so their writes do not deliberately trigger a traversal during the animated sequence.

Interpretation: if the normal control passes, animated input is visibly inherited, identity/reference controls pass, but the animated CSS output is stale and the final ordinary restyle repairs it, that is strong evidence of missing refresh on an animation-driven context change. A pass discharges this concrete inherited-font boundary; it does not prove all animated dependencies work. Failure of both acquisition modes instead points at general conversion/acquisition, and script-frame drift points at ownership. WPT cannot inspect traversal flags, so even the discriminating failure does not by itself prove the exact internal path. Source-level instrumentation would be a separate task only if needed.

`check.py` performs inert registration, genuine WPT manifest generation, and WPT lint in an owned temporary tree. It does not invoke the callbacks or simulate a DOM. No owner, native patch, browser run, or build is included. Intended path: `css/css-animations/contextual-easing-animated-inherited-font.tentative.html`.
