# Current primary-spec boundary

Fresh official HTML and response headers are captured under spec/FETCH.json. webspec-index is unavailable (81deee/1); this is a direct primary-text trace, not an exhaustive indexed call-graph claim. All links below were checked against ids in those captured bodies.

CSS keyframes: [Processing Keyframes](https://drafts.csswg.org/css-animations-2/#keyframe-processing) starts with the target (pseudo-)element, obtains computed animation defaults, and groups declarations by the computed explicit timing function. This establishes computation before grouping, rather than keeping a coefficient-derived placeholder. [Animations](https://drafts.csswg.org/css-animations-2/#animations) preserves successful setKeyframes/updateTiming overrides. Verdict REACHED for this ordering/override obligation; this trace alone does not supply a complete engine invalidation algorithm.

WAAPI: [Updating timing](https://drafts.csswg.org/web-animations-1/#update-the-timing-properties-of-an-animation-effect) checks easing grammar before assigning timing properties. [Computing property values](https://drafts.csswg.org/web-animations-1/#compute-a-property-value) explicitly takes a property, value and target element, and uses that element's computed values. [Calculating computed keyframes](https://drafts.csswg.org/web-animations-1/#calculating-computed-keyframes) calls it for keyframe property values; easing is separately stored keyframe metadata. The timing-update algorithm does not call that property-value algorithm with an element/property for easing. A null effect target is expressly permitted. It would be an unsupported leap to transfer the property-value context rule to all timing metadata without the missing call/context rule.

CSS Values' [Font-relative Lengths](https://drafts.csswg.org/css-values-4/#font-relative-lengths) defines initial font/line-height metrics outside an element context. This supplies behavior after a context is selected, not a rule deciding whether attached WAAPI timing is outside its target. Verdict INCONCLUSIVE for target-live versus elementless snapshot timing, null targets, retargeting and getters. No invented16px default, count, permanent TypeError policy or new normative WAAPI test oracle is introduced.
