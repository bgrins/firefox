# Selected dependency closure before SCC finalization

This isolated Lean model demonstrates a concrete failure of a proposed late preparation callback: discovering the selected dependency after popping a NonCustom node can split one real strongly connected component. Detecting a cycle somewhere is insufficient. The model compares a small Tarjan-style traversal against an independent bounded-walk reachability oracle; it does not merely define correctness as following the desired operation order.

Six nodes represent C(custom root), L(line-height), F(font-size), W(writing-mode), A(attribute request) and V(primary variable). Fixed edges are C→L, L→F and the generated priority dependency L→W. An evaluated W declaration reads A; A first reads V and adds A→C only when the consuming context rejects the primary and selects the fallback. Skipped declarations add no W→A edge. An eligible declaration evaluated before a later synthesized revert keeps its selected reads. Those branch choices are supplied inputs, not a CSS parser or normative taint/defaulting theorem.

The two schedules differ at one point. BeforePop visits the generated L→W edge with L still active. AfterPop visits the old explicit L→F edge, closes L as a singleton, then its application callback visits W. With the selected A→C back edge, C/W/A can still form a component, but the closed L is missing. The independent oracle sees mutual reachability of C and L. BeforePop recovers the complete component. With an accepted primary the fallback remains unused; inventing A→C from syntax alone would create a false cycle. An evaluated-then-reverted declaration is separate from a declaration skipped before evaluation.

Implementation and oracle are independent: traversal stores discovery indices, lowlinks, active stack and emitted components; oracle enumerates walks of at most six edges on the closed six-node graph without reading traversal state. Six bounds the shortest simple connecting paths for this graph. Theorems cover the complete four-selection/two-schedule family, not all graphs or arbitrary dependency depth. The explicit traversal fuel16 is an executable-model bound; the completion theorem additionally proves no tested run exhausts it, visits all six nodes and emits each exactly once. It is not a proposed native pass limit or cycle policy.

Five checked statements establish: pre-pop partitions equal the oracle for every selection; all eight runs finish without fuel exhaustion; the late selected case splits the real component while still grouping C/W; unused/skipped fallback cases do not spuriously cycle; and evaluated revert retains the selected-edge hazard. Five false controls attempt to certify premature finalization, invent a cycle from an unused fallback, claim late detection includes L, discard the evaluated-revert hazard, and accept a duplicate node inside one component. All must fail by deciding a false proposition rather than parser/type failure.
