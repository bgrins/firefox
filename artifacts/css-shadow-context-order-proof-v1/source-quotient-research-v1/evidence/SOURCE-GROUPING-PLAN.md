# Remaining source quotient proof

The native key is physical longhand plus exact unimportant priority plus live declaration-block allocation. `SourceCoherence` derives equal complete declaration lists from an immutable allocation lookup and arbitrary concatenated provider construction. It is not yet instantiated for all native providers and has not been silently added to `rawAdmitted`.

A declaration-level action function of that key is false. The mixed block witness retains important Rule and normal value actions under one allocation. The intended quotient proof must instead proceed through complete per-property block sequences:

1. Prove receiver writing mode, original-to-physical mapping, included flags and relevant evaluation inputs are stable while one property is resolved. Preserve the pre-filter writing-mode/attribute observation phase separately.
2. Project each immutable block to the relevant physical property, preserve reverse block order, and partition by importance. Equal block/key providers yield equal complete ordered sequences for each half, not equal actions for every declaration.
3. Prove an accepted non-Rule terminal or priority-rollback action disables further events of that key. Seen-property state disables all later candidates of the property; cumulative priority cuts reject their own triggering priority and never become weaker. Rule disables that semantic occurrence. State-changing evaluation before these actions must be accounted for separately.
4. Derive that a repeated same-key half either encounters the same first effective action before any value, has been removed for its own occurrence, or is entirely ineligible under retained cuts. Skipping repeated Rule events may change intermediate bookkeeping counts; observer equality needs its own idempotence/set-union argument.
5. Connect important and normal halves: every important occurrence of a relevant block is processed before any normal occurrence of that block. If the important projection has an effective Rule event, each corresponding semantic occurrence is removed or the key becomes globally ineligible before normal processing. If it has no effective event, normal processing uses the normal projection's first effective action.
6. Derive the premise from the complete rule-path construction, including adjacent source/priority elision, selector duplicates, transitions, origin buckets and buffering. Do not posit a prearranged declaration stream as raw admission.

The complete plan has not been proved. HalfBlockAtomic proves the local mixed-action half-block collapse under uniform key eligibility and self-disabling non-Rule effects; it also proves retained priority cuts reject all candidates with the same normalized priority. Importance-phase pairing, evaluation/observation obligations and source instantiation remain open. It identifies concrete prerequisites for using the existing grouped AliasEquivalence result without its invalid raw-declaration interpretation. OccurrenceDeletion remains the unconditional mixed-action semantic-identity core; RepresentedControl supplies cumulative priority-region control. Neither establishes the block-pointer quotient or complete native observer equivalence.

`OccurrenceState` strengthens the local half result to preserve both accumulated exclusions and computed state. It proves replacement by the first event in any prefix/suffix context and for arbitrary lists of half-blocks. This fixes the composition limitation of a theorem observing only the computed state. It assumes uniform eligibility by key and that each non-Rule effect disables its key; complete evaluation and source grouping must still derive these premises. The stream may contain mixed actions in every half and arbitrary repeated keys. This does not identify important and normal halves or prove the quotient from semantic occurrences to allocation/priority keys.

`PhaseCoverage` now proves the important-to-normal blocking obligation once earlier Rule occurrence coverage and non-reenabling eligibility are supplied. It permits arbitrary mixed actions and effects, and preserves semantic occurrence identities. The source-dependent coverage premise, evaluation monotonicity and allocation-key quotient remain open; the earlier per-key raw action determinism is still invalid.
