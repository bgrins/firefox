# Nowrap suppression: universal list contract

Eight Lean statements verify the local suppression contract for arbitrary finite lists and arbitrary element type, with a distinguished NONE value. This is useful independent evidence for the reviewed helper; it is not a publication gate or a machine-code, pointer-safety, scanner or glyph-storage proof.

`helper` follows the native structure: an empty span returns unchanged; a zero-offset nonempty span treats its first item using INITIAL and maps INSIDE over the tail; a positive-offset span maps INSIDE over the whole span. `positional` is an independent recursive specification that chooses the governing flag at each absolute chunk position. `helper_refines` proves equality for every offset and list. `zero_length`, `output_length`, `initial_position` and `interior_positions` expose the corresponding contracts.

`partition_consistency` proves that processing `left ++ right` at offset `o` equals concatenating separately processed spans at offsets `o` and `o + left.length`. Its proof uses induction on an arbitrary left list, not bounded examples. Both pieces retain the same original chunk flags. This does **not** prove arbitrary AppendText partition invariance when the caller changes chunk origins/flags or the underlying break producer changes its output. Those scanner/provider obligations remain separate.

Three concrete propositions are rejected by the kernel's `decide` tactic: resetting the second span's offset to zero preserves output; INSIDE suppresses the initial position; INITIAL suppresses a positive-offset span. These are false mathematical controls, not native mutation tests.
