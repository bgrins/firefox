# Native and model bridge

## Universal model

`RawFrame` stores specified offset/easing/composite and ordered raw declarations plus an ignored computed offset. `Ownership` is a fixed total allocation-to-content map. It models immutable declaration contents while references remain live. `projectDeclaration`, `project` and `projection` remove allocation identity. The pointer shortcut, structural comparison and finite list comparator are proved equivalent to specified projection equality. Equal allocation IDs cannot have changing contents in either the model or the native harness.

`directSetter` always installs the requested specified projection and recomputes its derived projection. For unchanged observations, cache validity makes that recomputation observationally identical to retention. Its no-notification/no-rebuild policy for unchanged inputs is an implementation observational contract, not a claim that the Web Animations specification dictates Gecko's internal event counts. `optimizedSetter` uses the recursive equality gate. `setter_refinement`, `getter_retention`, invariant preservation and `finite_sequence_refinement` connect them.

`derive` defines ordinary offsets from nearest surrounding anchors using rational interpolation. Named maps are explicit per-range geometry inputs, including unresolved and zero-width attachment ranges. `buildConsumer` obtains raw computed property values from the named computed-value provider, resolves auto from the effect default, groups and sorts entries independently, retains the first/last values of duplicate offsets and constructs ordinary and missing-endpoint segments. It does not accept expected segments as a provider. The semantic model uses stable insertion sorting; the extracted implementation uses its actual stable sort and scan.

`rebuild` compares complete segment/property observations, refreshes the admitted base-value provider, uses the native changed-base predicate over new entries, preserves running property identities, resets cumulative identities and specifies dirty/effect/restyle gates. `defaultSetter`, `contextRefresh` and `styleRefresh` carry the remaining action semantics. Pure computed-value and base providers are quantified; they cannot inspect allocation IDs or expected final state. Computed values include `none`, distinct from a missing endpoint entry and from a base value. Providers accept immutable style-version inputs rather than unrestricted geometry/state. Changes to style/target/style-availability inputs are explicit invalidations or delivered style-version changes.

The model's event projection includes compute, notification, update, effect publication, cumulative property, dirty, effect-updated and restyle events. Native observations additionally compare entry/provider calls, JS dictionary writes and errors. The theorem does not assert that those boundary calls are a browser scheduler or rendering engine.

## Admission and freshness obligations

- Processing either supplies valid finite typed specified frames or fails before the array setter and target-style acquisition. Reentrant user callbacks, arbitrary JS iteration side effects and allocator behavior are outside this atomicity theorem.
- An unchanged-input skip requires cached offsets to be valid for the admitted current timeline/range inputs. A real refresh must occur before such a skip after a relevant context change. The lower-level setter equality lemma alone does not justify current caches. The admitted sequence additionally requires delivered readiness for every equal skip, from which the invariant derives current offsets, properties and active base values.
- Context actions change only geometry/timeline inputs and model the real getter dispatch. The complete ordinary getter invokes `MaybeUpdateKeyframeComputedOffsets` only with an associated timeline. Missing dispatch may retain old derived offsets: the full cache certificate remains valid while the state is explicitly pending. The native missing-timeline control exercises this case. A subsequent equal setter in such a state lies outside the direct-setter refinement admission if its offsets are stale; it remains covered by invariant preservation and finite native agreement. The getter never invents an unconditional rebuild.
- Style actions enter complete `UpdateProperties` with supplied style. The scheduler's choice and timing of this call, style freshness and layout flushing are admitted orchestration boundaries. Default actions enter complete `SetComposite` and its actual target/style/relevance branches.
- Current mixed missing/named offset and unresolved-NaN behavior is explicitly an implementation contract. The source itself identifies specification gaps. No proof of a nonexistent normative algorithm is claimed.
- Signed zero is collapsed by rational embedding. Native sign bits are separately checked; exact `Object.is` equivalence is excluded from the universal model.

### Cache certificates and delivery

`Invariant` records the raw input snapshots that actually produced offsets, properties and base values. `propertyBasis` contains specified frames, derived offsets, default operation and provider environment; `baseBasis` contains the provider version and actual segments. These are mathematical history certificates, not extra native fields, expected-cache providers or assumptions of current freshness. Their equations are preserved for every finite action sequence, including invalidation, skipped setters and undelivered refreshes.

`pending = false` additionally implies `Fresh`: current offsets and complete property/base cache agreement with current raw inputs. Invalidation marks pending without altering native caches. Complete rebuild updates the certificates from the actual raw computation inputs, retains base values if target is absent (matching `EnsureBaseStyles`), and clears pending only when offsets are current. `rebuild_restores` and `style_restores` prove restoration from valid offsets; kernel witnesses establish a reachable stale-then-restored cache and a nonempty fresh state. Pending is conservative: a redundant invalidation may remain pending even when values happen to agree.

`finite_sequence_invariant` covers all finite model actions. `finite_sequence_refinement` additionally requires specified/raw representation, the full invariant and delivered readiness at every equal-setter step. `every_equal_prefix_current` proves current coherence before and after each such prefix, alongside exact skip preservation. The lower-level offset-only equality lemma is not a current-cache theorem. `every_ready_prefix_current` covers other ready observation prefixes; `finite_sequence_cache_contract` remains a complementary final-state corollary. No theorem labels a pending cache current. Dispatch delivery remains an external orchestration premise, not eventual-delivery liveness.

Native `INVALIDATE` mutates only raw target/style/provider inputs and makes no extracted call; it represents a scheduler interval before delivery. `STYLE` enters actual complete `UpdateProperties` with an explicitly supplied nonnull computed style. `CONTEXT` enters actual complete `GetKeyframes`. Their traces, intermediate cache retention and final restoration are checked independently. The fixed style-version model abstracts immutable raw style inputs; native versions are represented by the supplied base/scale values. `RUNNING` is a bounded native running-flag control, not an additional universally proved action.

## Source integrity and finite correspondence

The generator extracts whole definitions with a balanced-brace lexer. The inventory disambiguates the production comparator from the unchanged DEBUG helper. Logging inserts a single entry statement without altering the extracted statements. Each generated variant has its own complete-body inventory; only the one production comparator differs between original and candidate.

The oracle derives specified projections, rational offsets and grouped property segments from raw inputs, then predicts state and trace gates. Its comparator trace is a separate implementation-shaped schedule check; specified equality/state expectations do not use that schedule as their oracle. Base providers supply raw values, not expected cache contents. The model likewise builds its own segments from raw provider values.

There is no machine-checked universal translation from C++ to Lean or between the Python oracle and Lean. Exact state/control contracts, source extraction integrity, independent oracle agreement, kernel counterexamples and source review jointly support this finite bridge. The preserved explicit obligations must accompany any statement of formal verification.

The native numeric adapter has five property categories (opacity, float, offset, width and a custom property), finite numeric declaration payloads, three timing tokens plus the missing/linear representation, and affine view maps. This is deliberately a typed boundary domain, not all CSS values. Every branch of property-name serialization and all four composite operations are exercised. CSS longhand/shorthand resolution and generated binding internals are source-traced/external.

The complete dispatch/readiness mapping and external scheduling premise are in [READINESS-BRIDGE.md](READINESS-BRIDGE.md). V3 restores the original admitted-step/prefix obligation; pending history is retained as separate diagnostic evidence.
