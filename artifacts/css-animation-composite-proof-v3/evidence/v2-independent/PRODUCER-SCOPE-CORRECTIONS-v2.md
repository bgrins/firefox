# V2 correction boundary

The original approved SCOPE and addendum are preserved unchanged. Root's v2 assignment explicitly requires pending/delivered style states, true property/base cache preservation, optional raw computed values and exact pre-import source closure. This clarification resolves the original scope's shorthand that every unchanged setter must have a current property/base cache: a real equal setter can preserve a pending stale cache before the style scheduler delivers an update. The artifact must describe that observable interval rather than invent a rebuild or assume the expected cache.

The strengthened all-actions invariant certifies caches against their actual historical raw inputs. Ready states additionally have current complete consumer/base agreement; restoration after arbitrary finite actions is proved when a real style update is delivered and offsets are current. The independent direct-setter refinement still requires valid current derived offsets at equal setter steps. Stale named offsets caused by a missing timeline are represented and tested, but an equal setter in such a state is explicitly outside that refinement premise. They remain inside all-actions cache certification and finite native agreement. No claimed current-cache guarantee is made for a pending state.

No extraction or provider scope is removed. All 29 complete definitions, actual full setter/getter/consumer/base paths, original source snapshots, original corpus cases and 20 semantic mutation families remain. The optional raw computed-value domain preserves existing null AnimationValues, with independent missing-endpoint and getter/base controls. TypedOM, CSS-generated augmentation, positive normalized scroll delays, arbitrary CSS value algebra, browser scheduling and rendering retain their existing explicit boundaries.
