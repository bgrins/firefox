L13: ## Abstract
L14: 
L15: Bikeshed is a spec-generating tool that takes in lightly-decorated Markdown and spits out a full spec, with cross-spec autolinking, automatic generation of indexes/ToC/etc, and many other features.

L162: ### 1.1. Using Bikeshed Without A Local Install
L163: #### 1.1.1. Via the Web
L164: 
L165: If you use Bikeshed infrequently, and are okay with requiring a network roundtrip every time you invoke Bikeshed, you probably want to use cite146†the spec-generator instead†www.w3.org . In return, the API version is always up-to-date, so you don’t have to remember to update things yourself. See cite19†§ 2 Invoking Bikeshed Without Installing for options.
L166: Note: The remote API has several limitations; most notably, it can’t take multiple files. If you are using custom boilerplates, or include files, you’ll have to run Bikeshed yourself.
L167: #### 1.1.2. Via `pipx`
L168: 
L169: If you use Bikeshed infrequently, but have the prereqs for a local install (a recent Python 3, and `pipx`; see below), you can run an always-up-to-date Bikeshed locally as:
L170: 
L171:     pipx run bikeshed update && pipx run bikeshed
L172: 
L173:     # on subsequent invocations, just call:
L174:     pipx run bikeshed
L175: This does not have the limitations of the web version; you can use all the features of Bikeshed, including custom boilerplates and include files, or alternate run modes like cite28†`bikeshed watch` .
L176: Note: This actually creates a temporary local install, which automatically disappears after a few days. It does not add the `bikeshed` command to your PATH. However, it generally won’t require manual upgrading; so long as it’s been long enough for `pipx` to delete the cached version, it’ll always grab the newest version of Bikeshed.
L177: ### 1.2. Prereqs
L178: 
L179: Bikeshed is a Python program, and getting Python working well in modern systems has a few (pretty easy) steps. (These might already all work for you!)
L180: #### 1.2.1. `python3`
L181: 
L182: Bikeshed requires Python 3.12 or later. (It’s currently tested up to 3.14.)
L183: 
L184: To tell what version you have, run:
L185: 
L186:     python3 --version
L187: 
L188: 
L189: If it reports 3.12.0 or later, you’re fine.
