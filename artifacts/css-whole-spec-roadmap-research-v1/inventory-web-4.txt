L30: ## Abstract
L31: 
L32: This module extends the CSS sizing properties with keywords that represent content-based "intrinsic" sizes and context-based "extrinsic" sizes, allowing CSS to more easily describe boxes that fit their content or fit into a particular layout context.

L93: 
L94: This section is not normative.
L95: 
L96: CSS layout has several different concepts of automatic sizing that are used in various layout calculations. This section defines some more precise terminology to help connect the layout behaviors of this spec to the calculations used in other modules, and some new keywords for the cite70†width and cite71†height properties to allow authors to assign elements the dimensions resulting from these size calculations.

L122: ### 1.2. Value Definitions
L123: 
L124: This specification follows the cite117†CSS property definition conventions†www.w3.org from cite113†[CSS2] using the cite118†value definition syntax†www.w3.org from cite119†[CSS-VALUES-3] . L125: In addition to the property-specific values listed in their definitions, all properties defined in this specification also accept the cite120†CSS-wide keywords as their property value. For readability they have not been repeated explicitly.
L126: ## 2. Terminology
L127: 
L128: Some key terminology related to coordinate axises and dimensions is defined in cite121†CSS Writing Modes 3 § 6 Abstract Box Terminology .
L129: size
L130:     A one- or two-dimensional measurement: a cite122†block size and/or cite123†inline size ; alternatively a cite124†width and/or cite125†height .
L131: cite126†Image: In left-to-right, top-to-bottom horizontal English, the horizontal width and inline size are synonymous, and vertical height and block size are synonymous. cite127†Image: In top-to-bottom, right-to-left vertical Japanese, the horizontal width and block size are synonymous, and vertical height and inline size are synonymous. Whether the cite124†width or cite125†height corresponds to an cite123†inline size or cite122†block size depends on the cite128†writing mode .
L132: inner size
L133:     The cite129†content-box†www.w3.org cite130†size of a cite131†box . cite132†Image Inner size
L134: outer size
L135:     The cite129†margin-box†www.w3.org cite130†size of a cite131†box . cite133†Image Outer size
L136: definite size
L137:     A size that can be determined without performing layout; that is, a cite134†<length> , a measure of text (without consideration of line-wrapping), a size of the cite135†initial containing block , or a cite136†<percentage> or other formula (such the cite137†“stretch-fit” sizing of non-replaced blocks†www.w3.org cite113†[CSS2] ) that is resolved solely against cite138†definite sizes.
L138: Additionally, the size of the cite139†containing block of an absolutely positioned element is always cite138†definite with respect to that element.
