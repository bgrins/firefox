# Finite-scale hypot source and WPT proposal

This artifact-only proposal addresses the audited constant-folding and deferred-evaluation overflow/underflow in one generic calc source file. The repository native source is untouched. The captured base is the exact closure-v3 baseline, retaining all accepted shared-branch math changes. SOURCE-ROLES.json and native.patch identify the full base/candidate bytes; the patch applies exactly in an isolated temporary tree.

Both paths start with the first argument's absolute value and fold subsequent arguments using one helper. The helper widens both f32 operands to f64, squares and adds them, takes sqrt and converts back to f32. Finite nonzero f32 input squares lie between 2^-298 and 2^256, with pair sums below 2^257, safely within the normal finite f64 range. Ordinary IEEE multiplication/addition naturally retains infectious NaN, including an infinite operand paired with NaN. This avoids intermediate f32 squares while retaining CSS's infectious NaN behavior even after an infinite accumulator. The initial abs preserves single-argument magnitude and positive zero. Genuine result overflow can still produce infinity. The resolver retains its numeric-type combination; simplification retains try_op compatibility checks and returns unchanged for unresolved or incompatible leaf units. No new generic trait API or type conversion rule is introduced.

The pairwise conversion rounds after each input. This is not an all-input f64 accumulator, a correctly-rounded n-ary algorithm or an order-invariance guarantee. The try_op interface accepts an f32 pair operation; preserving that interface keeps the proposal small. Pairwise sqrt calls may cost more than the old single final sqrt; browser performance is not measured here. The CSS precision/range qualifications in the sealed audit still apply. Neither a universal IEEE/native theorem nor a new proof-discovery credit is claimed.

The proposed WPT has30 callbacks:16 finite-extreme targets and14 controls. It uses exact2^64/2^-80 literals, single and multiple arguments, input order/sign, four equal arguments, ordinary/moderate values, direct-ratio calibrations, signed zero, infinities and infectiousNaN in both orders. Absolute-unit targets and a mixed in/px control cover unit handling. Two sibling-index callbacks and two mixed em/px callbacks mutate and restore context; these keep unresolved inputs past the early all-leaf fold where possible. The dynamic expressions retain the same source and provide target-state recovery checks. They are proposed resolver coverage, not observed resolver execution.

EXPERIMENT.json records a future gate: fresh original completeness without an assumed failure count, all30 candidate callbacks passing, every originally passing callback preserved, and14 control plus1 ending full signatures preserved. Existing hypot computed/serialization regressions should also accompany a real engine comparison. No browser owner, metadata waiver or acceptance action is packaged here.

Validation is replayed for this successor: unchanged 30-callback WPT, exact extracted helper scalar Rust harness, and isolated patch application. The scalar harness is not native Stylo execution. v1 remains immutable; the only native change from v1 is replacing its guarded f64 hypot helper with direct widened arithmetic. This simplifies range reasoning and removes the libm hypot dependency; exploratory microbenchmarks are not a browser performance claim. Root's separate formal companion is not assumed by this package.

This v3 supersedes invalid preparation v2. v2's static replay failed because its inherited checker compared in-memory tuples with JSON lists, and a shell continuation prematurely published a passing CHECK claim. That claim must not be used. v3 normalizes the manifest through JSON and requires subprocess success; both static fixture and scalar arithmetic checks actually pass. The unchanged proposed WPT body and native candidate bytes match v2. The initial no-site missing-PyYAML diagnostic is retained; the configured Firefox Python environment supplies that dependency.
