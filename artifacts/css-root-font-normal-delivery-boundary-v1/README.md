# Conditional normal-traversal delivery boundary

Source-only finding: admitting an animated element during a normal traversal is insufficient unless that traversal reaches the element. Marking normal work only when an immediately examined child has animations does not establish that route through a fixed-font, unanimated intermediary. This is a conditional repair analysis, not the diagnosed cause of the native cancellation failure.

The completed font-unit-only eight-case run reports the first failing value 64 instead of 46 for an existing child and a root-host pseudo. Its settled values were collected by the page but not exported after the assertion failed. The original 34-case diagnostic observed 64/64; that does not establish the candidate's settled result. The candidate archive run and unchanged 34-case replay remain root-owned work. A 64/46 candidate would still violate the required first synchronous observation, but would imply different delivery timing from 64/64.

## Exact source chain

The attached excerpts authenticate the e86 matching/hint code and the two-file font-unit candidate against their immutable manifests. Searchfox discovery used the indexed traversal permalink below; the archived source, not indexed tip, determines this analysis.

* `matching.rs::finish_restyle` publishes root style, root font size, and root line height to Device, and builds `RESTYLE_IF_AFFECTED_BY_WM_OR_ANCESTOR_FONT` when the relevant values change.
* `traversal.rs::recalc_style_at` combines the hint returned by `data.hint.propagate` with the newly computed child hint. `note_children` inserts that combined hint into each existing child's data before deciding whether to enqueue it.
* Animation-only `RestyleHint::propagate` preserves the ancestor-font hint on the visited node but returns an empty propagated hint. It removes animation/recascade hints. Animation-only `element_needs_traversal` does not admit a node solely for the ancestor-font hint.
* `note_children` sets the parent's dirty-descendants bit only when a child is enqueued, and selects the animation-only bit during that pass. It does not thereby establish the separate normal dirty route.
* Normal `element_needs_traversal` accepts any nonempty hint or the normal dirty bit. Once reached, a fixed-font intermediary can be traversed without recascading, and normal `propagate` forwards its ancestor-font hint. The candidate admits an animated descendant for recascade in the normal pass. Existing-style `process_animations` returns early in animation-only passes; normal processing can queue `EFFECT_PROPERTIES`.

For example, consider root R → fixed-font unanimated A → fixed-font unanimated B → animated T. R may insert the hint on A during animation-only processing, but A need not be enqueued. Looking only for an immediately animated child misses T. Even if A is visited for another reason, its animation-only propagation does not carry its retained hint farther. Conversely, a normal traversal that reaches A with the hint can forward it through B without requiring either intermediary to recascade. Thus the missing obligation is normal entry and delivery, not blanket restyling of every intermediary.

## Two candidate repair locations, conditional on the trace

1. **Receiver-side normal handoff in `traversal.rs::note_children`, checked with `pre_traverse` and `recalc_style_at`.** When animation-only processing inserts or encounters retained ancestor-font work, establish the normal dirty-descendant route for that work regardless of the immediate child's animation membership. Preserve the hint on the child; let the existing normal propagation and selective recascade perform the descent. A bare dirty-bit write is not a complete patch: it must connect to the actual scheduled traversal root, respect upward propagation/thread ownership, and cause normal processing before the computed-style flush returns. Trace evidence must show that root entry/scheduling already exists or identify its missing handoff. Restricting this handoff to `child.has_animations()` is insufficient for the R/A/B/T case.

2. **Producer-side normal work obligation at `matching.rs::finish_restyle` and the traversal/flush boundary consuming its result.** On a relevant root provider change during animation-only work, preserve a normal ancestor-font delivery obligation rooted at that changed subtree, and have the existing normal traversal scheduling path consume it before the dependent observation. This can be more conservative but does not need to discover animated descendants during the animation pass. The implementation must use the existing traversal-root scheduling discipline; this report does not invent an enqueue API or endorse mutating shared computed styles. It must preserve selective normal recascade after delivery rather than force arbitrary animation-only `EFFECT_PROPERTIES` processing.

The first option is narrower if the trace proves a retained hint and a missing dirty route. The second is appropriate if the producer loses the normal obligation or no normal pass is scheduled. Neither is implementation-ready without the trace's actual pass, traversal root, and delivery sequence.

## Final animation and pseudo distinctions

`FinalAnimationTraversal` is not interchangeable with the ordinary animation-only case. `finish_restyle` performs root publication and constructs the child hint, then returns `RECASCADE_SELF` early in the final pass. The accumulated ancestor-font child hint is not returned by that branch. `RECASCADE_SELF` is animation-consumable and is removed by `remove_animation_hints`; simply preserving existing ancestor-font bits cannot recover a bit that was never returned. Separately, `clear_state_after_traversing` clears animation-only dirty descendants and restyle flags/damage in the final pass. Its `clear_restyle_flags_and_damage` does not clear the hint. The trace must distinguish these operations rather than attribute all loss to final cleanup.

Keep the root-host pseudo route separate from the ordinary child route. `note_children` walks traversal children, including implemented pseudo nodes; effect lookup/update uses the corresponding host/pseudo identity. A normal obligation must reach the actual pseudo consumer and queue the right host/pseudo effect update, without classifying its style as the root's style. Future trace integration must use instrumentation-v2 manifest `127d1f9fec3d8217d20b03b7af8a09f27797a214cfc757b1a92d39c1c83b25c4`, whose existing-value normalization log joins those identities. The older matching snapshot used here remains valid source evidence, not the requested future diagnostic payload.

## Required invariant and discriminating controls

For every live dependent effect whose root provider changes, a normal-delivery obligation must survive until the affected target is reached, its keyframes are rebuilt against the current provider revision, and its sampled style is refreshed **before the dependent computed-style observation returns**. Eventual delivery alone is insufficient. An unrelated dirty bit or an explicit root read must not be necessary to make the route reachable.

Useful tests are immediate child, depth-two and depth-three fixed-font unanimated wrappers, and root-host `::before`, each with no unrelated normal invalidation. Preserve no-read versus explicit-root-read, existing versus newly created child, rem versus rlh, first versus settled, and literal-animation controls. Exercise ordinary animation-only and final-animation phases distinctly. Include an unrelated sibling dirty branch to detect accidental dependence on another subtree's traversal. The existing 34-case probe remains unchanged; additional depth tests should be proposed only after its actual trace narrows the branch.

A useful Lean extension must model distinct animation and normal worklists, dirty reachability, retained versus newly produced hints, fixed-font intermediary nodes, and provider/effect revisions. It should derive normal target reachability by induction over the traversal path from a concrete scheduled obligation, then prove rebuild/sample freshness before an observation transition. It must not assume the normal visit as a premise and call that delivery, nor equate a pending hint with completed rebuilding. False controls should remove intermediate forwarding, restrict handoff to animated immediate children, erase the final-pass obligation, or permit observation before rebuild. Existing admission and provider-order models supply pieces, not this native scheduling refinement. Pseudo normalization, scheduler invocation, cleanup/coalescing, and native effect rebuilding still require source/trace correspondence.
