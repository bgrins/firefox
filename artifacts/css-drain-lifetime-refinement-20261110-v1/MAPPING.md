# Native correspondence and open obligations

Native basis: `b1f13d1516967034ca17255bcb1634e9f166b54a`. The prior [source audit](../css-drain-next-obligation-20261110-v1/REPORT.md) records Searchfox discovery, exact Git objects, excerpts and primary specification snapshots. `SOURCE-CONTEXT.json` authenticates that report and its native file pins. This module is a hand-authored refinement contract. It neither extracts the native algorithms nor derives a scheduler from specification prose.

The prior audit found no supported repeating style-lifetime renewal in the inspected inner-loop callsites. DOM removal, slot/shadow changes, frame/pseudo reconstruction and new animation sampling are outside the modeled epoch only if their native placement actually establishes that boundary. A caller inside the drain cannot be declared external merely to obtain termination. The audit is not a whole-program exclusion proof.

`CSSAnimation` lifetime and ElementData lifetime are different. Clearing ElementData does not itself mean the element's CSSAnimation collection was recreated. Likewise a nonexistent pseudo's CSSOM style does not require generated-element restyle posting. Existing bug 1615083 concerns lazy animation-rule composition/property-set freshness; this module is not a repair or a new report for that issue.

The next architecture step remains cause-bearing work accounting or a demonstrated refinement for every admitted inner-loop producer. Keep the existing 164-case first-read behavior gate for any production design. A fixed iteration cap, ignored queue entries or postponed necessary work would weaken the contract.
