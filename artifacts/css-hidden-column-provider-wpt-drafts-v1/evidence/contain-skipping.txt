# CSS-CONTAIN-2#skips-its-contents

**skips its contents** (definition)

**SHA**: hash:bb38ada349137a54b242110e34dc4f7deb644aa41141b7e61921a17a917e478c

## Content

When an element **skips its contents**, the user agent must change the [used value](CSS-CASCADE-5#used-value) of the [contain](CSS-CONTAIN-2#propdef-contain) property so as to turn on [layout containment](CSS-CONTAIN-2#layout-containment), [style containment](CSS-CONTAIN-2#style-containment), [paint containment](CSS-CONTAIN-2#paint-containment), and [size containment](CSS-CONTAIN-2#size-containment). Further, its **contents** (the [flat tree](CSS-SHADOW-1#flat-tree) descendants of the element, including both text and elements, or the replaced content of a [replaced element](CSS-DISPLAY-4#replaced-element)) are not painted (as if they had [visibility: hidden](CSS-DISPLAY-4#propdef-visibility)) and do not respond to hit-testing (as if they had [pointer-events: none](CSS-UI-4#propdef-pointer-events)), and to a large extent do not update their styles at all unless explicitly requested by script (see [§ 4.5 Restrictions and Clarifications](CSS-CONTAIN-2#cv-notes) for details).

The user agent *should* additionally avoid as much layout/rendering work as possible for [skipped contents](CSS-CONTAIN-2#skips-its-contents); the combination of heavy [containment](CSS-CONTAIN-2#containment) and making the contents invisible and untouchable enables heavy optimizations. If rendering work is done at some point, the user-agent should retain the previously computed layout state if possible, to allow the skipped contents to be displayed quickly at a later moment.

> **Note:** If an element has a value other than [content-visibility: visible](CSS-CONTAIN-2#propdef-content-visibility), then the following properties hold:
>
> *   [layout containment](CSS-CONTAIN-2#layout-containment) ensures that the user-agent is able to omit layout work in skipped subtrees, since the results of such layouts will not affect elements outside of the container element.
>
> *   [style containment](CSS-CONTAIN-2#style-containment) ensures that counters do not have to be processed in skipped subtrees, since they do not affect counters outside of the container element.
>
> *   [paint containment](CSS-CONTAIN-2#paint-containment) ensures that ink overflow of painted contents is clipped; this, in turn, means that user-agent can reliably determine when the visible portion of the element approaches the viewport (and, for [content-visibility: auto](CSS-CONTAIN-2#propdef-content-visibility), start painting it).
>
> *   [size containment](CSS-CONTAIN-2#size-containment) ensures that the user-agent is able to omit layout in skipped subtrees, since the results of such layouts will not affect the container element’s size.
>
> Note that in the [content-visibility: auto](CSS-CONTAIN-2#propdef-content-visibility) case, [layout containment](CSS-CONTAIN-2#layout-containment), [style containment](CSS-CONTAIN-2#style-containment), and [paint containment](CSS-CONTAIN-2#paint-containment) persist even if the element is not [skipped](CSS-CONTAIN-2#skips-its-contents). This is done to prevent layout changes that would be incurred by [containment](CSS-CONTAIN-2#containment) changes as a result of an element entering and exiting the skipped state.
