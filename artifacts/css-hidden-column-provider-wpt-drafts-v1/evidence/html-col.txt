[DOM interface](HTML#concept-element-dom):

Uses [`HTMLTableColElement`](HTML#htmltablecolelement), as defined for [`colgroup`](HTML#the-colgroup-element) elements.If a [`col`](HTML#the-col-element) element has a parent and that is a [`colgroup`](HTML#the-colgroup-element) element that itself has a parent that is a [`table`](HTML#the-table-element) element, then the [`col`](HTML#the-col-element) element [represents](HTML#represents) one or more [columns](HTML#concept-column) in the [column group](HTML#concept-column-group) represented by that [`colgroup`](HTML#the-colgroup-element).

The element may have a **`span`** content attribute specified, whose value must be a [valid non-negative integer](HTML#valid-non-negative-integer) greater than zero and less than or equal to 1000.

The [`col`](HTML#the-col-element) element and its [`span`](HTML#attr-col-span) attribute take part in the [table model](HTML#table-model).
