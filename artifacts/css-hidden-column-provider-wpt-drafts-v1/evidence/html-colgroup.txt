[Categories](HTML#concept-element-categories):

None.

[Contexts in which this element can be used](HTML#concept-element-contexts):

As a child of a [`table`](HTML#the-table-element) element, after any [`caption`](HTML#the-caption-element) elements and before any [`thead`](HTML#the-thead-element), [`tbody`](HTML#the-tbody-element), [`tfoot`](HTML#the-tfoot-element), and [`tr`](HTML#the-tr-element) elements.

[Content model](HTML#concept-element-content-model):

If the [`span`](HTML#attr-colgroup-span) attribute is present: [Nothing](HTML#concept-content-nothing).If the [`span`](HTML#attr-colgroup-span) attribute is absent: Zero or more [`col`](HTML#the-col-element) and [`template`](HTML#the-template-element) elements.

[Tag omission in text/html](HTML#concept-element-tag-omission):

A [`colgroup`](HTML#the-colgroup-element) element's [start tag](HTML#syntax-start-tag) can be omitted if the first thing inside the [`colgroup`](HTML#the-colgroup-element) element is a [`col`](HTML#the-col-element) element, and if the element is not immediately preceded by another [`colgroup`](HTML#the-colgroup-element) element whose [end tag](HTML#syntax-end-tag) has been omitted. (It can't be omitted if the element is empty.)A [`colgroup`](HTML#the-colgroup-element) element's [end tag](HTML#syntax-end-tag) can be omitted if the [`colgroup`](HTML#the-colgroup-element) element is not immediately followed by [ASCII whitespace](INFRA#ascii-whitespace) or a [comment](HTML#syntax-comments).

The [`colgroup`](HTML#the-colgroup-element) element [represents](HTML#represents) a [group](HTML#concept-column-group) of one or more [columns](HTML#concept-column) in the [`table`](HTML#the-table-element) that is its parent, if it has a parent and that is a [`table`](HTML#the-table-element) element.

If the [`colgroup`](HTML#the-colgroup-element) element contains no [`col`](HTML#the-col-element) elements, then the element may have a **`span`** content attribute specified, whose value must be a [valid non-negative integer](HTML#valid-non-negative-integer) greater than zero and less than or equal to 1000.

The [`colgroup`](HTML#the-colgroup-element) element and its [`span`](HTML#attr-colgroup-span) attribute take part in the [table model](HTML#table-model).
