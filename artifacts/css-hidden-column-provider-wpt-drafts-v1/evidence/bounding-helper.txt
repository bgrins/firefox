## Content

To **get the bounding box** for *element*, run the following steps:

1. Let *list* be the result of invoking [`getClientRects()`](CSSOM-VIEW#dom-element-getclientrects) on *element*.
2. If the *list* is empty return a [`DOMRect`](GEOMETRY-1#domrect) object whose [`x`](GEOMETRY-1#dom-domrect-x), [`y`](GEOMETRY-1#dom-domrect-y), [`width`](GEOMETRY-1#dom-domrect-width) and [`height`](GEOMETRY-1#dom-domrect-height) members are zero.
3. If all rectangles in *list* have zero width or height, return the first rectangle in *list*.
4. Otherwise, return a [`DOMRect`](GEOMETRY-1#domrect) object describing the smallest rectangle that includes all of the rectangles in *list* of which the height or width is not zero.
