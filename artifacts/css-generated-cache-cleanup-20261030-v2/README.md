# Obsolete debug incremental cache cleanup

Removed only the host and aarch64 debug-profile Rust incremental directories under objdir-full.noindex. Every retained inventory entry was last modified before 2026-10-17; no compiler or build executor was running. These are regenerable caches, absent from canonical source/application claims. Release caches, compiled browser binaries, research records and Lean build outputs were retained.

6,632,144,944 logical file bytes were removed. Available disk space increased from 29,700,247,552 to 34,155,204,608 bytes. Filesystem allocation and logical byte counts differ. Canonical controls were unchanged. The new free-space observation supersedes the earlier diagnostic proposal budget, but future runs must still measure actual backup size and free space.
