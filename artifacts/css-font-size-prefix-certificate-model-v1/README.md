# Executable prefix certificate stability

The checker, rather than an assumed reached-agreement premise, establishes that adding APPEARANCE_BASE preserves the selected static result, evaluated declarations, dependency-read trace and complete visited rollback-state trace. This is a selection theorem for the proposed computed-size path, not a proof of application effects or the scheduler.

`certificate` follows the native checker's order: reject any encountered base-gated entry before eligibility; skip other-ineligible or rollback-disallowed entries; reject eligible dynamic declarations; update the rollback state for a static revert and continue; otherwise stop successfully at the terminal declaration. Exhaustion succeeds. A lower never-reached gate is allowed. A higher gated entry is rejected even if its current eligibility is false or rollback would exclude it.

The flag abstraction records APPEARANCE_BASE separately from the unchanged conjunction of all other required flags. The rollback eligibility relation is arbitrary but fixed across the two scans. Static evaluations retain their complete outcome and reads; eligible dynamic evaluation may differ arbitrarily between scans because acceptance proves it is never invoked. Thus the proof does not assume the Stability theorem's reached-agreement premise: `certificate_implies_reached_agreement` derives it and `checked_prefix_preserves_selection_and_reads` applies the unchanged `Selection.scan` theorem. A second induction proves equality of all visited state/declaration pairs, including skipped decisions and rollback transitions.

The native correspondence is the finite most-important/next-index declaration chain presented as a list in the same order; MAX/zero sentinels become exhaustion. The proof does not establish validity/acyclicity of that Rust representation. The static evaluation abstraction includes a blocked terminal as a conservative generalization; the native static keyword classifier has rollback or non-revert terminal branches. RevertKind/priority bit encodings, substitution, actual CSS value parsing, readset finality, style mutation, min-font-size/zoom effects, publication identity, Tarjan ownership and progress remain outside this proof. In particular, checker acceptance does not establish that a FontSize operation is absolute or that its computed value is final. Those are separate implementation checks.

Concrete controls cover a skipped higher gate, allowed lower gate, rollback skipping with retained rollback reads, eligible dynamic rejection, and a rollback-skipped dynamic declaration that is safe to ignore. The unchecked higher-gate witness changes the selected reads. Four separately compiled false propositions reject accepting the higher gate/dynamic input, rejecting the lower gate and discarding rollback reads.

Both runs preserve exact compiled sources, commands and diagnostics; scratch is removed. Existing pinned Lean/imports and the prior replay mechanism are reused.
