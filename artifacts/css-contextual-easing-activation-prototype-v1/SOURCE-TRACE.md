Both Gecko and Servo keyframe computations instead receive their real context and selected scope. No infallible easing wrapper remains in the eight-source candidate. Existing unrelated filter/range APIs with similar method names are not changed.

[CSS Animations model](https://drafts.csswg.org/css-animations-1/#animations) requires dynamic keyframe updates to preserve an existing animation rather than restart it. [animation-timing-function](https://drafts.csswg.org/css-animations-1/#animation-timing-function) computes easing values and applies keyframe-local easing to the following interval. Fresh primary read on 2026-10-28 supports retaining the same paused effect and testing actual opacity against literal references. [CSS Easing](https://drafts.csswg.org/css-easing-2/) supplies steps, Bezier and linear outputs; the literal animation is an independent engine calibration, not a mathematical verification of that implementation. [CSSWG14246](https://github.com/w3c/csswg-drafts/issues/14246) remains a separate open API-policy question, as recorded by root's fresh primary review; no API restriction is inferred for CSS properties.

The test inputs use only an unanimated sibling relation or an externally changed inherited font; no claim is made that the general native supplied style is unanimated. Each sibling target has no ordinary tree-counting property to force a competing invalidation path. Count-only cases mutate after the target, preserving its index. The selected-rule transition is intended to reveal failure to install a newly needed dependency, rather than merely retest a previously flagged contextual element. Existing scope-v2 correction and the resolved one-result fallback apply unchanged.
