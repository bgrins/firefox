# Animated GIV publication: bounded formal companion

## Result and scope

The Lean component proves that a present named invalid animation endpoint is preserved through the modeled declaration conversion and admitted recascade. It remains distinct from no animation result, explicit `initial`, and valid empty tokens. GIV selects the supplied fallback independently of the registration initial value. This is a component theorem with named native/provider admissions, not a whole animation or browser correctness proof.

All six approved obligations are implemented. The original conversion is retained: under the fresh-name and reset-initial-seeding premises, its structured observation differs from GIV **iff the initial is non-GIV**. Equal numeric fallback output can conceal that difference, so the theorem uses tagged invalid/value observations. Explicit Initial behavior and valid conversion are preserved at the stated provider tier.
