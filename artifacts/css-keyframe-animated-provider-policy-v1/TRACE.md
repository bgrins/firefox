# Current-provider dependencies and animated cycles

Verdict: REACHED for current-provider ordering, composition dependencies and ordinary guarded defaulting; INCONCLUSIVE for a general rule that defaults an animated property/effect stack whenever its flattened dependency graph has an SCC. This narrows, rather than replaces, the existing animated-cycle audit. No browser observation, implementation acceptance, or new theorem is claimed.

## Normative call chain

Web Animations computes endpoints in the target's current computed context, with dependencies first. It obtains computed keyframes before selecting an interval. Missing boundary endpoints use the incoming underlying value; non-replace composition also consumes that value. An effect stack threads its prefix result into the next effect, starting with the no-animation base, and inserts its result into the cascade. Thus the consumer's prefix is not the final provider context. [Computing values](https://drafts.csswg.org/web-animations-1/#computing-property-values), [computed keyframes](https://drafts.csswg.org/web-animations-1/#calculating-computed-keyframes), [effect value](https://drafts.csswg.org/web-animations-1/#the-effect-value-of-a-keyframe-animation-effect), [stack](https://drafts.csswg.org/web-animations-1/#calculating-the-result-of-an-effect-stack), [publication](https://drafts.csswg.org/web-animations-1/#applying-the-composited-result).

`var()` reads the referenced property's computed value; obtaining it implies property replacement. It evaluates its fallback only when that result is guaranteed-invalid. Reading a stale sample or silently selecting an underlying value is not this operation. Animation taint blocks use in a non-animatable consumer; it does not generally disable registered numeric animation. [Replacement](https://drafts.csswg.org/css-variables-1/#replace-a-var-function).

Property replacement guards the property-name context. Recursive re-entry marks participating contexts cyclic; the marks survive an inner fallback. Invalid substitution/grammar causes invalid-at-computed-value-time, not a search for an earlier declaration. These rules determine substitution failures; they do not name effect-stack/prefix nodes. [Contexts](https://drafts.csswg.org/css-values-5/#substitution-context), [cycles](https://drafts.csswg.org/css-values-5/#cyclic-substitution-contexts), [replacement](https://drafts.csswg.org/css-values-5/#property-replacement), [invalidity](https://drafts.csswg.org/css-values-5/#invalid-at-computed-value-time).

Registered values are checked at computed-value time and interpolate by the parsed type. Registration changes the default and serialized tokens supplied to `var()`. The cycle section extends ordinary dependency rules for relative units; it does not give an animation-stack invalidation algorithm. For non-inherited registered numbers with initial 10/20, ordinary invalid declarations default to 10/20; inherited registrations require their inherited/defaulting context instead. [Computed values](https://drafts.css-houdini.org/css-properties-values-api-1/#calculation-of-computed-values), [animation](https://drafts.css-houdini.org/css-properties-values-api-1/#animation-behavior-of-custom-properties), [substitution](https://drafts.css-houdini.org/css-properties-values-api-1/#substitution), [cycles](https://drafts.css-houdini.org/css-properties-values-api-1/#dependency-cycles).

## The exact remaining decision

A self-referencing endpoint must not be read as an implicit endpoint: the former requests the current computed property through `var()`, whereas the latter is explicitly supplied the lower prefix. Likewise two selected animated providers can recursively request each other's current computed values. A resolver must retain cycle state across those requests; restarting an independent fresh ordinary solver at every endpoint loses the guard chain.

What is not established is the semantic owner and lifetime of that state across endpoint computation and composition. The endpoint's property name and the final selected property's name coincide, but their computations are not identical. The specification requests all computed keyframes before interval selection. It does not explicitly say whether an endpoint cycle invalidates only that endpoint, every endpoint for that property, or the final composed property, nor how marks persist across independently calculated endpoints. A property-wide SCC-defaulting implementation chooses one of these policies. The ordinary guard rule alone is not a proof of that choice.

This is a concrete numerical distinction. Let non-inherited numeric x/y have initial 10/20, underlying 77/88, and replace endpoints x=[var(y),100], y=[200,var(x)] sampled halfway. Whole-property defaulting predicts (10,20); independently defaulting just cyclic endpoint operands before interpolation predicts (55,110). These are competing policy illustrations, NOT two claimed conforming outcomes or a WPT numeric oracle. A self-cycle with additive endpoints similarly distinguishes defaulting the endpoint then adding the base from defaulting the final property. Constant-endpoint cycles conceal part of this distinction and are insufficient alone.

No searched issue supplied the missing animation-specific mapping. ISSUE-DISCOVERY*.json records bounded official-repository queries; this is not an exhaustive proof that no resolution exists. The current primary algorithms were read directly; this is not a request to require an explicit CSSWG example for every rule. The issue here is the different semantic values being invalidated, not merely absence of an example.

## A second boundary: demand is not just the final arithmetic DAG

`var(p, fallback)` short-circuits its fallback, but Web Animations' computed-keyframe procedure is not short-circuited by selecting an interpolation interval later. Therefore “not reachable from the selected arena root” does not by itself prove “irrelevant to substitution/cycle semantics.” Complete replacement discards the prior numeric contribution. A proof or experiment is still needed before using that arithmetic pruning to suppress the prior work's cycle effects. Do not indiscriminately add every syntactic fallback edge either. Keep these two distinct questions in the producer contract.
