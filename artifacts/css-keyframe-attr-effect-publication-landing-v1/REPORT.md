# Attribute-effect publication landing package

Prepared Gecko/WPT-only patch: eight native paths and four WPT files,46 cases total. Native bytes are exactly the compiled candidate; WPT bytes are exactly the four tested fixtures: mutation12, corrected lifecycle22, generated pseudo10 and unstyled replacement2. The unrelated URL provenance and custom-context diagnostics remain comparison controls and are excluded from the patch. Research, models, tooling, reports and runtime evidence are separate artifact files. This package is not an acceptance or a signed commit.

The candidate build-source receipt joins all eight postimages, and candidate RUN joins the exact four fixture hashes and phase binaries. All46 selected cases passed in the completed candidate capture. Those records are pinned as preliminary completed-phase evidence; full runtime restoration/root/peer verification is still a separate required decision and is not invented here.

## Transport and prerequisites

The full12-path patch applies and reverses in scratch against the archived installed130 originals, producing every exact candidate/fixture postimage and returning every original byte. It also applies and reverses against explicit HEAD90 objects. Seven C++ originals are byte-identical to HEAD90. The full Rust file differs because of prior local repairs; only this proposal's two changes are in the native patch.

The relevant `Servo_GetComputedKeyframeValues` difference between HEAD90 and the installed preimage consists exactly of fix130's ordinary-declaration attribute preparation and forwarding the real AttributeTracker instead of a dummy. The source difference is retained in HEAD90-keyframe-function-delta.patch. A second scratch check applies accepted fix130 and then this exact landing patch to HEAD90: the whole keyframe computation function equals the tested candidate, all seven C++ postimages equal their tested bodies, and all four WPT bodies match. Both patches reverse exactly. This is transport/composition evidence, not a clean-HEAD90 browser test or universal dependency proof.

Fix130 is therefore an explicit functional prerequisite for the ordinary-property histories; clean textual application on HEAD90 alone is insufficient. Its committed structural prerequisite fix70 is already in HEAD90. No additional pending dependency is identified in the changed native bodies. The new patch does not absorb fix130 or duplicate its WPT.

## Formatting and tests

Scoped clang-format on the seven changed C++ file ranges and rustfmt on the changed Rust function produce identical bytes. Formatter binaries and the historical .clang-format configuration are pinned; version/stdout/stderr and commands are retained. No formatting change was made to tested code. Unrelated existing file regions were not reformatted.

Each of the four exact WPT bodies already passed isolated WPT lint under its correct css/css-animations logical path. WPT-LINT-JOINS authenticates those prior receipts against the packaged fixture hashes; no unnecessary repeat or live WPT modification was performed. The package's replay performs scratch apply/reverse, source composition and formatting only, not a browser run. Scratch trees/build products are removed.

The repair remains scoped to active effect attribute dependency publication and the measured ordinary/registered, namespace, equal-value replacement, cancellation-survivor, retarget/copy, initially missing, ::before/::after/::marker histories. Dormant sole-effect replay, SMIL class changes and named view-transition provider/routing remain outside the claim. The boolean watch is conservative and may request normal updates for unrelated attribute names. Formal models prove conditional publication/admission abstractions, not extracted native execution or scheduler liveness.

Reproduce with `python3 -I -S -B artifacts/css-keyframe-attr-effect-publication-landing-v1/check.py --output /absolute/absent/output`. This reads archived bodies and pinned local formatting tools. No live native/source/index/build/browser mutation is needed.
