# Registered-number self-font observation

This tool records policy behavior for the disputed self-font numeric division case. It assigns **no normative pass/fail expectation** to any of its four rows and never accepts a native fix. The exact `observation-only.html` from sealed fixture-v2 is served inside a same-origin reporting frame. Its two declaration orders and two first-query orders, first observed value, final registered number, font size and width are all retained.

The reporter then records separate literal-number and true var self-cycle calibration rows. Expected calibration values are diagnostic annotations. Even calibration discrepancies remain data: they do not turn the disputed numeric result into a conformance verdict. The execution exit checks only complete structured capture, pinned inputs and cleanup/preservation. Candidate output lists every original-to-candidate value change without classifying it as a repair or regression.

Run only after the corresponding normative WPT phase, with the same compiled committed-HEAD epoch and normal browser binary. The tool requires the completed and preserved WPT assessment, matching native source roles, exact epoch SHA and application metadata, and the same frozen HEAD across original/candidate. It does not require the normative WPT assertions to pass: original failures and an exploratory candidate failure can both be observed. Fix acceptance remains the separate normative experiment's responsibility.

```sh
python3 -I -S -B artifacts/css-registered-number-self-font-observation-v1/run.py OBSERVATION_MANIFEST_SHA candidate-1 ABSOLUTE_EPOCH_PATH EPOCH_SHA ABSOLUTE_CANDIDATE_WPT_ASSESSMENT WPT_SHA /Users/bgrins/code/firefox/artifacts/css-registered-number-self-font-runtime-candidate-1 /Users/bgrins/code/firefox/artifacts/css-registered-number-self-font-runtime-original-1/RESULT.json ORIGINAL_RESULT_SHA
```

Replace uppercase arguments with independently verified values, redirect the outer invocation output to an owned artifact log, and retain actual outer session/terminal exits. Output directories must be absent. Observation suffixes can advance independently on retry, but each phase must bind the matching role's WPT assessment and exact epoch. The tool is pinned to normative capsule-v2 and its original/candidate source roles; a revised native proposal or normative capsule requires a new observation artifact version.

The browser launches directly from the pinned Nightly binary with headless/no-remote flags and a fresh owned profile. The loopback server uses an ephemeral port and unpredictable path; it accepts one same-origin bounded result. No existing browser profile or tab is used. This is a fresh default profile; WPT preference configuration is not imported. Results describe this diagnostic environment under the same binary, not an identical WPT-pref run. The owned browser process group is terminated after capture, so its recorded exit can be signal-related and is not a natural browser-test failure. `natural_exit_before_cleanup` and `browser_exit` distinguish those observations. The server stops and profile is removed only after owned process cleanup; full source/index/nested-repository, epoch, binary and application metadata preservation is checked afterwards.

`RAW.json` retains the HTTP payload. `RESULT.json` contains the structured observations, calibration discrepancies, exact build/source bindings and optional paired differences. `CLEANUP.json`, `PRE.json`, `POST.json` and application metadata records document execution preservation. A result with `complete:false` cannot support a behavior comparison. A complete result still has `normative_verdict: not evaluated` and `native_fix_acceptance:false`.

The Firefox desktop frontend skill was applied. `check.py` validates synthetic capture shapes and rejects missing/duplicate/misordered rows while confirming that arbitrary value changes and calibration mismatches remain observations. It also authenticates the source page, normative capsule and helper inputs. No browser, server, build, native source or Git mutation occurred during preparation. The self-font oracle remains unresolved as documented in the registered-number normative trace; this artifact adds no Lean or spec coverage claim.
