# Startup animation queue boundary diagnostic

This is an unexecuted logging-only successor of the built eight-role RFST capsule `css-root-font-startup-trace-instrumentation-v1`. It keeps every byte of those eight candidates and adds only `dom/animation/EffectCompositor.cpp` and `layout/style/ServoStyleSet.cpp`. `native.patch` is the complete ten-role e86 overlay; `PARENT-DELTA.patch` adds the two logging files to the previous trace. All source bases remain the exact immutable e86 revision in SOURCE-ROLES.json. No native build or browser run was performed for this successor.

The existing single-late fixture and MOZ_ROOT_FONT_STARTUP_TRACE environment gate remain unchanged. Reproduce the same first/settled/post-calibration 46px and later class-restyle 64px observations under this logging before interpreting the new events. Logging can perturb scheduling. This is separate from cancellation correctness and is not a repair or a new accepted defect.

## Question and exact source chain

The saved late trace contains one child/effect rebuilding endpoints to 64px with `changed=1` after root publication and normal task mask 4 delivery; JavaScript still observes 46px. Later class restyling rebuilds 64px with `changed=0`. The earlier log lacks outer StyleDocument pass and queue boundaries. This supports checking pending animation installation, not asserting that the request was queued or skipped.

At exact e86, KeyframeEffect::UpdateProperties assigns changed properties and requests a Layer restyle after its changed-properties branch. EffectCompositor::RequestRestyle exchanges the queue entry to true before posting; an already true entry skips posting. PostRestyleForAnimation returns during Servo traversal or PreTraverse, relying on a subsequent PreTraverse. StyleDocument invokes PreTraverse before its first traversal and once between first and second traversals, but not after its second traversal. Each Servo_TraverseSubtree can itself perform animation-only and normal traversals: existing Rust flags cannot identify the C++ outer pass.

RestyleManager::DoProcessPendingRestyles clears the Servo root during post-traversal. Its outer StyleDocument loop alone does not guarantee queue drainage: StyleDocument returns before PreTraverse when there is no root. AutoSetInServoTraversal clears its traversal flag and runs existing post-traversal tasks on exit; RunPostTraversalTasks executes its queued tasks, not an unconditional compositor drain. These facts do not exclude other paths scheduling work; the new logs are intended to distinguish them.

Immutable full context bytes and hashes are retained in context/ and SOURCE-CONTEXT.json. Discovery used Searchfox at indexed revision 7a315fc898bbd3e61ba7dd220a8fb1d0721a1eb7: [StyleDocument](https://searchfox.org/firefox-main/rev/7a315fc898bbd3e61ba7dd220a8fb1d0721a1eb7/layout/style/ServoStyleSet.cpp#807-893). Local e86 objects, rather than the indexed revision, define this patch.

## New records

- `document-enter`, `document-no-root`, `document-pre`, `document-pass-begin`, `document-subtree`, `document-new-subtree`, `document-pass-end`, `document-between-pre`, `document-exit`: exact StyleDocument call and outer pass boundaries. The new-subtree branch is labeled separately; it can run its own subtree pre-traverse. Exit follows guard destruction and post-traversal tasks. A second-pass begin followed by document-exit brackets that pass; no extra traversal is added.
- `request` and `request-post`: already obtained queue entry and original exchange result, target/pseudo, cascade level and restyle type. No new EffectSet or target lookup. Requests rejected before queue lookup produce no request record.
- `post-deferred` and `post-shell`: actual existing branch taken, including already normalized node. `pretraverse=0` in the deferred branch implies the existing Servo-traversal operand was true; no extra invocation of that predicate is made. Missing prescontext or normalized target returns remain unlogged.
- `pre-enter`, `pre-queue`, `pre-selected`, `pre-remaining`, `pre-exit`: existing pre-traversal entry, per-level counts, selected valid target before hint posting, remaining counts, and original return value. Counts are read-only map queries and can include throttled or unselected entries. A selected event is before PostRestyleEventForAnimations; it is not proof of later composition. No queue iteration or cleanup is added beyond count reads.

The desired discriminator is a target request with skip=0 and post-deferred inside the second outer traversal, followed by document-exit without a target selection, then later selection after class restyling. Conversely, a post-shell or pre-selected event before the observation would redirect investigation to subsequent composition/install. Exact JavaScript/native timestamp boundaries remain unavailable: unchanged script history and effect/target cohorts bound interpretation; stderr order alone is not a global cross-thread happens-before proof.

Pointers identify live objects only, can be reused after destruction, and need document/cohort context. Both child and pseudo-host identities use the nsINode base conversion, not assumed C++ Element address equivalence. Existing RFST normalization supplies pseudo joins. Style-set and compositor pointers are distinct namespaces; pair their synchronous PreTraverse call nesting and target document cohort, not equal addresses. No persistent sequence framework, style getter, flush, normalization, animation lookup, or scheduling call is added.

## Validation and remaining boundary

Actual focused check e1dd65/0 authenticated all ten role triples, exact previous eight candidates, erasure of all 18 new replacements to their parent, zero-fuzz forward/reverse cumulative and parent patches, and formatter-parser acceptance of only the two new C++ files. Scratch was removed. The existing eight formatter checks were not repeated. Formatter parsing is not C++ typechecking. `mDocument` is a raw Document pointer in the pinned ServoStyleSet header; pinned ServoTypes and EffectCompositor headers establish enum masks/levels/restyle types, while AnimationTarget/PseudoStyleType establish raw element pointers and the pseudo enum; enums are explicitly converted for printf, `%p` arguments are pointer casts, and queue Count is converted to unsigned. No original branch predicate or return value is replaced or evaluated an extra time.

Do not replace the fixed second traversal with an unbounded drain loop on this evidence. Font-relative animation feedback, transitions and deeper dependency chains need an explicit convergence/cycle rule; one extra pass is also not a general proof. First measure the queue boundary with this capsule and the unchanged late fixture. Native compile, archive preservation, reproduced behavior, and actual trace interpretation remain root-owned future work.
