# Wrapper history replay evidence

RUN.json pins the immutable source capsule and records a successful clean relocated replay. `fresh/` retains the proof audit, complete Rust debug/release and semantic-mutation outputs, and exact ordered model/native snapshots. `authentication/` retains seven rejection logs before output creation. `development-receipts/` preserves prior development outcomes, including failed discrimination and packaging attempts; those do not replace the final successful replay. CLEANUP.json records removal of completed owned compiler targets after these receipts were copied.

Authenticate externally supplied manifest/seal/checker hashes, then run `python3 -I -S check.py` to check this evidence closure. The actual source-only rebuild command is in the source capsule README and RUN.json. These are producer receipts, not independent approval or whole-parser verification.
