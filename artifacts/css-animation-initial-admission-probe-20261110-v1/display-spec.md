# CSS-DISPLAY-4#display-animation

**Animating and Interpolating display** (heading)

**SHA**: hash:ebfed48b1348ef0c0dd5788cd6b8ee077728e2e47197386a78be544be0e51a84

## Content

In general, the [display](CSS-DISPLAY-4#propdef-display) property’s [animation type](WEB-ANIMATIONS-1#animation-type) is [discrete](WEB-ANIMATIONS-1#discrete). However, similar to interpolation of [visibility](CSS-DISPLAY-4#propdef-visibility) (see [Web Animations §  Animation of visibility](WEB-ANIMATIONS-1#animating-visibility)), during interpolation between [none](CSS-DISPLAY-4#valdef-display-none) and any other display value, *p* values between 0 and 1 map to the non-none value. Additionally, the element is [inert](HTML#inert) as long as its display value would compute to none when ignoring the Transitions and Animations [cascade origins](CSS-CASCADE-6#origin).
