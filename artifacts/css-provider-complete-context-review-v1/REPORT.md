## Actual footprint domains

- Font and line-height leaves read current/parent font, writing mode and metrics/font-set state. Root-relative variants additionally read root/device metrics. Computation records font/cache dependencies. A font-size bit alone is not a metrics certificate.
- Physical viewport leaves read device dimensions; logical viewport leaves additionally read target writing mode. Their dependency flags must survive retries.
- Container leaves read per-axis query containers, geometry/source zoom, target logical axes and fallback viewport. Preserve the accepted registered zoom boundary and query snapshot.
- Tree-counting leaves read element identity, declaration scope, sibling tree and tree-counting cache. They mark sibling-dependence and cache conditions. No prioritary property represents this input.
- Random leaves read document/element identity and cache keys; retries are not necessarily new draws. The current upstream seed implementation differs from the accepted branch, so this report does not assume byte equivalence.
- Colors and nested image/transform/list values require recursive selected-component analysis. Relative-color channels may remain symbolic, unlike ready local property values. Join all child requirements and unknowns; do not classify whole syntax names as safe/unsafe.

The prioritary table conservatively schedules font-weight/width/style/size-adjust and writing-mode properties before line-height. A fixed line-height does not thereby acquire all those semantic read dependencies. Routing a provider demand through that schedule must not add an invalidating SCC edge for each prerequisite.

## Bounded integration recommendation

Separate actual local reads, external inputs and deferred effects. A typed-value visitor can accumulate the first two, but only the owner can certify that they are ready for this registration, target and generation. Keep selected parse/URL/scope identity; Unknown survives unresolved children. Stable external inputs may be certified by the existing style-computation scope when justified, without inventing a global generation mechanism.

Pending/Applying must mask cached provider values. Commit the completed provider and relevant dependency effects together; a temporary context that produces the right number but discards viewport/font/container flags is incomplete. Restore provisional effects on suspension or justify their idempotent conservative accumulation individually.

Retain the selection/traversal continuation before retirement. Resetting an enum cannot restore a popped Tarjan owner. Keep demand scheduling distinct from CSS cycle edges. The sealed Lean model proves context agreement only under complete-footprint/coherence premises; it is not an exhaustive native visitor or invalidation proof.
