# Finite-depth acyclic duration diagnostic

This prepared, unexecuted WPT has four callbacks at depths 1, 2, 4, 8. Each callback collects a literal trajectory and then a contextual trajectory in separate visible iframes. Depth counts intermediate animated nodes; the opacity leaf adds one more dependency edge. It challenges finite-pass repair proposals without claiming a native pass corresponds to one edge.

Odd-numbered nodes animate explicit line-height 16px→32px with duration `calc(1em / 16px * 1s)`. Even-numbered nodes animate explicit font-size 16px→32px with duration `calc(1lh / 16px * 1s)`. A non-root container supplies font 16px and line-height 16px. Every input metric is inherited from the previous stage and is not changed by that stage's own effect. The leaf animates opacity 0→1 and uses whichever metric the last stage outputs. There are no rem units, custom properties, unitless/normal line-height, pseudo-elements, script timing overrides or rescue seeks.

Every effect is paused at 1500ms with one iteration, fill both and steps(1,end). Input 16px gives 1000ms and output 32px; input 32px gives 2000ms and output 16px. The leaf maps input 16 to opacity 1 and input 32 to opacity 0. All numbers are exact endpoints, with progress 1 or 0.75 before keyframe easing. CSS animation timing-function changes keyframe interpolation, so the recorded effect progress need not equal the rendered step output.

The dependency graph is root font→node 1 line-height→node 2 font→node 3 line-height→…→leaf opacity. Explicit-pixel line-height inherits as a length and is not rescaled by descendants' font sizes. The metric used by each duration equals its parent's metric, so the numerical oracle does not depend on choosing own versus parent metrics under the font-affecting-property exception. This differs from a self-font-duration feedback cycle. [CSS Values 4](https://drafts.csswg.org/css-values-4/#font-relative-lengths) and [CSS Inline 3](https://drafts.csswg.org/css-inline-3/#line-height-property) support those metric relationships; [CSS Easing](https://drafts.csswg.org/css-easing-2/#step-easing-functions) supplies the exact step endpoints.

All chains begin with literal 1s/2s durations, acquired CSSAnimation objects and held time 1500. After three setup frames, the complete initial state is calibrated. The contextual trajectory then changes only its duration declarations to equivalent expressions with unchanged inputs and calibrates again. This avoids assuming that an initially stale deep contextual chain was already valid. A calibration failure remains a setup FAIL with its snapshot, can prevent the record POST, and is not silently discarded or converted into a post-intervention measurement. These setup reads may flush style; they do not prove native queue quiescence.

The intervention changes only the container class, setting font 32px. For literal controls, the same class also switches fixed stage durations to the independently known final 1s/2s values. In contextual trajectories no descendant authored duration changes. The very next API operation is a leaf computed-opacity read. Three frame callbacks then sample only that leaf; detailed ancestor/style/effect reads follow, then membership checks and another detailed snapshot. No author seek/restyle rescues the measured interval. The [Web Animations update obligation](https://drafts.csswg.org/web-animations-1/#model-liveness) motivates asserting the first value as well as all subsequent bounded samples. Frames are observations, not the definition of correctness.

Both trajectories are collected and removed before POST, which precedes final literal-first assertions. Setup assertions are the explicit earlier exception. Four exclusive private records (`depth-1.json`, `depth-2.json`, `depth-4.json`, `depth-8.json`) retain initial and post-intervention state, four leaf samples and animation/effect membership. The receiver preserves wrong/null numeric values and false identities; schema validity is not PASS. Its private-directory/exclusive-file/acknowledgement tail is byte-identical to the previously reviewed same-element receiver. Use the exact resources/manifest/metadata in INPUTS.json; no native WPT tree installation or owner is supplied.

The finite Boolean chain model is a structural companion, not a refinement of this CSS graph. Its arbitrary-k counterexample applies to its concrete snapshot-frontier evaluator. These four browser cases cannot prove arbitrary-depth termination, absence of cycles in all CSS, a native number of passes, or correctness of a future implementation.
