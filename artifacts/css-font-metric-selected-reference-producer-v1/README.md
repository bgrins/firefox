# Selected-reference producer

This artifact extends the actually compiled identity candidate `0b22a697` with an executable producer for `MetricActionProgress::References`. It changes only the copied cascade source; the copied custom-property demand provider remains exactly `90acb505`. `native.patch` contains both complete source overlays relative to the published base. `PARENT-DELTA.patch` is the precise change from the sealed identity capsule. No current source, Git/index, canonical state, application or native build was changed.

A retained metric action now owns its selected longhand, exact unparsed Arc, `ReferenceWalk`, included flags, frame depth and semantic index floor. The walk drives the existing `start_frame` and retained traversal above that depth. An initially unvisited size alias can therefore compute before the original selected declaration resumes. Only completed or settled-cycle child results are passed back to the selected walk. Completion is derived from exhausting that walk, not supplied by the caller. The existing preparation checks the exact longhand/Arc again, substitutes once, retains rollback results and publishes the owned declaration.

The side traversal does not replace `frame_root`, renumber Tarjan indices or add a semantic edge from the waiting metric node. A foreign open ancestor is blocked before `receive` can modify a lowlink. Both an immediate lookup and an already retained reply preserve the waiting frame/cursor. A child-local SCC may settle normally. Side-root completion returns at its boundary without sending a reply to the suspended outer frame. A nested metric wait retains the original action/drain and remains pending; this slice does not implement nested metric action scheduling. Flags are checked before traversal and again before consuming its result. Typed attributes use the selected declaration's `substitution_property_id`.

The final extracted Rust check runs nine positive tests and eight compiled behavioral mutants with debug assertions disabled. It extracts the real reference walker, frame creation/stepping, frame driver, metric action methods, preparation, drain and provider. Test support combines the prior traversal harness with the identity capsule's distinct priority enum, which deliberately has no equality traits. The tests force the metric root before its initially unvisited alias; no hash-order assumption supplies coverage. They cover child-produced size/alias values, child-local cycle/fallback, direct and descendant foreign waits, retained foreign replies, nested-action ownership, changed flags, typed-attribute consumer identity and rollback to a different raw Arc. Mutants remove the foreign boundary, consume a foreign reply, overwrite the outer action, lose the root, use the wrong consumer, ignore post-walk flags, skip traversal or ignore rollback; each compiles and fails an assertion.

This is control-flow verification, not a native CSS evaluator or complete scheduler proof. Test doubles implement small numeric substitution and font-size computations, registration maps, attribute parsing and generated property prerequisites. Their explicit values do not establish real CSS parsing, font metrics, generated dependency completeness, or browser behavior. The earlier identity capsule's 15-test/16-mutant/3-trait-negative run remains historical evidence, not a rerun here. The initial empty-test extraction smoke run is retained in `TEST-INITIAL.log`; the authoritative final tests are `TEST.log` and `TEST-RESULT.json`.

Actual native compilation and browser validation remain root-owned and pending for this source. The existing unsupported font-input producer and generated-prerequisite branches remain blocking; this change supplies selected references, not those producers. A real scheduling recurrence or unsupported nested metric wait remains explicit `ComputationPending`; the existing top-level completion assertion still rejects it. No inherited/default metric policy, CSS cycle expansion, matrix repair, native acceptance or publication is claimed. The finite-plan Lean model is supporting conditional reasoning, not proof that this native graph discovers such a plan.
