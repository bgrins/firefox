Independent review of the NameRepeat context/cache proposal. The reviewer did not author this patch or fixture. Final source authentication and replay are recorded in CHECK.json; this report is not runtime acceptance.

The parser retains Integer representation and its positive-range policy while removing the context-free rejection and all parse-time count/cache arithmetic together. Computation evaluates the retained entries with the supplied Context before calculating the cache. Empty name groups count as one, auto-fill contributes zero, and integer patterns use saturating multiplication followed by saturating addition. This preserves the producer arithmetic of fix 122. The existing C++ full-width guarded consumer is not modified. The HEAD90 alternative has no claim to repair that older consumer's separate narrowing issue.

The specified-value and inverse-conversion cache placeholder must not be used as a computed cache. Specified serialization uses the retained line-name entries. Computed-as-specified conversion must preserve the complete computed value, including its cache; the final proposal supplies a distinct identity implementation for i32. Subgrid's compute(field_bound) carries the manual conversion's associated-type requirement through the enclosing generic enum. Entry conversion, resolved conversion, animation rejection, clone/shmem layout and repr(C) storage otherwise remain unchanged. The field layout is unchanged. Full generated derive and Gecko compilation remain a required gate; the isolated facade is not that gate.

Independent Searchfox discovery found the specified parser constructor, generic representation and the native computed-style cache consumer, plus generated FFI storage/equality. The remote index is older than the installed saturation fix, so it is discovery evidence, not the candidate's baseline. Exact archived bodies and the proposal's constructor/derive audit supply the review basis.

The ten tests are bounded and independent of either Round guard and held Sign fix 120. The finite expression has counts 2/3/1/2 at fonts 16/32/8/16. Explicit literal line-name lists provide the oracle, with separate admission, font, em-width, parent-size and literal-resolution calibration before target admission. Later comparisons check deterministic repeat reads and each font transition. Additional cases cover positive clamping, empty groups/truncation, computed inheritance, sibling insertion/removal, and unchanged invalid literal/structural syntax. The inheritance twin uses explicit groups rather than a repeat count, avoiding the same cache operation in its oracle. Failures at target admission are meaningful baseline witnesses only after the initial calibration succeeds; subsequent history assertions are then NOT_REACHED, not measured.

The expected names agree with the positive-integer name-repeat grammar and the five-line resolved subgrid representation, including distinct name groups, truncation and trailing empty groups. [CSS Grid 2 name-repeat and auto-fill](https://drafts.csswg.org/css-grid-2/#repeat-syntax), [resolved subgrid values](https://drafts.csswg.org/css-grid-2/#resolved-track-list-subgrid). Available font information is used at computed-value time, and numeric functions are clamped to the count's permitted range. [CSS Values computed values](https://drafts.csswg.org/css-values-4/#calc-computed-value), [numeric functions](https://drafts.csswg.org/css-values-4/#numeric-functions). These are source/spec oracles, not evidence that style invalidation or the candidate has executed successfully.

This is support for the already tracked bug 2037744, not a newly discovered defect or accepted fix. The bounded host facade supplies Context and OwnedSlice/entry conversions; it does not prove the real parser, dependency tracking, derived conversion, whole native pipeline or universal platform behavior. Its small host64 pattern lengths do not themselves exhaust usize saturation. Source operators retain saturation, with prior dedicated proof/helper evidence separate. Steps and its targetless API policy remain outside this patch. A controlled Gecko compile and paired browser run with existing saturation and grid controls remain necessary.
