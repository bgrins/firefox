This scratch model separates child flush request, embedder completion and viewport publication. It reuses canonical ProviderObservation.query for the request-only observer and UnitConversion.ready_preserves for conversion arithmetic. No canonical module or audit/case totals change.

State carries an explicit demanded key (provider generation plus relevant geometry revision), a supplied required extent, a request flag, optional completion certificate and fallback-or-layout publication. Request changes only the flag. completeEmbedder records completion for the current demanded key and required extent; publish refuses absent or mismatched certificates. Resize invalidates completion and changes the geometry revision while retaining the earlier publication. Reconstruction changes generation, clears completion and installs a supplied fallback. These are abstract protocol transitions, not instrumented Gecko functions or claims that native counters/certificates exist.

The required extent is explicit. For root's now-scoped REACHED obligation it represents the viewport prescribed for the hidden child in the admitted layout profile. The Lean proof does not independently establish that spec mapping or derive the required size from CSS. In particular completeEmbedder assumes successful layout computes that required extent; the proof establishes that matching publication transports it and enables the existing factor-preservation theorem. It does not prove that a native Style/Layout request forces that completion. Ready is a sufficient provenance/currentness certificate, not a necessary condition for numerical factor equality.

The generic results establish: requests preserve existing readiness rather than create it; completion followed by publication yields a ready state without changing demand/required extent; ready publication supplies the required extent and therefore preserves successful rational conversion; resize invalidates a previously ready publication even when the required dimensions are unchanged; reconstruction cannot certify its fallback; and a delayed old-generation certificate is rejected after reconstruction, even if the numeric dimensions match. The last two laws prevent old publication evidence from being reused across replacement.

The concrete hide-only witness starts with a ready240×120 layout, then applies the hypothesized reconstruction/fallback transition to300×150 and issues a request. The canonical query returns30 for10vw; the supplied required extent instead gives24/12 forvw/vh, while sampled fallback gives30/15. The resize witness retains the same fallback observation but requires460×260, giving46/26. Root's eight-case browser result corroborates these numeric histories; it does not establish that our reconstruction event, missing completion, or publication branch occurred natively. A source/native trace correspondence remains external. These examples were motivated by source inspection and browser observations, not automatically discovered by Lean.
