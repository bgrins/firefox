# Scratch publication contract

The universal theorem covers a typed ordinary declaration list plus independent `all` storage, callback classification, branch selection, abandonment, publication, and arbitrary finite transaction histories. It preserves the exact selected declaration order and all field. Failed actions publish nothing. Canonical identities are preserved under an explicit premise that the selected callback expansion is canonical. `runNative`/`runDirect` retain the latest accepted transaction output; they are not implementations of CSSOM declaration-block update.

The native bridge compiles the complete selected helper and actual current LinkParameters and VariableValue parsing from the frozen discovery closure. It additionally extracts the complete SourcePropertyDeclaration record and implementation and drain record. Storage uses a bounded Vec adapter (capacity 128), declarations use publication tags, and `all` payload uses a marker enum. The extracted method bodies are unchanged for original/candidate. Abstract drain corresponds to the native state after the returned iterator is consumed/dropped; Rust borrowing and partial-drain semantics are not proved. No allocation, enum representation, full generated dispatch, real ArrayVec capacity, ownership or whole CSSOM proof is claimed.

Source obligations: entry scratch empty; generated longhand and shorthand callbacks push only on successful whole-value parsing; ordinary callback failure leaves scratch empty; wide and fallback callbacks publish their own canonical expansion; scratch is discarded on outer parse failure; generated `all` uses its separate storage. The proof treats final fallback acceptance as a provider outcome, covering failed observation, top-level validation, and VariableValue rejection together. These premises are source-reviewed and finite-probed, not universally derived from every property grammar or tokenizer history.

Synthetic successful callbacks that subsequently fail real VariableValue parsing exercise abandoned ordinary/all state. They test the generic helper and clear methods; the actual `all` property does not establish that successful callback path, and no second browser bug is claimed. Three compiled mutation witnesses use real LinkParameters inputs; the all-field mutation uses this explicitly synthetic callback. Each has a separately kernel-checked model witness.

The discovery source is frozen and copied with externally pinned MANIFEST/FREEZE/checker identities. Candidate source is exactly SHA256 `2ef96482f50b06dcf87a18abc4d1a9aa0109a9063aa71cadc53e7737022c094d`. Source-only replay builds from the copied closure, checks all five native variants, compiles Lean, audits axioms, and binds every declared witness. Final browser/build/standalone-patch acceptance remains separate.
