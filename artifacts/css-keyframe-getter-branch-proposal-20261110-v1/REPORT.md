# Specified-branch discriminator proposal

Four focused callbacks audit two gaps not covered by the fully authored relative-value controls. This is source-backed hypothesis plus a proposed conformance test, not browser reproduction, accepted repair or a new counted bug.

The API selects computed frames only when both conditions hold: current association with CSSAnimation, and no successful setKeyframes replacement. The existing getter instead obtains computedStyle from AsCSSAnimation alone, passes it into specified serialization, and invokes GetComputedKeyframes without checking current animation ownership. CSSAnimationKeyframeEffect's override checks only mIgnoreKeyframesGeneration.

The first pair uses ordinary marginLeft var(--source)/var(--other), with current values 12px/24px. Both plain WAAPI and a CSS animation whose effect received setKeyframes must return the specified expressions. Current single_value_to_css substitutes ordinary WithVariables when passed computedStyle, so replaced CSS can differ from plain WAAPI even though the prior 1em/2em controls passed. A correct gate must intentionally stop passing computedStyle to the specified serializer for replaced CSS; preserving that old substitution would preserve a suspected defect. Ordinary WAAPI behavior remains unchanged.

The second pair keeps a CSS-created effect with one authored 100% endpoint, then either detaches it or transfers it to plain Animation. Assert that the old CSS animation no longer owns it before calling the getter. The specified branch should return one endpoint, offset/computedOffset 1 and specified 1em. Existing unconditional virtual generation may still create a missing 0% entry because the CSS-derived effect class and generation flag persist. Single-endpoint membership distinguishes this from the fully authored two-endpoint controls.

A minimal gate can combine postflush current CSS association with the existing GetComputedKeyframes result, invoking the generator only when currently associated with CSSAnimation. Its result also encodes the setKeyframes opt-out. That same combined decision must select computed versus context-free specified serialization. A preflush AsCSSAnimation bool alone is insufficient; GetComputedKeyframes true alone is insufficient after detachment/transfer. Retarget/null-style handling still needs a stated contract. Do not alter rendering/SMIL or force every plain effect through computed conversion.

The code uses no generated-value oracle beyond the branch's endpoint inventory; variable cases avoid calc/shorthand normalization ambiguity. Four callback registrations and syntax pass inert Node checks. No live WPT/native/browser/build/Git edits or execution occurred. Root can run this before committing a native gate repair and inspect exact setup-versus-getter failure stages. Baseline outcomes are not asserted here as observed facts.
