# Source and model boundary

* evaluate's fallback branch follows VariableExpr.substitute, imported unchanged from CssSemantics.Variables. The erasure proof is over every expression/environment, not just the witnesses. Kind.other groups var/env selection at this abstract settled lookup boundary; their parsing and environments are not equated.
* mark(.attr) corresponds to the standalone own-fallback fix in substitute_one_reference: only after do_substitute_chunk succeeds, OR attr_tainted with reference.substitution_kind == Attr. The primary success returns before this fallback tail; its correct aggregate bit is independently required. This model marks either successful attr branch, expressing that required input invariant rather than re-proving native primary parsing.
* Value.origins is ghost provenance. The native value carries a Boolean, not this list. chunk converts nonempty provenance to the aggregate bit. Occurrence IDs need not be globally unique for the stated membership/conservation claims.
* RetainedAggregateTaint.append/publish/alias are reused unchanged, connecting a chosen attr fallback to the aggregate repair's RetainedSubstitutionResult.attr_tainted and custom-value publication. Its ranges-only ordinary parser conversion remains separate. The imported assembly model permits clean separator bytes but this evaluator models serialized token composition without deriving separators; evaluate_erasure is value semantics, not exact native CSS byte/tokenizer refinement.
* The sealed aggregate repair provider still has SubstitutionReferenceStage::Fallback => continue. It does NOT include the standalone fallback-tail correction. The new theorem states the required composed behavior; it does not claim this retained arm already implements it. Active browser candidates remain untouched.
* RegisteredInitialEmbedding's registeredUnspecified nodes and complete/default machinery determine settled initial values. Its domain lacks provenance and uses singleton-px completion; this successor does not assert a representation theorem from those tokens to arbitrary native strings. A supplied valid initial is a primary; a supplied guaranteed-invalid initial selects fallback. Neither is Pending or a valid empty string.

The seven false controls independently reject losing the outer mark, tainting an unused fallback, dropping a nested outer origin, losing empty-result aggregate provenance, broadening direct intervals, conflating empty with invalid, and marking a clean non-attr fallback. They are false Lean examples checked by decide, not malformed source or API failures. The byte-erasure theorem does not establish no repeated DOM reads or parser side-effect ordering.
