# Selected attribute fallback provenance

This closes an input-provenance gap between two existing models. RetainedAggregateTaint assumes correctly tainted completed chunks, then proves aggregate preservation through assembly/publication. RegisteredInitialEmbedding proves which settled value an acyclic registered source produces, but its px token values have no taint. Neither proves that a selected successful attr fallback adds its own outer attribute origin.

The new effect-free evaluator carries bytes and an origin list. A reference's primary is supplied as a settled optional value. If it is invalid, only its fallback is evaluated. A successful attr result adds the outer occurrence origin; var/env-like references preserve only the chosen child's origins. A failed fallback remains invalid. The structural evaluate_erasure theorem proves byte results exactly match the existing VariableExpr.substitute after annotation erasure for every finite expression and arbitrary settled environment. Thus provenance is added without changing the preexisting value-selection algorithm.

selected_fallback_publication composes actual successful fallback evaluation with RetainedAggregateTaint.append/run/publish: outer attr provenance survives arbitrary preceding state and subsequent chunks, including an empty fallback and later alias. discarded_fallback proves replacing an unused fallback cannot alter the returned value or origins. Nested attr origins remain present. The omitted-outer counterexample produces identical value bytes but clean versus tainted custom publication; it is not just an assumed invariant of the output.

Direct byte intervals remain separate. A nonempty tainted result yields its local interval through the imported assembly model. An empty selected attr fallback contributes aggregate custom-value provenance without introducing a range covering an unrelated literal URL. This does not turn an entire direct property into an aggregate-tainted value. No discarded fallback is charged as an origin.
