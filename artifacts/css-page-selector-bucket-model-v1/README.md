# Page-selector bucket equivalence

Six checked Lean declarations show that a normalized exhaustive selector maximum equals the maximum from the nameless bucket and the actual named bucket, when each bucket filters individual selectors by name before testing pseudo-classes. Two concrete kernel witnesses show the old all-name maximum creating applicability and inflating specificity. Two corresponding false equality claims are rejected.

`0` encodes no matching selector; `specificity + 1` encodes a matching selector. Thus equality preserves both applicability and the maximum specificity, including a genuine specificity-zero match. `ruleScore` separately handles an empty selector list as universal. Names are abstract natural identifiers; the current page is named. The separate unnamed-current-page path is not modeled. Each selector's pseudo-class result is an input Boolean for the current page. Specificity is an abstract ordered rank. These are explicit normalizations, not proofs of Atom equality, CSS parsing, pseudo-class evaluation, tuple packing/clamping, or the native representation.

The main theorem is for every finite selector list and page name. `bucket_eq_filtered` additionally equates the fold implementation with a literal name-filtered list. Native correspondence is narrow: the proposed PageRule::match_specificity filters by the bucket name, while PageRuleMap separately visits nameless and named buckets. The model assumes the relevant rule is indexed in each necessary bucket; it does not establish native indexing completeness, source/layer order, duplicate rule handling in the full cascade, pagination, print rendering, or C++/Rust refinement. Duplicate selectors are harmless for the mathematical maximum, but no whole-native duplicate-index theorem is claimed.

The applicability witness is an alpha:first selector that fails its pseudo-class and a bare beta selector that succeeds, on an alpha page. The specificity witness is a matching alpha selector beside a higher-specificity beta:first selector. Both are manually constructed from the already-discovered source defect and existing print probes; Lean did not discover the native defect automatically. This adds no accepted fix count or canonical CSS coverage claim.
