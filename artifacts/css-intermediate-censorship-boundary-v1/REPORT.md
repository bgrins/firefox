# Intermediate censorship boundary

This is a conditional mathematical boundary model over the existing exact rational/extended-scalar semantics. It is not an IEEE or Stylo refinement, a native implementation proof, or a newly accepted browser defect. Boundary.lean remains the root-authored source; no canonical source or registration is changed.

The four named results establish: NaN remains infectious through addition before final censorship; censoring a NaN leaf early changes the result to a retained finite offset; equality of final standalone observations is not preserved by every enclosing arithmetic context; and infinity multiplied by either signed zero yields the same observable early-versus-late distinction. Bounds must retain zero and the selected nonzero offset where stated. The zero-basis result allows either infinity sign and either abstract zero sign. These hypotheses are real restrictions; clipping can mask differences outside the retained range.

Three concrete controls use bounds [0, 2] and offset 1. They compare late evaluation with early leaf censorship for NaN plus offset, NaN times zero plus offset, and positive infinity times zero plus offset. Each late result is proved equal to 0 and each early result to 1. Their inequalities compile, while the contrary equalities are rejected after rewriting to the concrete unequal results. This tests meaningful semantic distinctions rather than parse errors. The infinity control censors before multiplication; the fourth general result separately covers censorship of the resulting NaN before addition.
