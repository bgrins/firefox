# Recognize escaped terminal quotes during EOF recovery

The original quoted-token arm regards any final matching quote as a closing quote. An odd run of backslashes immediately before it instead escapes that quote. The patch counts that run and recognizes a real closer only for an even count, while retaining the `len() > 1` opening-quote guard. It appends a missing matching quote for escaped terminal quotes, preserving their literal decoded value.

`ClosureRepair.lean` derives exact closing classification, independently decoded contents, recovery-content preservation, closure before any appended suffix and ordinary-prefix framing. The original n=1 false-closure and an always-append n=0 overcorrection are counterexamples. There are nineteen exact standard-axiom reports across two modules; two false semantic model mutations are rejected, and two native semantic mutants compile and are discriminated.

The byte slice excluding the final quote is evaluated only after short-circuiting confirms the ASCII matching quote and length greater than one; it therefore ends at a UTF-8 boundary. Counting stops at the first non-backslash. The opening quote alone remains unclosed. Both quote kinds share the proof grammar and execute separately in the native controls.

The endpoint integration changes only this same closure predicate. A newly recognized escaped-terminal-quote recovery ends in a quote byte, so the endpoint repair's backslash-deletion flag stays false. The separate parity predicate is untouched. Normal genuinely closed strings and odd unclosed-backslash behavior are preserved.

## Source boundary and independent oracle

The complete original `custom_properties.rs` is pinned at `d7765d0a1de32f85ad7713409398282556078331e7a1b8ecc047d82b1fc789ab`. CSS Syntax's string algorithm consumes a pair of backslashes as one literal backslash. A backslash immediately before EOF contributes nothing. A backslash immediately before the matching quote contributes that quote to string contents instead of ending the string. These rules determine the semantic oracle; no exact raw custom-property serialization spelling is required. After a valid string is substituted in `font-family`, the following `, serif` must remain outside that string. Primary spec/bug retrieval records and the separately authenticated root browser observations are under `context/`. ## Kernel model: what is proved

`TerminalString.lean` defines an independent pairwise escape grammar over slash, matching quote and opaque ordinary units. It consumes escapes from the front; the repair uses trailing-count parity. The proof does not define the decoder in terms of the repair. Pair decomposition, even/odd EOF behavior, even/odd final-quote behavior, maximal reversed slash-run count and ordinary-prefix framing are derived by induction. Arbitrary following units remain unconsumed once the reconstructed string closes.

This is a terminal-run component, not a full CSS tokenizer theorem. Admission requires one valid quoted token, a matching opening quote, and tokenizer state inside that string immediately before its maximal terminal backslash run. `other` represents ordinary non-delimiter/non-newline/non-NUL input in the framing theorem; it is not a proof of hex escapes, Unicode decoding or preprocessing. The general algebraic suffix theorem leaves its suffix unconsumed, so it does not assert that the simplified decoder handles every possible suffix character like CSS. Native UTF-8/source-position validity, byte-to-model correspondence, normal metadata return, usize arithmetic, allocation, standard-library iterator semantics and Rust compiler correctness remain explicit premises. The native byte count iterates backward over ASCII backslash bytes and cannot split or count a multibyte scalar as a backslash. That source argument is not a verified Rust execution semantics.

## Executed source and tests

The offline driver builds pinned complete cssparser plus vendored dependencies. It reuses the authenticated endpoint producer's lexical Rust extractor and declared type/provider facade. Complete `VariableValue::parse`, both declaration-value functions, `parse_name`, `empty`, `push`, substitution structures, `ReferenceFlags::from_unit`, `do_substitute_chunk`, `substitute_internal`, and `Substitution` constructors are extracted and compiled. The actual complete declaration parser executes on each input; this is no longer a hand-reimplemented recovery branch.

The twenty terminal-run rows cover both quote kinds, zero through four backslashes, EOF versus a final quote; two additional controls cover the opening quote alone. Each compares actual tokenizer contents with an independently calculated pair grammar, then re-tokenizes the stored recovered CSS followed by `, serif` and verifies both decoded content and the exact unconsumed suffix. These twenty-two native rows are not identical to root's twenty-two browser rows: root's last two are fallback controls, while these last two are opening-only controls. Full recursive fallback endpoint correctness belongs to the separate endpoint companion.

The runner compiles original, candidate, restored-original mutant and overcorrection mutant in three source configurations: standalone, on the formatted endpoint repair, and composed with both semantic repairs. Standalone and endpoint configurations each remove exactly this repair's four semantic failures and retain the other four. The composed source passes all twenty-two rows. This finite source execution supports the source binding; it is not a universal Gecko proof or browser gate.

`substitute_one_reference` remains a declared provider facade: its signature and missing-provider fallback tail compile, while the main var/env/attr lookup is replaced by missing/present fixtures. Namespace parsing deliberately panics if reached; attr types admit only the omitted type. Derived enum recognition, atoms/maps/context/taint are facades. Those providers are not exercised by the single-string native semantic matrix. Optional cssparser fast-match features are disabled in this direct-rustc build. The complete token source is pinned; this does not certify all configured Gecko builds, heap behavior, CSS cascade scheduling or all native callers.
