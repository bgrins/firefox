# Proposed full provider obligations

No obligation below is declared proved by the 646-case source witness. Existing name/escape proofs may be reused only after binding their assumptions and source versions.

1. **Raw admission and dispatch.** Start from arbitrary valid UTF-8 input and an admitted byte boundary. Establish quote/`/*` call guards from the complete raw dispatcher; do not replace them with arbitrary well-formed output/payload premises. Include EOF and public iterator entry behavior.
2. **Preprocessing relation.** Map raw CRLF/CR/FF and NUL to the spec's code points, with a monotone original-byte endpoint map. Raw surrogates cannot inhabit &str; bind upstream conversion separately.
3. **Borrowed string loop.** Prove decoded prefix, progress, matching/opposite-quote behavior, exact endpoint and transition to owned storage. Include empty strings and unterminated strings.
4. **Owned string loop.** Relate byte append to code-point output, allowing an intermediate partial UTF-8 suffix only while copying one admitted multibyte scalar. Prove complete UTF-8 at every escape/newline/quote/EOF return before the unchecked String conversion.
5. **Escape composition.** Admit complete hex consumption, six-digit bound, optional preprocessed whitespace, replacement for zero/surrogate/out-of-range, simple scalar escapes, and exact consumption. Bind the existing helper proof instead of assuming its returned character/progress.
6. **EOF versus bad newline.** Prove escaped EOF is dropped in strings while generic escape EOF returns U+FFFD elsewhere. Prove BadString leaves the raw newline and preserves the already decoded diagnostic prefix; the diagnostic payload itself is an API extension.
7. **Complete comment loop.** Prove first-terminator/EOF semantics, non-nesting, at-least-two-byte progress from admitted opening delimiter, exact raw-content slice and endpoint. Do not normalize the extension's raw payload into the spec's ignored content.
8. **Public stream composition.** Compose repeated ignored comments with the next real token and relevant whitespace handling. Separately admit the preserving-comment API, cached token replay, resetting parser state and block skipping; raw dispatch and public next are not identical iterators.
9. **Observers.** Include UTF-8 cursor, UTF-16 column, line number, source-map URL and sourceURL. Comment directives update fields even for an unterminated comment. History/last-writer behavior and reset/cache behavior need source-derived transitions; no arbitrary trace-equality premise.
10. **Native bounds.** Current ParserState packs the line counter in 30 high bits and block type in 2 low bits. advance_line_number uses u32 addition; debug overflow and release wrapping must not silently be equated to unbounded natural lines. Columns use u32 casts/wrapping. State explicit input/state bounds for native correspondence or model the wrapping behavior, with the mathematical unbounded specification distinguished. usize cursor arithmetic, allocations and standard UTF-8/char conversion remain native admission obligations.
11. **Observer/evaluator connection.** Bind actual callers that parse properties/selectors or preserve raw custom-property text. Expected-failure metadata for raw-text CSSOM and rule serialization cannot be discharged with token-payload equality alone.
12. **Replay and independence.** Use an independent preprocessed-code-point reference, arbitrary input rather than a prepared token stream, complete source extraction, audited Lean axioms, meaningful compiled semantic mutants and relocation/tamper gates. Separate universal model proof, finite native agreement and unproved external providers.

Suggested order: prove the complete comment/observer loop first, then both string phases with the existing escape provider, then raw dispatch/public-iterator composition. This order does not remove any of the obligations or change the full tokenizer roadmap.
