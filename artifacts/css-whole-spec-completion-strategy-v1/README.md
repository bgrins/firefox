# Whole-CSS completion strategy

Two research agents assessed what completing a CSS model would require, using
the current library and fragmentation requirement pilot. This is a research
plan; it does not add proved CSS coverage.

- [Coverage and interpretation](coverage/REPORT.md): reconcile current official
  catalogs, surviving CSS2 clauses, roles/media and external contracts into a
  versioned universe. A 17-family matrix identifies gaps; requirement counts
  cannot yet provide a completion percentage.
- [Architecture and tools](architecture/REPORT.md): connect one complete
  rendering episode before broad family expansion. Construct inputs, preserve
  text/fragment identity, provide distinct CSSOM and paint observations, and
  prove update histories and numerical branch behavior.
