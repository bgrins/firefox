# Cancellation to dependent keyframe conversion

This conditional source map follows plan719ab1c5. It proposes no instrumentation or native change. The cancellation8 result is still needed before assigning another defect. Existing font-unit repair changes only data.rs/traversal.rs admission; the current map keeps glue83cc and all other original e86 sources.

## Concrete path

1. `Animation::Cancel` clears hold/start time, calls `UpdateEffect`, removes the animation from its timeline and, when newly idle under `PostRestyleMode::IfNeeded`, calls `PostUpdate`. `UpdateEffect` updates relevance and calls `KeyframeEffect::NotifyAnimationTimingUpdated`; that updates target registration, may request Standard/Throttled restyle, and marks cascade changes when in-effect status changes. `PostUpdate` requests Layer restyle. These functions schedule work; their bodies do not directly set Device root metrics or synchronously prove the root has returned to23px.
2. The fixture next calls target.animate without a root getter. The exact e86 `KeyframeEffect::ConstructKeyframeEffect` calls `SetKeyframes`. The JS `SetKeyframes` obtains `GetTargetComputedStyle(Flush::None)`, whose branch is `GetComputedStyleNoFlush`; when a style exists, the overload immediately calls `UpdateProperties`. Thus eager endpoint computation can precede the target's first getter. This is a possible timing path, not proof that every call avoids all internal style work. `BuildProperties` itself documents possible subsequent restyles while computing keyframes.
3. `UpdateProperties` first calls `BuildProperties`, before comparing old/new properties. `BuildProperties` calls `KeyframeUtils::GetAnimationPropertiesFromKeyframes`, whose local `GetComputedKeyframeValues` calls StyleSet's `GetComputedKeyframeValuesFor`. The saved Rust entry `Servo_GetComputedKeyframeValues` builds the animation Context from supplied target style and borrowed parent style. The selected rem branch in saved length.rs reads `Device::root_font_size` for this child/non-root-pseudo context; rlh reads `Device::root_line_height`. These getters mark used flags and load stored atomic values; they do not themselves schedule or verify a refresh. Initial-reference root classification is a separate route and must not be conflated with these child cases.
4. Root `finish_restyle` in matching.rs identifies `IS_ROOT_ELEMENT_STYLE`, publishes `set_root_style`, and, when `font_size_changed`, publishes unzoomed `set_root_font_size`; `line_height_likely_changed` controls the corresponding root-line-height setter. Font or line-height change generates `RESTYLE_IF_AFFECTED_BY_WM_OR_ANCESTOR_FONT` for children. Normal `recalc_style_at` in traversal.rs now queries `element.has_animations` only for that hint and outside animation-only traversal. `needs_to_recascade_self` admits either the ordinary `USES_FONT_OR_WM_RELATIVE_UNITS` bit or relevant-animation membership. `process_animations` inserts `UpdateAnimationsTasks::EFFECT_PROPERTIES` for animated targets that reach processing; existing EffectCompositor updating then calls `KeyframeEffect::UpdateProperties`.

The fix can repair a stale eager conversion by admitting the later normal rebuild. It does not alter Cancel, the no-flush initial conversion, the Device setters/getters, or root identity. It cannot by itself prove that the requisite ancestor hint was produced/delivered or that a later conversion used the newly published metric.

Then investigate property installation/composition/output rather than expanding admission or adding a provider refresh. |

Associate every record with the same document, target/pseudo, Animation/KeyframeEffect, property and monotonically ordered event within the observation. Keep currentTime500 and underlying root23/37 controls. Do not implement a synthetic revision protocol from Provider.lean: its revisions and progress premises are abstract. Values32/64 describe the saved initial16 environment; log measured initial metrics and zoom instead of hard-coding them into native diagnosis.

No-root-read versus root-read, existing versus new target, and unchanged-rlh controls already separate useful schedules. A root getter inserted into the failing arm would destroy the discriminator. No additional getter or flush should be introduced to collect these proposed native records. Source-only inspection cannot establish which traversal occurred during a particular browser getter.
