# Registered image font dependencies without contextual colors

Three standalone WPT callbacks use only red/blue gradients: direct em/lh stops, a typed-attr em stop plus lh stop, and inheritance of an already computed parent image. The existing frozen 42 suite and its expectations are unchanged. This supplemental page has not been executed in a browser.

Each fresh iframe registers one non-inheriting `<image>` custom property with an absolute-color, length-free initial gradient. Two phases change the target's explicit font/line-height from 20/40px to 32/64px and its parent's from 12/24px to 18/36px. The first getter in each phase reads the target custom image before reference, font or line-height getters. An ordinary background-image with matching metrics supplies the serialized image oracle. The inheritance case uses explicit substituted inherit and a reference computed with parent metrics, so recomputing inherited tokens against child metrics is detectable. All diagnostics are collected before assertions; registration errors and unsupported image/attr syntax remain failures. The typed-attr arm independently compares attr width against literal 2em.

Registered `<image>` values compute as images under [Properties and Values computed-value rules](https://drafts.css-houdini.org/css-properties-values-api-1/#calculation-of-computed-values). The definitions of em and lh use the relevant element's computed font-size and line-height; these images do not set font-affecting properties. [CSS Values font-relative lengths](https://drafts.csswg.org/css-values-4/#font-relative-lengths). Literal reference comparisons avoid a hard-coded gradient serialization or system palette. This page contains no CanvasText, light-dark, currentColor, system color or color-scheme declaration.

The frozen source path explains why this is a separate discriminator. `find_non_custom_references` gates token unit flags by registration LENGTH eligibility and supplies a coarse scheme flag for COLOR. Its result is used in `cascade_custom_property` to choose immediate computation versus storing unresolved tokens for DFS. Once DFS is entered, `visit_value_references` ORs root flags and selected referenced-value flags into the non-custom set, including typed-attribute primary flags; it follows fallback references only when the primary is invalid. The combined V3's Image admission can therefore cause an absolute-color image to reach the unit walker even when its selected AST has no scheme dependency. That is a source prediction, not a measured fix. Exact frozen excerpts are in SOURCE-TRACE.json; this does not prove complete image unit/cycle coverage.

The original 42 relative-image cases all include CanvasText. Their outcomes alone cannot distinguish a complete image-unit repair from incidental scheme-driven ordering. Root-reported original values 20/40 expected versus 12/24 actual (and parent 12/24 versus 16/19.2) motivated this supplemental test; they are not assertions about this new unexecuted page. The three callbacks should be observed on original and candidate separately after their existing run/restore ownership permits. No owner or runner is added here.
