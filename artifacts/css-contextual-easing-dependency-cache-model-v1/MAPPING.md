# Source and fixture mapping

The pinned activation candidate's `LinearFunction::to_computed_value` visits output, optional start and optional end independently before feeding the scalar builder. `support` models the union of reads from all present components. It does not model optional-position filling or the piecewise builder. `linearStop = [0,0,ownFont]` is an omitted-endpoint-field abstraction with 32/48 scalar endpoints. The actual static diagnostic uses `sibling-index() * 20%`; it is not the same numeric witness. Both have a contextual second endpoint after a constant first endpoint. No assertion says the candidate currently omits this field; its source explicitly visits it.

`parent_font_is_not_pseudo_font` holds parent font at 16 while own font changes 32 to 48, proving a parent-only key can alias different step parameters 3 and 4. This is a separate theoretical cache witness. The WPT changes originating font 16 to 24 and pseudo font 32 to 48, so both dependencies can invalidate there. That WPT distinguishes the value context, not exclusive dependency tracking. `pseudo_first_snapshot_wrong_binding` matches its first snapshot exactly: `1 + 32/16 = 3`, while incorrectly using the originating font gives `1 + 16/16 = 2`.

`index_is_not_count` uses index 2 with count 3 to 4. It corresponds to the count-only append topology in the activation lifecycle tests, rather than claiming that every static-sharing target follows that topology. The static diagnostic also tests differing contexts across parents and class-identical targets; it does not establish that native style sharing occurred.

The transition trace uses count 3 to 4 as a generic field change. The follow-up WPT instead captures index 3, changes the current property to index 2, finishes the old transition, then starts a new one. The correspondence is temporal separation, not identical numerical rows. The model does not establish that the browser emitted the requisite event or chose the right effect.

The existing rank model proves a different bounded transport contract and is not re-proved here. Current fallback for an inaccessible tree-counting scope remains 1 under CSSWG issue 13736; no zero-scope oracle is encoded. The CSS-wide keyframe descriptor ambiguity from issue 14096 is also outside this model. Source/fixture hashes are in SOURCE-PINS.json; those packages remain immutable.
