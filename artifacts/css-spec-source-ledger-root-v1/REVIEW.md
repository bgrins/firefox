# Source-ledger pilot review

Root read the complete importer, replay checker, output contract and report,
and the independent fragmentation interpretation, requirement candidates,
scenarios and validation recommendations. The deliverable is source accounting,
not accepted CSS semantics.

The byte validator checks exact source identity and complete ordered UTF-8 byte
intervals. Regeneration additionally checks this importer version's lexical
categories, anchor map and candidate contexts. Those are distinct claims:
mutating a category without changing spans can pass the byte validator. None of
the checks decides normative meaning or proves an exhaustive requirement set.

The independent reviewer selected the same fragmentation range and retained all
four fallback paragraphs plus the adjacent zero-size placement dependency.
The proposed thirteen contracts remain unaccepted interpretations. The class-B
label/class-A link disagreement and the ED/CR decoration change remain explicit;
no automatic rule resolves them. The progress candidate does not establish
termination over arbitrary real-valued geometry. A finite content abstraction
needs a correspondence contract and a well-founded consumption measure.

The root replay and authenticated producer/reviewer identities are recorded in
ROOT-CHECK.json after final delivery. No native or browser claim follows from
these checks. The next semantic gate is a source-bound, reviewed finite
fragmentation relation, with explicit feasibility and opportunity providers,
nonempty branch examples and a separately proved executable selector.

## Accepted accounting result

Fresh root replay from a manifest-only copy and unrelated working directory
passes for three documents, 2,029,554 source bytes and 75,626 lexical units,
with 16 rejected corruption/edit controls. The independent review's importer
and fragmentation ledger hashes exactly match the final producer. Its own
checker also passes. Root's initial manifest-reader error occurred before any
replay and is retained separately; the corrected replay is recorded explicitly.
Temporary replay copies and regenerated inventories were removed after receipts
were retained. This is a portable implementation milestone, not new CSS proof
coverage.

## Whole-CSS architecture review

Root read the v5 architecture proposal and authenticated its 21 retained inputs.
Its sketches are uncompiled. The useful next boundaries are a real host
observation history, content-preserving layout/text continuations, and equality
relative to all admitted downstream consumers. The proposal relates these to
existing Style, Variables, TransitionMachine and finite-scalar components;
those existing theorems do not discharge the proposed integration contracts.

The three workstreams agree on separate claims for source accounting, reviewed
interpretation, reference correctness and native conformance. Their proposed
pilot ordering differs. Current implementation proceeds with the already
prepared fragmentation contract while bug work pursues the custom-value to URL
observation path. The finite flex loop and broader text/scroll composition stay
queued; no speculative whole-CSS completion date or percentage is adopted.
