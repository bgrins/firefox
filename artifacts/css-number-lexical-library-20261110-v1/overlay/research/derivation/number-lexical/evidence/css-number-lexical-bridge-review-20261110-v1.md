# Independent numeric lexical bridge review

Root independent source review and cold source-only replay pass. All 83 source inputs and 63 preserved Git objects are authenticated. The replay completed 457 axiom audits (37 new general laws and 22 new boundary cases), 126 executable rows, five malformed-document refusals, three compiling semantic mutants and three provenance controls. Author and reviewer semantic receipts agree; command logs are hash-checked. No native execution or canonical mutation occurred.

The proof connects the fixed typed JSON number document through the existing full-state parser lowering to a separate scalar syntax model and then to the preserved byte lexical model. The observation includes exact consumed prefix/remainder, three digit runs, outer-sign presence and syntactic integer classification. `prefix_from_suffix` uses the preserved cover theorem; it does not reconstruct source spelling from a numeric value. Optional fraction/exponent rollback is proved separately, including unused exponent suffixes. The public admitted domain is normalized ASCII plus actual number-entry recognition. The stronger byte-lift lemmas do not claim equivalence with UTF-8 decoding for arbitrary non-ASCII native input.

The full-token theorem only identifies its numeric component and retains the old full-token count/rest guarantees. It does not equate the numeric remainder with the remainder after percentage or dimension suffix consumption. The fixed document identity is material; arbitrary accepted NumberShape documents are not claimed to be CSS number algorithms. Error-flag preservation is model state, not a native error mapping.

The runtime runner imports the executable document machinery and observation adapter, not the fixed fixture identity or correspondence proof module. A changed valid input document must change output. Fixed actual-file and reference runners, malformed document refusal, compiling observation mutants and exact false witnesses are appropriate checks of the executable boundary. Axiom audits and authenticated unchanged sources supplement, rather than replace, review of theorem statements.

Native Rust execution/refinement, floating-point conversion and integer clamping, JSON text-parser correctness, Unicode preprocessing and mechanical CSS prose derivation remain outside this milestone. Existing finite native corpora remain historical evidence until a separately reviewed expanded native harness is executed.

The three preserved legacy modules retain nine unused-simp warnings. Their exact full-output hashes are admitted; all other build diagnostics remain strict. No proof source was edited to silence those legacy warnings. Compiled temporary directories were removed. See CHECK.json and ORIGIN-AUDIT.json for the independent tool/input/receipt identities.
