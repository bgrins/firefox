Registered-value parsing constructs ParserContext with no error reporter or use counters, preserving URL data, property ID, None namespaces and whole-substitution AttrTaint. The specified AST is owned until SCC settlement; computation remains after a noncyclic component exits. Parsing is not globally pure: allocation, atom interning, preference reads and attribute/environment queries can occur earlier. This audit does not assume rollback of those effects.

Optional use-counter writes are disabled by this ParserContext. The inspected constructor does not resolve URLs or initiate network loads. URL ToComputedValue clones the specified value. This is a trace of the captured paths, not a claim about all URL consumers.
