# Independent bounded projection/native source review

No blocker found in the reviewed mathematical statements or the inspected native correction/diagnostic schedule. This is independent source review, not a new compiler replay, native binary proof or full caller acceptance. INPUTS.json pins the exact reviewed bytes; Projection.reviewed.lean preserves the eleven-theorem version before possible later additions. I authored the earlier outside-int32 counterexample and conditional reporting helpers; these root-authored projection/flag/budget proofs are distinct.

Clamp commutation and telescoping correction require ordered effective bounds inside signed32. Both flag equivalences include bounds on both sides, so they cover equal-endpoint cases without overclaiming. Exclusivity follows from those ordered bounds. Correction magnitude is bounded by delta magnitude only because base is representable. Aggregate identity is an unbounded-integer result; prefix safety explicitly requires the absolute-delta budget and count. Arbitrary independent correction/clamp prefixes make that last theorem suitable for the native mixed schedule, but the actual list/order/provider correspondence remains unproved.

Native totalViolation is reset before guarded distribution. Every visited unfrozen item contributes stored−raw, with overflow-side flags seeded before the forward clamp loop adds clamp(stored)−stored. Their sum matches the mathematical raw violation under the stated bounds. Preseeded and ordinary flags cannot conflict. The reverse index decrements once for every visited item, including frozen gaps; frozen diagnostics are skipped. Raw int64 delta capture matches the documented requested-change meaning and double conversion avoids an intervening nscoord narrowing.

An initial concern about stale diagnostic values on skipped distribution was withdrawn after checking the exact old braces: old and new captures have the same availableFreeSpace/weightSum guards. No reset is recommended on that basis. Existing source-provider validity, fresh survivor flags, buffers/indexes and all arithmetic-definedness remain native joins.

A conservative budget route is recorded in RANGE-NOTE.md. It is not a proof that native execution meets the budget. In particular Fits64(raw) alone does not suffice; raw=INT64_MIN and minimum0 has violation2^63. The current caller target/proof remains unchanged and covers its acquired32 provider domain only. This review neither upgrades that domain nor calls the widened native correction fully verified.
