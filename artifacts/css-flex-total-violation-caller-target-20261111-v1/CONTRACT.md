# Proposed caller/history target

Status: definition/admission work and concrete witness checks only; no universal proof campaign. The accepted scalar violation V2 definitions are copied unchanged. This model adds a source-shaped control/state layer, not native memory or compiler verification.

## Constructed initial state

A Seed is a settled item after external base/minimum/aspect/intrinsic providers and before ResolveFlexibleLengths. Normal seeds construct the hypothetical size by clamping base and initialize frozen/violation flags false. Retained-frozen seeds explicitly carry an already frozen size and mutually exclusive clamp flags; this covers struts, previously inflexible items and retained/copy states at the abstract interface, not proof that every such seed is native-reachable. strutSeed constructs the concrete zero-size/frozen form. Fields retain full identity, base/effective bounds and exact zero-test results for the chosen source flex factors. No unique-identity premise is imposed.

initialLine folds appendItem from an empty count0 line. Each append increments frozenCount iff the appended settled item is frozen, mirroring AddLastItemToMainSizeTotals. Count agreement is a theorem target, not an input field equation. Source reachability requires actual exactly-once bookkeeping after each item's final line assignment and correct handling of relocation/cloning; that is recorded separately.

Early freezing models the actual factor-zero and grow/shrink base-versus-hypothetical tests, skips already frozen items, clears flags through Freeze and reassigns the clamp interpretation. The walker consumes the original length−frozenCount active-record budget and retains the actual early-stop behavior. The target derives exhaustion and agreement with the all-record early map from construction; it does not assume the count correct to define history.

## Each pass and history

At each pass the modeled reset puts unfrozen sizes back at their bases. A provider then supplies positional full-list target values after native floating distribution; frozen entries ignore their supplied slots and remain byte-for-field equal in the modeled state. ProviderValid requires equal length and signed32 values only for the active positions. This is an explicit external acquisition boundary, not a theorem that arbitrary floating calculations produce it. Pairing never looks up a supposedly unique identity.

The clamp walker executes native min-first/max-second branches, sets only the corresponding violation flag, updates the size and accumulates the exact promoted difference in source order. It uses the same active-record counter and records exhaustion. The accepted scalar target supplies the independent sum/acquisition bridge in the future proof.

The freeze walker selects from actual flags using the total sign. It preserves previously frozen records; selected items execute Freeze then restore clamping flags; unmatched survivors clear flags. Crucially, the actual finalIteration emergency branch remains executable and records fallback=true. It is not deleted or equated with sign selection by definition. No remaining-count/history invariant appears in History constructors.

History starts from constructed append/early initialization and is extended only by a not-finished, in-loop-range step, valid provider values and actual runPass equality. The index guard is the source for-loop guard. Progress, full record/identity order, fresh survivors, count agreement, remaining≤originalCount−iteration, completion and fallback unreachability are conclusions in the target. The proof must derive the last-pass at-most-one fact from earlier transitions, not assume it.

## Optional line information and upstream providers

wantsInfo remains an explicit parameter. Empty lines have no loop iteration. Already-frozen nonempty lines exit immediately only without requested line info; with it they can perform the source's extra pass and then stop. The model does not silently fix aLineInfo=null.

The optional line-info writes are outside the modeled state: base/growth/delta output fields, indexing/buffer validity, and especially narrow deltaSize=MainSize−mMainBaseSize require a separate provider/refinement argument. Abstracting these writes as non-mutating algorithm state is not a proof that all native operations are defined.

The other upstream narrow addition MainSize+nscoord(sizeDelta.ToMinMaxClamped()) is not asserted unsafe. preferredMax is2^30−1 (the actual nscoord preferred bound, not INT32_MAX). DeltaAdmissionTarget conditionally proves signed32 representability and unchanged final clamp when base/effective bounds are in[0,preferredMax]. It does not establish those source-provider bounds, floating-point rounding, delta formation, NaN/infinite handling, or every native caller path. The root assessment's16 passing browser cases are supporting context, not proof premises.

## Concrete controls and proof boundary

The two-pass witness uses duplicate identities deliberately: first provider[-1,5] freezes only the first slot; second provider[123,5] must preserve that frozen slot while freezing the survivor. JointTarget requires actual History of the final state. The witness proof must build History.initial and real History.step constructors, never invoke UniversalTarget. Other controls cover grow/shrink early choices, a pre-frozen strut, null/non-null line info, empty inputs and rejected provider-length mismatch.

Arbitrary final-iteration invocation and corrupted frozenCount remain negative controls: they can activate fallback or skip active records, respectively. They are excluded by derived history properties, not arbitrary native behavior equivalences. No full caller closure is claimed before the allocation/lifetime/provider/native correspondence obligations are discharged.
