# Source roles in the joined consumer model

The native-source capsule is unchanged. Its BINDINGS.json and PROVIDERS.json retain complete selected consumer bodies and distinguish compiled functions from admitted providers. The top checker authenticates that closed capsule before execution. New proofs do not turn those hashes into a proof of C++ translation.

## Indexed identities and fields

World.nodes is the existing finite facade projection of live frame identities. first, next and parent represent the retained canonical/continuation/parent helpers; canonical/IB-split discovery is external. A Chain witnesses actual next links ending at none, with unique in-bounds indices. Graph adds common canonical first and parent. This is a representation premise about the raw graph, not a supplied output list. Index equality corresponds to stable native identity throughout a call. No reentrancy, deletion or pointer reuse occurs within the modeled call.

The normal getter returns the normal property when present, otherwise the frame's own current coordinate. moveChain reads that getter before each write. Because a valid chain has no repeated identity, the independent array reference can use each frame's initial observed normal. A missing property is not replaced by the first frame's normal. The loop changes only current; all other Node fields and unvisited Nodes are preserved. The theorem derives that the model's fuel cannot exhaust on the graph domain. Fuel is model termination instrumentation, not arithmetic executed by the C++ pointer loop.

ComputeTranslationIgnoringScrolling selects the canonical first frame and subtracts its observed normal. GetPositionIgnoringScrollingAndSticky adds this common translation to the selected frame's own observed normal. Those frames need not have equal normals or equal property presence. The fallback path returns the supplied non-sticky/scrolling-independent position and does not execute sticky translation.

## Primary updates and overflow requests

UpdatePositions supplies stable shallow-first primaries. The mathematical update theorem accepts any finite order while the native bridge retains the stronger actual ordered-provider premise. Each reflow action first installs that primary's admitted recomputed offsets; then movement sees the installed value. The independent fold uses this refreshed state and the results of prior primaries. It never assumes the old offset epoch still applies.

The source-shaped overflow loop follows the retained parent/continuation enumeration. The facade document root is the synthetic index nodes.size, which terminates before array access. OverflowPath explicitly models that distinction. The proof preserves frame storage and exhaustion and the machine/math equality preserves request traces. It does not prove overflow unions, rendering, scheduling, successful allocation or Flush side effects.

## Machine arithmetic and upstream geometry

The model implements signed32 conversion/addition/subtraction and saturating far-edge construction separately from mathematical operations. Domain predicates bound both coordinates of every modeled point operation, including an unselected component. Rectangle exact-sum premises retain v2's conservative domain; equality outside that domain is not claimed. Native stored offsets/coordinates must already have faithful signed32 representations. Optional inset interpretation still excludes an explicit value aliasing the reserved AUTO code.

The admitted limit provider is called in both current and ignore-scroll space with the original missing-offset behavior. It must return the real geometry at the particular call, including after earlier ancestor movements. All arithmetic executed inside the full upstream ComputeStickyLimits provider remains an external premise: a safe final rectangle alone is not asserted to prove its construction safe. The consumer still calls that provider for all-auto or missing-offset inputs. A missing normal property in PositionContinuations returns before geometry and arithmetic, which the new guarded domain preserves.

## Calibration

The new driver preserves the original RawInput/RawNode decoder byte-for-byte. It derives candidate index paths from raw next links, checks those lists against Chain/OverflowPath and evaluates ActionSafe before comparing complete machine/math/native observations. This finite check does not establish graph validity for every Gecko graph. The separate independent observation uses simultaneous frame updates and a sequential reference fold, not moveChain or the actual source for-loop.

The preserved native outputs observe returned points, current positions and provider/caller trace strings. Universal Node-record preservation is a Lean theorem; the finite native output format does not directly expose every structural field. Native source/field-update inspection and provider representation remain part of the source interpretation boundary.
