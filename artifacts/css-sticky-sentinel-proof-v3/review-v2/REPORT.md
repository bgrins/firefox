`StickyComposition.continuations_refinement` proves a recursive list traversal equals a map over supplied frames. `StickyLifecycle.continuations` instead calls `moveChain` over indexed `World.nodes`, reads optional normal properties on each visited node, updates array entries and follows `next`, using `nodes.size + 1` fuel. No universal theorem relates that actual indexed execution to the list result. There is no Lean graph validity/representation predicate matching the admitted canonical, acyclic, in-bounds, same-parent graph, no derived no-exhaustion theorem, and no visited/nonvisited frame preservation theorem for `moveChain`.

The producer's theorem pattern still succeeds. `shared_refinement_allows_exhaustion` additionally shows the equality remains true for a cyclic graph whose fuel is exhausted. The native validator correctly rejects that graph; this is a premise necessity example, not a reachable native bug.

**Required closure:** define a finite graph/list representation with explicit provider premises (stable identity, in-bounds indices, acyclic continuation chains, canonical membership, getter/property stability). Prove sufficient fuel from those premises; prove indexed traversal applies one delta to each visited frame's actual pre-call observed normal, preserves unvisited frames/structural metadata, and handles missing normal and unchanged writes. Join canonical translation and ordinary position-continuation callers to that independent result. For modeled update dispatch, carry the invariant across each admitted primary/reflow action or clearly retain only the originally required caller scope; do not replace the actual traversal with a precomputed expected final frame list. General Gecko graph construction and arbitrary browser lifecycle histories need not become proved properties: the original external provider boundary can remain explicit.
