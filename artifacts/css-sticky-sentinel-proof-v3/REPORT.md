`StickyUpdate` joins this result through the actual update prefix, optional reflow installation, primary loop, parent overflow requests and flush. Its reference is a sequential fold of independent array maps. Structural links preserve subsequent traversal readiness. The synthetic overflow root terminates explicitly before array access; cycles are rejected. No desired final array or nonexhaustion observation is assumed.

R2 is addressed by separately defined signed32 operations and source-shaped machine wrappers. `ComputeSafe`, `TranslationSafe`, `ContinuationSafe`, `FrameSafe` and `BatchSafe` bound both coordinates of the executed operations.
