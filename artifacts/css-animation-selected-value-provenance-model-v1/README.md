# Selected-value provenance and metadata-only change

The isolated module kernel-checks twelve theorems and rejects six false controls. Actual successful replay: session 80294, terminal 5b9911, exit 0. The earlier elaboration failure remains in run1. Both temporary directories were removed. AliasGuard.lean is an unchanged copy of the sealed proposal's model; no canonical Lean or native file is changed.

The new obligation is what happens after existing CSS-wide selection chooses a replacement. `selected source replacement` preserves absence and the selected token/attr metadata, and ORs animation provenance into a valid replacement. The module derives that an active selected value remains rejected at an ordinary non-animatable sink through arbitrarily many aliases. It imports the existing alias evaluation theorem instead of reproving that resolver. The concrete control also rejects a tainted reference nested inside the outer fallback.

The second obligation is metadata-sensitive change detection. `changed` compares the complete optional value. The publication function retains the old value only when that comparison is equal; its result is proved equal to the fresh value, and silent publication implies semantic equality. Parametric counterexamples show that identical tokens with changed animation provenance require notification, and attr-only differences continue to require notification. This is a local map-entry obligation, not a proof that native restyle propagation occurs.

The source correspondence is narrow. The proposal's `resolve_custom_property` selects a CSS-wide result using the existing keyword handling, then marks a surviving map value when substitution carries animation provenance. The cascade's `mark_animation_taint` does the corresponding direct-keyword operation. These map to `selected`; a missing/invalid entry remains absent. `CustomPropertiesMap::can_deduplicate_values` and `value_may_affect_style` compare the additional metadata, motivating `changed`. The model does not implement tokenization, keyword selection, map inheritance, registration, cascade winner selection, or native invalidation. Its inputs explicitly assume the existing selector has supplied the correct optional value and the producer has supplied the correct provenance bit. It does not certify those assumptions.

`Value.token : Nat` stands for an opaque selected payload, not a CSS numeric value. Its separate attr bit is preserved, but URL range taint and complete typed-value equality are not modeled. The model's publication is a pure local value operation and has no relation proved to Stylo publication, task execution, child traversal, or browser output. No global inactive-keyframe policy, registration exemption, ordinary winner policy, cycle semantics or native correctness is established.
