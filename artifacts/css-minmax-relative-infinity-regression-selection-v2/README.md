# Singleton preservation added to the broader selection

The broader selection still has twelve pages: ten existing pages, the original eighteen-case fixture, and an extension now containing twelve callbacks. The previous ten-case extension is an exact byte prefix of the new fixture; its six n-ary targets and four explicit-NaN controls are unchanged. All original files and prior seals remain intact.

Two added controls cover `min(infinity * 1em)` and `max(-infinity * 1em)`. They require the specified forms `calc(infinity * 1em)` and `calc(-infinity * 1em)` respectively. The CSS Values simplification algorithm returns the only child of a Min/Max node: [calculation simplification](https://drafts.csswg.org/css-values-4/#calc-simplification). The general relative-infinity defer guard must not suppress this required singleton reduction.

Each control declares its expression once, then changes font size through 0px, 16px and 0px. It records all computed snapshots before assertions, calibrates the inherited em basis, checks repeated reads, requires zero at both zero-basis stages, and compares each computed value with the corresponding plain `calc()` reference. The positive-basis result must have the appropriate sign. This avoids hardcoding a platform-specific saturated length for infinity. Exact specified-form checking detects retention of the min/max function even if computed values still match.
