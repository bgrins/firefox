# Private single-trigger index-cost comparison

Prepared without browser/build/native/index changes. The separate standalone fixture is copied exactly from css-revert-rule-single-trigger-benchmark-v1. It tests N=0,32,64,128,256 matched custom-only payload blocks plus one strongest opacity declaration, in literal/revert-rule/revert-layer modes. Seven samples, 1024 updates/sample and four warmups give 105 samples and 107520 measured updates per repetition.

This measures the whole-source-index construction tradeoff separately from repeated Rule chains. Baseline is exact committed A+B+D; candidate is exact indexed C. SOURCE-ROLES.json retains the reviewed three-file/six-hash descriptor. No memory result or slowdown is claimed before measurement. N=0 still has one Rule trigger in Rule mode; it is not the zero-Rule chain floor.

The public interface remains run(root, output, pins, cancelled), active_processes(), and the conventional RESULT fields complete_observation, safe_to_continue, supplemental_audit_passed and all_pass. Fresh source/application/build pins are required. pins['repetitions'] defaults to two, accepts one or two, and each repetition uses a separate WPT process/profile. CLI: python3 -I -S -B run.py --pins FRESH-PINS.json --output artifacts/NEW-OUTPUT --repetitions 1 --execute. Root owns actual execution/build/restoration.

Reports use prefix CSS_ROLLBACK_SINGLE_TRIGGER_V1, version indexed-c-single-trigger-v1 and workload single-trigger-custom-payload. Row count is payloadBlocks (not rules); timing summaries use payload_blocks. The generator oracle requires exact lower-layer floor, exactly N custom-only blocks in order, and exactly one final mode-specific opacity block. All seven per-row samples, 7168 measured reads/writes/checks, finite timings and exact opacity outcomes remain required. No timing threshold is used. Failure to complete within bounds is an incomplete measurement, not a conformance bug.

The same 1-second sample/30-second page guards, 40-second wrapper completion wait, WPT long timeout and 180-second runner deadline remain. Explicit preferences are layout.css.revert-rule.enabled=true, dom.window.dump.enabled=true and privacy.reduceTimerPrecision=false. Native/run_info/source bindings, raw fault detection, chunk integrity, cancellation, cleanup and preservation checks are inherited unchanged from the reviewed long-batch runner.

Only explicit sealed input files were copied. staged/tests/tools is a symlink to the existing WPT tools directory, never a recursive copy. Original short/long packages remain unchanged. CHECK.json distinguishes syntax compilation, inert wrapper registration, pure generator evaluation and synthetic validator checks from browser/native execution; none of the latter occurred. FILES.json seals the new artifact.
