# Definition-only high-bit partition target

Target.lean proposes exactly the fifteen obligations from the reviewed source-only strategy. Backing is an indexed vector of five UInt8 values; original input allocation and initialized input bytes must be related to it by a separate Rust adapter. The vector does not model scratch initialization, pointer identity, compiler semantics or actual UTF-8 decoding.

All main equivalences quantify an arbitrary Type C without requiring any inhabitant. Nonvacuity takes an explicit c : C. Controls.empty_context makes the empty-context distinction explicit. The unused-tail witness clause requires both goodLength n and n < 5; it asserts equal consumed prefixes and different complete tails only when a tail exists. For N=5, vector/image/suffix laws continue to hold, but no nonexistent tail is demanded.

Good lengths are exactly 2 through 5. Cell.ascii clears bit 7 in the consumed prefix. Cell.high j clears bit 7 before j, sets it at j and leaves every later byte unchanged. A high cell is admitted only if j<n. The initial native experiment remains a separate N=3,j=1 Gecko proposal. No cell, length or feature has native proof credit here.

The first eight clauses describe exact byte algebra, lengths/tails, image membership, fixed points and the unique exhaustive class. Universal, filtered and cover_union operate on arbitrary predicates over the entire backing and context. They assume no suffix-insensitivity. The filtered validity predicate is arbitrary: neither ASCII UTF-8 validity nor invalidity of the final-position high-bit class is imported into this proof. validity_split separates an arbitrary predicate and its negation inside a generated cell. Actual decoder outcomes and safety remain native obligations.

ascii_refinement preserves the entire ASCII domain through all 128 first-byte choices, including controls, punctuation and NUL. It includes universal, validity-filtered and existential-cover equivalences. length_feature_aggregation relates the numeric length bounds to the explicit four-length list and both Feature constructors. It does not cover length 0, length 1 or unbounded strings.

Controls.lean contains six proposed checked-control statements: five exact domain-loss counterexamples and an empty-context control. Omitting the first-high-bit class loses copyWitness; forcing the high bytes to one scalar loses otherScalarWitness; zeroing the unused tail loses copyWitness; omitting the NUL first-ASCII-byte child loses asciiComplementWitness; filtering mode/page excludes two explicitly supplied contexts. These are mathematical domain controls. The copied byte strings' interpretation as real UTF-8 and the planned high-byte native mutation remain separate; no native method is executed or axiomatized here.
