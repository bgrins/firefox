# Empty-mask composition proof scope

## Universal model

Use Lean with exact rational alpha, four Porter-Duff operations, and finite bottom-to-top layer lists. Prove the empty-source identities for arbitrary destination alpha; equivalence of transparent-source composition to clear/no-op dispatch; preservation under arbitrary prefixes and suffixes of the fold; ignored bottom operator; and restoration by later layers after an empty-source clear. Define native outcomes separately as surface, empty-area, reference rejection, allocation failure, and snapshot/luminance failure. Only empty-area dispatch changes. Keep the two existing no-output callers and bottom override explicit.

The algebra will be independent of SVG geometry and reusable by a future CSS-image repair, but this package will connect only the current SVG classification/dispatch. No CSS-image native correspondence claim is made.

## Native capsule

Authenticate exact original and candidate GetMaskForMaskedFrame bodies, MaskParams/header API and the complete PaintMaskSurface caller. Compile source extraction with explicit providers for reference guard, mask area, allocation/validity, snapshot/luminance outcome, mode and operator mapping; retain returned surface identity, output initialization/optional-null behavior, operation trace, clear rectangle and transform restoration. Exercise all null outcomes, both rendering modes, both output choices, all operators, bottom override and three-layer continuation. Include offset rectangles in the adapter's coordinate trace, while clearly stating that backend pixels/clip behavior are outside the executable abstraction and are supported separately by accepted WPT evidence.

## Bridge and tests

Use independently written rational fixtures and Lean executable values for finite cross-language agreement. Prove universal laws in Lean; finite native fixtures do not establish universal C++ correctness. Pin exact source slices and their enclosing complete files, include mutation controls for wrong classification, operator swaps, bottom handling, target rectangle/origin and transform restoration. Require semantic mutants to reach comparison failures and diagnostic guards to fail for the intended reason. Record toolchain paths/hashes, no sorry/axiom additions, theorem dependency audits, clean replay and source-only tooling manifest.

No shared build/browser/Git/native/WPT edits. Work stays in this artifact directory. Kernel-checked mathematics, source-bound finite native extraction, abstract provider assumptions and existing rendering receipts will be reported separately.
