## Composition and theorem boundaries

The end-to-end theorem must link F3 ownership and F4/F5 normalization through F6/F7/F8 into F9/F10. Standalone and combined code have genuinely different collapsed-item allocation behavior outside this patch. They require separate source correspondences and clearly stated preservation domains.

Reachability concerns the alignment subject, not every possible overflowing descendant. The complete model must still describe signed margins and separately overflowing descendants, including counterexamples to an overbroad “all content is reachable” statement. A reachability theorem may state exact containment/size premises for the alignment subject, provided those premises are derived at the native joins or listed as unresolved obligations. They cannot be introduced late to mark an originally required producer/consumer obligation complete.

Similarly, C++ arithmetic safety is conditional on explicit derived prefix/count/rectangle bounds. Rejecting a concrete overflowing input is useful evidence, but does not prove all web-reachable inputs satisfy the domain. Maintain a separate reachability investigation for any rejected inputs whose actual browser reachability is unknown.

For nonowners, fitting content and explicit unsafe/default branches, prove old/new observer preservation across the affected downstream path. At zero free space, allow normalized keyword differences while proving identical geometric and allocation effects. Existing behavior and conformance to the latest draft are separate claims; the known non-scroller discrepancy must remain visible.

## Suggested implementation order

1. Freeze source/provider roles and build F3–F5 extraction with complete branch matrices. Reuse this review's constructor corpus as independent challenge data, not as a replacement specification.
2. Add F6 arithmetic and F7 axis/origin joins; reject unsupported domains with concrete witnesses.
3. Close F8 positioning and F9/F10 consumers, starting with the actual 640-case WPT and 72 ownership-boundary shapes, then generalize the theorem domain without dropping required branches.
4. Complete F11/F12 mutations, relocation and closed-roster review. Keep full acceptance pending until every required join is proved or explicitly returned as unresolved; do not promote the preliminary interval model to the full companion.
