# Complete path and execution boundaries

1. `Element::GetBoundingClientRect` allocates a DOMRect and obtains the frame's bounding rectangle. Layout flush, document state and frame availability are external to this numeric component.
2. `nsIFrame::GetBoundingClientRect` uses `nsLayoutUtils::GetAllInFlowRectsUnion`. `GetAllInFlowRects` and `AddBoxesForFrame` traverse boxes/continuations; table wrapper traversal includes inner table and caption in this path. A wrapper's dimensions must not be silently used as the element rectangle. The full retained layout utilities source and predecessor authenticated report preserve this distinction.
3. `BoxToRect::AddBox` selects border/padding/content rectangle and calls `TransformFrameRectToAncestor` on the relative-frame path. The retained full source is authoritative; CSS `transform:none` does not itself erase all coordinate transforms.
4. `TransformFrameRectToAncestor` reads source appunits/devicepixel and calls `LayoutDeviceRect::FromAppUnits`. `LayoutDevicePixel::FromAppUnits` uses `NSAppUnitsToFloatPixels`, with separate start and size conversions. The actual coordinate wrappers use gfx float storage. The selected scalar helper is compiled in this capsule, while the wrappers' field forwarding is a reviewed source admission.
5. `TransformGfxRectToAncestor` handles SVG text specially, selects/caches or computes `GetTransformToAncestor`, derives maximum bounds from the ancestor's appunit factor, and calls `TransformAndClipBounds`. This full method is retained for review but is NOT executed or universally modeled here. Actual matrix composition, projective coordinates, numerical width reconstruction and clipping are explicit open providers. The native harness supplies a finite graphics rectangle directly at this boundary.
6. `ScaleThenRoundGfxRectToAppRect` copies/scales the graphics rectangle; scaling multiplies each float component. It promotes each start/size to double, constrains endpoints and recenters oversized spans, and rounds/clamps start and size independently. It restores zero width/height explicitly. Both complete constraint functions and double integer conversion helpers are compiled. The model does not silently treat clipping as identity; native/reference boundary cases execute it. Universal exact-edge conditions concern the nonclipped/rounding-cell interface.
7. `DOMRect::SetLayoutRect` uses grid65536, a binary64 approximation of65536/60, binary64 multiplications and `floor(value+0.5)`. It computes width as rounded end minus rounded start. `SetRect` takes four FLOAT parameters, stores in double fields, and `Right` selects the larger of x and x+width. Full setters, rounding helper and accessor are compiled. The finite facade's NaNSafeMax agrees on the admitted finite nonnegative widths; NaN behavior is not generalized.
