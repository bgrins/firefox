# Local correctness review

The candidate separates current style-range limits from a pending word's captured limits. Each of the four writes to pending limits follows a nonempty contribution in the UTF-16/Latin-1 paths. Installing a later style, an offset-zero delimiter, or invisible whitespace can therefore flush an earlier word without replacing its owner. Immediate words use current limits; the buffered path uses captured limits. The language classifier and buffered-language updater are byte-identical to the published language candidate, with all four buffered updates and both immediate queries retained. The existing byte saturation and Unicode/dictionary filter are unchanged.

The continuation walk keeps the existing mapped-flow and shaping boundaries. It coalesces adjacent equal-limit continuations, so ordinary visual-line continuations do not create extra ranges. For ordered continuation offsets, clamping both start and end to the same mapped-flow buffer limit preserves nonnegative lengths and contiguous coverage; the end-only alternative would give -2 for start10/end12/flowEnd8. The shared skip iterator converts that contiguous original coverage into possibly empty transformed ranges. Each range creates a sink at its transformed start even when its length is zero; only AppendText is conditional on positive length. This preserves empty transformed-run finalization and prevents later range callbacks from using the first range's offset.

Only the first nonempty range retains the mapped-flow ancestor's initial-break controller. Skipped-only ranges retain that marker while still checking compressed whitespace. Subsequent ranges use their own frame controller. The loop uses the existing continuation reachability/order contract also used by AssignTextRun; it does not introduce a new pointer lifetime across reflow or script execution. This is a bounded source review, not a machine memory-safety proof.

The first-line/first-letter fixture measures the whole ordinary word after the prefix. It compares opposing pseudo limits, matching limits, and restored opposing limits against the ordinary control; permissive controls require a real English dictionary opportunity. A naive mapped-flow-only change previously failed all four cases. The corrected range walk retains the actual continuation styles and the existing text-run rebuilding providers. Adjacent equal-limit grouping relies on the same-content shaping compatibility and pseudo property restrictions documented in the pinned prior RANGE-INVARIANTS review; it does not claim arbitrary StyleText equality.

The normative ownership matrix uses a uniformly styled seven-letter word and limits100,5/100/2,5/2/100, making automatic hyphenation invalid independently of dictionary placement. It varies delimiter ownership, sibling limits, boundaries and partitions, with hyphens:none controls. Mixed-style words retain the candidate's explicit last-nonempty-contributor implementation policy; the fixture does not claim this policy is prescribed for every mixed-style word. The dynamic page is a preservation control, not a separately counted defect.

No concrete source blocker was found in this rebase. The three current native preimages must still be authenticated by the next root capture, and the isolated build/pair remains required. Arbitrary Unicode, fragmentation, allocation failure and full-CSS formal coverage remain assurance limits rather than evidence of a local failure. Primary spec/oracle analysis is reused from the pinned historical independent report; this preparation does not claim a new online spec retrieval.
