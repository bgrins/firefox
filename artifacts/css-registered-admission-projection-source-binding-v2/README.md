# Projection proof binding to the selected-token candidate

The existing six-declaration projection model and independent root replay remain unchanged. Its `exactly_agreed` theorem states that an output bit is present exactly when both the old mask and requested mask contain it. `no_added_bit` is one consequence; preservation of every already-present requested bit is the other. The cycle theorem assumes a fixed original graph.

The two source variants now obtain requested references from the selected substituted tokens after actual grammar admission, retaining intrinsic color-scheme requirements. They no longer call the admitted-AST collector. This prevents additional dependency loss caused solely by simplifying that selected value, such as `sign(1em)` becoming a number before inspection. The parser and substitution can themselves normalize values; this binding does not prove their semantics or resolve the CSS cycle-policy question.

SOURCE-ROLES.json binds the exact two candidate files in each sealed proposal. CHECK.json records only structural observations, not a proof of Rust execution or lexer correspondence. The generic Lean theorem applies to the local intersection under its explicit Boolean-mask interpretation; dynamically chosen providers, fallback selection, typed-attribute normalization, invalid-value handling and native side effects are outside it. The earlier collector model remains a separate research artifact for future scheduling work.

No new theorem or canonical coverage is claimed. Native compilation, paired WPT, selected-sign observations and pending-prototype integration remain separate gates.
