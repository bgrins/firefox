# Explicit provenance across a typed reparse

This extends the existing retained-aggregate model at a different representation boundary: a completed universal wrapper is uncomputed to an explicitly tainted, reference-free declaration, then re-enters substitution under a typed registration. The saved e86 no-reference path preserves bytes but constructs default substitution taint. The conditional counterexample therefore occurs after the wrapper correctly exported its provenance; it is not the earlier retained-empty aggregate loss or attr-own-fallback omission.

`uncompute` follows the saved wrapper/inner conditional. It preserves bytes and retains the OR of wrapper taint and existing explicit taint. The model's reference-free inner value also has no ATTR reference flag, so native `is_attr_tainted()` reduces to the explicit bit. This is a stated representation premise; an empty reference vector alone is not asserted to prove the flag premise for every native object. The concrete counterexample has a tainted wrapper and a clean inner value.

`legacyNoReferences` models the saved default-taint result. `transportedNoReferences` specifies the missing provenance transport, without proposing or installing a Rust patch. Both preserve bytes. The actual source also passes a full-value taint range into typed parsing and ORs the parser's output taint with substitution taint. Accordingly, `parseNative` accepts an arbitrary parser taking both bytes and input taint, returning an optional payload with its own taint. A failed parse stays invalid; a successful parse retains both sources of taint. The model does not force taint-sensitive URL/image parsing to succeed.

`native_admitted_handoff_counterexample` explicitly requires the old and transported inputs each to parse successfully to the **same clean payload**. Under those premises, the legacy pipeline returns that payload clean and the transported pipeline returns it tainted. This is conditional on the admitted input and successful typed-parser behavior. It is not a theorem that every CSS parser ignores taint, nor proof of a browser transition reaching the pipeline.

The separate `parseTyped` interface is deliberately narrower: its parser takes only bytes and contributes no new provenance. `liftPayloadParser` and `payload_parser_is_native_subset` prove its embedding in the general interface. Only this taint-insensitive subset has unconditional payload-erasure and parse-decision equality theorems. The transition probe targets `<string>`; establishing its native parse behavior and lifecycle handoff remains a source/browser obligation. The executable `echo` witness is an uninterpreted successful payload parser, not a CSS grammar implementation.

The extension also composes the new handoff with the existing `publication_conserves_trace` theorem: contributing origins survive assembly, universal publication, uncompute and transported reparse. Equal serialized bytes cannot reconstruct the explicit provenance. A rejected parse remains invalid before default handling; when a caller supplies a chosen registered initial, that initial's provenance is preserved instead of charging it for a discarded invalid value. Selecting the correct default/inherited value is outside this theorem. Successful parsing does not select that default.

The three earlier models do not already prove this result. RetainedAggregateTaint proves assembly/publication from correctly tainted chunks; selected-fallback proves origin acquisition and value selection; registered-initial embedding covers acyclic px values and explicitly excludes universal syntax, taint and reparsing. This module imports only the first model and its unchanged range dependency. It does not duplicate the other evaluators.
