# Selected-reference resumption: conditional selector refinement

This extension proves that a finite selected prerequisite program can execute child actions across pauses, consume the produced value, and return the same value, evaluated-declaration list and read trace as the existing `SelectedDeclaration.scan`. It adds no native code and does not prove that the current Stylo candidate supplies such a program. The next native producer remains the missing `MetricActionProgress::References` branch described in the separately sealed next-step report.

`Task` is a finite expansion of an already selected acyclic dependency plan. A read action supplies its immutable input value; a combine action computes from two completed child results using an arbitrary fixed reducer. Compilation produces an instruction tape. `tick` performs one actual read or reduction and preserves the unused tape, operand stack and trace. Child action ranks and the remaining instruction count strictly decrease. `execution_produces_actual_steps` and `finite_task_progress` construct operational execution from the independently defined evaluator, rather than assuming a readiness Boolean becomes true. Any finite pause prefix preserves the eventual result. The concrete example loads 20 and 35 and computes 700; scheduling those children does not make 20 a usable final result.

`Waiting` retains the rollback state, declaration, remainder, plan and cursor. A resume changes only the cursor. `fromCursor` cannot consume a value until all instructions finish and exactly one result remains. The unsupported-instruction example stays blocked; it is not converted to invalid/default or a semantic cycle. The terminal publication transition consumes its waiting token. Repeating completion produces one declaration-completion entry and one publication, not two. This is exactly-once *durable terminal completion per token*, not a proof of global memoization or a count of calls to a pure decoder.

`resumable_scan_refines_selection` holds for arbitrary declaration lists and plans: the executed evaluator refines the plan's direct denotation. The imported `scan_eq_of_reached_agreement` then yields `stable_resumption_refines_selection`, conditional on stable eligibility at every visited decision (including skipped declarations) and complete evaluation agreement at eligible decisions. The rollback witness executes a child-produced rollback, skips the now-ineligible intervening declaration and retains both rollback and winner reads. No task is constructed for a never-reached loser by this scanner.

The refinement boundary is deliberate. Plan discovery, selected fallback timing, native child-input finality, semantic versus scheduling ownership, retained Arc/context authentication, Tarjan lowlinks, attr/random caches, and invalidation under context mutation remain unproved. Task leaves are supplied final inputs; this package does not prove their correspondence to Gecko font metrics. A native DAG can be unfolded into the finite tree premise, but repeated action occurrences are not a shared-cache identity proof. True readiness cycles and unavailable producers have no progress theorem. `resumedScan` uses the complete task executor at each declaration; the pause theorem justifies pauses *within* that executor. It does not implement a whole-native-stack interleaving scheduler. Rollback results and terminal evaluation are pure model values; native exactly-once side effects still require the retained source continuation.

Validation: Lean 4.35.0-rc4, final `run3`, 21 theorem audits (only `propext` and `Quot.sound`) and five genuinely false propositions rejected by `decide`. The controls reject early publication, treating an unsupported wait as invalid zero, consuming a stale value, dropping a rollback read and publishing twice. `run1` retains two unfinished proof goals in the action-count lemma; `run2` passed the preceding 17-theorem/three-control version. All replay scratch directories were removed. No native build, browser run, canonical update or accepted-fix increment occurred.
