The central theorem is substantive: `deliver` reuses clean cached stacks while `full` recomputes every operation. Induction proves equality by preserving a clean-name table invariant and propagating the current calculated result through the remaining table. It does not assume equality of the final answers. However, the old cache is supplied *as* `full false old edits`; arbitrary stale, truncated or misaligned native cache storage is not covered. Clean names must have identical initial tables and identical complete old/new recipes. All reads depend on the same name by construction, so selective dirtying would need additional premises if dependencies crossed names.

The essential boundary is that the model's reference calculation is not proved to implement CSS counter scope selection. Source indices, reset dropInner, local versus inherited empty stacks, identity labels and traversal worklists are supplied. `Ordered` and its executable checker assert an existing same/ancestor-owner source; they neither select the correct preceding DOM/frame node nor prove all native scope rules. Moreover, Ordered is not a premise of the central equality theorem: that equality also holds for malformed recipes because both functions use the same total missing-index-to-empty semantics. Only correctly normalized ordered recipes support the intended interpretation. This is accurately disclosed in the author's report.

`append_then_deliver` proves the same selective recalculation property after publishing a supplied parent computation and marking its name. It does not prove that child presence triggers the native flag, that flags survive until every scope is visited, or that a requested layout flush is delivered. `childless_fastpath` is an empty-descendant identity; it does not certify all native leaf obligations, particularly reversed-counter initialization. Existing native invalidation and arithmetic remain separate premises.

Examples distinguish reset identity, sibling-versus-nested suffix selection, set/increment/use, full stacks versus scalar output, rebinding current sources, clean unrelated names and an empty intermediate owner path. The child-before-parent false control intentionally violates Ordered and demonstrates the total reference's wrong input, not an implemented scheduler defect. No negative-control claim is based on a parser or reduction failure.

Native mapping is plausible for the intended patch: per-name shared dirty state, scope reconstruction, and parent-before-child traversal provide the relevant mechanisms. They are source-reviewed correspondence arguments, not extracted C++ or a full refinement proof. Mathematical Int, supplied worklist/cache alignment, actual scope recipes, reset-stack provenance, pointer lifetimes, text formatting/notification and scheduler delivery remain unproved. Reversed/content-based counters and dynamic arbitrary subtree edits are outside this model.
