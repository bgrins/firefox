# Simultaneous CSS root/child startup: conversion and delivery boundary

The matched post-calibration observation establishes late child46 at first, settled and afterCalibration in both broad and selective apps, with later root32/plain64 controls. It does not establish the device value during initial endpoint conversion, or that a post-publication EFFECT_PROPERTIES task reached this child. Initial-lane results vary across launches. AnimationOnly is not synonymous with FinalAnimationTraversal.

## Exact source chain

1. In normal `finish_restyle`, `process_animations` queues CSS_ANIMATIONS and EFFECT_PROPERTIES when animation declarations need updating. It returns early for existing-style AnimationOnly work. The queue call precedes `data.set_styles`; subsequent root handling publishes the root style and changed font size to Device. This is source order within one element, not a total order among worker tasks.
2. `SequentialTaskList::drop` executes pending tasks. `GeckoElement::update_animations` fetches the element's stored primary style at execution; the task does not retain a separate new-style snapshot. `Gecko_UpdateAnimations` handles CSSAnimations before EffectProperties in that invocation.
3. `nsAnimationManager::BuildAnimation` builds declarations, creates the CSS keyframe effect, and calls its base `SetKeyframes(..., aBuilder.Style(), ...)` before associating it with the new CSSAnimation through `SetEffectNoUpdate` and starting/pausing it. `SetKeyframes` calls `UpdateProperties` when style exists. This can be an initial conversion before the new root animation has been applied by an animation traversal. Creating the root effect is not itself Device root-size publication.
4. `UpdateProperties` always calls `BuildProperties` before checking whether the resulting property array changed. `BuildProperties` obtains CSS computed-keyframe structure, then calls `KeyframeUtils::GetAnimationPropertiesFromKeyframes` and Servo computed-keyframe conversion. `CSSAnimationKeyframeEffect::GetComputedKeyframes` generates offsets/missing endpoints but preserves declaration blocks; it does not permanently replace 2rem with an initial numeric value. The fixture supplies both endpoints, so missing-endpoint/base-style generation is not its ordinary path.
5. `Servo_GetComputedKeyframeValues` creates the animation conversion context. For this ordinary child, Rem uses `context.device().root_font_size()` and effective zoom. The Device getter both loads the atomic and marks root-size usage. An instrumentation read must reuse that existing load, not call the getter again. The separate root-self-context repair is not needed to select the ordinary-child branch.
6. In the same Gecko task, EffectProperties obtains the current EffectSet and calls each effect's `UpdateProperties` again. This can still precede a later traversal applying the newly created root effect. On subsequent delivery, even unchanged specified keyframes are recomputed by this route: `SetKeyframes`' equal-input early return alone cannot explain retained46 if EFFECT_PROPERTIES actually reaches this effect using current root32 metrics.
7. When a rebuilt property array differs, `UpdateProperties` assigns `mProperties`, updates effect/cascade state, notifies the animation and requests a Layer restyle. A computed64 result does not by itself prove the resulting animation rule was sampled and installed before the getter.

`ServoStyleSet::StyleDocument` performs its normal traversal and conditionally a second traversal after `EffectCompositor::PreTraverse` starts animation work. Selective `Servo_TraverseSubtree` can perform an AnimationOnly traversal followed by the caller's flags; its post-join handoff depends on a fresh returned ancestor-font hint. Those facts identify possible opportunities, not the actual late-start sequence. The actual signal, selected traversal root, normal target recascade and task delivery remain unobserved. The broad handoff would already force descendant recascade if reached; adding membership alone is not an explanation for both variants' persistent late failure.

## Smallest useful discrimination

After the exact original observations, including afterCalibration, force a target-only normal style update with a predeclared non-font class (background-color), then read target fontSize first. Retain the existing child CSSAnimation object and compare it after the read; do not recreate the animation or alter keyframes. Retain the old assertions and add only an observational field. Read background-color/root/plain/effect controls afterward. A same-effect change to64 demonstrates a later target update can repair the observable value without a new root seek. Remaining46 does not prove failure to rebuild: conversion input or subsequent rule installation can still be responsible. This experiment changes the scheduling history deliberately and must not replace the original regression observation.

For native discrimination, first correlate root/child/effect identity and the existing root publication, traversal flags and task mask. Add only the following conversion boundary if needed:

- At `KeyframeEffect::UpdateProperties`, log the effect/target identity, caller reason (construction versus delivered update), already-built font-size segment values and the existing `propertiesChanged` result. Both identical2rem endpoints make a46/64 distinction direct. Do not invoke serialization APIs that recompute style.
- At the existing child Rem conversion, log the already-loaded reference size and result, tied to the enclosing conversion's target. Do not perform another Device getter or metric lookup; these carry usage effects. Distinguish a missing post-root32 call from a post-root32 call that actually loads23.
- Only if a current64 conversion is installed into `mProperties` yet target remains46, trace `RequestRestyle(Layer)` through EffectCompositor pending/restyle processing to the later sampled animation rule. Queueing, rebuilding properties and installing a sampled rule are separate boundaries.

Possible outcomes remain separate: no later rebuild; only rebuilds before root32 publication; a later conversion reading23; a64 rebuild not reaching the sampled style. Current numeric evidence does not choose among them. Paused status is not an excuse to skip dependency recomputation, but this report makes no new normative adjudication or bug count.
