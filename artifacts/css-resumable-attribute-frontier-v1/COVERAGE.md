# Remaining entry coverage

| Entry | This successor |
| --- | --- |
| Retained font-selection provider is inside an actual attribute body and requests an unresolved custom property | `resolve_metric_lookup_inner` enters a guarded custom frame with that exact request's ancestry. Its reached custom children inherit their actual provider request ancestry. |
| Guarded custom frame reaches a typed attribute | Owned raw capture and per-URL parse feed the provider's attribute body directly. The occurrence carries its syntax/URL/consumer and guard ancestry; no name-only global attribute result is substituted for it. |
| Ordinary custom-property root entered by `poll_root`/`start_frame` | Still starts with legacy `ReferenceWalk`, not a new property invocation guard. Its reached Attr links still use legacy graph/cache handling. This is unfinished integration. |
| Ordinary priority/eager reference discovery and eager attribute-map preparation | Unchanged. Their global attribute setup and selected-reference walk are not replaced by this capsule. An eager prepass can already have queried raw text before the owned snapshot route; one-read tests concern the owned snapshot route, not the entire cascade. |
| Owned provider reaches an already-active legacy Attr with no established guard ancestry | Remains unresolved under the existing boundary. A graph index or historical CycleSettled result cannot manufacture invocation ancestry. |
| Already completed custom property | Existing named storage-finality receipt remains authoritative. This is not a proof that every earlier numeric computation was correct. |
| Root retirement | Existing frame/action/lookup/claim retirement assertions still apply. A guarded frame retains its engine through its existing frame lifetime; guard marks are not reusable cross-root cache evidence. |

The next implementation boundary is ordinary/root discovery and consumer identity, including eager setup. It must create the actual guarded body at the correct invocation entry and preserve its consumer/source occurrence through publication. Merely attaching all active Tarjan names, clearing old flags, or treating missing maps as invalid would not complete that work. This capsule therefore provides a functioning reached side-frame route, not a full attribute graph/attempt join or a browser repair.
