The exact captured PresShell NeedFlush checks style, requested throttled-animation and applicable layout flags, not the compositor map. Its flush implementation calls PostRestyleForThrottledAnimations and then ProcessPendingRestyles before clearing mNeedStyleFlush. Thus setting a flag during a transaction requires an ownership/clearing rule; a flag which that same transaction clears is not a durable wake-up.

The captured StyleDocument calls PreTraverse only after its no-root guard, then performs its first traversal and another compositor PreTraverse before a conditional traversal. The surrounding DoProcessPendingRestyles loop clears the old root during post-traversal and can repeat for newly created invalidations. The Rust wrapper can itself run animation-only and ordinary traversals. There is no global two-pass bound to replace. Any proposed same-query follow-up must survive the existing root-clearing points and obey the no-reentrant-flush/element-borrow restrictions, rather than invoking PostRestyleForAnimation from an unsafe scope.

In the sealed tri-state code, Pending and DispatchAttempted are both PreTraverse-eligible; Throttled is conditional. PreTraverse posts explicit animation hints, calls WillComposeStyle and removes entries. Removal is consumption intent, not proof that fresh values were composed. Wrong-document/no-effect removal and full-map clear must be distinguished from normal consumption. DispatchAttempted means only the PresShell call is about to occur. A stale return after apparent consumption may instead require examining effective timing, rule generation, or computed/frame style caching; indiscriminately posting again is not justified.

For each aligned first query, retain target/pseudo/cascade identity, entry and return pending snapshots, each request/post deferral, shell gate flags, available root/traversal fields, explicit hints and removal reason, and the returned string. Compare ordinary versus animated rem and lh cases and the immediately correct width controls. Width can request a layout flush; rem can cause broader root-font invalidation. Neither is an interchangeable control for lh opacity.
