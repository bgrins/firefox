# Selected registered values and invalid-initial dependencies

This is the default-aware successor to sealed V1, which remains immutable and held from activation. It is a standalone three-source repair draft against the committed provider `8a4adc`, original cascade `2cc7b3`, and original registered-value implementation `81f8cb`. It does not include animation-provenance changes, contextual attr request/session storage, priority traversal restructuring, or the held provider edit. The exact five-case WPT and genuine manifest are copied from the sealed `css-registered-color-scheme-dependency-review-v1` package. No native checkout, build, browser, Git, or canonical controls were changed here.

The observed Firefox failure has a concrete source explanation: a registration containing any `<color>` clause currently adds a ColorScheme graph edge even when the successful clause is `<custom-ident>`. An otherwise unused attr fallback admits the `color-scheme` declaration into the existing dependency graph; the extra edge can then turn that valid identifier dependency into a cycle. Root reports Firefox 158 fails the two union-plus-unused-attr cases and Chrome 156 passes all five. Those measurements motivate this draft; a native before/after run is still required to attribute the repair.

`native.patch` separates conservative admission from selected computation. The original coarse color test still defers possible work, and also defers `<image>` alternatives because they can contain color computation. After the existing selected-reference DFS returns with this node alone on its stack suffix, `prepare_custom_value` performs existing substitution and parses the first completely matching registration clause. It retains that specified AST. Only the AST classifier supplies the ColorScheme edge. The same AST is converted after graph dependencies close; it is not reparsed against changed inputs. A custom-reference cycle skips preparation and follows existing loop handling.

The parser's ordered `try_parse(parse_entirely(...))` determines the successful union branch and multiplier. The classifier therefore handles both ambiguous first-match ordering and space/comma repetition without token-name guesses. A failed alternative contributes no AST nodes. The target scheme is read by System and LightDark colors; relative color origins, all color-mix items and contrast-color recurse. CurrentColor remains symbolic, absolute colors are independent, and the body-color quirk reads the device body color rather than this element's scheme. Images recurse through gradient stops, cross-fade items, image(color), and every image-set item, matching the current computation order before image-set filtering. An image LightDark itself depends on scheme. Other component kinds and universal token values do not add this edge.

The ordinary `apply_substituted_value` tail is mechanically extracted without changing its branches. CSS-wide selections select the existing parent/initial value through that tail. Invalid substitution or registered parse is different: the clean handler copies a parent value only for a nonroot inheriting registration; for a non-inheriting registration or the root it parses and computes specified initial CSS. V1 incorrectly treated that entire Invalid case as edge-free. V2 mirrors the exact condition, parses that selected initial using its own URL, default attr taint, actual property ID and the existing AllowComputationallyDependent::Yes runtime mode, and retains a successful initial AST. Its scheme dependency is classified just like an ordinary selected value, and the same AST is computed after dependency closure. Identifier initials in color unions remain edge-free. The initial result does not acquire attr taint from the discarded invalid expression. A nonroot inherited copy, absent initial, or failed initial parse retains the existing handler; failed parsing performs no scheme-dependent conversion. A registration's inherits:true flag alone is therefore insufficient to choose the parent-copy branch. Attr-security taint is supplied to the retained parse and ORed into the computed wrapper as before. No animation taint field is added. The existing unit-flag and non-custom-declaration admission rules are retained; admitting images can now route them through those existing rules. This draft does not claim exact selection for all non-color dependency kinds or repair the old priority/attr closure limits.

Selected var/attr fallbacks use the existing walker and substitution semantics. A suspected early-computation problem was checked and rejected against the exact provider: typed attr calls `parse_typed_value`, which returns a specified registered value, then serializes it with `to_variable_value`; this route does not call `to_computed_value`. Consequently preparation does not first convert an attr-sourced System color using an old scheme. This is not a fix for the separate consuming-property context bug or for all pre-existing attr cache/dependency behavior.

`CustomDeclarationValue::Parsed` keeps its existing immediate computation path. The inspected producer `ComputedValue::to_declared_value` constructs it by uncomputing an already-computed value; the upstream identifier census found no additional constructor. System/LightDark color computation has already selected its result on that path. This is a bounded source argument, not a type-system invariant that arbitrary future Parsed values cannot contain new dependencies. Initial-value construction, animation conversion, and this roundtrip remain native preservation gates.

Validation is deliberately separated. V1 pure check `2e565b` / `5b54fd`, exit 0, authenticated the three sources, parsed all three postimages with installed rustfmt 1.97.1, and applied/reversed the exact patch in removed scratch. The exact classifier method passes 16 operation tests with substituted AST/container types; four mutants fail (all colors dependent, dropped relative origin, dropped image-set children, dropped repetition). These checks do not run the real registered-value parser, instantiate Stylo types/borrows, or execute the dependency scheduler. The five fresh admitted color/image source bodies are each joined to HEAD by root; the specified-image alias source is an explicitly historical frozen body. Servo-only PaintWorklet computation is not independently validated by the Gecko-configured harness. Native compile, real parser/graph preservation, and before/after WPT execution remain required before calling the patch landable or accepted.

The next validation should run all 42 callbacks: the exact five observed cases, the separately sealed 23-case preservation page (`47fbc7cc`), and the 14-case cycle/default page (`0be91be8`). It includes invalid System/light-dark initial ordering and an independent identifier initial in a color union. Those dynamic-initial checks are explicitly source-order preservation research, not a new normative ruling on initial-value timing. `PRESERVATION.json` retains additional suggested coverage. In particular, a System color selected by color-first versus ident-first syntax, repeated mixed colors, nested image colors, valid and invalid selected var/attr fallbacks, and CSS-wide inherited/default values must not be reduced to the literal light/dark reproducer. Existing source/app preservation and original-vs-candidate execution remain root-owned.

V2-DELTA.patch is the complete narrow successor delta. Actual V2 check ce8643/e9c6a2, exit 0, passes three-file syntax and exact patch roundtrip with removed scratch, plus the unchanged 16 classifier operations and four rejecting mutants. Those operations do not test the new default-selection semantics. The final post-edge source revision subsequently passed d70ded/6853e2, exit 0, with the same syntax, exact patch roundtrip and unchanged classifier checks. The acyclic-only V2 draft still missed SCC invalidation, because `Context::handle_loop(Custom)` calls the same invalid handler. A custom-reference cycle skips ordinary preparation; a selected length can also become cyclic later through FontUnits. The final hook checks cycle membership only after selected custom and non-custom edges have been visited, before publishing lowlink or popping the component. Self-ref, a lowlink to an active ancestor, or a remaining unfinished descendant suffix identifies a cyclic node in this existing traversal. For that node, when the selected scheme edge has not already been visited, the helper classifies the invalid handler's actual initial and adds the scheme edge through ordinary `visit_link`. That call can enlarge the SCC and updates lowlink/self-ref. A prepared ordinary declaration is never committed when the final `in_loop` result is true.

This late helper performs parse/classification only. Existing `handle_loop` bookkeeping and invalid-value application are unchanged: cyclic default application reparses the same initial CSS using the same immutable registration syntax/URL/property ID/runtime parser mode. The required lifetime assumption is that these inputs stay fixed during the synchronous cascade, not that all values are settled. Acyclic invalid defaults retain their AST directly. No direct `ensure` bypass, SCC pop/reopen protocol, or contextual attr session machinery is introduced. A cycle formed by the selected scheme edge already has that edge; a cycle formed by FontUnits is handled by the new post-edge hook. The separate cycle/default probe distinguishes these paths and mixed unregistered members. Scheme-backedge endpoint controls alone do not prove SCC enlargement. Existing priority-callback closure/default-publication limits are not proved away by this patch.

The earlier acyclic-only delta/check are retained as preparation history. The initial check receipts do not validate the final post-edge hook; final checks and independent source review are recorded in CHECK.json when complete.

The newly admitted pure-image route is a distinct production boundary: if native before/after evidence shows a separate pure-image bug, that change and its tests should be isolated from the overbroad color-union fix. Recursive image classification can still be needed when an image is selected from a union containing color. No split or accepted regression count is asserted before those observations.
