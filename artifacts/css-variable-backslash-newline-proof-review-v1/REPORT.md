## Mathematical review

Read all new definitions and proofs in ProtectedSpan, PreservationGuard, ProtectedMetadata, ProtectedBoundary and ProtectedWitnesses, the calibration modules, and the already accepted unchanged Span dependency contract. The right-to-left reference suffix partition never reads the source-shaped accumulator or its trailing length. The extent theorem uses maximal whitespace coalescing to connect this reference to the immediate-previous-token scanner. Byte partition and first/last metadata results then follow without assuming the expected stored suffix.

The persistent standalone flag is not equated to the integrated scanner's final previous-token bit: the saved-newline witness correctly gives different final bits. The theorem compares the preservation decision instead. A backslash delimiter cannot be the last native token under the follower admission; without that condition the explicit counterexample makes the decisions differ. Whole constructor output equality is expressly excluded because the standalone versions retain the separate escaped-SP/HT trimming defect.

The metadata theorem requires nonempty raw spans and initial readiness for the first token. It preserves terminal WhiteSpace metadata when the newline is retained and selects the last nonwhite class only after actual trimming. EOF completion and retained-reference slices have explicit compatibility/bounds premises; the theorem does not construct native EOF repairs or derive native reference endpoints. Recursive scanner locality is source-reviewed, not universally lowered into this model.

## Lexical-bit and nonvacuity challenges

WellFormed is deliberately one-way: a true lexical bit implies Other plus raw backslash. It does not establish the converse. Independent kernel examples show both marked and unmarked raw backslash satisfy WellFormed, yet the unmarked case drops the newline even while the other main abstract premises hold. Therefore exact native DelimBackslash projection remains essential. The report states this clearly; the native projection computes the bit from Token::Delim, independently of serialization class.

Additional examples exercise an inhabited mixed-prefix/CRLF/space/tab component satisfying the full contract, a missing follower, two adjacent whitespace tokens, all-whitespace input without initial readiness, an empty whitespace span without positivity, invalid EOF compatibility, retained-reference slicing, comment reset, and the standalone escaped-whitespace difference. These are model challenges, not extra browser observations or native semantic mutants.
