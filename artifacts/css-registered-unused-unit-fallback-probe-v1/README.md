## Frozen source finding

`SOURCE-EXCERPTS.json` contains exact base/V4 excerpts and their hashes. `parse_declaration_value_block` bubbles fallback flags into the enclosing References. `find_non_custom_references` admits the raw unit flags for a LENGTH-capable registration. `visit_value_references` ORs the root flags before checking whether the primary is valid; avoiding traversal of an unused fallback therefore does not remove its previously bubbled unit bit. The FontUnits mapping goes to FontSize. V4's selected-AST block removes/refines only COLOR_SCHEME and is gated by COLOR-capable syntax; this pure-length case is outside it. Hence `--v→FontSize→--v` remains source-supported even with a valid absolute primary. This is a hypothesis about the observable endpoint, not instrumentation of an actual traversal.

This source concern is not newly discovered: the unfinished `css-animation-contextual-attr-proposal-v2` explicitly describes selected-token unit staging instead of unused fallback inventory. That broader proposal was not accepted or installed here. The current source note and narrow portable probe isolate that prior unresolved boundary; they do not claim an accepted fix was lost.
