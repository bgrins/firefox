# Attribute dependency publication source review

Scoped source GO for a native compile and controlled original/candidate/restored comparison. The final68-payload capsule was authenticated against manifest98dba9cb6e0999e1672a86f49b099755c72ea22ffa9ede323fcc362779e86204. No concrete correctness blocker found in the eight-path draft. This is not native acceptance, a performance measurement, a same-flush proof, or complete pseudo/lifetime coverage.

The reviewer did not author this native proposal or its lifecycle fixture. The reviewer authored related attribute preparation models, diagnostic capture/verifier code, and earlier tree-counting prototypes. Those related artifacts are context, not independent validation of this patch.

The Rust tracker exists outside the keyframe loop, and query records a namespace-qualified reference before lookup. Therefore the returned boolean includes earlier endpoints and absent/fallback-producing queries. It does not infer dependency from the output value or taint. Preparation may query declarations later discarded by animation filtering, so extra sensitivity is conservative. The patch adds no borrowed pointer or allocated ownership across FFI: cbindgen regenerates the sole exported return type, and the sole caller copies a bool through local C++ output references. Missing target/PresContext paths initialize false; full Gecko compilation remains required to verify generated declarations and all ABI/type integration.

UpdateProperties publishes the returned bit before its equal-value early return, including true-to-false changes. Existing taint comparisons and base-style work remain. The copy constructor copies metadata alongside cached properties. Changed keyframes and new targets mark sensitivity conservatively until computation. UpdateBaseStyle discards its separate computation result and cannot clear metadata associated with retained mProperties. No lifetime extension, frame pointer, or cycle-collection edge is introduced. Existing copied-keyframe/reentrancy assumptions remain external.

Mutation uses the live EffectSet OR. Removal of one effect cannot clear another effect's bit, and no cached aggregate requires synchronized updates. AttributeWillChange already runs outside traversal; normal RESTYLE_SELF survives animation-only hint removal, unlike RECASCADE_SELF. Normal matching queues EFFECT_PROPERTIES even with unchanged ordinary values; installed129 also queues it for CSS animation updates. This is source correspondence for intended same-flush delivery, not an observed candidate result. Pending cancellation and target/pseudo histories still need actual browser validation.

GetElementPseudoPair maps concrete generated pseudo nodes to the corresponding originating-element effect-set key. The existing ForEachElementAndPseudo iterator has limited coverage under bug 2037724; the patch preserves that limit and does not repair named view-transition owner selection. The new fixture tests ::before in four CSS/WAAPI ordinary/registered modes, not ::after, ::marker or all generated pseudo kinds. ClassAttributeWillBeChangedBySMIL still calls TakeSnapshotForAttributeChange directly and bypasses MaybeRecascadeForAttrFunction; this patch does not establish correctness for every attribute-change mechanism, and any ordinary attr impact of that adjacent path is not separately demonstrated. Cancelled sole effects retain cached properties while unregistered; mutations during dormancy followed by replay without a new mutation are explicitly outside this patch. An equal specified-keyframes early return likewise does not promise freshness of a stale cache.

Cost: each attribute mutation now scans registered effects for the element and the existing enumerated pseudos, stopping at the first sensitive effect. The boolean intentionally loses name/namespace precision: unrelated attribute changes on a sensitive target request normal matching, not just recascade. No global traversal, retained name list, or new effect-set allocation is introduced. The patch trades this bounded extra matching for simpler ownership; throughput has not been measured.

The22 new cases cover initially absent queries, equal-valued replacement, cancellation with a remaining effect, ::before, cloning and styled/unstyled retargeting. They save target results before ordinary control reads and force normal recomputation only after saving observations. Retain installed130's24 landing cases, the12 actual retained/fresh/namespace mutation cases, existing effect-copy/target/setKeyframes/style-change/cancellation controls, and existing attr-taint/URL controls in the comparison. Candidate must complete target histories; an early setup failure does not validate later steps. Useful separate coverage gaps are attr-to-literal metadata clearing, unstyled setKeyframes replacement, other supported generated pseudos, and an independently calibrated dormant-replay discriminator. These do not justify silently broadening this patch's claim.
