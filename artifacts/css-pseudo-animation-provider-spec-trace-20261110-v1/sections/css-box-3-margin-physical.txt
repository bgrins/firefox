 3.1. Page-relative (Physical) Margin Properties: the margin-top , margin-right , margin-bottom , and margin-left properties 
 
 
 
 Name:
 margin-top , margin-right , margin-bottom , margin-left 
 
 Value: 
 <length-percentage> | auto
 
 Initial: 
 0
 
 Applies to: 
 all elements except internal table elements 
 
 Inherited: 
 no
 
 Percentages: 
 refer to logical width of containing block
 
 Computed value: 
 the keyword auto or a computed <length-percentage> value
 
 Canonical order: 
 per grammar
 
 Animation type: 
 by computed value type
 
 Logical property group: 
 margin 
 
 These properties set the top, right, bottom, and left
 margin of a box , respectively. 
 Negative values for margin properties are allowed,
 but there may be implementation-specific limits. 
 Note: Application to internal ruby boxes [CSS-RUBY-1] 
 is not defined in this specification.
