# Source and test boundary

The exact e86 snapshot is the authority for the native patch. ComputedValue::to_declared_value in properties_and_values/value.rs copies wrapper attr_tainted into explicitly_attr_tainted when the universal inner value does not already carry it. substitute_references_if_needed_and_apply directly inserts a universal reference-free value; under a typed registration it instead calls apply_substituted_value → substitute_internal. The no-reference chunk returns default aggregate taint. The repaired wrapper ORs the explicit bit after successful substitution and before apply_substituted_value/into_value. into_value transports aggregate taint into typed parser input and the computed value. Existing comments identify animation recascade as the reason the explicit field exists.

The browser probe's saved source trace supplies the transition endpoint route through uncompute and keyframe map construction. Native stack instrumentation of this exact callback is not supplied here. Archived e86 and release158 observations independently demonstrate the calibrated visible discrepancy; the proposed source cause is supported by the captured control flow, not a proof that no other code participates.

SUBSTITUTE-BASE/CANDIDATE are exact extracted method bodies. TestSupport defines simplified native shapes and a delegated do_substitute_chunk contract, whose explicit invalid/selected_taint result is controlled per test. It does not parse CSS, build a Stylist/Context, produce real animation keyframes, or establish the full substitution engine. The six tests establish the actual wrapper's propagation contract; four compiled controls remove explicit transport, overtaint from syntactic ATTR, overwrite existing selected taint, or swallow Err. The syntactic-unused control represents a clean resolved primary with an attr-bearing unused fallback; it is not a new native fallback-parser test.

The empty test proves the wrapper emits no new direct range while preserving aggregate taint; it does not prove every preexisting interval predicate. The source patch does not modify intervals. The separate Lean23/9 model proves conditional parse transport and remains outside native refinement.

The WPT has actual DOM/CSS/animation semantics and must still be run on archived baseline and a newly built candidate. Its clean literal control changes A→B to guarantee distinct endpoints. The unchanged-token registration-only probe is intentionally omitted from the portable roster. Native source tests and WPT expectations use no external receiver or secret value.
