# Preserve explicit attribute taint during typed recascade

This standalone candidate fixes an observed taint loss when a universal custom-property transition endpoint is re-cascaded after registration changes to <string>. Independent saved observations on signed e86 and Firefox158 both show the attribute-derived start endpoint accepted by image-set at25%, with blocking restored at75% and after cancellation. Actual CSSTransition, paused progress, endpoint strings, effective registration, stable-typed and clean-literal controls distinguish the result from a missing transition. OBSERVATIONS is a compact independently authenticated projection; it does not rehash the browser archives or assert network disclosure.

The captured ComputedValue::to_declared_value already transfers wrapper provenance to VariableValue.explicitly_attr_tainted. Universal direct application preserves it, but typed registration calls substitute_internal, whose reference-free chunk carries default aggregate taint. Substitution::into_value consequently receives a clean bit before typed parsing. The patch ORs the explicit bit into every successful substitution result; failures remain Err and selected child taint remains set. It uses the explicit bit, not syntactic ATTR flags, so unused fallbacks do not become provenance.

No direct AttrTaint interval is added or changed. Empty output retains its aggregate bit without synthesizing a direct interval. Aggregate provenance is distinct from the existing half-open interval overlap rule; a zero-length range does not overlap adjacent text. The real typed into_value path already constructs full-value parser taint from the aggregate bit; this candidate restores that input. The wrapper tests delegate chunk production and model native types, so they do not establish parsing, animation, interval or native compiler refinement.
