# Substitution suspension: effects and smallest reusable boundary

Source audit of sealed f0d21abe cascade and provider90ac. The existing substitution API cannot suspend: get_var(None), a recursive Err(()) and absent typed-attribute cache values can reach fallback/invalid handling. A proposed Pending/SettledInvalid/SettledValue lookup must preserve Pending through every caller, separately from genuine invalidity. No implementation, test execution, browser result or new native acceptance is supplied here.

## Minimal continuation boundary

Prefer a retained continuation inside the actual substitution walk, ending before final property parsing. This avoids a second evaluator or a blanket rollback of shared style state. Each frame needs the owned source/URL/reference identity, slice bounds, reference cursor and before/after-append phase, accumulated CSS/token/taint/budget state, recursive active-name path, selected primary/fallback branch, and any raw attribute or env result already obtained. On Pending it retains the demanded node and stops before fallback. On resumption it consumes the settled reply for that same reference and proceeds once.

The source/map currently provides borrowed Cow values and references. A suspended frame cannot hold those borrows across scheduler mutation of the map; retain immutable Arc sources or owned substitution strings and stable node/registration identities. An immutable input lease is an alternative only if it covers the exact selected reads and branch decisions and remains valid while prerequisites finish. Scanning all reference/fallback inventory first is not an adequate lease: it can create losing/fallback dependencies or perform unnecessary reads. The existing ReferenceWalk acknowledgement alone is not the actual substitution-and-parse receipt.

The selected declaration's eligibility/rollback state and context must still be validated before final publication. During a normal same-context wait, preserve prior conservative dependency marks and query accounting rather than rollback. If invalidation requires abandoning the attempt, no parsed declaration or shorthand cache output may be published from it; that is a separate invalidation policy, not permission to silently reuse stale reads.

The surrounding API must also become suspension-aware: VariableDeclaration::substitute_variables currently turns substitution Err into CSS-wide Inherit/Initial; resume_font_selection immediately retains the returned declaration. Pending must instead retain its waiting state and must not advance the candidate, select a fallback, mark seen/ensured, apply hooks, or call invalid-at-computed-value-time handling. Custom-property PreparedCustomKind::Invalid and apply_substituted_value must likewise receive only terminal invalidity, never Pending.

## Distinguishing controls (proposed, not run)

Use the actual substitution primitive with a controlled publication-state provider. For font-size: calc(attr(data-prefix px) + var(--later, attr(data-fallback px))), set data-prefix=3 and data-fallback=999. Make --later Pending, then SettledValue(17px). First and repeated pending polls must produce no fallback query, no property declaration, no invalid-at-computed-value-time action and no cache publication. Resume must produce the equivalent of calc(3px + 17px), retain the attribute taint, and query the prefix only once within this substitution attempt. Baseline query counts exclude any independently existing setup/walk calls. A mutant mapping Pending to invalid instead produces the fallback expression and must fail.

A separate SettledInvalid primary must query the fallback and produce calc(3px + 999px); a permanently absent variable with authoritative settled-invalid state has that same route. A recursive unresolved alias must propagate Pending rather than turn its Err into fallback. Include a genuinely settled cycle and a valid empty primary so that suspension handling does not erase existing invalid/empty distinctions.

Additional controls: adjacent var(--a)var(--b) separator preservation; attr-tainted URL rejection after suspension; exact taint offsets after a prefix; output-limit boundary; one already-read env prefix; shorthand source-identity and logical alias isolation; property-index-scoped random keys with stable occurrence order; and no duplicate computed dependency/application effects. None of these controls has been executed by this audit.
