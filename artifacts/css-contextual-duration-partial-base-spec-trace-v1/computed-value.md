## Content

The **computed value** is the result of resolving the [specified value](https://drafts.csswg.org/css-cascade-5#specified-value) as defined in the “Computed Value” line of the property definition table, generally absolutizing it in preparation for [inheritance](https://drafts.csswg.org/css-cascade-5#css-inheritance).
