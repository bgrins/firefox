This report script reads only explicitly pinned, frozen runtime manifests. It does not open the running candidate output or perform current-state guards. Both actual completed runtimes are authenticated in the finalized INTERPRETATION.md, OBSERVED.json and VALUES.tsv. Candidate failure is retained; no missing aggregate receipt is fabricated.

Each role retains acquisition before/after ready and all four phases, including both getter orders. The report records primary/repeat/current membership differences separately from changes between original and candidate. Calibration status comes from the actual callback assessment and optional record receipt; a missing receipt is not converted to success.

The fixed 2s literal and script-override controls check 750ms, progress .375 and the authored font/opacity references. Self-dependent values, identity and membership remain observations. Sequential equality is not proof of atomic composition, a scheduling step, convergence or a cycle. The existing native proposal and earlier three-case evidence are unchanged.

Run report.py with --original DIRECTORY MANIFEST_SHA256 and, only after completion and freezing, --candidate DIRECTORY MANIFEST_SHA256. Output goes to stdout; the script never writes either runtime.
