# Registered font metric demand probe

Three portable callbacks compare registered 1em, registered 1ch with changing family, and registered 1ch with changing selected weight face. Each uses explicit 20px and 30px font sizes and two loaded WPT fonts. The artificial weight family maps 400 to Ahem and 700 to Noto Sans regular. Existing font files are copied unchanged as runtime resources; no installed OS font metric or numeric character-width constant is assumed.

Each callback creates an isolated document and loads its two required faces before creating targets. Each phase writes the selected font style, reads the registered target first, and only then reads literal width references and other diagnostics. All four phase records are collected before assertions. The controls first require positive character widths that differ by more than 1px between the selected faces at each size. Target values then must match same-style literal widths within 0.02px, allowing width layout rounding without masking the calibrated metric difference. The 1em case also equals the explicit font size.

This guards a proposed narrowing of font readiness: 1em needs the chosen size, whereas 1ch must retain selected font metric dependencies, including the selected weight. The weight callback may discriminate an existing missing dependency, but no browser/native observation or defect is claimed. No alias case, preferences, metadata expectations, animation or custom transport is added. Ordinary assertion failures include complete collected phase JSON; PASS raw records do not archive hidden phase values.

The artifact supplies a genuine WPT manifest, inert callback inventory and underlying WPT path/content lint. Mozilla's mach lint excludes artifact fixture paths, so the same checked-in WPT lint functions are called directly without Git traversal or a browser. The initial draft lint rejected a custom Ahem face because the standard Ahem stylesheet was absent; the fixture now uses /fonts/ahem.css. Ahem/font assets are existing WPT resources, not new font files intended for publication. Fresh baseline/candidate observations and peer review remain required before using the probe as evidence.
