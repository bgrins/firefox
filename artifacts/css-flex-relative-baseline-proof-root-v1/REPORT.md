## Remaining assumptions

- Normal-position property installation, removal, freshness and lifetime are not proved. The selected donor's property must describe its normal geometry when read.
- Selected lines, raw item order, resolved ascents, non-reentrancy and frame geometry are supplied by native providers. The reference preserves existing donor policy rather than proving all CSS baseline selection.
- Defined signed32 arithmetic and a non-sentinel result are necessary for the claimed delivered baseline. The full downstream synthesis/publication/parent lifecycle is not derived by the local assignment theorem.
- The parent-displacement equation assumes an unchanged common parent baseline and alignment policy. Orthogonal donors, sticky updates and fragmented donor readiness remain open.
- Lean's kernel and installed libraries, compiler/runtime, OS, source-to-model interpretation and facade providers remain trusted. Finite native agreement is not a universal compiler or provider proof.

The new scroll-provider defect changes the natural-donor patch's readiness. This relative-position patch introduces no new natural-baseline query and leaves existing ascent providers unchanged; its separate normal-position correction remains justified within the stated domain.
