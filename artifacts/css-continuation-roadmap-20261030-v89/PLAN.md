# CSS and Stylo verification — V89

The latest work separates animation timing input selection from animation-taint substitution. Eight browser runs completed with their original failures preserved and temporary profiles removed. The accepted native-fix count remains 149. No snapshot or taint proposal has been accepted as a native fix.

## Findings

The local original six-case baseline passed five callbacks and failed the tainted-duration fallback callback. Its three lifecycle/preservation controls pass: fresh descendant rem widths, collection destruction/recreation, and duration-list changes with script ownership. Release Firefox and Chrome also fail the tainted-duration fallback oracle, but differ in timing selection. Firefox retains the old 1s effect; Chrome updates to the new 2s ordinary value. Current CSSWG discussion explicitly distinguishes property-name taint in the draft from value taint in Blink. That shared specification/implementation gap remains separate from the stale-timing repair.

The follow-up removes animation-control dependencies: a fixed 2s driver animates an unregistered variable used by direction or writing-mode. Both the recorded local original and release Firefox fail the direct and alias cases for both sinks, passing the two literal controls. Chrome passes all three writing-mode cases and the direction literal control, but fails the direction direct/alias mutation cases. Writing-mode is the strongest discriminator: the animated value is vertical-rl, the mutated ordinary value is vertical-lr, and the fallback is horizontal-tb. Firefox consumes vertical-rl; Chrome preserves the asserted horizontal-tb fallback. The strengthened writing-mode test changes its fallback to non-default vertical-lr while retaining animated vertical-rl and initial ordinary horizontal-tb. Chrome still passes both direct and alias cases; Firefox still consumes vertical-rl. This rejects an incorrect implementation that merely discards the declaration and returns the initial value. It is a concrete separate Firefox substitution defect candidate under the active same-element scenario. It does not settle global keyframe-name marking or inherited taint policy.

Chrome's direction ltr→rtl trajectory cannot distinguish the ordinary from animated value because both are rtl after mutation. Do not infer its internal route. The earlier release Firefox auto-duration failure is an unsupported-feature assertion; Chrome's script-duration/auto failure needs a separate reduction before attribution.

The new isolated Lean model compiled six theorems and rejected five false controls. It separates coherence of the old cache, honesty of captured input, and correctness of selected timing. Cache freshness or cache/applied equality alone does not certify taint-correct substitution. This extends the model's obligations without proving native implementation or increasing canonical coverage.
