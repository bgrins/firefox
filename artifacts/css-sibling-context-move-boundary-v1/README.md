# Sibling context across moves

Prepared observation-only WPT: 18 callbacks, one page, three snapshots and nine target records per callback (162 records total). This package does not establish a new defect or native acceptance. Root owns browser execution.

The cases combine `insertBefore` reorder, `moveBefore` reorder, and `moveBefore` reparenting with width, opacity and inherited font-weight, each using sibling-index or sibling-count. Reordering preserves count three while original target order has indices 1/2/3, then 2/3/1, then 1/2/3. Reparenting has counts 2/2/2, then 1/3/3, then 2/2/2; indices 1/2/1, then 1/3/1, then 1/2/1. Stationary siblings therefore distinguish index invalidation from count invalidation.

Each callback uses a visible iframe, explicit body, equal parent computed styles, precreated literal references, stable repeated reads and no active animations. Width has independent geometry checks. It captures all three phases, checks every phase's topology and literal calibration, and only then compares actual values. The same target objects survive each operation and restoration. Every value assertion includes the complete nine-record case JSON. Standard WPT logs retain callback outcomes and failure messages; there is no separate full-record export hook. Missing moveBefore support is an explicit assertion failure, not successful coverage.

The fixture covers ordinary elements in the same document. It does not establish shadow-root fallback, slot redistribution, pseudo topology, callback scheduling beyond these operations, or which native cache/invalidation path executed. The resolved outer-scope tree-counting fallback remains one; the previously rejected draft-zero proposal is unrelated.

Primary references are CSS Values 5 [tree counting](https://drafts.csswg.org/css-values-5/#tree-counting) and DOM [moveBefore](https://dom.spec.whatwg.org/#dom-parentnode-movebefore).
