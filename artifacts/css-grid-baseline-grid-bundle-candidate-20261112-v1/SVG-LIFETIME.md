The direct text-path route requires mTargetIsValid. SVGTextPathObserver supplies IsSVGGeometryElement as its eligibility predicate. Its geometry tags select NS_NewSVGGeometryFrame, with preceding exceptional contexts selecting suppression or SVG container behavior, not CSS grid. Thus setting display:grid on a referenced SVG geometry element does not make that element the measured nsGridContainerFrame. This is a construction-order argument, not an assumption that SVG namespaces can never contain CSS layout.
