The cache owns one current measurement, not a collection of measurements. Its geometry comprises measured border/content block size, physical frame size, and used margins captured after FinishReflowChild. The snapshot contains four scalar slots, its original request, and explicit single-answer/bundle presence. Unused initialized slots do not imply captured answers.

Matching natural requests return a captured Maybe, including Nothing, without a new live query. A different natural request misses. A geometry request can use any admitted current snapshot but its projected answer is always Nothing; it never exposes a stored natural/grid answer to a perpendicular caller. Geometry capture makes no baseline query. Geometry hits do not erase stored exports.

A grid request with a current producer marker and clean subtree captures B-first, B-last, I-first, and I-last together. Subsequent admitted grid requests project their own axis/group. Without the marker/clean qualification, the exact previous single requested getter runs. No extra natural-provider call is introduced. Every real measurement, including geometry, replaces the complete previous payload and all presence flags. No sibling snapshot survives an intervening measurement.

NS_STATE_GRID_PRODUCED_BASELINES is GridContainer bit 31. The original applicable Generic and GridContainer inventories leave it free. The constructor clears it, Reflow clears it before normalization and both early returns, and the normal tail sets it after both baseline producers and FinishAndStoreOverflow. The bit expresses producer execution only. It is not a validity certificate for the cache key, a freshness epoch, or a claim that hidden/depth-limit reflows produce new values. The fallback preserves their existing query behavior.

The original key (containing-block inline size and block-axis baseline padding) and subtree-dirty rejection are unchanged. Baseline callers use NS_MAXSIZE clamps, while ContentContribution can supply finite clamps; available sizes, containing-block block size, and parent contexts also differ outside this key. These omissions are inherited, not proved harmless here. A later diagnostic must record complete inputs on stores/hits before classifying same-key/different-context reuse.

No extra per-frame field or allocation is added. The state bit replaces the contemplated bool certificate. The payload's intended size is larger than the single-answer payload; actual frame/cache/result layout must be measured, not inferred from these declarations. MeasuringReflowResult now has a geometry base and may be non-standard-layout.
