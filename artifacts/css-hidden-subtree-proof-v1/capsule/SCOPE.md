# Scope and source projection

This successor models the actual one-line MarkPrincipalChildrenDirty call at the hidden ReflowChildren return. It does not combine that candidate with the earlier miss-only dirty mark. Complete native acceptance is not a theorem of this artifact.

Tree has separate IS_DIRTY and HAS_DIRTY_CHILDREN bits. Native MarkSubtreeDirty prunes on IS_DIRTY; query admission uses either bit. A root call ignores its own table-column-group type but descendant traversal prunes table-column groups. The helper begins from each actual principal child, then follows all actual child lists under that root. It does not follow placeholder-to-OOF pointers, container sibling lists, or another continuation's principal list.

The general theorems establish: every principal root becomes query-eligible; initially eligible paths stay eligible; a path without an initially dirty/table-column-group barrier is marked; and allDirty after marking equals a predicate of the original barrier subtrees. This last predicate requires every dirty bit already present behind a pruned barrier. It is a structural characterization, not an assumption that native callers always satisfy it. Countermodels retain an already-dirty parent with a clean child, a dirty intermediate subtree, a table barrier, and unvisited external frames.

The separate forceAll producer models the actual FrameNeedsReflow branch specialized to aBitToAdd=IS_DIRTY and IntrinsicDirty::None. Its explicit descendant walk does not prune dirty roots or table groups. A general theorem proves that it establishes every descendant bit and hence the helper's barrier-closure condition. RestyleManager's ordinary IS_DIRTY path uses this producer; its HAS_DIRTY_CHILDREN alternative does not trigger the helper's early return. No global invariant through partial child completion, callbacks, interrupted reflow, reparenting, frame reconstruction or all dirty-bit publishers is claimed.

The tree semantics assumes a finite stable ownership forest with each node represented once, and ignores visitation order. Native extraction executes the real explicit stack on a fixed acyclic graph. The equivalence of recursion and stack traversal for arbitrary native frame graphs is reviewed correspondence, not a kernel simulation theorem. Native identity, list virtual dispatch, graph ownership and all mutations during callbacks remain provider obligations.

Eight complete native methods compile in the facade: the two marking helpers, two hidden predicates and four PresShell forcing methods. The in-flow-parent hidden predicate is retained but not invoked by this corpus; the other seven execute. Complete old/new ReflowChildren and FrameNeedsReflow methods are also bound, but only their exact initial candidate guard and specialized root/descendant marking statements execute. The rest of those large methods is not extracted execution. The principal caller guard's original return/status is retained; its subsequent normal layout path is represented only by an inert nonhidden return.

The native corpus has 6,144 cases: optional dirty producer × hidden branch × 128 direct-dirty masks (six principal-subtree nodes plus container) × four independent HAS_DIRTY_CHILDREN masks × three table placements. It includes an anonymous-placeholder role with a separate external target, a container nonprincipal list and another continuation role. Those are graph roles, not proofs of actual DOM/frame construction for each role. Nine node observations per row compare direct dirty bit, query eligibility and scheduled-forcing count. Stable styles are ordinary/nonanonymous and ancestors are supplied. The PresShell flush callback is intentionally a no-op: source calibration tests admission/set clearing, not successful native geometry recomputation.

Selected-query geometry theorems compose with the imported earlier Hidden model using an arbitrary returned-size provider and an explicit identity/bit projection. They inherit its forced traversal, successful completion, stable frame and layout-provider admissions. They do not prove every marked frame is actually revisited or receives correct CSS geometry. The copied Hidden module is byte-identical and its 30 earlier results are counted separately from 36 new results.

Lean's kernel/library and the pinned external compiler/Lean executables are trusted. Complete installed libraries and SDK are not packaged. The native projection uses only state bits and small graph indices; it does not claim general layout arithmetic safety. No native source, browser, build or Git state is modified by this artifact.
