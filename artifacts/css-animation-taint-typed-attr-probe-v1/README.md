# Unexecuted typed-attribute animation-provenance probe

A typed attribute can reach the proposed metadata-loss boundary without an animation-duration dependency. The page uses `--a: attr(data-value type(<custom-ident>))`, an attribute whose text is `var(--v)`, and `writing-mode: var(--a, vertical-lr)`. The custom property `--v` is unregistered. Three fresh-iframe callbacks compare an active constant `--v: horizontal-tb` keyframe, an untainted variable, and a literal attribute. All use a fixed two-second paused CSS driver held at 750 ms.

The tainted case expects the intermediate alias to remain the valid token `horizontal-tb`, but the writing-mode sink to choose `vertical-lr` under the explicitly named animation-provenance hypothesis. The untainted case instead follows the ordinary `--v` change from `horizontal-tb` to `vertical-rl`. The literal attribute is `vertical-rl` throughout, distinguishing successful typed-attribute parsing from the sink's `vertical-lr` fallback. Controls animate only constant opacity; the tainted case animates only the constant custom value. Every case checks its selected custom value, fixed duration/progress, held time, paused state and retained animation/effect identity.

The ordinary base change precedes a first sink-only computed-style read and three passive frame samples. Alias, source variable and timing details are collected afterward, followed by membership and another detail snapshot. Complete diagnostics are captured before value assertions. Initial acquisition/readiness failures may prevent full collection. There is no private PASS transport, and later fields are sequential diagnostic reads, not a simultaneous snapshot.

SOURCE-TRACE.json retains exact excerpts and whole-source hashes from sealed proposal 982c5bc9. The source route is concrete: typed attribute discovery parses the attribute text, dependency traversal creates an Attr node, and the noncyclic node invokes substitute_references_if_needed_and_apply with a present namespace. Intermediate substitution is passed a custom-property identifier, allowing the valid animated value to carry its flag into the local Substitution. The namespace branch then constructs a fresh resolved value and copies attr taint without copying animation taint. Later, the typed Attr arm extracts only `.css` from the stored value and reparses it, a second metadata boundary. These are source inferences, not an executed trace, and this fixture has not observed the compiled proposal.

CSS Values 5 attr substitution step 6 explicitly substitutes functions in a typed attribute's text before parsing its type. Variables defines infectious animation taint and rejects tainted custom-property references in a non-animatable sink; writing-mode is non-animatable. The unresolved bridge is whether and how that provenance must survive this attribute-mediated dependency and typed conversion. The tentative tainted assertion expresses the tested hypothesis; it is not a completed normative call-chain proof or evidence that the proposal is already wrong in a browser. The literal and untainted controls establish the parsing/value path independently. Global inactive declarations, registered-property exemptions and ordinary important winners are outside this probe.

A direct non-animatable `writing-mode: attr(...)` sink is a separate unresolved context-routing boundary: the cached Attr node is resolved with a custom-property identifier and the final sink filter checks only Var references. Merely restoring metadata at the two identified copies would not prove that direct route correct. This page deliberately tests an outer custom-property reference instead.

The source audit found no equivalent loss in Env lookup: it passes the full VariableValue to Substitution::from_value, while missing-env fallback uses the existing accumulating substitution path.
