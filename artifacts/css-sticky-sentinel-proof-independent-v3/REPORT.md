## R1: actual traversal, independent array result and sequential composition

`Chain` describes the actual starting identity and next links, in-bounds unique indices and termination at `none`. `chain_members` and `chain_length` derive the finite cardinality bound. `source_fuel_sufficient` therefore proves adequate fuel; nonexhaustion is not an input assertion. `indexed_common_translation` follows actual indexed writes, and `continuation_array_refinement` equates them to an independently defined array map. Every visited frame uses its own initial observed normal: property value if present, otherwise its own current position. Whole `Node` equality preserves all other fields and all unvisited records. This is stronger than equality of the output positions alone.

The separate `Graph` relation adds common canonical first and parent. These metadata are preserved; their construction by Gecko remains an external representation premise. Some caller theorems require only `Chain`, proving the result on a larger mathematical domain. They do not infer valid canonical ownership from coordinates. Canonical translation and the selected-frame wrapper maintain distinct normal sources. Native `PositionContinuations` is called on a first continuation; the model does not silently canonicalize an arbitrary selected continuation before that early-return test.

`PrimaryReady`, `Linked`, and their transfer lemmas preserve subsequent next/parent/canonical paths through movement and offset refresh. `primaryReference` refreshes offsets before an independent simultaneous update; `updateReference` folds those references over the states produced by prior primaries. `update_decompose` relates the original for-loop to the proved recursive primary sequence, including prefix, overflow requests and flush. `complete_update_reference` yields the final independent array and preserves exhaustion/links. No final native array is supplied as an assumption.

`OverflowPath` admits the synthetic root at exactly `nodes.size`, terminal before any array lookup. Its unique-path bound supplies sufficient traversal fuel. The actual overflow loop preserves frame storage and exhaustion. Machine/mathematical caller equality preserves the modeled request trace. This proves the modeled request enumeration and its composition, not the real overflow unions or successful tracker delivery.

## R2: machine operations and sequential safety

The separate machine operations cover signed32 point conversion, both coordinates of addition/subtraction, saturated far edges, and ordered masked projection. `RectSafe` retains the conservative exact-sum endpoint domain even though native saturated endpoint evaluation also has defined behavior outside that domain. This is an explicit restriction, not an assertion that every valid browser rectangle meets it.

`ContinuationSafe` is guarded by the actual missing-normal return, and `FrameSafe` by the sticky/container branch. `LoopSafe` bounds each visited frame's observed normal, the common delta and each resulting coordinate. `TranslationSafe` also bounds canonical subtraction. `complete_machine_continuations`, `complete_machine_translation` and `complete_machine_frame` join machine callers to the independent references. `all_entry_machine_refinement` preserves the complete mathematical return, state and trace for all seven modeled entries.

For updates, `BatchSafe` checks the refreshed state and recursively advances through `primaryReference` before checking the next primary. `machine_primary_loop_exact` transfers actual earlier output to that reference state; `complete_machine_update` joins the complete machine update to the independent sequential array fold. The separate final `independentObservation` dispatcher remains a finite-calibration helper, without a claimed universal dispatcher theorem. The required universal constituent results are present; acceptance does not use the helper's name or test count as a substitute.

## Independent challenges and limits

The ten new results are in `IndependentChallenges.lean`:

- A two-update example is initially numerically safe and structurally ready, but its second update exceeds signed32. `BatchSafe` and `admitted` reject it. Checking each primary against only the initial state would incorrectly accept it. A one-unit-smaller example is admitted and ends exactly at `INT32_MAX`.
- The overflowing example has repeated primaries. It deliberately stresses the general theorem's larger finite-list domain; the native provider requires unique shallow-first primaries, so this is **not a browser-reachable defect claim**. Outside the admitted domain, total machine-model wrap is only a diagnostic contrast, not a claim about undefined C++ overflow.
- Reflow installs the new offsets before geometry/movement. A missing normal still allows that installation while skipping hazardous geometry and movement.
- Parent overflow traversal reaches the synthetic root, emits its terminal request/next trace and flushes; direct-root reflow suppresses the parent request. An index above the synthetic root is rejected.
- Generic theorem consequences accept an arbitrary initial trace while establishing the full sequential array result, no newly introduced exhaustion, and preservation of an arbitrary unvisited whole `Node` record.

False controls assert initial-only safety, stale-offset movement and omitted overflow requests; each is rejected. The first development attempt had Lean record-layout syntax errors, and a later runner rejected a legitimate kernel type-mismatch diagnostic because it expected only the other false-proposition wording. Both failed attempts and the original challenge source are retained. They are not successful evidence; `replay-v3` is the terminal successful run.

## Explicit admissions

Acceptance retains all original boundaries:

1. Stable live-frame identities, valid indices, canonical/common-parent membership, acyclic continuation and overflow paths, actual shallow-first unique primary selection, and no reentrancy/deletion/pointer reuse. The graph premises are proved sufficient, not proved for every Gecko frame tree.
2. Faithful raw signed32 values and no explicit inset aliasing the reserved AUTO code. The separate alias repair is not imported into these frozen sources.
3. Actual geometry and recomputed-offset provider values at each call, including freshness after an ancestor moves. Static per-node rectangles do not derive that dependence. `ComputeStickyLimits` is invoked before missing/all-auto offset handling; its entire construction arithmetic remains an external safety obligation. Safe output rectangles alone do not discharge it.
4. Exact source interpretation and field correspondence, selected helper/provider behavior, C++ compiler/SDK/host execution, allocation, and actual setter/overflow/display effects. The documentary source mapping plus finite native calibration is not a verified C++ translation.
5. The pinned Lean kernel and installed library inventory, Python and the host environment. Forbidden proof axioms and cached producer compiler products are separately guarded.

No new native bug or theorem unsoundness was found in this review. Later full-provider verification remains useful separate work, not a reason to relabel this accepted conditional consumer result as universal browser safety.
