# String source/model correspondence

INPUT-AUTHENTICATION.json authenticates the frozen comment capsule before reuse. Its eleven Lean modules are unchanged. inherited/ retains the original name/escape source/version bindings and the comment parent manifest/freeze. HELPER-SOURCE-COMPARISON.json confirms byte-identical complete `byte_to_hex_digit`, `consume_hex_digits`, `consume_escape_and_write` and `consume_escape` bodies between the prior helper capsule and the current pinned tokenizer. The current tokenizer differs from indexed source in already reviewed identifier/URL/numeric areas; string/escape bodies are unchanged.

| Native operation | Model and proof connection |
|---|---|
| `consume_string` | Chooses `QuotedString` for successful closed/EOF returns and `BadString` for bad-newline returns. `Ending` distinguishes closed versus EOF only as a ghost. Both quote dispatches and wrapper results are exercised in the native witness. |
| Borrowed phase of `consume_quoted_string` | `borrowed single xs pre`: matching quote ends; opposite quote copies; EOF returns the borrowed prefix; newline returns the same prefix without consumption; backslash/NUL transfers the exact prefix to `owned`. Byte copy classes include UTF-8 leader/continuation bytes. `borrowed_slice` proves exact slice/closing count when allocation is false. |
| Owned phase | `owned single xs buffer`: buffer appends versus the reference's output prepends. Matching quote is consumed without copying; opposite quote is copied. Bad newline returns before consumption. The universal accumulator relation covers arbitrary buffers; safety then specializes it to complete or explicitly in-flight UTF-8 units. |
| NUL | Appends encoded U+FFFD and consumes one raw byte. Source preprocessing is lazy in this consumer; raw NUL is never copied as a literal output scalar. |
| Backslash | Consumes the slash first. If EOF follows, no helper call and no output. If newline follows, consumes the raw newline/CRLF with no output. Otherwise composes the exact escape provider. This caller guard is modeled explicitly, rather than assuming generic escape EOF is appropriate. |
| Hex and simple escapes | Native/reference helper equivalence is inherited with exact source-body/version equality. New theorems establish sanitized scalar bounds, encoded-unit shape, output/suffix boundaries and caller-level progress even when the generic EOF provider itself consumes zero bytes. |
| Partial multibyte copy | `owned_copy_prefix`, `partial_copy_rejoin`, `partial_copy_return_valid`: source can append a leader and then continuation bytes while its buffer is temporarily incomplete. All bytes of a non-ASCII unit classify as copy, so no quote/newline/escape/NUL return can interrupt that unit. |
| Slice and UTF-8 conversion | `reference_valid`, `raw_valid`, the raw slice theorem and finite pointer/output checks. Rust `str` encoding validity, standard codecs and unsafe conversion semantics are admitted; encoding-shape proofs alone are not advertised as a Rust memory-safety theorem. |
| Location state | `StringTrace.run` derives raw bytes traversed by the source actions, including variable escape spans; `trace_exact` proves the selected prefix. `nativeObserved` interprets that trace through the inherited comment helper observer; the independent reference folds that prefix. `raw_observer_reference` includes the initial quote. This is a source projection with an explicit imperative/compiler admission boundary. |
| `consume_char` versus raw byte helpers | A simple escaped scalar advances by `len_utf8` and adjusts line-start by `len_utf8-len_utf16`. Existing whole-unit observer theorems explain the same final UTF-16 contribution as individual byte helper steps. The standard char/codec correspondence is still a primitive boundary. |
| `CowRcStr` | Full actual module retained and included unchanged in the Rust replay. Borrowed From<&str> stores its pointer/length; owned From<String> stores Rc<String>. A separate test-only inspector observes the sentinel field, with exact content and clone/drop checks. Rc allocation/refcount implementation is not formalized. |

The generator extracts complete function bodies and hashes their UTF-8 text. Span offsets are Python string offsets, not advertised as byte offsets. A complete storage-provider include augments the 25 extracted functions. The only added native harness operations are type scaffolding, ordinary-match macro expansion, test entry/expectations and a private-field storage inspector. There are no live source changes.

The pure observer model preserves sourceURL/sourceMappingURL by construction because no complete string/escape helper calls their writer; source inspection and all 808 finite cases verify that fact. It does not assume that every public parser operation preserves them. Cached-token replay, reset and block traversal remain separate source obligations.

## Native admission domain

Inputs executed natively are valid Rust strings; model results for malformed byte lists do not license native calls. The real caller must enter at an opening quote/character boundary with a matching quote mode. The raw totalization proves this guard for its modeled entry; full dispatcher composition is still open. All offsets, packed line numbers and projected columns must satisfy the explicit capacity bounds; output length must fit the allocator/object domain. Rust standard string/vector/char/Rc primitives, optimized byte-match expansion, compiler and allocation behavior remain external. Source pinning and finite extraction do not prove those primitives universally.
