# Unexecuted inherited-value and nested-fallback taint controls

Two standalone WPT pages add six follow-up callbacks without changing the running 106-case suite. They use active unregistered custom-property keyframes, a fixed two-second paused CSS animation held at 750 ms, and the non-animatable inherited writing-mode property. No duration-input policy or ordinary important-winner behavior is asserted.

The inherited-value page compares direct `inherit`, `var(--missing, inherit)`, and a literal sink control. The parent supplies the valid custom value `horizontal-tb`; the target's own ordinary value changes from `vertical-rl` to `vertical-lr` beneath the active keyframe. Both keyframe forms must select the parent's custom value while the non-animatable sink selects its outer `vertical-lr` fallback. The literal control still checks the selected active custom value, fixed timing and retained identities.

The nested-fallback page uses `var(--missing, var(--v))` with active `--v: horizontal-tb`. The nested reference is rejected too, leaving an invalid computed value; inherited writing-mode must therefore be the parent's `vertical-rl`. This differs from both the initial value and animated token. The second case supplies a clean nested fallback, `var(--missing, var(--v, vertical-lr))`, and must select `vertical-lr`; a literal control calibrates the same result. These cases distinguish accepting a tainted nested reference from discarding every fallback as invalid.

Each callback uses a fresh iframe. Acquisition and readiness precede the held seek. After the ordinary base mutation, the first observation reads only the sink, followed by three animation-frame sink samples. Detailed variable/timing diagnostics and current animation membership are read afterward. All diagnostics are collected before the authored value and identity assertions. Setup failure can prevent full collection; there is no private PASS-record transport. Later getters are sequential observations and can flush style; this test does not infer an internal cache path, pass count, or queue quiescence.

The scope follows the current Variables replacement steps: reject an animation-tainted named custom property in a non-animatable sink, then recursively substitute its fallback. CSS-wide inheritance selects the parent's computed value, and writing-mode is inherited and non-animatable. The tests target active declarations, avoiding unresolved global inactive-rule, registration-exemption and ordinary-winner compatibility questions. They do not establish native implementation correctness until executed. See SPEC.json for primary anchors and the earlier sealed interop study for the broader policy boundary.

Resources are the two HTML pages and unchanged testharness scripts. INPUTS.json and ROSTER.json provide future runner mappings.
