The proposal preserves the 32-byte applicable-declaration collector rather than relaxing its assertion. It adds one pointer-sized borrowed primitive inside servo_arc, converts StyleSourceBorrow to a safe wrapper, extends the existing OwnerLayout GTest, and removes the unused Locked import as a separately reviewable trivial delta. No native paths were changed and nothing was compiled or executed.

Existing ArcUnionBorrow is an enum, so wrapping it retains its separate discriminant. Borrowing &StyleSource would require a stable owner object for ordinary declaration-only inputs that currently provide ArcBorrow directly. Replacing collection with owning ArcUnion clones would add reference-count traffic. Packing the discriminator into unrelated collector fields would spread tag invariants across matching and priority code. None is used here.

ArcUnionBorrowPtr stores the same allocation pointer/tag domain as ArcUnion plus PhantomData<&'a ArcUnion<A, B>>. Safe constructors take ArcBorrow or &ArcUnion. ArcBorrow constructors recover ArcInner with ManuallyDrop<Arc::from_raw>, following existing ArcBorrow::with_arc mechanics without imposing its unnecessary 'static callback bound. Construction, copying, reading, comparison and destruction of the borrowed pointer do not call clone or drop the transient Arc. Only explicit to_owned clones the selected allocation. Existing ArcUnion and enum APIs remain byte-identical.

The unsafe boundary stays in servo_arc. ArcInner contains an atomic counter and has a free low bit even for zero-sized or alignment-one payloads. NonNull::map_addr adds or removes that bit while retaining provenance; the encoded pointer is never dereferenced before decoding. Constructors are private-field safe APIs, and returned ArcBorrow lifetimes are tied to the original borrow, not the temporary view. Conservative Send/Sync bounds match ArcUnion (both payloads Send + Sync), allowing owned conversion without silently making local-only payloads transferable. No style-layer raw-pointer reconstruction is added. The non-Gecko branch remains an ordinary ArcBorrow wrapper.

The primitive relies on the existing ArcInner layout/from_raw/static-allocation contracts. from_union also inherits the existing ArcUnion integer-tag construction provenance contract; this proposal does not prove that older implementation under LLVM or Miri. The new operations use strict-provenance map_addr and require a toolchain supporting it. Pointer/address equality is identity, not allocation ownership or equality of contents. The sampled source key remains its original untagged data address, distinct from the concrete PDB address; owned and borrowed keys retain their existing correspondence.

Five unexecuted library tests cover pointer/Option layout, tag distinction even for two variants of the same allocation, actual atomic reference counts, copying versus explicit ownership conversion, drop timing, equal contents in different allocations, zero-sized/high-alignment payloads, and static Arc count neutrality. The static test uses permanent actual ArcInner storage and includes the track_alloc_size field under its feature. Three compile-fail doctests cover escaping an ArcBorrow owner, escaping an ArcUnion owner, and sending an Rc payload borrow to a scoped thread. Their expected rejection has not yet been checked. No stub Arc types are used.
