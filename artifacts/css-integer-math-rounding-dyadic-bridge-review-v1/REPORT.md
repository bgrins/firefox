The capacity results quantify over signed mantissas in the stated 24-bit range. Exponent bounds cover the explicit central representations; the two encoding identities are algebraic identities for arbitrary exponents. Their combined theorem constructs a coefficient/denominator encoding instead of assuming that adding one half is representable. This is nonvacuous support for exact addition in the central input range, conditional on actual binary32 decoding and binary64 representability/correct-rounding semantics. SmallDyadic53 is a rational predicate, not an IEEE type. The bounded exponent and coefficient conditions keep constructed nonzero values away from binary64 underflow/overflow, but the theorem does not formalize that floating-point bridge.

The small-value result is sufficient only with its supplied margin and error premises. From nonnegative error < gap, gap ≤ p ≤ d−gap and p−error ≤ rounded ≤ p+error, it derives positive d, strict 0 < rounded < d and Euclidean quotient zero. These premises are jointly satisfiable, and neither the floor result nor the required boundary inequalities are assumed. At the documented scale 2^150, gap 2^125 is 2^−25 and error 2^97 is 2^−53; the proof correctly requires the strict error-versus-gap inequality. It does not establish that every binary32 input below one half has that gap, that the actual binary64 result has this common-denominator encoding, or that IEEE rounding obeys the supplied error bound. Those are clearly marked external premises. The exact subnormal-addend counterexample correctly prevents the stronger, false claim that all promoted additions are exact.
