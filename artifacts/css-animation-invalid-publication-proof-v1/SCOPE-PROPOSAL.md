# Animated GIV publication: proposed bounded proof scope

## Domain and independent observation

Model a selected custom animation result as an outer optional named endpoint, whose inner optional computed payload represents GIV. Outer absence means no published declaration; inner absence is a present named invalid value. Valid empty tokens are a distinct payload even though their CSSOM serialization can equal GIV serialization. The independent reference observer selects a supplied fallback exactly for GIV, without consulting the registration initial value. This is a semantic observation contract, not a proof of the CSS parser or DOM observation implementation.

Use arbitrary property names, payloads, both registration routing partitions, registration initial values (including GIV), arbitrary preexisting maps and seen-name state. Source-shaped conversion and recascade are separate operations. Noninvalid payload conversion is a supplied provider with an explicit preservation law; no implicit equality or metadata quotient.

## Explicit limits

No full parser, registered typed invalid-value policy, numerical conversion, metadata payload quotient, map representation/compiler/heap bounds, CSSOM enumeration, registration-change routing, root/pseudo/SMIL, effect-stack/segment scheduling, or browser-refinement theorem. Stable registration/name routing and disjoint partition ownership are caller conditions; noninvalid conversion and map removal are named providers. Revert and priority acceptance are modeled gate inputs, not proved from rule-tree construction. Actual candidate browser evidence remains a separate root-owned finite gate.
