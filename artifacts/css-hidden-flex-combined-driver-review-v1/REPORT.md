## What timing measures

The fixture performs real style-width toggles followed by geometry queries. It separates construction, establishment, mutation/outer flush, recovery preparation, and selected-leaf queries. Principal and OOF branches have 1/32/256 siblings and three nested levels. Visible dimensions are calibrated before hiding. Two warmup rounds precede seven retained rotated rounds: 84 batches, 1344 mutation flushes, 1344 recovery preparations and 4032 leaf reads.

Validation reconstructs row order, indices, workload checksums, observed-size checksums and mismatch counts. Returned sizes drive the geometry checksum. The separate query checksum is workload bookkeeping, not proof of native dispatch. The hidden predicate/marking count is not instrumented. Width changes request the intended layout work, but already-dirty pruning and cache state can alter which native branches execute.

No timing issue blocks this diagnostic. Its limits must remain attached to results: millisecond precision and individually summed short recovery intervals; zero samples; only one process per phase; fixed baseline/principal/OOF/both order; build aftermath, GC, background services and machine drift; only up to four selected leaves checked; no position calibration in the cost fixture. Separate WPT supplies correctness coverage. Geometry mismatches are retained, and faster stale/zero output cannot be called equivalent completed work. There is no broad cost-neutrality, significance or regression claim from these samples alone.
