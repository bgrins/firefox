# Finite representable-weight share proof

The original seven-clause target and its aggregate pass Coq compilation and coqchk. The target was pinned before the first proof attempt and was not changed. The complete theorem derives a positive denominator bounded by 2^192 and a rounded share in [0,1] from a positive selected weight, an actual rounded left-fold of nonnegative representable weights, and at most 4294967295 entries. It does not assume that the final denominator already has these properties.

The proof explicitly uses representability: rounding leaves each input weight unchanged, so monotonicity proves that adding it to a nonnegative sum cannot produce less than that weight. Subsequent rounded additions preserve that lower bound. Exact division is then in (0,1], and rounding monotonicity plus exact zero and one yields [0,1]. Scaled finite weights satisfy the representation premise because they are rounded products. A singleton weight-one witness satisfies the premises and produces share one; zero-weight division is also checked for positive denominators.
