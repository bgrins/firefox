# Standalone dependency review

Static review supports both minimal Gecko/WPT pairs as independent of the pending 119 raw-length, 118 integer-rounding and 121 integer-range changes. No prerequisite on those changes was found. This is source/fixture analysis, not a clean-HEAD90 browser result or a formal whole-engine noninterference proof.

Both native patches apply independently to the exact HEAD90 generic calc body (`63a9b384909ddd08ef254dce9ca438ce8357346171caa759064e814447653637`), as already verified by the data review. Each changes only that file and adds its own landing fixture. Neither needs the other repair or the deferred-value parse guard.

The archived pre-119 specified calc body is also exact HEAD90 (`75abb70d9bbb779c8c89b049dc923906cbb47d3fd2e9aa481dad8411a60e9570`). Its `parse_product` division path already calls `right.resolve()` before folding a distributive numerator. Runtime10's literal `0.25 / round(strategy, NaN, infinity)` and reversed operands therefore reach numeric Round resolution through an existing eager-division path, without a pending parser change. Its controls likewise contain only dimensionless literals. Finitepow8 uses literal `round` operands nested in `pow` and `clamp`; its division control uses that same existing eager-resolution route. Positive/negative-zero calibrations and its infinite-step control use the unchanged literal-number paths.

The 119 change affects `Leaf::Length` conversion and length/percentage math. Neither fixture contains a length leaf in its opacity expression. Finitepow8's separate `font-size: 32px` is a finite absolute calibration, not an arithmetic dependency. The new raw conversion agrees with the old finite conversion for this value. Runtime10 needs no font setting.

118 and 121 change integer resolution/rounding, not the Number branch used by these opacity declarations. Independently reversing just their number.rs hunks in disposable scratch reconstructs exact HEAD90 number.rs (`d56a163e715ceb44834eb46be8ccc945f51e633015a3f59210378c425bee0c5e`). Thus there is no other installed number.rs delta hidden in this trace. No integer-valued property, repeat count, counter descriptor, grid, relative length, custom property, scope/import rule or pseudo-element is required by either fixture.

Other pending changes remain present in the actual comparison browser. Their mere presence does not establish a dependency, and this bounded review does not claim to exhaust every possible interaction in shared style/DOM machinery. A passing isolated HEAD90-plus-one-patch browser run would provide direct empirical independence evidence; none was performed here. All reads were archived; the only operations were source comparison and owned temporary scratch patch reversal. No live source, index, binary, build or browser was accessed.
