## Substantive review findings

The bad-remnant proof is useful beyond finite tests: the parity-labeled reference selects the first unescaped close independently of the native two-byte shortcut. `BadURLEscape` and `BadURLSpec` connect complete escape consumption to that boundary under explicit unit premises. This is not a theorem assuming the desired endpoint equality.

`URLScan` uses an independent class table and reference output construction. The borrowed buffer handoff and owned append behavior are related through projections, including NUL replacement, escapes and invalid input. `URLWhitespace` compares forward state updates against a backward summary. These are substantive universal component relations. They do not automatically translate all native state, allocation or slicing operations.

`URLLeading.admitted_quoted_completion` derives the whitespace/quote decomposition from a modeled Function result before using the string completion theorem. The more general `combined_string` algebra alone permits arbitrary prefix bytes and must not be presented as production admission. The final source mapping states this correctly.

The native test wrapper clears pending-block state between raw token requests. It tests the lexical seam through complete source, not normal `Parser::next` caching, reset, speculative rollback or automatic block skipping. The driver tracks URL requests; arbitrary requested-name behavior is a separate model result. Native sourceURL/sourceMappingURL checks cover explicit absence only. Arbitrary initial annotation framing remains a model/native-source obligation.
