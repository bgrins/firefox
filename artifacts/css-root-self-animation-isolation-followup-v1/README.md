# Root identity and cancellation-order isolation

The actual archived-e86 discriminator has 34 calibrated cases and 68 first/settled samples. Its saved assessor replays exactly. Existing-child and root-pseudo rem endpoints after root em cancellation without a root read remain 64 at both samples, instead of 46; an explicit root read or a newly created child yields 46. The rlh child/pseudo controls remain 74. This is potentially another manifestation of the already-investigated font-hint admission defect, not a separately counted bug or a proven native cause.

The root-identity observation survives removing cancellation contamination: clean root font-size rem is 46 rather than initial-metric 32, and clean root font-size/line-height rlh is 74 rather than initial-normal 38.4. Comparator reset without a root read can additionally produce root rem 128 and root line-height rlh 153.6. These exact values belong to the saved environment, not hard-coded initial font assumptions in the fixtures.

## Source deduction and remaining observation

In the pinned e86 data.rs, needs_to_recascade_self admits the ancestor-font/writing-mode hint only with the persisted USES_FONT_OR_WM_RELATIVE_UNITS flag. In matching.rs, process_animations queues EFFECT_PROPERTIES for animated targets that reach normal processing. A child's ordinary absolute font declarations need not publish the keyframe's relative-unit dependency. Thus root cancellation can plausibly compute a new effect against the previous animated root and subsequently miss its endpoint rebuild. Fresh-child style construction or a prior root flush avoids that ordering. The observations do not expose Device values, precise hint delivery, or the point at which endpoints were computed; this mechanism remains a hypothesis.

The separate sealed two-Rust-file font-hint admission candidate is the appropriate first discriminator. Its normal-pass admission should be tested against these cancellation cases without changing its source. If they remain stale, trace effect creation, ancestor-hint delivery and UpdateProperties ordering before proposing another repair. No native changes or new acceptance claims are made here.

## Separate fixtures

root-font-self-reference.html retains the original 14 callback names, target types, two underlying configurations, expected values and first/settled assertions. Calibration animations and ordinary comparators now run in an independent reference iframe. Both initial metrics are compared across frames. The target receives no calibration animation or comparator reset, and its literal root size/line-height is explicitly verified immediately before target animation creation. The reference itself is flushed after calibration cancellation before its comparator. This intentionally isolates root identity; it is not evidence that cancellation is correct.

root-font-cancel-child-animation.html independently preserves the cancellation ordering: six rem cases cross existing/new child and root-host pseudo with no-read/root-read; two rlh cases preserve unchanged root-line-height behavior. Existing child and pseudo styles are established before the root em disturbance. The no-read arm creates the target animation directly after cancellation, then reads that target first and after ready/two frames. No root getter intervenes. New-child creation occurs after cancellation. Both samples are recorded before either value assertion, and both must match. Root em calibration uses measured initial metrics, while target rem/rlh values use literal root 23px/37px.
