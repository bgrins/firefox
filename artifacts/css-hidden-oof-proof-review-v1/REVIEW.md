## Mathematical and source correspondence

- Pre-input marking makes the direct dirty bit true, so the modeled exact `SetIResize(!IS_DIRTY && isIResize)` assignment returns false. This does not prove preservation of every other RI initialization flag or effect.
- Under a stable hidden predicate and no next continuation, the actual block entry branch returns without computing normal dimensions. Zero-initialized output, preserved hidden DidReflow dirty bits, and selected placement explain the transient zero rectangle. The repair deliberately does **not** make that first rectangle nonzero.
- Root eligibility is unconditional in this selected branch; descendant eligibility needs the represented clear path. Existing dirty/table barriers remain explicit counterexamples. The direct-bit `rootClosure` characterization is stronger than mere query eligibility, which also accepts HAS_DIRTY_CHILDREN.
- Leaf recovery is a composition with the imported single-frame query/provider theorem. The model substitutes the selected target's eligibility into that frame. Native identity, successful forcing/completion, current key and actual layout result still need a real state correspondence. The conclusion is the supplied provider result, not independently established CSS dimensions.
- `GetInFlowParent` executes the retained placeholder/first-continuation lookup. Its valid pointer, lifetime and ownership inputs are supplied. Independently varying physical-owner visibility tests use of that getter; it is not a DOM reachability theorem.
- The full native caller conditionally executes SetRect (including non-popup positioning) and can iterate fallback attempts. The facade represents one selected placement iteration. It does not establish arbitrary popup, anchor, fragment, status or retry behavior.
- The actual hidden DidReflow branch bypasses later SVG and percent-size observer work. However full RI initialization, virtual Reflow, and FinishAndStoreOverflow remain effect boundaries. The latter can temporarily alter frame size and invoke other machinery; treating it as a no-op in finite calibration does not derive its required frame/dirty-state footprint.

Visible preservation is appropriately relative to the same arbitrary provider and pure placement. A continuation provider may erase the dirty state. The supplied resize-sensitive provider demonstrates why pre/late marking cannot be declared equivalent, but is **not an observed native regression**. The placeholder-named Boolean witness does not prove heap/placeholder construction. The centered 720×480/zero arithmetic witnesses have small nonnegative numerators; no general equivalence between Lean integer division and C++ signed division is inferred.
