Open [issue13933](https://github.com/w3c/csswg-drafts/issues/13933) proposes removing inherited taint and acknowledges uncertainty in implementation; it does not remove same-element taint. Open [issue6398](https://github.com/w3c/csswg-drafts/issues/6398) discusses broader animation side-effect isolation but is not a superseding normative rule.
