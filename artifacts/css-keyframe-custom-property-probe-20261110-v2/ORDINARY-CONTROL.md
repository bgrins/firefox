# Ordinary relative-unit discriminator

The frozen original seven-callback/eighteen-record proposal remains unchanged. `FIXTURE-DELTA.patch` records the runtime v2 addition: `margin-left: 2em` alongside the registered/unregistered relative values in the existing CSS replace/add scenarios and WAAPI control. Captured baseline/current context adds `margin-left`; setup verifies a static `2em` margin computes to `32px`, then restores a `10px` underlying value. Callback and record counts remain seven and eighteen.

The current Web Animations [getKeyframes](https://drafts.csswg.org/web-animations-1/#dom-keyframeeffect-getkeyframes) CSS branch selects [computed keyframes](https://drafts.csswg.org/web-animations-1/#calculating-computed-keyframes). Its per-property computation is not restricted to custom properties; an ordinary literal relative length also uses the element's dependency context. The already captured primary documents and source trace in `css-keyframe-custom-property-contract-20261110-v1` establish this chain. `single_value_to_css`'s non-variable direct declaration serialization likewise includes ordinary literal declarations. Thus this is a useful discriminator for one potentially broader serialization gap, not evidence for a separate new bug.

Pinned canonical test inspection: the CSSAnimation getter page has no `em` declaration; the WAAPI `getKeyframes.html` delegates to `gKeyframeSerializationTests`, whose sole serialization case normalizes RGB whitespace. Neither supplies an existing relative-length getter oracle. Other animation effect-value context tests exercise rendered relative-unit behavior, which is a different boundary. This is a bounded inventory inspection, not a claim that no such test exists anywhere.

The diagnostic does not assert the getter's relative value. CSS and WAAPI getter branches intentionally differ: unchanged CSS keyframes select computed values, while the WAAPI-created effect returns specified values. The ordinary static setup and captured font size help interpret observations without confusing correct rendering with correct getter serialization. `ORDINARY-CONTROL-PINS.json` authenticates the inspected tests; the old proposal/report remain frozen.
