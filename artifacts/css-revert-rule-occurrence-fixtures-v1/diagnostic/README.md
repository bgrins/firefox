# Optional source-roster diagnostic

`native.patch` is a one-file overlay on the frozen indexed candidate pinned in `SOURCE.json`. The full changed snapshot is under `candidate/servo/components/style/properties/cascade.rs`. It adds a read-only `DeclarationSources::trace_occurrences` call at `RuleExclusions::new`, before source indexing deduplicates blocks. No original source was modified. Root must verify applicability to the chosen build inputs before applying it elsewhere.

Enable only for a separate diagnostic run using environment `CSS_OCCURRENCE_TRACE=1`. The hook logs source ordinal, borrowed block pointer, complete raw and normalized priority Debug representations, and up to eight original declaration pointers/property IDs per source. Priorities include flags; do not compare only their ordering projection. Direct-block calls are labeled separately. The hook does not dereference any logged pointer after its existing read-guard lifetime.

Bounds are per content process: 128 first-Rule calls, 64 rule-tree nodes per call, eight declarations per source. Explicit `call-cap`, `node-cap` and `entry-cap` events identify truncation. A call is allocated by a process-local atomic counter; pair it with PID. `event=end` closes the node walk but does not override an earlier declaration cap. These limits do not establish completeness of the document's cascades. No shared counter across processes, document/element identity or global stylesheet-occurrence ID is recorded.

Join a roster to the surrounding fixture begin/end markers only where ordering and process identity permit. Initial style work can occur outside markers. Within one complete retained roster, two equal block pointers at the same raw priority demonstrate repeated source allocation in that importance phase. Require the expected declaration IDs and intervening competitor, and compare the independent control. Equal normalized priority across important/normal nodes alone is expected for one occurrence and is not sufficient. The trace records source membership, not actual rejection events or a proof of native semantic equivalence.

The snapshot was rustfmt-formatted and the patch checked forward/reverse on temporary copies. It has not been typechecked or built. The diagnostic changes code execution and logs synchronously; exclude it from performance experiments. No diagnostic execution was performed here.
