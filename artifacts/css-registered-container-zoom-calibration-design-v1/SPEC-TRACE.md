Question: which coordinate frame should cross-zoom container-unit values use, including a registered custom property that later feeds width?

The exact official discussion is [CSSWG issue10268](https://github.com/w3c/csswg-drafts/issues/10268). Its author raises both query conditions and query-relative units. The [June2024 resolution](https://github.com/w3c/csswg-drafts/issues/10268#issuecomment-2192195262) adopts Chrome/Firefox behavior; the minutes discuss the container's own CSS-pixel dimensions. A later [editor comment](https://github.com/w3c/csswg-drafts/issues/10268#issuecomment-2269576031) proposes clarifying that principal-box bounds are unscaled. The issue remains open with Needs Edits in the captured primary metadata. The linked WPT, captured here, checks width-threshold query conditions under nested zoom; it contains no cqw declaration. That distinction prevents treating this test as a direct oracle for the requested unit-conversion matrix.

1. [Conditional5 container lengths](https://drafts.csswg.org/css-conditional/#container-lengths) selects eligible ancestor containers per relevant axis, relates evaluation to size-query rules, and substitutes small viewport dimensions when no eligible container exists. Different axes can select different containers.
2. [Viewport zoom](https://drafts.csswg.org/css-viewport/#zoom-property) distinguishes length scaling at the used-value stage from percentages and defines effective zoom using the ancestor chain. Its [unscaled definition](https://drafts.csswg.org/css-viewport/#unscaled) identifies the element relative to which scale is removed.
3. [Viewport CSSOM](https://drafts.csswg.org/css-viewport/#zoom-om) requires unscaled nonpercentage computed-style lengths and scaled bounding rectangles. These are separate observable boundaries.
4. The retrieved query-condition resolution and clauses do not, in this bounded review, supply an explicit numeric worked rule for cqw computed on a differently zoomed descendant, stored as a registered value and substituted again. Inferring that frame from raw native Au storage would reverse the specification/implementation relationship.

Verdict: INCONCLUSIVE for a numeric cross-zoom cqw oracle. The query-condition resolution is established, but this case package does not promote it to untested unit-output expectations. Ordinary-CSS measurements will supply implementation calibration, not normative proof by themselves. Further clause/editor clarification may still be required. webspec-index was unavailable; this was a manual primary-source trace with anchors checked against full captured HTML, not an exhaustive automated route search.
