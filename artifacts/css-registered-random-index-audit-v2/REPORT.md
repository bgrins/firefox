## Model and limits

Rollback.lean has five checked declarations: failed-prefix neutrality under transactional rollback, first-success termination, two concrete scalar/list counterexamples, and a same-cursor/different-key witness. Two separate false controls are rejected: cursor-only rollback is not equivalent to transactional rollback; resetting between successful list members would wrongly reuse index1. The general theorem permits any starting counter and arbitrary finite failed prefix. The model is about abstract reached random parses, not full CSS token grammar or all parser side effects.

Manual source correspondence: State.cursor abstracts cssparser state; State.count abstracts ParserContext.random_count; Attempt.reads counts random parsings reached before an alternative terminates. select false mirrors cursor-only rollback, and select true describes a possible correction contract. It does not prove that resetting only random_count is a complete native repair: nested speculation, other context fields and numbering across successful repeated members require an implementation audit. It does not model PRNG arithmetic, CSSOM rounding, independence admission, property context or DOM lifetime.
