## Accepted claim

For a delegated last baseline, the child returns an inward distance from its block-end. The conversion uses the inner extent to recover a block-start point, adds the outer start border, clamps in the outer border box, then converts to an outer block-end distance. First-group mathematical behavior is preserved. Native first-group equivalence is claimed only where the original signed addition was defined.

The method's complete modeled output and represented provider-call sequence refine the stated dispatch/reference contract. Numeric proofs cover nonnegative signed32 inner/outer extents, arbitrary signed32 borders and child offsets, int64 intermediate arithmetic, and safe final narrowing/subtraction. The reference is piecewise physical-coordinate clamping; no premise assumes the final baseline answer. A block-end-border-only substitution is refuted when inner and outer extents differ.

The original fourteen root formulas are transferred unchanged. Additional producer results derive complete dispatch, absence, actual CSSMinMax meaning and arithmetic bounds. The root projection joins preserve the independent review's interpretation rather than replacing it with the native expression alone.

## Assumptions and dependent work

The child is stable and nonnull; its baseline and logical geometry describe the appropriate completed frame state in a compatible writing mode. Child padding, border origin, initial-scroll-position semantics, query classification, containment and legacy synthesis remain native provider obligations. Frame size invariants are premises of the arithmetic proof. The exact extraction uses synthetic Maybe/frame/query/geometry adapters; C++ lowering, compiler/runtime, Lean libraries and OS remain trusted.

The legacy synthesized result bypasses border clamping. Root's boundary check retains that fact; the delegated range theorem must not be applied to legacy results. Negative outer extents violate the frame-size premise and have an explicit counterexample. Full orthogonal/fragmented readiness, Flexbox donor selection, normal-property lifetime, publication and allocation F11/F12 remain open.

This repair is independently applicable. The natural-donor candidate newly exposes the defective provider through nested block scrollers and therefore currently has a semantic prerequisite on this fix. Source commutation does not make that donor candidate independently landable. Its withdrawn acceptance and blocked commit queue remain in force until that requirement is resolved explicitly.
