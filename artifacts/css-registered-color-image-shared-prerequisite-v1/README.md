# Shared prerequisite alternative for independently landable repairs

A shared prerequisite is a legitimate option even when some added APIs have no callers until a following bug fix. Absence of unused APIs is a review preference, not a user requirement. This package supplies a concrete alternative to the previously proposed dependent A→B stack; it does not yet establish behavior preservation or satisfy independent landability by assertion.

With original cascade, no caller invokes prepare_custom_value or invalid_custom_value_depends_on_color_scheme. Existing handling of failed substitution, CSS-wide keyword selection, attribute insertion, parsing/computation and invalid/default application remains the same tail. Extra immutable registration/is_var lookup placement and Rust borrow boundaries still require source review and actual type checking.

Prepared APIs, classifier and Prepared enum variant may be unused in this intermediate state. Actual compiler warnings and the repository's warning policy are pending. No warning suppression is added or pre-authorized. If that state fails build/lint, respond to the real diagnostics and review the smallest adjustment; do not claim the exact state compiled merely because the final combined state compiled. No broad neutrality theorem follows from unused cascade hooks alone.
