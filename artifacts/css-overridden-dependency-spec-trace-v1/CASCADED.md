# CSS-CASCADE-5#cascaded

**Cascaded Values** (heading)

**SHA**: hash:2c51fc71d5bfec21aee9acf5004344fc0b5197db31fc48a1ae5373f3fbc4670f

## Content

The **cascaded value** represents the result of [the cascade](CSS-CASCADE-5#cascade): it is the [declared value](CSS-CASCADE-5#declared-value) that wins the cascade (is sorted first in the [output of the cascade](CSS-CASCADE-5#output-of-the-cascade)). If the output of the cascade is an empty list, there is no [cascaded value](CSS-CASCADE-5#cascaded-value).
