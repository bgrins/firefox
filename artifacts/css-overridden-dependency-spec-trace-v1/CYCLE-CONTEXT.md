# CSS-VALUES-5#cyclic-substitution-contexts

**cyclic substitution contexts** (definition)

**SHA**: hash:6b2a51b0538dade54a602cc25535750a94d9cd637a495ddd6e0e82124deef42a

## Content

When a [substitution context](CSS-VALUES-5#substitution-context) is **guarded**, it means that, for the duration of the guard, an attempt to guard a matching substitution context again will mark all substitution contexts involved in the cycle as **cyclic substitution contexts**.
