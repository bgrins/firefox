# CSS-CASCADE-5#specified

**Specified Values** (heading)

## Content

The **specified value** is the value of a given property that the style sheet authors intended for that element. It is the result of putting the [cascaded value](CSS-CASCADE-5#cascaded-value) through the [defaulting](CSS-CASCADE-5#defaulting) processes, guaranteeing that a [specified value](CSS-CASCADE-5#specified-value) exists for every property on every element.

In many cases, the [specified value](CSS-CASCADE-5#specified-value) is the [cascaded value](CSS-CASCADE-5#cascaded-value). However, if there is no cascaded value at all, the specified value is [defaulted](CSS-CASCADE-5#defaulting). The [CSS-wide keywords](CSS-VALUES-4#css-wide-keywords) are handled specially when they are the cascaded value of a property, setting the specified value as required by that keyword, see [§ 7.3 Explicit Defaulting](CSS-CASCADE-5#defaulting-keywords).
