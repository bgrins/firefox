# Public missing-pseudo CSSOM integration: provider contract

The next useful implementation should exercise getComputedStyle itself, using one owned query transaction and a provider-aware endpoint/dependency interface. The existing raw-style → concrete maps → transient recascade helpers are necessary but insufficient for a full-value repair. Wiring them directly and accepting only fixed-pixel success would leave known architectural gaps in endpoint providers and potentially underlying values.

This is a concrete source-pinned implementation sequence, not a native candidate or conformance result. Production sources are copied from research-only HEAD449da6d3112d164287e6a76de66c45344e4cc2a7 in SOURCES.json. Searchfox discovery is saved separately because its indexed revision differs. Root's active composed diagnostic source/app transaction was not read as production source or modified.

## Exact public entry and cache boundary

Put the opt-in orchestration in nsComputedDOMStyle::UpdateCurrentStyleSources, after required flushes and shell/document validation and before its generation-cache early return. Keep the static DoGetComputedStyleNoFlush/GetComputedStyleNoFlush paths raw: internal animation callers use those paths and must not recursively compose the same pseudo. Resolve the originating primary and raw pseudo through the existing paths, return from lazy resolution before C++ effect capture, and recheck document/shell/target identity at the boundary.

Eligibility is an actual absent pseudo element, not merely an absent frame. Preserve ordinary elements, generated pseudos, unsupported or identified pseudo requests, flat-tree/disconnected restrictions, default-only styles, printing/non-dynamic behavior and the existing privileged visited-exposure gate. Before/After use the eager pseudo parent resolver; Marker uses the accepted lazy route with its existing layout-parent limitation. Do not label Marker eager.

A query-produced style must never satisfy the persistent generation-only cache check. Introduce an explicit request-local style marker, reset it with ClearComputedStyle, and clear the style through ClearCurrentStyleSources. Also reject marked cache entries on the next UpdateCurrentStyleSources regardless of whether the effect set still exists. Audit every exit: IndexedGetter and other no-style exits can return early; UsedFontSize does not call ClearCurrentStyleSources; GetCSSImageURLs has a no-style early return. A cleanup convention alone is therefore weaker than independently disqualifying query results from reuse. Test a retained CSSStyleDeclaration across creation, seek, mutation, cancellation and generated/absent transitions.

Do not publish pseudo ElementData or request renderer restyles to repair a missing pseudo. Preserve ordinary traversal, effect bookkeeping, overflow synchronization and transform-layer hints on their existing paths.

## Three distinct contexts

| Context | Required inputs and purpose | Existing seam / gap |
| --- | --- | --- |
| Origin/parent context | Current originating primary style, appropriate layout ancestry, inherited custom values, font/root/container state | Transient recascade accepts a primary style; keyframe conversion still independently rereads parent ElementData and container context |
| Underlying property context | Value below the current effect stack, preserving the correct dependency environment | Query helper currently extracts every base from one raw style; provider-dependent underlying semantics need explicit treatment |
| Endpoint/provider context | Current providers for each original endpoint declaration, including per-keyframe declarations, registration/attributes and logical mapping | Concrete conversion receives one complete style; no API yet schedules unresolved sampled providers inside the ordinary dependency cascade |

RefPtr/Arc ownership prevents premature destruction; it does not prove these contexts refer to one style epoch or sampled time. A coherent transaction must own specified keyframes, captured CSS generation settings/opt-out, refreshed named-range offsets, effect/animation identity, class/order, computed timing and endpoint behavior exactly once. Conversion must not reread changing effect properties or resample pending state between provider stages. Recheck identities after allowed flush boundaries; do not introduce an unbounded retry loop.

## Why one supplied style is not enough

Servo_GetComputedKeyframeValues constructs a derived context from its supplied style, but separately reads the parent style and ContainerSizeQuery. For a pseudo its inheritance parent is the originating element. Each keyframe seeds KeyframeCustomPropertiesBuilder from the supplied custom properties, overlays that keyframe's custom declarations, prepares typed attribute references, and uses apply_custom_and_prioritary_properties. Non-universal registered custom endpoints then read the computed result; ordinary endpoints pass through AnimationValue::from_declaration.

AnimationValue::from_declaration computes a value using the current Context, maps logical properties with its writing mode, and uses the supplied style for animated conversions. It does not apply each converted font-size or writing-mode endpoint back into a new current provider style. PrioritizedPropertyIter orders custom/physical/logical/shorthand categories; it is not a complete cross-effect provider dependency scheduler. A fresh supplied raw style therefore does not establish current animated font/custom providers for other endpoints.

The ordinary cascade already has useful machinery: Cascade::apply_custom_and_prioritary_properties invokes substitute_all for custom-property dependencies/cycles and ensures prioritary dependencies; ensure_prioritary_property walks its declared dependencies; apply_one_longhand performs cascade selection/rollback, substitution, scope selection and computed-value application. KeyframeCustomPropertiesBuilder reuses a restricted custom-only cascade. Any new endpoint route must preserve per-keyframe custom/attribute semantics and origin/cascade winner semantics rather than replace them with a hand-coded custom→font→everything order.

This also applies to underlying values. Servo_StyleSet_GetBaseComputedValuesForElement removes all own animation rules and recascades. That is the existing renderer policy, not proof that a single raw style can supply every dependency-aware underlying property. Keep the following discriminator unresolved until a dedicated spec trace: authored margin2em, animated font20→40 at half, additive margin10. A raw-font20 base suggests50; a current-font30 provider base suggests70. Neither number is asserted here as a new WPT oracle. The base issue must be resolved rather than hidden by replace-only tests.

The normative sources require effect composition against underlying values and define font-relative computation, but they do not by themselves prove the proposed implementation scheduling. [Web Animations composition](https://drafts.csswg.org/web-animations-1/#applying-the-composited-result), [CSS Values font units](https://drafts.csswg.org/css-values-4/#font-relative-lengths).

## Concrete implementation sequence

1. **Owned public-query transaction and tests.** Extend the accepted owned snapshot seam to carry explicit origin/parent/context identities and request-local output lifetime. Add the CSSOM-only hook/cache marker in nsComputedDOMStyle, initially as a copied experimental candidate. Exercise the existing20+9 CSSOM controls through the public API, plus the provider tests below from the start. The hook is not landable while any supported provider behavior is silently bypassed or any known expected failure is merely hidden.

2. **Retain endpoint recipes before eager conversion loses them.** At the KeyframeUtils/Servo_GetComputedKeyframeValues boundary, preserve owned original declarations, their keyframe-local context and source-property identities alongside the selected segment/timing data. Do not reconstruct recipes by uncomputing cached values: that loses var/attr, relative units, namespaces, tree scopes and logical identity. Logical-to-physical property selection itself must happen against the right writing-mode provider, so merely attaching a recipe to an already-selected stale physical ID is insufficient. Preserve duplicate/shorthand precedence and invalid endpoint handling.

3. **Add a request-local provider-aware cascade seam.** Factor the existing composition value operations into an owned Rust sample representation or equivalent recipe interface, with separate Animation and Transition roots. Let the ordinary cascade's selected property/dependency evaluation request an endpoint in its coherent context. Preserve custom dependency/cycle handling, typed attribute preparation, registration lookup, prioritary-property order, inherited/initial/rollback handling and important-origin winners. Select concrete transition endpoints without reinterpreting them as authored CSS keyframes. Keep the effect sample fixed while providers are evaluated. Avoid C++ reentry from within borrowed Rust document/cascade state; prepare owned input before entering Rust and do conversion/composition there or provide a proven non-reentrant interface.

   The precise missing interface is a cascade declaration/root that resolves an owned sampled operation when its providers are available, without publishing style or borrowing renderer effect arrays. Existing concrete maps cannot express that. A small finite multi-pass solution is acceptable only if it has a demonstrated dependency ordering/cycle policy equivalent to the supported cascade—not because two or three recascades happen to fix examples. No convergence or arbitrary iteration cap is justified by this review.

4. **Integrate provider-dependent underlying resolution and final recascade.** Define per-property underlying evaluation consistently with the resolved policy, preserve lower-stack transition contributions, and never feed a previous fully composed value back as the next iteration's base. Keep origin masks distinct from the conservative compositor mask. Current null-progress origin-selection interpretation remains a separate question; do not silently adopt the proposed in-effect policy as part of this missing-pseudo repair. Reuse the accepted transient recascade for final origin insertion and pseudo inheritance/layout adjustments once values are coherent.

5. **Close public behavior and ordinary-path/debug gates.** Run full exact public control inventories, existing keyframe/range/attribute preservation, targeted dependency cases and the debug historical transform-hint gate. Only then prepare a standalone bug1615083 native/WPT fix. Temporary privileged diagnostics and research machinery precede that delivery; they are not needed in the final fix commit.

## Existing drafts and reuse decision

PRIOR-DRAFTS.json records exact copied hashes of four preexisting untracked prototypes. AnimationComposeResult and animation_rule_sample/deferred_animation_operations already describe owned value-or-recipe operation roots. keyframe_endpoint retains declarations and has explicit unsupported statuses; its registered endpoint resolver says it does not schedule sampled roots or define animated-cycle behavior. These drafts corroborate the missing seam and avoid inventing a second arena. They are not tracked production implementation, not accepted prerequisites, and are not adopted by this report. Before reuse, review their ownership, complete value categories, dependency integration, failure semantics, memory accounting and tests against the current pinned cascade. No modifications were made to them.

## Adversarial public WPT inventory

Keep public tests centered on getComputedStyle with content:none and generated-pseudo/ordinary controls. Verify readiness and the sampled timing before interpreting values. Use exact numeric expectations only where independently established; comparison to a generated pseudo alone is insufficient if both paths could share a defect.

| Group | Adversarial cases | Oracle / gate |
| --- | --- | --- |
| Current font providers | Font20→40 at half; explicit margin endpoints1em→2em; change originating font and seek retained declaration | Check font30 then relative endpoint arithmetic; first trace whether current endpoint context yields45 before freezing the WPT |
| Underlying dependencies | Authored2em + animated font + additive/implicit margin; cancellation | Dedicated50-versus70 spec decision above; do not invent expected value |
| Custom providers | Registered length and universal token custom values; var consumer in same keyframe and separate effects; important custom winner; inheritance true/false | Pin registration and winner first; distinguish per-keyframe overlay from sampled provider; retain source-change and cancellation checks |
| Cycles and attributes | Registered length using em feeding font-size var; direct/mutual var cycles; typed attr fallback and attribute mutation; taint-bearing URL rejection | Reuse existing normative invalid-at-computed-value and taint controls; no new cycle default policy |
| Logical and shorthand | Current direction/writing-mode changes; logical and physical declarations collide; shorthand plus longhand duplicates | Assert final physical side and untouched opposite side with current writing mode, then mutate without recreating effect |
| Inheritance and origins | Animated originating parent font/custom/color; inherit/unset endpoints; transition provider plus WAAPI consumer; important font/custom override | Preserve current parent and origin winners; count actual transition class when retargeted; separate unresolved origin probes |
| Timing and generation | Pending/held/zero-rate/unresolved finite timeline; named-range attachment changes; CSS-generated implicit endpoints; JS setKeyframes opt-out | Retain existing timing/generation controls; one captured sample per query, no readiness mutation |
| CSSOM lifetime and privacy | Reuse declaration before/after effect creation/cancel/retarget; custom count/name enumeration; absent↔generated; detach/reattach; visited sanitization | Fresh values without persistent query cache or new pseudo publication; supported identity gates |
| Broader value context | currentColor, root/font metrics, container units and percentages/calc; display:contents originating element | Computed/resolved value contracts must account for no pseudo frame; do not assert invented used pixel sizes |

A compact first public fixture can group these cases, but dependency categories cannot be declared covered solely by the existing donor-map recascade tests. Those tests prove authored declarations respond to supplied providers, not that animated endpoints and their underlying values are computed from the correct providers.

## Remaining acceptance boundary

The immediate reviewable work is the public transaction/cache seam plus owned endpoint/provider interface and its failing-then-passing public dependency tests. The missing architecture is now named rather than left as generic future coherence work. Final acceptance still needs a debug build exercising ordinary traversal with animated transform and missing/generated toggles, CSSOM reads between animation ticks, and change-hint/overflow bookkeeping assertions. Optimized direct helper success does not waive that gate. No browser run, native build, canonical edit or Git mutation was performed in this design task.
