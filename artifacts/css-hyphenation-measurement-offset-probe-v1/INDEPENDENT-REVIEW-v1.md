## What the full dossier proves, and what it still assumes

The component chain is much stronger than the earlier event-only model. It now includes complete modeled Append control and arbitrary failure continuations, independent pending-source and ordered event chronology, indexed ownership capture, range/skip/transform projections, manager/loader models, sink identities/liveness/finalization and last-nonzero publication. Universal model statements and bounded complete native extraction are distinct evidence layers.

The source-range admission target is conditionally joined: `NativeFlowAdmission` derives slices and source order from ordered continuation metadata and an explicit whole transformed-buffer binding. This is not an unconditional theorem that every actual DOM/style/skip allocation arrives in that relation. `UniformWordPublication` derives target-word policy and complete fallible publication under admitted operations; it does not settle a mixed-language normative policy or bypass the source admission requirements.

Temporal invalidation is the most useful remaining ownership join. `Temporal.invalidation_removes_old_opportunities` clears a cached reference and selects a supplied fresh result. The proof does not derive that actual native reconstruction allocates/initializes suitable glyph storage and publishes precisely that fresh result. `OwnershipStreamComposition.zero_writes_do_not_establish_reconstruction` correctly retains the counterexample: zero writes preserve an old nonzero break kind. Universal removal of old opportunities therefore needs the actual invalidation/reconstruction-to-storage relation, including shared runs, pseudos, failure prefixes and zero-length sinks. Merely replaying additional dirtying fixtures would not close it.

The measurement join derives storage/query-length facts, including the full modeled ordinary/justification/tab computation. But `MeasurementSpacingProvider.completeSpacing` obtains a separate `tabState first finish` and returns only the spacing list from `calculateAndApply`; it discards that function's returned state. This is a valid per-query pure interface, not an association theorem for one persistent native PropertyProvider. Actual `CalcTabWidths` mutates mTabWidths, mTabWidthsAnalyzedLimit, mOffsetFromBlockOriginForTabs and the frame's TabWidthProperty. Persistent cache owner, source/style epoch, range start, property load/removal and recursion with ignoreTabs must be related across the actual sequence of measurement requests. `NEXT-PROOF.md` specifies that join.

`FilterBoundary` proves scalar-end safety for the supplied points/mask; actual points must still be associated with the decoded current word and the mapped dictionary resource. The universal filter implementation/reference equality is valuable but cannot establish that source/provider association by itself. The real retained synthetic mask-loss witness separately refutes all-opportunity completeness; it is not a shipped-dictionary/browser bug claim.

C++ array/refcount/atom representation, foreign Unicode/FFI results, actual font/shaping and defined numeric domains are explicitly named boundaries in the approved scope. This review does not invent a requirement to verify the whole compiler or all font rendering. It does require distinguishing such declared trusted providers from semantic connections that were promised but remain open: actual caller readiness, meaningful refresh, persistent cache/query association and complete consumer publication. `OPEN-GATES.json` preserves that distinction.
