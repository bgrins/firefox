The source audit separately maps sign(), computed context and opacity.

Round selects enclosing integer multiples of the absolute step. An exact multiple returns the input, including zero sign. Nearest ties choose the upper multiple; up/down select upper/lower; to-zero selects the smaller magnitude. A zero lower bound is positive zero; a zero upper bound is negative zero. Zero step and two infinite operands yield NaN; other infinite combinations follow the listed strategy/sign rules. The patch preserves the current special branches and four existing strategies; it adds no line-width syntax or other new feature.

The four discriminator operands are exact binary32 values: b=11184811/33554432 and a=±1. Since 2b<1<3b, positive down/to-zero select2b and negative up/to-zero select−2b. The negative opacity fixture adds1 after rounding. Promoting the final bound arithmetic is an implementation choice supported by the retained exact-oracle checks; the spec does not prescribe this algorithm or guarantee correctness merely because it uses f64. General numerical precision remains implementation-defined under §5, and the finite helper checks are not a proof covering every binary32 input.
