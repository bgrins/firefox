# Registered-number selected-dependency WPT fixture

This package prepares genuine WPT inputs for a clean signed-HEAD original/candidate experiment. It does not run a browser, change live WPT files, choose candidate source pins, or claim acceptance of a native repair. Root will freeze a paired runner after the combined clean-HEAD native proposal is reviewed.

The new testharness page has **58 named tests**: all 14 earlier probe rows, all eight normative cases, eight selected-cycle/type/attribute controls, twelve CSS-wide controls, four declaration/query-order controls, three provider/attribute mutation tests, three inheritance mutation tests, and six additional admitted-AST controls. The normative division cases include both direct and provider-introduced `calc(1em / 1px)` with a fixed 20px font changed to 30px. No cases were deduplicated; `COVERAGE-MAP.json` maps every prior row.

`candidate/` contains the proposed WPT page. `capture/` contains that exact page, 21 unchanged regression pages (15 testharness pages and six reftests), four reference documents, required resources, headers and metadata. The regression roster has **446 named assertions**: the previous accepted raw suite's 402 actual passing names, plus 44 statically enumerated names in five existing registered-property pages. `SELECTED.json` therefore lists 22 pages total. `SUBSET-MANIFEST.json` was generated by the repository's real WPT manifest library; all 21 regression manifest entries remain identical. Existing metadata, including an Android intermittent expectation, is copied unchanged.

`observation-only.html` is not selected in WPT, absent from the manifest, and has no testharness assertions. It records self-font numeric division in four declaration/query orders. This unresolved normative case must never be converted into an expected result or accepted-fix evidence by this package.

The raw attribute-cycle pages are the accepted, tested post-fix pages, including the three explicitly adjudicated historical oracle corrections. Their captured bytes match the installed WPT inputs. They are unchanged regressions here, not targets and not newly revised oracles.

The 14 probe rows preserve CSS declarations, parent declarations and expected font size exactly; the new page additionally asserts the registered number. The original probe's repeated query mechanics are not claimed identical: four explicit order controls cover number-first/font-first reads separately. Browser-visible provider/attribute mutation tests cover missing, ready, wrong-type, real selected cycles and recovery. They do not force or observe an internal native pending state; separate native resolver tests remain necessary.

Cycle controls retain actual selected var self/mutual cycles and typed attribute/property cycles. An attribute-only cycle selects its outer attribute fallback; a wrong-type but present universal primary does not retry a numeric fallback. The explicit `<number>` attr grammar rejection control does select its attr fallback. The package does not settle unused-var-fallback graph semantics or prove parser/taint correspondence.

The Firefox desktop frontend skill was applied. Inline styles and synchronous computed-style reads are deliberate test inputs and observation points. No product UI is introduced.

`enumerate.js` validates JavaScript syntax and registers names in a stub context without invoking test callbacks. It authenticates the 14 prior rows and eight normative inputs/expectations. Stubs for existing unit-cycle setup only allow name enumeration; their assertions are never simulated. Static success is not browser validation. `verify_capture.py` authenticates captures, absence roles, reference files, source inputs, real manifest entries and exact roster boundaries.

A future paired runner must bind clean signed-HEAD original and combined candidate native source roles, caller-supplied frozen HEAD/epoch, phase-specific compiled transition, application.ini symlink target and BuildID, all binary/source pins, full preservation and owned-process cleanup. It must require all 58 target tests to pass in candidate and retain exact original/candidate regression signatures, reporting any baseline failures explicitly. No executable runner or provisional baseline is provided here.

Known tooling limitation: Searchfox discovery succeeded, but its subsequent get-file requests failed DNS resolution. The discovered local WPT paths were captured with exact hashes; empty redirected placeholders were removed. No bootstrap, browser, build, live manifest or metadata mutation was performed.

Root-relative tests restore the complete original root style attribute. No assertion is added for self-font numeric division or for an internal collector return value.
