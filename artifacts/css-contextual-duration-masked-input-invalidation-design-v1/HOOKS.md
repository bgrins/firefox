# Proposed implementation hooks — no executable patch

| Hook | Existing behavior | Proposed change / required proof |
| --- | --- | --- |
| `MatchMethods::needs_animations_update` | Existing positive reasons followed by false for equal composed lists | Keep these reasons; do not replace false with true. A separate bounded verifier reason belongs at task discovery. |
| Gecko `MatchMethods::process_animations` | Normal-traversal CSS_ANIMATIONS/EFFECT_PROPERTIES and transition task collection; existing animation-only early return | Add a distinct timing-input verification task bit for eligible otherwise-skipped targets. Preserve the existing EFFECT_PROPERTIES path and transition-before-change payload. No verification in animation-only traversal in this local experiment. |
| `SequentialTask::UpdateAnimations` / wrapper | Main-thread update uses current published style; prepared-style prerequisite is separate | Carry only verification intent unless an owned style transaction is explicitly validated. Never reuse transition `before_change_style` as an old timing snapshot: it is optional and has different semantics. |
| `Gecko_UpdateAnimations` | Dispatches CSS manager and independent effect/transition work | Handle the new verification reason without suppressing existing full-update reasons. The captured public excerpt is discovery evidence, not a fresh tested-branch full-body join; obtain that join before coding this switch. |
| `nsAnimationManager::UpdateAnimations` | Null/display:none stop path; composed `ServoCSSAnimationBuilder`; composed UIReset passed to DoUpdateAnimations | Add a verification-only entry/helper that resolves and compares duration inputs before entering DoUpdateAnimations; preserve builder/input for existing ordinary updates. A future pre-own selection change is separate. |
| `Servo_StyleSet_GetBaseComputedValuesForElement` | Removes all animation cascade origins, recascades with current parent; no global root publication | Provides one concrete candidate key computation, not a policy-neutral base value or stable parent snapshot. Missing pseudo must not seed from a different target/fallback style as if equivalent. |
| `DoUpdateAnimations` / collection creation/destruction | Builds/reuses animation collection; destroys empty result; updates named timeline bookkeeping | Seed/commit owned snapshot after successful transaction; clear on cancellation/destruction. Store duration list independently of effect override state. Exact collection field/type placement and lifecycle census remain implementation work. |
| `UpdateOldAnimationPropertiesWithNew` | Copies duration only if CSSAnimationProperties::Duration is not script-overridden | Reuse unchanged. Snapshot equality is not permission to clear overrides; changed source input does not transfer ownership from script. |

Minimal discriminating local variant without persistent state: compare freshly resolved old/new base duration inputs only when non-animation rule paths differ, restricted to direct target declarations with unchanged inherited/environment inputs. This can isolate the element inline-font case, but does not cover the pseudo inherited-variable control or general inherited changes. Those preconditions are not available as a proven existing bit, so this is a diagnostic alternative, not the recommended general fix.

Before a native patch: authenticate the full Gecko dispatcher and collection lifecycle against the current branch, decide the snapshot's selected-input policy, define unknown/seed behavior and stale-task transaction validation, then use actual original/isolated candidate control outcomes. No unconditional normal-restyle manager admission is justified by this document.
