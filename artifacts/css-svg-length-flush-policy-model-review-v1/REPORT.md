## What the result establishes

The selector and requirement are defined separately. `required` assigns semantic dependency tiers to ten distinct public units; `selected` reconstructs the implementation’s percentage/font tests on their numeric codes. Exhaustive finite proofs establish the exact equivalence between selection being no stronger than an available tier and that tier covering both endpoints. This is meaningful minimality in the modeled three-tier order, not circular minimality obtained by defining sufficiency as the selector itself. It does not prove that these semantic dependency assignments are sufficient for every real provider or necessary for every numerical result.

Exact unit identity is not dependency equivalence: em→ex is unequal and requests Style even though both require the same tier. All ten units map injectively to public codes1…10; Layout dominates a simultaneous font requirement. The unequal-unit premise on `differing_request_minimal` is necessary because same-unit conversion bypasses acquisition.

`ProviderContract` is an explicit successful-acquisition assumption. It requires current factors for covered units after a successful tier acquisition; at None it requires context-independent factors already correct. `selected_factors_ready` obtains the two readiness equalities from that contract and independently proved sufficiency. `repaired_preserves` directly invokes the existing `UnitConversion.ready_preserves`, preserving the actual target unit and current denotation after a successful conversion. It does not assume the final result-preservation conclusion as its provider contract. The explicit refreshing provider proves that the contract is inhabited; the incomplete provider demonstrates that selecting Layout alone does not establish it.

Same-unit preservation is separately proved without a provider contract and remains valid for stale or zero factors because it preserves the representation unchanged. Conversion failure and provider failure are not turned into successful values. The percentage and font counterexamples actually exhibit stale target factors causing incorrect represented values, rather than merely asserting a wrong tier label.

Same-unit laws do not assert that all native scalar initialization/notification side effects are absent.

These are stated limitations, not blockers for the actual theorem claims. The model improves the previous library obligation by deriving both factor equalities from a minimal selector plus a successful-provider contract; it does not prove document flushing itself satisfies that contract or certify all SVGLength calls.
