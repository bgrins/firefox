# Proposed source-bound companion scope

The preliminary 12 results are not a full companion. A complete bounded proof should preserve these obligations before acceptance:

1. Applicability and branch preservation: bind the frame-aware relative predicate to ReflowInput's offset producer and FinishReflowChild's relative/sticky gate; preserve all nonrelative/sticky paths, skip/eligibility branches, flags and caller identities. The six retained callers all pass Default. A hypothetical NoMoveFrame caller is outside the observed roster and must not be silently imported as proved.
2. Predecessor origin: establish continuation normal-property readiness for the actual ordered reflow path, and the fallback semantics when absent. Do not assume previous used position is normal. Include style transitions and prior dynamic positioning; preserve a counterexample whenever absence allows an inherited inline offset to become the cached normal position.
3. Coordinate transfer: join actual child/predecessor writing modes, passed physical container size, predecessor/current physical dimensions and the concrete logical inversion. No equality of actual sizes is required algebraically; any size equality claimed by a provider must be derived separately. Every executed signed operation must satisfy its representability condition; do not replace them by a final simplified cancellation.
4. Offset provider and commit: consume the current ReflowInput computed margins, including both physical components, after FinishReflowChild installs the actual returned size. Show NormalPositionProperty stores the unshifted physical point, final SetRect uses exactly one offset, and ConsiderChildOverflow consumes committed geometry. Percentage/auto/overconstrained inset resolution can be an explicit upstream provider boundary if its actual outputs and numeric preconditions are retained, not a zero-offset substitution.
5. Dynamic cache join: bind actual RestyleManager continuation traversal, property read/default/store, computed offsets and SetPosition. Prove the same normal property supports zero→offset, nonzero→different offset, offset→zero and repeated updates. Restrict the theorem to frames admitted by RecomputePosition's real early guards; dirty/reflow paths must use the native reflow theorem instead.
6. Lifecycle and observers: preserve list/tracker/status code and eligibility; account for dirty reflow, skipped existing children, dimensions changing, property refresh and overflow union. Browser geometry alone is not proof a skipped branch executed. Shared fieldset/block/canvas/grid/table users require their source/caller assumptions and targeted regression gates; do not claim only flex is changed.
7. Replay: genuine before/candidate source snapshots, exact helper/provider extraction and role pins, primitive kernel challenges plus source-semantic mutants (used-position+apply, normal-position without apply, cached-used-as-normal), closed source-only canonical/relocated replay, forbidden-axiom controls and no extra compiler caches. Native build/browser evidence must authenticate exact tested bytes separately from formatting transfers.

The standalone ordinary-coordinate bugfix does not inherit the broad packing/exact-fragment proof or fix its unrelated numeric/temporary-size issues. Conversely those known independent failures do not establish an introduced regression in this bounded relative-position repair. Record concrete boundary cases and reject any overbroad theorem without relabeling its original contract.
