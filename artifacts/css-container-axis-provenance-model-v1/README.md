This is a conditional container-dimension provenance model, not a CSS conformance or Rust refinement proof. Seven named Lean theorems pass kernel checking; five deliberately false controls are decisively rejected. Replay used Lean 4.35.0-rc4, session76695 terminal075ec4 exit0. Dimension groups a source identity, nonzero source zoom and raw length. Axes stores separate optional width and height records. merge chooses the nearest available whole record independently on each physical axis. normalize_merge proves that normalizing the selected records commutes with this merge; source and scale are never selected independently. recover_source_value then recovers a canonical value when raw evaluation factors through that record's scale. normalized_bounds proves that min/max after independent normalization returns the bounds of the two canonical values. The imported Normalization.lean is byte-identical to the prior registered-zoom model.

PositiveZoom is explicitly a nonzero natural number. The generic length model uses the prior Scaling structure and its explicit left-inverse hypothesis. The concrete exactNaturalScaling instance proves cancellation for positive integer scales and integer lengths produced by multiplication. It is an exact-arithmetic example, not a model of every CSS zoom. Fractional zoom, negative lengths, f32/f64 division, app-unit rounding, clamping, overflow, subframes, transforms and full-page zoom are outside this artifact.

The concrete records use outer width640/sourceZoom2 and inner height120/sourceZoom1. Their normalized dimensions are320 and120; the minimum is120 and maximum320. Replacing both source scales with targetZoom2 incorrectly makes height60. Five rejected controls cover that mistake, min-before-normalization, attaching the outer zoom to the inner height, unzooming already canonical viewport fallback, and treating guarded zero as a zero scale. guardedZoom maps zero to the identity scale separately; no cancellation theorem admits a zero divisor.

Viewport fallback is passed as an already canonical value and is returned without source/target unzoom. That is an explicit representation precondition. The proof does not establish which Gecko quantity is canonical or scaled. Likewise fromCanonical encodes the raw-factorization precondition; it does not prove that frame dimensions, fonts or containers meet it.
