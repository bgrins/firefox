## Why this avoids the identified fix70 dependency

The retained clean-base animated_properties.mako.rs already implements PropertyDeclaration::WithVariables by substitute_variables against the supplied Context, then recursively converts the substituted ordinary declaration into an AnimationValue. margin-left takes that route. The provider's endpoints are literal numbers, so it does not require the typed Unparsed var() consumer route that committed fix70 repaired. The relevant clean-base sources are pinned in the landability audit c5a51190; the one-file compositor preimage is exactly the clean-base body and its patch dry-run passes.

This is source-based independence from the identified custom-consumer conversion, not a clean-base runtime result or a proof of complete native independence. Pending130 ordinary attr() preparation and131 attribute watch publication are not used; no attr(), taint, changed registration, CSS-wide or invalid endpoint is introduced. Pending129 CSS-duration reactivation and unaccepted dormant/active sampling work are not invoked. Ordinary interpolation, additive length composition, the provider's current full computed context and synchronous commit serialization still need actual browser validation. A multi-hop provider chain remains outside the production proposal's scoped guarantee.
