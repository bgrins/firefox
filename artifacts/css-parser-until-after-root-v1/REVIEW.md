# Root review: parser delimiter continuation

The fresh manifest-only replay passed 22 general theorem audits and 11 finite
kernel challenges, followed by 27 exact-source native histories with 138 equal
snapshots in debug and release. All six compiled native mutants execute and
produce the recorded semantic differences. Four unsupported model providers
are rejected. This is component verification; no new browser defect is claimed.

Read the complete UntilAfter model/proofs, root challenges, inherited
NestedControl and WrapperControl contracts, PublicAnnotations, the calibration
driver/controller, native build/adapter/mutations, and ten complete source body
bindings. Current parser.rs and tokenizer.rs match the retained source hashes.

The independent continuation consumes a source token, whereas the native-shaped
continuation advances one byte. Their agreement follows from an explicit lexical
delimiter law, pending-block cleanup and a boundary derived from the before phase.
Outer ownership takes precedence even where requested and enclosing masks overlap.
Stop/error returns the exact before-phase state. The direct continuation preserves
the existing coherent cache; this does not say arbitrary callback execution leaves
the original cache untouched. Curly cleanup uses the accepted raw block relation.

The result preserves the inherited alignment projection and control fields.
Alignment excludes URL annotations; separate continuation write equations cover
those effects. A complete source-only URL projection through arbitrary represented
callback programs is still a composition task, not supplied by this acceptance.
The finite native projection does compare both URL fields, tracking, cache and
controls for its restricted callbacks.

The predecessor renderer swapped closing-curly/parenthesis bits and omitted the
opening-curly bit. The correction authenticates both old 91-row traces, whose
observed masks are all zero. The old finite comparison remains supported only
within that recorded scope. The new native/model cases exercise nonzero masks.
Frozen predecessor artifacts are preserved.

Remaining admissions include source/provider correspondence, lexical progress,
valid native UTF-8 and machine offsets, cache/history validity, represented
callbacks and normal return, native compiler/runtime and installed Lean libraries.
The formal result is not an automatic Rust translation, whole-parser verification,
CSS specification equivalence, or a native memory-safety theorem.

A separate draft DelimiterProvider module now derives the delimiter law from
ByteLex and an explicit punctuation-width contract. Its final corollary still
requires global provider progress. The actual finite driver does not satisfy
that premise on every family/input pair; independent review retains this boundary.
This draft is not part of the sealed until-after component or its audit count.
