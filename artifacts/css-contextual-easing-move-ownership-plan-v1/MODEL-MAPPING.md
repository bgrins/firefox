# Existing model boundary and the new browser witness

No Lean source or theorem is added. The sealed ownership modelv2 remains an abstract protocol with supplied selection and numeric context. Its successful_override_shields and rejected_call_erases_from_trace results are reused without new proof-discovery credit.

| Model premise or branch | Concrete fixture obligation |
| --- | --- |
| Fixed element, association and referenceRoot across refresh | Same target object, original CSSAnimation and KeyframeEffect, same shadow root, animation name and selected CSS rule/keyframe objects before/after/back |
| Supplied elementContext may change | Directly move the animated target between two parents; measured sibling index2→3→2, or own inherited font16→24→16px |
| CSS-owned refresh evaluates current expression/context | Unchanged expression gives steps2→3→2 and opacity0.5→2/3→0.5 at paused750ms; effect frame serialization changes and recovers |
| Successful literal override shields script frames | setKeyframes steps5 retains byte-equal frames and opacity0.6 through both moves; a parallel CSS-owned moved target still changes |
| Rejected processed call is inert | Plain offset2 call throws TypeError, leaves immediate frames unchanged and permits subsequent CSS-owned refresh |

The original model witness changes expressions while holding context fixed. The completed three rule-expression callbacks correspond to that witness. This new fixture changes context while holding the expression/rule/reference-root/association fixed and checks that a native state-preserving move actually discharges the otherwise external association premise. No DOM move operation, style invalidation algorithm, object-identity semantics, CSS arithmetic or rendering pipeline is proved by the abstract event model.

The sibling-index branch holds own font16px and sibling count3 fixed. The inherited-font branch necessarily also changes topological index, but its easing expression depends only on own font; the index is measured rather than assumed. Both branches keep count3. A count-dependent branch could be added later only for a separately justified invalidation gap; this proposal avoids another Cartesian-product expansion.

Declaring-root changes/bug1458189, rule removal, name changes, effect replacement, cancellation, arbitrary script reentrancy, animated numeric feedback and transition-start scheduling remain outside scope. The known WithVariables boundary is unchanged. Six future passing browser callbacks would supply bounded native correspondence evidence, not a new theorem, bug count or acceptance.
