# Same-association move obligation

Primary drafts read on2026-10-29:

- [DOM move algorithm](https://dom.spec.whatwg.org/#concept-node-move) checks shared shadow-including root, reparents through its separate move primitive and invokes moving steps rather than insertion/removal steps. Our fixture is stricter: both parents and targets retain the identical uncomposed shadow root throughout. It uses no custom elements, slots or author callbacks during movement.
- [CSS Animations2 ownership precedence](https://drafts.csswg.org/css-animations-2/#animations) makes successful setKeyframes overrides authoritative over subsequent CSS keyframe updates; throwing calls do not acquire that override. The cancellation exception for removal of the last matching rule is excluded.
- [Web Animations setKeyframes](https://drafts.csswg.org/web-animations-1/#dom-keyframeeffect-setkeyframes) leaves effect keyframes unchanged when argument processing throws. Offset2 rejects. The plain data arguments have no getters, iterators or reentrant author side effects.
- [Tree-counting functions](https://drafts.csswg.org/css-values-5/#tree-counting) and [font-relative lengths](https://drafts.csswg.org/css-values-4/#font-relative-lengths) supply the target-relative numeric inputs. These inputs are measured independently in each snapshot.

The browser obligation is the composition of move preservation with CSS regeneration and the existing override rule. DOM's separate primitive alone is not a theorem that every CSS animation association persists. The fixture therefore explicitly checks CSSAnimation/effect/target identity, a single animation, unchanged name/rule objects, currentTime750, paused state and no pending task. Neither an unchanged name nor a shared composed root substitutes for those checks.

Searchfox source reads are retained in three small logs. CSSAnimationKeyframeEffect::SetKeyframes returns on processing error before the keyframe-generation/override changes. The current nsAnimationManager Keyframes override gate remains present; its detailed historical source join is authenticated by REFERENCES.json. nsINode::MoveBefore validates shared root/reference-child legality and propagates old/new parent information through removal/insertion calls. Searchfox failed DNS in the initial sandbox call; the read-only network retry succeeded. Failed generic-symbol discovery is not treated as source evidence.

The locally accepted Element::UnbindFromTree excerpt in SOURCE-READ.json keeps ClearServoData and ClearAllAnimationCollections behind !IsMove. Its file hash matches the completed experiment's accepted payload. The exact activation-v2 matching.rs capture requests an animation update on ordinary restyle when the selected keyframes have contextual timing. Together these paths motivate testing that the move retains the existing override bit while refreshing target context; they do not establish that the complete native path behaves correctly. No native defect is claimed from source inspection.
