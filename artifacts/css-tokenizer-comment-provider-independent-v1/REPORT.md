## Model and source adjudication

`CommentScan.reference` computes adjacent delimiter marks and the first marked position independently of the recursive `scan`. It handles a lone final star, EOF, non-nesting and the first terminator. `CommentExecution.run` composes that result with complete grouped-newline and ordinary-byte state updates. `nativeRaw` validates the opening itself; illegal helper input returns `none` only in this mathematical wrapper, with no such native-helper guarantee inferred.

The observer reference uses a pending-CR byte fold, whereas the modeled native loop groups CRLF. Its whole-unit theorem then accounts for UTF-16 width. Continuation bytes update the native adjusted line-start while the cursor is temporarily inside a scalar; no theorem requires every intermediate cursor to be a character boundary. The ASCII terminator cannot occur inside a continuation sequence. The returned body and suffix consist of complete encoding units. `Boundary.Unit` admits shapes broader than valid Unicode, so the Rust-str/codec connection remains an explicit premise.

Directive parsing checks exact modern/deprecated headers and the five native whitespace delimiters. Both fields preserve their old values on no match, overwrite with an empty value on a matching empty directive, and update for unterminated comments too. The universal history theorem is over supplied body lists. The per-call raw execution theorem can support such direct-call composition; it does not establish parser cache/reset behavior. URL fields live outside `ParserState`, so that omitted caller obligation is material.

Native storage is represented honestly: two low block bits, a 30-bit line counter, wrapping adjusted line-start and u32 column projection. Source `advance_line_number` performs ordinary addition; debug overflow abort and release wrap are deliberately reproduced at the boundary. The supplied conservative capacity theorem is a mathematical bound that can be applied to every consumed prefix, including the opening bytes. It is not a universal machine-arithmetic/representation refinement. `has_at_least`, byte indexing, unsafe slicing, actual usize capacity, immutable borrowed-input lifetime and compiler/macro behavior remain external admissions.

The Rust witness replaces `match_byte!` with ordinary match and uses minimal parser/state facades. This is adequate for the declared finite source agreement, not proof of the actual fast macro, full parser layout, all feature configurations or Rust compiler. No unsupported lowering claim was found. The independent source audit verifies the supplied bodies rather than trusting the generator's first same-indentation closing brace as a general-purpose Rust parser.
