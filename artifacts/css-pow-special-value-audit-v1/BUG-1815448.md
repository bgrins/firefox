**2023-02-07 14:51:23** - Comment #0 by tlouw@mozilla.com
The parser assumes that all the functions are distributive, e.g.

```
calc(calc(1 + 2) * 2) == calc(2 + 4)
calc(round(3.1456) * 2) == calc(6.2912)
```
Some newer functions like `sign()` doesn't work like that:

```
sign(1) * 2 != sign(2)
```
