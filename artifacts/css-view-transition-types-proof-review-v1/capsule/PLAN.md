# Initial type deduplication companion

## Preserved acceptance scope

The accepted native review's proposed companion is the scope, not the broader scout's separate invalidation/lifecycle proposals.

1. Independent first-occurrence ordered-set reference over exact DOMString UTF-16 code-unit lists.
2. Native startup seen-set/vector accumulator: every processed prefix, uniqueness, first occurrence order, complete membership, seen/vector agreement. Hash-table iteration never supplies output order.
3. Atom interning bridge: identity iff exact code-unit equality; case and surrogate preservation. Prove conditional transport of initialization and successful operation histories; do not assume final vector correctness as a provider premise.
4. Ownership: prove every weak seen key has an owning vector entry at iteration boundaries, and either the local reference or vector owns it during insertion. Actual RefPtr/move/allocation/cache lifetime behavior is source-reviewed and admitted, not a verified C++ memory model.
5. Lazy successful backing initialization and stable repeated materialization; public/native ordered equality and uniqueness.
6. Successful Add/Delete/Clear/Observe: existing add leaves position, absent add appends, delete removes the first native occurrence versus every specification occurrence, return value tracks prior membership, clear empties both. Arbitrary finite histories, identities/document fields and ordered observable contents.
7. Direct selector observation joins document active pointer, transition native list, root/state, parsed valid query names and public membership. No-active, false-state, multiple-query and foreign-owner controls.
8. Retain duplicate-deletion counterexample, missing provider premises, ignored lazy helper errors, invalid-name filter and state/owner counterexamples.
9. Authenticate exact source bodies and accepted native/WPT evidence; fresh Lean replay, source-shaped extracted C++ control calibration with explicitly substituted providers, compiled semantic mutants and strict execution integrity controls. Artifact source must freeze before independent review.

## Boundaries

Native atom/cache/hash/array/RefPtr and generated JS realm/Set behavior remain explicit provider contracts. Successful helper calls include initialization's ignored errors not occurring. No OOM/GC, all asynchronous lifecycle, cross-document/scoped transitions, live iterators, native memory safety or restyle cache invalidation theorem. Browser evidence is the accepted historical 21-case pair and 3 candidate-only mutable tests; no fresh browser claims. Reserved/invalid selector policy is separately filtered; public TypeSet accepts arbitrary strings. Completed-transition interference and style invalidation remain open, not downgraded to this set proof.

## Tool trust

Lean and C++ executable paths/hashes are pinned for replay. Installed Lean Init/Std compiled libraries, compiler implementation, runtime, OS and hardware are trusted; no exhaustive standard-library inventory is claimed. C++ control extraction replaces only documented external providers; it is not a full Gecko build or whole native translation proof.
