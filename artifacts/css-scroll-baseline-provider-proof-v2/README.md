    python3 -I -S /absolute/path/to/check.py --output /absolute/absent/external/output

The controller validates an exact regular-file and directory roster, source bindings and independently reconstructed finite inputs before compiler dispatch. It rejects unsafe Python modes before other imports. It compiles all modules, checks exact axiom/name inventories, compares full extracted native methods to independent Python and Lean observations, runs source and model semantic mutants, and reauthenticates inputs after each stage.

    python3 -I -S /absolute/path/to/test_integrity.py --output /absolute/absent/external/guards

Only tool executable bytes are pinned; compiler headers, Lean libraries, OS and runtime remain trusted. Source extraction/adapter correspondence requires human review; passing this checker is not automatic C++ or CSS refinement. Source and proofs are immutable after external handoff. Generated outputs belong outside this capsule and can be removed after retaining command/raw/result/cleanup receipts.
