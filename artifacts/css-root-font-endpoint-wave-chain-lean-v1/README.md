# Finite parent-dependent endpoint waves

This compact extension imports the sealed endpoint/application model unchanged. It gives a terminating **specified wave scheduler** for a finite acyclic font-dependency chain. It does not equate that scheduler with Gecko's coalesced restyle queue or count native passes in the depth probe.

A chain has `depth` nodes indexed 0 through depth−1; root is an external stable value. Node 0 computes from root, and node i+1 computes only from node i's installed value. `compute` is an arbitrary fixed, pure, total deterministic function for each node. Nodes retain the previous model's endpoint generation/value, installed generation/value and application queue. Initial states may have arbitrary values and queued work, provided they satisfy that model's generation/coverage invariant.

One `wave` takes a snapshot of the preceding chain, recomputes each in-range endpoint from that snapshot's parent value, then refreshes/drains that node through the existing application relation. All parents therefore come from the **previous** wave, not an earlier sibling operation in the current wave. Only the finite prefix changes; indices outside it are unchanged. A function indexed by Nat is a convenient representation of this finite prefix, not an infinite set of scheduled nodes. `waves` is structurally recursive on its finite budget; no unbounded search for equality or queue quiescence is used.

Two different conditions are proved:

- **Local application readiness:** after a wave, each processed node has drained its own queue and installed its own current endpoint. This alone does not establish that the endpoint was computed from a globally current parent.
- **Global dependency coherence:** `expected` recursively computes the chain from the stable root. `rank_bound` proves that node i's installed value equals this independent expected value after any budget ≥i+1. The proof advances the coherent frontier by induction on node rank, using the previous-wave parent theorem; it does not assume the desired installed/read equality. `depth_waves_ready` combines this with local readiness for every node after any budget ≥depth.

Consequently, executing exactly `depth` complete waves and returning is a finite, globally ready schedule under these premises. The substantive result is readiness at termination, not merely termination of a fixed-count loop. Depth is a sufficient worst-case bound for this scheduler; constant functions or already-current nodes may settle earlier. The theorem does not prescribe a native loop of depth passes.

The counterexample family uses a stable root1, zero-initialized descendants and doubling functions. After k waves, node k of a depth k+1 chain is still zero, while its recursively expected value is positive. `no_depth_independent_budget` proves this for every natural k. The concrete three-node/two-wave control has a locally ready leaf (current endpoint installed, empty queue) with value0 instead of8. A genuine false control rejects the implication from that local readiness to global coherence. Three waves reach8; a separate four-node/root32 arithmetic control reaches512. These are formal examples, not fitted native measurements.

Native obligations remain substantial:

1. A fixed finite acyclic parent-only graph, a stable selected root/provider and unchanged deterministic computation functions during settling must be established. No feedback to ancestors, changing animation progress, dynamic target/graph changes, external invalidation or transition creation is represented. Other frozen inputs can be parameters inside the functions; their stability is assumed.
2. Native invalidation, routing and queue coalescing must preserve every needed descendant refresh and provide fair execution. This scheduler recomputes every in-range node on every wave, so it supplies that scheduling property by definition. It does not prove Gecko does so or propose the associated performance cost.
3. A native wave boundary and parent snapshot relation must be justified. Native asynchronous work, parallel traversal and composition are not assumed to use this synchronous old-parent snapshot, and no one-to-one pass/wave mapping is claimed.
4. Each native endpoint computation and application must implement the imported transition relation for the correct target/pseudo/effect lifetime. Composition, interpolation, generation representation/overflow, style installation and observer ordering remain outside this model. Nat payloads are mathematical descriptors, not a floating-point CSS font implementation.
5. A readiness-respecting getter must observe after required dependency propagation/application, with no intervening unaccounted input change. Native feedback/cycles require their own policy; this acyclic theorem cannot justify an unbounded native drain loop.
