# Selected declarations and selected registered values must agree

A precise winning-declaration traversal is insufficient if the custom property's reverse edge still comes from registration-wide syntax capability. This small bridge imports the exact existing declaration scan/demand evaluator and selected-color parser/cycle oracle, with no changes to either model. It formalizes the interaction exposed by `Selected identifier color-scheme dependency: union-plain` in the completed ordinary lane: original PASS becomes candidate FAIL with both custom value and scheme `normal` in the light/dark phases. The sealed source review pins these observations; this package did not inspect later lanes or infer an owner terminal/restoration result.

`winning_reference_is_retained` uses `SelectedDeclaration.terminal_ignores_tail` and actual `DemandFallback.eval` to derive the winning `--v` read for every finite lower-declaration suffix and abstract token. The terminal evaluator, initial eligibility and token value are supplied model inputs. The demand evaluator's literal text is an opaque token label; its read trace is used here, not a claimed CSS serialization/parser correspondence. The imported first-success finite parser classifies that token separately.

`read_graph_requires_selected_reverse` states the general local obligation: given a reached forward read, equality with the selected-value graph's cycle result holds exactly when the proposed reverse edge equals selected-value dependence. It uses the imported independent two-node cycle enumerator and its existing edge theorem. This is a local graph obligation, not an arbitrary-graph SCC theorem.

The concrete arbitrary-suffix witness preserves three distinctions. The old omitted forward edge hides the broad reverse edge; adding the genuine selected read makes the broad graph cyclic; classifying light/dark as identifiers removes the reverse edge and leaves the genuine forward read intact. A separate system-color witness shows why dropping the winning read or suppressing every reverse edge is not a repair: the genuine two-node cycle then disappears. The two false controls actually reject both proposed shortcuts. No new graph evaluator, fallback evaluator or parser is introduced.
