# Direct missing-pseudo query driver

This is isolated, temporary instrumentation for exercising the request-local helper. It does not change the public CSSOM query path or claim to fix bug 1615083. No native build, browser execution, live source, browser bundle, canonical library or Git mutation was performed here.

## Inputs and application

`BASIS.json` authenticates 11 files: eight exact copied files from the frozen query-input candidate and three original Git sources at `3f8f7324c20de730eddcf07b224dd93e9be6694d`. First apply that capsule's cumulative `candidate.patch` (SHA 29390ea55c62ceefb36395a0a0657c26600a859991d937caa97f437a754b3757), then this capsule's `generated/driver.patch`. Do not apply the query candidate over its individual prerequisites. This driver's patch changes five files: window-utils XPIDL/implementation, test-only Animation friendship, one mochitest and its manifest. The complete copied overlay is `generated/candidate/` (12 files including cumulative prerequisites).

The XPIDL method is `getMissingPseudoAnimationValuesForTesting(element, pseudo, property, flushType)`, returning a JSON string. This instrumentation must not land as a shipping web feature. It accepts one non-custom longhand, a composed element in this window's document, and exactly FLUSH_NONE or FLUSH_STYLE. Invalid diagnostic arguments throw. Helper-level rejections instead return `admitted:false` with null map values.

## Actual call path and ownership

The driver completes any explicitly requested style flush first, then snapshots strong effect/animation/timeline references, exact target identity and selected raw timing fields. It calls the unchanged raw lazy style resolver and lets that call's guards/borrows end before invoking the helper. EffectSet membership and effect-to-animation identity are checked immediately before and after the helper calls. No EffectSet iterator spans conversion.

The driver first verifies that aliased output references and already occupied output references are rejected without changing their ownership. It then invokes the ordinary empty/distinct-output call, serializes the requested property from each map separately, and destroys both maps at the end of the request. There is no insertion of animation rules, computed-style field overwrite, persistent cache, renderer composition or transient recascade.

`stateUnchanged` compares the captured target/effect/animation/timeline identities, timeline range, hold/start times, exact pending enum, raw playback and pending playback rates, pending-ready timestamp, auto-align flag and cascade level; it also covers the EffectSet membership checks. The snapshot precedes raw lazy resolution, so changes during preparation count as failures too. This is a comparison of named fields at boundaries, not a complete renderer-state digest, a detector of mutate-and-restore behavior, or a proof against reentrant mutation. The temporary friendship exposes raw fields only to this diagnostic implementation; the code reads them and adds no setter.

Both explicit style arguments are the raw missing-pseudo style. Fixtures deliberately use fixed endpoints or stable inherited providers; they do not claim this is valid for animated custom properties/fonts on the queried pseudo. The raw lazy `match_pseudo` path supplies empty animation declarations. Appropriate origin inheritance remains present. The driver does not reuse the generated-pseudo-only unanimated-style API or ordinary-element base recascade. The query helper's provider/sample/no-reentrant-mutation premises remain necessary.

## Test inventory and oracles

`ASSERTIONS.json` is generated by parsing the actual JS AST using `inventory.cjs`: 13 tasks and 208 unique assertions, comprising 150 diagnostic checks, 20 setup gates, 36 result assertions and two pending-state preservation checks. It expands every query's five fixed diagnostic assertions and records each direct assertion in evaluation order. These tasks have no conditional assertion loop; a thrown setup error yields a missing inventory and fails the run.

All categories must pass. A failed setup gate invalidates that task's semantic interpretation; it must not be counted as a native helper defect. Runtime analysis must reject missing, duplicated, unexpected or failed assertions, crashes and harness errors. Do not reduce acceptance to aggregate PASS counts. Retain original failure messages and identify the task/category using the inventory. A setup exception is a setup failure even when it prevents its explicit gate from running.

The numerical value oracles are fixture arithmetic under [Web Animations composition](https://drafts.csswg.org/web-animations-1/#applying-the-composited-result): half of 0–100 is 50; an implicit underlying 10 to 100 gives 55 (20 to 100 gives 60); replace 50 followed by additive 20 gives 70. Explicit before/after retargeting, cancellation and setKeyframes check actual target registration and absence of stale properties. Stable inherited 10px/20px fonts with 1em–3em endpoints give 20px/40px. Real CSSAnimation identity is required for the implicit CSS endpoint case; [CSS Animations keyframe processing](https://drafts.csswg.org/css-animations-2/#keyframe-processing) supplies its endpoint contract. Important-rule precedence is not tested by map inspection and still needs final recascade coverage.

The pending-pause task establishes readiness on an ordinary element before retargeting to the missing pseudo. It explicitly requires the native null-hold/non-null-start wallclock branch. Constant 37px endpoints make its output independent of elapsed wallclock noise; this proves execution/preservation of that branch, not numerical accuracy of the chosen current timestamp. Pending play then exercises a held sample. These are preservation checks for the inspected Firefox composition policy, not a new claim that the specification prescribes its flicker-prevention strategy.

The unresolved-timeline task requires an actual native unresolved timeline and registered held effect; the existing unresolved exclusion must return no map value. Its setup is not silently replaced by an ordinary null timeline. A separate null-timeline/zero-rate task exercises held times. These setups have not been calibrated in a browser yet; exceptions or failed native counts reject the experiment rather than establish an implementation defect.

The finite scroll task checks measured geometry, exact interior/boundary progress and expected 50px/100px values. The named-range task uses a ViewTimeline with cover 25%/75% keyframes, changes attachment from cover 25%–75% to 0%–100%, and requires known sampled progress before expecting 50px then 0px. [Scroll Animations named-range keyframes](https://drafts.csswg.org/scroll-animations-1/#named-range-keyframes) is the mapping contract. Initial readiness is established on an ordinary target; only then is the effect retargeted to the missing pseudo. No query advances the refresh driver or triggers pending readiness. Two rendering callbacks are only a scheduling opportunity: explicit progress assertions, not the callback count, are the actual readiness gates.

The transition task creates two genuine CSS transitions on an unchanged owner, then retargets their effects. Native level counters must remain two Transitions and initially zero Animations. The transition-only opacity value must be absent from the animation map and equal 0.5 in the transition map. Adding a margin animation must yield one animation-level effect; transition underlying 50 plus additive 20 gives animation value 70, with that overlapping property absent from the transition map. The pinned UpdateTarget path does not clear CSS ownership; CancelFromStyle would clear it and change cascade level, which is why level checks are required. This tests the inspected map split and underlying composition, not final cascade insertion.

The temporary manifest explicitly enables both `layout.css.scroll-driven-animations.enabled` and `layout.css.typed-om.enabled`, authenticated against the existing scroll-animations directory metadata in `PREF-ORIGINS.json`. CSS.percent availability and real timeline sampling are not assumed from the default browser configuration.

## V2 source correction

The immutable v1 driver passed structural checks but independent source review found a real C++ conversion error: GetAnimationTarget returns NonOwningAnimationTarget, which cannot implicitly initialize or compare the owned snapshot. V2 constructs OwningAnimationTarget explicitly from its element and pseudo request and compares those fields explicitly. No helper semantics, test expectations, native timing reads or output schema changed. V1-ORIGIN.json pins the prior capsule. This correction still requires real compilation; source-only checks do not establish C++ type correctness.
