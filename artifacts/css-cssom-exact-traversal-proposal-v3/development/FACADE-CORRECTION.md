The first development replay mapped svgText into the state-mask getter but left IsInSVGTextSubtree returning only svgText. Independent review identified that states=SVG_TEXT with svgText=false would break the native accessor identity. The final facade uses the exact native IsInSVGTextSubtree body (calling HasAnyStateBits). An explicit states-bit-only SVG_TEXT rectangle fallback control was added. Initial development sources/results remain retained; native candidate did not change.
