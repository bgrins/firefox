# Retained provider substitution prototype

This artifact adds an opt-in provider continuation to sealed provider90ac/f0d. The original synchronous substitution functions and callers are byte-identical. No cascade facet, semantic graph, completion ledger, application path or running browser source uses the new API. Native Stylo compilation and browser execution have not run for this prototype.

ResumableSubstitution::new owns a parsed VariableValue, retains the consumer PropertyIdRef and container-query mode, and begins a chunk stack. poll returns an owned lookup request, completion, WrongReply, or Finished. Each request owns an Arc identity and exact kind/name/namespace/URL. Repeated poll(None) or a matching Pending reply returns that same request without changing the cursor, output, seen path or taint. A wrong token or reply kind is rejected without consuming the request. Completion is delivered once; later polls return Finished.

Lookup outcomes deliberately separate Pending, Invalid, Value, Expand and raw Attribute. Invalid means the caller authorizes invalid-primary fallback; it must never stand for an unfinished node. A Variable Value must be reference-free. Expand explicitly owns an unresolved universal variable body that may be recursively substituted under the existing active-name cycle guard; it is not a settled computed-value receipt. Repeated names become invalid only on this actual active expansion path. Pending does not trigger that cycle rule. A scheduler that cannot safely expose an expandable body must keep it Pending; this prototype supplies no eventual-progress or true metric-cycle policy.

Chunks retain original CSS ranges, parsed references, token boundaries, cursor, partial ComputedValue output, root taint ranges and aggregate child taint. They call the actual ComputedValue::push helper, preserving its existing 2 MiB append check and separator insertion. The original whole-reference shortcut bypasses that append limit; the new engine preserves that behavior rather than silently changing the budget. Fallback and alias frames retain child results and pop the active alias name at the same completed boundary as the synchronous implementation. Used fallbacks are traversed; unused ones are not queried.

Attribute lookup has two stages. RawAttribute is acquired once, including namespace/missing information. A typed attribute outside a container query then requests TypedAttribute; a Pending cache result retains the first query. Type parsing uses the actual AttributeData::parse_typed_value helper with the captured consumer and URL. Unit conversion uses actual parse_attr_number and token metadata. Raw-string/omitted type, invalid type, absent attributes with the special empty string result, typed failure/fallback and container-query raw input branches are implemented. Unknown namespaces do not query the element in the adapter. Environment replies and variable bodies are owned snapshots, so later provider-map mutation cannot invalidate borrowed output.

SubstitutionLookup::read_current is a synchronous compatibility adapter using the existing map, environment and AttributeTracker accessors. It maps missing entries to Invalid just as the old path does and explicitly marks unresolved universal bodies Expand. It is not a completed-binding certificate. A future readiness-aware caller must return Pending before invoking that adapter where absence/publication is unfinished, and must establish immutable binding/input provenance for consumed values. The provider owns retained bytes, not the proof that those bytes remain the correct final CSS value. The DOM, registration, URL/property context and device assumptions must remain valid throughout a continuation. There is no native context-invalidation/restart implementation here.

Final property parsing, shorthand-cache publication, random-property evaluation and application remain outside this engine, as in the existing substitute entry point. A future caller should run them once after successful substitution and retain the parsed result. The engine itself adds no property evaluation or style publication. AttributeTracker effects occur when the caller services a RawAttribute request; wrong/repeated Pending replies do not query it again. An application must not independently service the same request repeatedly and call those repeated external reads a machine guarantee.

## Allocation and integration limits

The opt-in complete result owns its CSS, including the original single-reference/no-reference fast paths that could borrow. Chunk/reference frames share Arc<VariableValue>, avoiding a full source-string clone per reference. Parsed reference/fallback trees are still cloned when constructing frames; deeply nested fallbacks can incur extra allocation/copying. That performance boundary remains unsuitable for claiming native readiness without further optimization and profiling. The existing synchronous path retains its old allocation behavior.

The new API uses real provider types in the candidate copy, but only an extracted compilation has run. Actual Stylo lifetime/API/typechecking remains pending. No full scheduler or selected-declaration certificate is wired. This does not fix the current dynamic FontSize or typed-attribute browser case and is not an accepted native patch.

## Saved checks

Final actual test bf519c/57053/7c4441/0 passed twelve tests and rejected seven separately compiled behavioral mutants. The tests directly compile full original do_substitute_chunk, substitute_one_reference, substitute_internal and substitute bodies, the actual VariableValue parser/push and taint helpers, the new continuation and adapter. The same pinned vendored cssparser supplies real tokenization/serialization for both paths; real servo_arc and stable_deref_trait are compiled directly with rustc in an owned /private/tmp directory. No Cargo, Mach, shared target, native checkout, application or browser was changed.

The extraction supplies explicit facades for the style environment, registration maps, DOM tracker, PropertyIdRef and typed registered-value parser. The typed parser facade covers <length>, <number> and universal syntax through real cssparser tokens; unsupported typed grammar panics rather than being counted as native coverage. Actual AttributeData::parse_typed_value and its calls are compiled, but the full Gecko registered-value parser and numeric computation are not. Namespace parser and unit enum facades are likewise bounded. The code dispatches all existing provider branches, but tests do not prove every native grammar/namespace/unit/context combination.

Positive tests compare old/new complete CSS and taint plus query traces, both uninterrupted and with pauses at every external lookup. Explicit controls check foo/**/bar, foo/**/2px/**/bar with taint[7,10], pending-prefix ownership, typed raw query count1, invalid-only fallback, environment and alias snapshots after provider mutation, actual recursive alias cycles versus Pending, empty/invalid distinctions, wrong request identity/type and the 2 MiB append/whole-reference distinction. Mutants independently break Pending retention, request identity, alias taint, separators, output limit, resolved-vs-expandable reply validation, and typed raw-query reuse; all compile and fail behavioral assertions.

The initial extraction compile omitted Atom and References::has_references; the next run revealed that provider Name strips the leading --, so test-map keys were corrected and explicit positive outputs added. Both failures remain archived. Third/fourth runs passed eight/eleven tests. Fifth completed twelve positives and seven negatives; its log prints the final expected failing mutant, while its outer exit is0. Final logging reports the aggregate clearly. All owned scratch directories from every run are absent. No failed attempt is counted as successful validation.
