The primary Web Animations 2 draft's [CSSNumberish validation](https://drafts.csswg.org/web-animations-2/#validating-a-cssnumberish-time) rejects a non-percent value for a progress timeline. Its [current-time setting algorithm](https://drafts.csswg.org/web-animations-2/#setting-the-current-time-of-an-animation) stores the seek in hold time when the timeline is inactive and synchronously completes a pending pause. These rules support preserving the held setup while changing its units. They do not establish the request-local helper's later runtime results.
