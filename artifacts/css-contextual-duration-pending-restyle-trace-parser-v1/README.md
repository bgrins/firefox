# Bounded pending/posting trace reviewer

This parser implements the exact sealed EffectCompositor logger contract f194668b. It accepts plain captured stderr lines, with optional logging prefixes, or mozlog process_output JSON lines whose data field contains the native lines. It preserves input line order and records process-local sequence numbers. It never runs a browser, imports an owner, changes a runtime or performs a live-state guard. No native trace has been collected or parsed by this package yet.

The ten allowed suffixes are coupled/zero-start crossed with passive/seek/outline/override/literal. IDs map directly to the trace fixture's initial duration-feedback-* IDs and the posted record kind/role fields. The captured header pins RestyleType Throttled=0, Standard=1, Layer=2 and CascadeLevel Animations=0, Transitions=1. Pointers are normalized only for equality; original event order is not sorted or deduplicated. Each matching table key includes PID, label, element pointer, pseudo type, pseudo identifier and cascade level. This is a bounded stable-target fixture join, not proof of identity across compositor destruction, document adoption or address reuse.

Malformed trace lines, unknown labels/stages, invalid fields (including pre-* outside PreTraverse), process-local gaps, duplicates or out-of-order sequences suppress all witness extraction. The explicit 4096-event cap is recorded as truncation. A valid closed prefix interval may still provide a bounded candidate witness, but the parser does not assert absence of later work. No cap does not establish complete capture: an external terminal, log-integrity and trace-coverage check is still required. Missing target IDs are reported separately. Separate process sequences are never treated as one causal order.

A candidate witness requires consecutive request-before(bit0), request-set(bit1) and post-deferred events for the same key, with matching traversal flags and Servo or PreTraverse active. A later consecutive outside-traversal Layer request-before(present1,bit1)/request-coalesced pair must share that key. Any intervening logged post-dispatch, pre-post-hint, removal or clear invalidates the remembered pending interval; a new observed false bit also invalidates it. post-dispatch is logged before the PresShell call and is only an attempted dispatch. Removal and hint markers likewise denote instrumented call boundaries. pre-selected and skip events have no cascade-level consumption meaning. pre-will-compose is preparation; it is never classified as actual composition.

The output means that the selected sequence was observed with no intervening instrumented post attempt or removal boundary. It does not establish absence of all native drains, other wakeups or compositor destruction. It does not identify a Layer request as an effective timing change, an exact JavaScript override/seek call, or a model iteration. The pending/posted model's exitWithoutDrain premise remains conditional even if this sequence is later observed. Native refinement needs the remaining event coverage and call-path checks.

The pinned prior frozen measurements establish two failed fixed-2s override font controls, with current animation/effect membership, coherent literal measurements and no fixed-point oracle for the self-dependent targets. Those are observations from an uninstrumented candidate. Role labels permit a later join to the newly instrumented run's posted records; they do not make the old and new runs identical or align snapshots to native sequence numbers automatically.
