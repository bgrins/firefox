# Fresh language-pair current capture

Read-only capture adaptation for the published nowrap baseline. `capture_current.py` is byte-identical to the executed published-original helper. The small `baseline.py` adapter authenticates that executed helper/owner, replaces only role admission with the actual signed nowrap receipt and installation marker, retains image ancestry and retired-provider provenance, and additionally checks nsLineBreaker a87f against HEAD and the canonical owned identity. It does not bind or run a candidate.

Root executes the existing four-argument interface: capsule FILES digest, actual signed V98 result path, its SHA256, and a new artifact JSON output path. All original full-state/source/app/binary/extras/index/flag checks remain. No epoch, source, app, index or Git writes occur. The adapter is process-local; the old helper files remain untouched. The output still captures the three published style sources and every payload claim, including nsLineBreaker.

Saved checks exercise marker/role admission using documented publication transforms over saved pre-publication data; they are not a fresh live capture. Candidate formatting and native validation are separate.
