# CSS pow special-value proposal

This artifact-only one-file proposal handles CSS NaN/infinity rules consistently in generic calc's resolver and constant simplifier. Its base is cleaned hypot proposal-v4, SHA b7a6ac851ba6b56ed5d98f72980941f168a65ea75cf046d44e5adf7877849f35. That stacked dependency is not accepted or installed by this package; it preserves the accepted145 math base plus proposed hypot changes. Root source, app, Git/index and canonical epoch remain untouched.

The helper returns NaN when either argument is NaN or the base magnitude is exactly1 with an infinite exponent. Otherwise it delegates unchanged to f32::powf. NaN must be checked before that operation's zero-exponent/one-base special cases. Both resolver number-type checks and simplifier number-leaf eligibility are byte-identical; non-number and deferred operands retain existing behavior. Only the shared helper and two call sites change. No ordinary precision, unit-conversion, negative-base fraction, signed-zero or other infinity rule is reimplemented.

The primary CSS argument-range tables explicitly require NaN for±1^±infinity; the infectious-NaN rule also covers NaN^±0 and1^NaN. SPEC-PREDICATE.json records the exact bounded model interface. The separate Lean companion belongs to root; this package neither implements nor assumes its proof. No full powf/native/IEEE conformance proof or formal-discovery credit is claimed.
