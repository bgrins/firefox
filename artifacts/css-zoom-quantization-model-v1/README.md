This model makes rounding explicit in the registered-value zoom investigation. Ten named Lean theorems pass kernel checking; five deliberately false controls are rejected because their propositions are false. It supports arbitrary signed rational lengths and positive rational zoom, with exact arithmetic and truncation toward zero to a grid of 60 app units per CSS pixel.

For a length x/d and zoom p/q, quantize computes trunc(60*x*p/(d*q)). normalize represents the resulting integer r as r*q/(60*p). The cross-multiplied error is exactly the signed division remainder. Its absolute value is less than d*q, proving the normalized CSS-pixel error is strictly less than q/(60*p), or one app unit divided by zoom. Exact recovery holds precisely when the scaled input has no remainder. Negative values preserve sign symmetry; truncation is not floor for negative inputs.

The exact-arithmetic witnesses use 0.13px. At zoom 1.5 it quantizes to 11 app units and normalizes to 11/90px, approximately 0.122222px. At zoom 0.5 it quantizes to 3 app units and normalizes to 0.1px. At zoom 1 it becomes 7/60px. Thus quantizing after scaling and then removing zoom does not generally produce the same result as quantizing a canonical value. Even integer zoom does not imply exact cancellation after quantization. The former provenance model's raw-factorization precondition remains essential.

The five false controls reject exact cancellation at fractional and integer zoom, commuting normalization with quantization, bounding half-zoom error by one canonical app unit, and replacing signed truncation with floor.
