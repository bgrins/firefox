# Scope

ProviderObservation is generic over world, stable target, observation, erased view and mutation token. Its query first obtains the provider-returned world and resolves the target against that world. The successful-state theorem identifies the actual conditional provider result, and the successful-observation theorem relates the emitted value to that returned world. Operations receive only world/event, never the accumulated log; arbitrary non-injective observation erasure therefore commutes with both individual queries and TransitionMachine histories. Erasure retains the complete modeled world and maps only observations/logs, including equality of Option success/failure outcomes. No second history runner is introduced.

A stable target denotes a single object lifetime, not a slot that can be reused for another frame. Native lifetime correspondence is not proved. Option failure means no successful abstract observation/history result, exposes no post-failure state and terminates the abstract history. It does not assert native rollback, absence of already-performed side effects or a CSSOM empty rectangle. The deletion witness covers a provider-returned world where the target no longer resolves.

The MathML example observes a leaf-local rectangle plus aggregate ancestor translation in integer CSS pixels. It reproduces c3's stale [70,25,40,16] and visible reference [30,10,40,16]. Both size-erased observations equal 40×16. The whole-provider example updates ancestor translation and clears eligibility; the selected-size-only counterprovider also clears eligibility, isolating its incorrect position from readiness. The pre-force adapter ends in the corrected world while returning stale geometry. Both false correctness claims are rejected using kernel decide, not a missing import or syntax error.

The positive whole-provider history derives eligibility from marking the observed clean mrow/leaf tree using the existing Subtree clear-path result, then checks admission and first/repeat rectangles. The reference provider's coordinate update is stipulated arithmetic, not a verified Gecko algorithm. Aggregate ancestor translation does not identify a native y-position setter. Target re-resolution is modeled by a live bit and stable target enum, not a verified native allocation system.

horizontalSize maps physical width/height to Hidden.Size's logical inline/block axes only for this horizontal-writing-mode example. The generic erasure theorems make no such axis assumption. No theorem equates the whole world with Hidden.Frame: native admission, identity, provider output, completion/cache behavior and coordinate correspondence remain explicit bridge obligations. MathML's unconditional output publication is not silently treated as Hidden's cache-miss transition.

No fragmented boxes, transforms, scrolling, rounding, native scheduling or memory lifetimes are modeled. No CSS specification coverage claim follows from these proofs. The pinned Lean compiler, installed Lean libraries, Python and OS remain trusted replay infrastructure. Independent design-review requirements about log independence, failure/deletion, size-only completion, horizontal axes and identity reuse are incorporated. Accepted library modules remain unchanged.
