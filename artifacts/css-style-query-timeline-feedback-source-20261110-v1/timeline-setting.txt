# WEB-ANIMATIONS-1#setting-the-timeline

**Setting the timeline of an animation** (heading)

**SHA**: hash:cd72b5821823c7cfde12f892b8f0725078b841004b5824f4701afffaafdf5649

## Content

The procedure to **set the timeline of an animation**, *animation*, to *new timeline* which may be null, is as follows:

1.  Let *old timeline* be the current [timeline](https://drafts.csswg.org/web-animations-1#timeline) of *animation*, if any.

2.  If *new timeline* is the same object as *old timeline*, abort this procedure.

3.  Let the [timeline](https://drafts.csswg.org/web-animations-1#timeline) of *animation* be *new timeline*.

4.  If the [start time](https://drafts.csswg.org/web-animations-1#animation-start-time) of *animation* is [resolved](https://drafts.csswg.org/web-animations-1#unresolved), make *animation*’s [hold time](https://drafts.csswg.org/web-animations-1#animation-hold-time) unresolved.

    > **Note:** Note: This step ensures that the [finished play state](https://drafts.csswg.org/web-animations-1#play-state-finished) of *animation* is not “sticky”, but is re-evaluated based on its updated [current time](https://drafts.csswg.org/web-animations-1#animation-current-time).

5.  Run the procedure to [update an animation’s finished state](https://drafts.csswg.org/web-animations-1#update-an-animations-finished-state) for *animation* with the *did seek* flag set to false, and the *synchronously notify* flag set to false.
