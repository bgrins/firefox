The selected ranges are derived from the complete core result before projection; the endpoint theorem composes that result through the original optional defaults and strict endpoint rules.

Root reviewed `StickyFullEndpoint`, `StickyFullChallenges`, the unchanged numeric/core/range/endpoint definitions, the source-role mapping and the native driver. The original scalar theorem remains a useful isolated-axis intermediate, not a full native-entry theorem. All three original root witnesses and their swapped-axis versions are rejected by the new domain. ## Independent continuation checks

Nine additional root-owned kernel results and twelve extracted-native executions check the distinction between the selected continuation and its canonical first continuation. The native driver creates a linked first/later pair with different current and normal positions. It preserves canonical range geometry while varying the selected frame's displacement, separately removes the selected and canonical normal-position properties, and makes the selected frame's offset property absent while retaining the canonical one.

Ten executions pass at `-O0` and `-O2` with exact public range/displacement/endpoint values and provider traces. Two additional executions diagnose the predicted overflow in an unselected component of the selected continuation's point subtraction. Missing canonical offsets and an inactive requested axis return before that same hazardous subtraction. These are source-facade checks, not browser reachability claims. The native API does not expose the model's frame identity or intermediate core record; those are not asserted as observed native outputs.

## Scope

Acceptance incorporates the existing independently accepted native/spec/WPT review preserved in the producer's `inputs`. The four browser variants isolate H1 and H2 while sharing other project repairs; isolated upstream browser execution is not claimed. Their raw standalone patch contexts overlap and may need ordinary context resolution when stacked.

The proof remains conditional on raw geometry-provider correctness, stable frame/property observations, valid frame traversal, actual numeric/anchor resolution and the stated per-operation bounds. It does not prove compositor delivery, animation sampling, H3 nested-restyle freshness, all margin-collapse semantics, unrestricted integer behavior or all CSS sticky conformance. Later sentinel, explicit-auto-code and negative-inset repairs are separate source versions and separate companions. No admission was added to waive R3's executed opposite-coordinate arithmetic.

Root replay and independent challenges were terminal before deleting owned compiler products. `CLEANUP.json` records their sizes and hashes; source, commands, logs, raw rows and results remain. The shared Firefox build was untouched.
