Actual results:

The page is rendered with all text in small-caps.


Expected results:

The page should be rendered normally.

This is an issue due to the fix for the “Cycle in unused fallback” WPT, see here: https://wpt.fyi/results/css/css-variables/variable-cycles.html?label=master&product=chrome%5Bexperimental%5D&product=edge%5Bexperimental%5D&product=firefox%5Bexperimental%5D&product=safari%5Bexperimental%5D&product=firefox%5Bstable%5D&aligned&q=variable-cycles

The article in question (https://blog.kizu.dev/future-proofing-indirect-cyclic-conditions/) talks about what is happening in detail, but basically: this WPT is a result of this issue: https://github.com/w3c/csswg-drafts/issues/11500 — sadly, when we resolved it, we did not mention the link to the `if()`, but we did discuss it during the meeting.

This change is not interop for that one technique that allows implementing a workaround for `if()`, so we decided it should be fine to do this change alongside the `if()` implementation, as then it is possible to combine both without a breakage.

Releasing it without the `if()` would mean my technique will break. It is unlikely anyone is using it in the wild aside from me, but still :)
