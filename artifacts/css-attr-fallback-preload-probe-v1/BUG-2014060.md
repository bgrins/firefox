**2026-02-03 08:42:43** - Comment #0 by emilio@crisal.io
A quick run with attr enabled by default shows some interesting failures: https://treeherder.mozilla.org/jobs?repo=try&revision=4242db087491ac39f9e5ad169228b746fc926082

A bunch of them are due to missing namespace support for `attr()`. The [`<attr-name>`](https://drafts.csswg.org/css-values-5/#typedef-attr-name) production includes an optional namespace prefix. The [`content`](https://searchfox.org/firefox-main/rev/7709f0a26aeb3c39a5fd86e794425530f0d0b528/servo/components/style/values/specified/mod.rs#914-920) function deals with it, might be worth factoring the `namespace_prefix` + `namespace_url` + `attribute` into a common `AttrName` struct.
