# Scope and provenance boundaries

The original eight-part caller target is preserved exactly. The model consumes already acquired signed32 values for active items; it does not prove floating-point weight/share calculation, content measurement, native pointer/container validity, or all native producer states. The generic proof must derive counts, freshness, positional field identity, progress, and absence of the final fallback from the actual History constructors rather than adding them as assumptions.

The native snapshot authenticated by the target predates the later measured-base/correction repair. Those later changes are not silently substituted for the snapshot. ProviderBoundary separately shows a mathematical counterexample outside the preferred-base conditional domain, a representable signed32-target cancellation/reporting lemma, and an aggregate-sign counterexample outside signed32. They neither weaken DeltaAdmissionTarget nor establish native execution of those examples.

Optional line-info behavior remains represented by wantsInfo, including the all-frozen extra pass. Native diagnostic arithmetic, buffer/index validity, and exact reporting conversion are separate provider/correspondence obligations. Initial append/early semantics do not assert that every native FlexLine producer uses the same construction; the target's retained source audit covers append/move/restart/continuation distinctions without turning that audit into a kernel proof.

Mutation controls are changed mathematical call/output behavior: omitted count updates, premature final-iteration selection, and reversed returned records. They are not compiled native implementation mutations. The corrupt-count example deliberately violates the history domain and demonstrates why count agreement must be derived at valid entries.

No canonical source, native code, browser state, WPT, Git/index, toolchain, or accepted target is changed by this capsule.
