# Registered keyframe ordering discriminator

Eight observation callbacks independently vary an explicit pre-animation style read, equal underlying/animated tokens at activation, and a constant opacity keyframe driver. A ninth callback supplies a literal sink calibration. All cases use a fresh iframe and registered `--v: <custom-ident>`, non-inherited with initial horizontal-tb. Registration syntax/inheritance calibration completes and its elements are removed before the subject is created.

Every arm appends the ordinary subject, optionally reads its computed custom value and writing-mode, then adds the active class synchronously. There is no intervening await, frame, layout read or reporting getter in the unflushed arm. The optional read is recorded in `before`; absent reads remain null. This controls an explicit flush, not an assertion that the engine performed no other internal style work.

The active keyframes always supply vertical-rl. Equal-token arms start with underlying vertical-rl; different-token arms start with vertical-lr. The later ordinary mutation sets underlying horizontal-tb in every arm. Thus final underlying horizontal-tb, animated vertical-rl and fallback vertical-lr are distinct. The opacity factor adds constant opacity 1 keyframes; without it the registered custom property is the sole animated property and opacity remains the ordinary .25. Both use one fixed two-second paused CSS animation, await readiness, then seek to 750 ms. Membership, effect identity and fixed timing are calibrated.

Initial and post-mutation phases capture first writing-mode plus three frame-delayed writing-mode reads before custom-value/timing/membership details. All variable sink values remain diagnostics, with no normative fallback assertion. WPT PASS means registration, optional ordinary read, active custom source, driver/identity and literal controls passed. Later details are sequential observations rather than proof of first-getter internal state. The initial/final variable sinks and the optional pre-animation sink are not calibration verdicts.

The existing defaulting observation motivated this factorial experiment but does not establish its cause. Changing preflush, token equality or driver can expose an interaction without proving a particular taint cache or invalid-keyframe mechanism. Invalid keyframes are excluded here so their selected-value uncertainty cannot mask the valid-source comparison. Hidden output/window records support the existing reporting adapter; setup failure or timeout can leave incomplete observations. No browser or native build was run during preparation.
