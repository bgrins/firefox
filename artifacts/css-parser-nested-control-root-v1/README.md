# Nested parser control: root review

Accepted as a bounded formal component. Fresh manifest-only replay compiles 59
modules and checks 39 audited declarations. Eighteen histories yield 91 identical
model/native snapshots in debug and release. Three compiled native mutations
change 10, 25 and five rows; three Lean proof mutations are rejected.

Root read RawRecovery, RawSafety, NestedControl, LinkEmpty, LinkComposition,
LinkPaths, fixtures and driver; compared the retained parser bodies, callback
facade and build runner. Independent v3 review and all retained input pins were
checked. The full cssparser bodies are compiled, while the LinkParameters
callback remains an empty-value projection of Stylo.

Five additional root kernel challenges show why progress is an explicit premise:
finite byte fuel and cleared pending state do not prove completion for a stalled
provider. A callback that changes the nesting limit retains that new limit even
when outer stop/depth are restored. Those are contract boundaries, not new native
bugs. Source translation, complete grammar, machine bounds, annotation/line/error
coverage and native termination remain open; see ACCEPTANCE.json.

V3 fixes the earlier pre-import guard and file-roster gaps. The independent review
retains the negative v1 account. This acceptance covers the externally pinned v3
capsule, without treating historical v1/v2 checkers as accepted verifiers.
