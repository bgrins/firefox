# Selective handoff: source-to-obligation boundary

The selective cancellation candidate supplies a normal-entry request and preserves the ancestor-font hint across fixed-font intermediates. **Visiting an intermediary does not require recascading it.** The remaining theorem premises are actual route membership, eligible style state, correct target/pseudo membership, dispatch, and later delivery/application. This does not prove a native scheduler refinement or repair startup settlement.

The stable-tree review rules out a simple shadow/slot or ordinary `display:contents` iterator mismatch because seeding and normal child traversal use the same interface. That is a conditional source argument, not proof of all native tree-state invariants. No new unaddressed source defect or WPT is proposed here.

`RouteAdmission.lean` imports the existing Handoff/Entry/Route/Admission library. `eligible_route_visits` weakens the old global `forwardAll` premise to any forwarding predicate true on the finite selected route and proves ordered visitation. `normalForward` is a deliberately conservative **specification-side projection** for a stable styled, non-hidden route; it is not a transcription of the complete native predicate (which also has initial/dirty/snapshot paths). `stable_route_eligible` supplies that premise. The composition theorem combines selective entry, route visitation, exact target identity, and the existing registered-normal-hint admission theorem. Its `true` normal/hint arguments express the required incoming normal ancestor-font event; visitation alone does not invent that native event. It proves neither native route extraction nor dispatch.

The old concrete fixed-middle counterexample remains useful: forwarding only to animated next nodes stops before the unanimated intermediary, even though normal entry was granted. The source does not use that restricted rule. Four genuine false controls reject restricted forwarding across that route, seeding an unstyled child, membership-based recascade during AnimationOnly, and admission from a hint with neither a retained dependency flag nor membership. These are boundaries of the model, not new Firefox failures.
