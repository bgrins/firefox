# Preparation and cycle boundaries

| Boundary | Composed operation | Remaining evidence requirement |
| --- | --- | --- |
| Custom primary references | Existing selected-reference traversal precedes preparation. A prepares only an acyclic singleton with no pending child suffix. | Real parser applicability is inherited from A; broader V3 priority traversal requires comparison. |
| Selected COLOR-capable value | Retain the first successful specified AST. Replace only COLOR_SCHEME with its classification; preserve other flags. | Keep union-order/list/selected-fallback controls; no eager computed-color or literal-only shortcut. |
| Priority declaration | V3 follows reached references, substitutes and adjusts once, retaining owned declarations across prerequisites. | Exact selected-priority block equality is checked. A cyclic return prevents preparing an unfinished priority. |
| Acyclic custom application | Apply the retained AST after outgoing dependencies close and the node pops without a cycle. | No repeated primary selection/substitution; actual borrow/type correctness still needs compilation. |
| Early cycle | Remove conservative COLOR, then classify the actual invalid/default initial after other edges and visit its dependency normally. | Inherited copy, absent/default and specified initial remain distinct routes. |
| Late unit cycle | Run the invalid/default hook before final lowlink assignment and SCC pop. | Preserve late-font-edge controls; early classification alone is insufficient. |
| Genuine selected scheme edge | Avoid duplicating a ColorScheme visit already caused by the selected AST. | Exact A behavior, not a proof of every graph shape. |
| Cyclic publication | V3 handles every member, discards prepared priorities, then ensures invalid priorities after the SCC is marked/popped. Prepared custom AST is not applied. | Custom invalid handling may compute during popping before invalid-priority publication. This composition does not prove equality between that builder value and the eventual priority default; conditional-default comparisons remain necessary. |
| Root/session boundary | Prepared custom value stays local to its traversal frame; no new cache or pointer identity. | V3 reset/ensured shortcuts remain; no general root-order proof. |

Pure-Image eligibility is unnecessary here. The existing selected-value/default mechanism, or an independently justified equivalent, is necessary to remove the false edge without concealing the real winning reference. Restoring the old plain-variable omission, clearing all COLOR edges, or handling only literal identifiers would leave missing dependency/default cases.

Earlier bounded graph/default models do not refine the whole implementation: eligibility, parser selection, computation side effects and publication are outside their proved bridge. Parent experiments likewise do not substitute for this composed experiment.
