# Language classification, cache validity, and failure bookkeeping

Seven kernel-checked theorems isolate the concrete review issue in the standalone language repair. `failure_cannot_be_quotiented_to_false` proves that no Bool-only recorder can reproduce both failed parsing (leave language unset) and valid non-CJK parsing (record the supplied atom) after those outcomes are collapsed to the same false script bit. Thus adding `Maybe<bool>` preserves information required by the buffered updater; this is stronger than merely enumerating one bad tag.

`query_correct` proves the single-entry cache returns the classifier's result and preserves cache validity. `queryAll_correct` extends this to every finite list, including duplicate keys and alternating cache hits/misses. `failed_query_preserves_cache` shows failed parsing cannot replace a valid successful cache entry. These theorems assume a fixed classifier and initially valid cache; they do not prove locale parsing, pointer lifetime, atom interning, thread ownership, or shutdown behavior.

The small fresh-word state adapter records a non-null language only on successful classification, clears script on failure, and ignores the preceding word's script. Three direct contract lemmas connect it to the corrected updater. This adapter is an explicit specification boundary, not a derived proof of every native control path: it assumes a fresh buffered word after language/mixed flags were cleared. It does not cover an already mixed word, arbitrary chunk admission, implicit null language, or browser geometry. The separately saved source map explains those assumptions and quotes the exact helper/updater. Native null returns Some(false) but has no atom to record; the non-null-key theorem must not be applied to it.

The replay reuses the pinned Lean 4.35.0-rc4 toolchain and isolated scratch workflow from the earlier nowrap model. Actual run1 passed with unused-simp-argument warnings; run2 removes only those unused arguments and passes without warnings (`aba3d3`/`8e7756`, exit 0). Seven axiom audits contain only propext/Quot.sound or no axioms; there is no sorry, new axiom, reduction oracle, or native refinement claim. Three separate `by decide` controls are rejected because their propositions are false: conflating failure with valid false bookkeeping, trusting a stale cache entry without validity, and retaining a preceding true script after parse failure. Both owned scratch directories are absent.

This proof is not a gate delaying the independently reviewed paired native experiment. It changes no library in the nested CSS Lean checkout, native source, test installation, browser, index, canonical ledger, or accepted bug count.
