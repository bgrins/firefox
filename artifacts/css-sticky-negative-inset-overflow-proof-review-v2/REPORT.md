## Source-sensitive findings

The final source's int64 cast precedes both subtractions. Near-end normalization cannot simply be justified by quoting a swapped operand algorithm: v2 now carries the actual intermediate bounds before proving equivalence. Compound assignment still narrows to nscoord, and the explicit narrowing premise is necessary. The independent challenges distinguish a valid signed32 result outside InCoordinate from a genuine result-narrowing failure under a storage-only size assumption.

The new absolute stick record and unchanged containment nsRect have different roles. The model does not recreate a signed32 width for wide stick edges. The absolute caller's FromRect applies to containment; its separate record theorem makes that input connection explicit. The mathematical reference uses interval minimum/projection and independently defined intersection/movement, while expression trees preserve native order and intermediate checks.

An empty horizontal overlap can force MoveInsideAndClamp to evaluate vertical width/height even when the vertical interval was otherwise valid. This is why the retained clamp example is excluded despite defined old normalization/storage. It is a preexisting arithmetic limitation, not a regression from this repair. The safe wide example takes the non-clamp path and does not need the forbidden stick-width subtraction.

The raw native adapter decodes NS_AUTOOFFSET to None before constructing Lean insets. An arbitrary abstract `some coordMax` is not evidence of a faithful native explicit-inset state. This is consistent with the retained source representation boundary; the review's new narrowing witness uses coordMax-1 to avoid confusing that separate encoding issue with normalization.

## Limits and trust boundaries

This acceptance does not establish unrestricted all-coordinate safety. The expression domain may conservatively exclude cases whose final native answer would be defined, and its missing bounds are not supplied by browser realism. Safe ranges do not imply DebugSafe sentinel assertions. Mathematical signed32 wrap outside the admitted domain is a diagnostic totalization, not C++ signed-overflow semantics.

The theorem begins after admitted union/transform/geometry acquisition and canonical frame selection. Local padding Deflate is checked separately before the transform-output boundary. Raw frame lifetime, graph discovery, allocation, reflow scheduling, percentage/anchor resolution, timeline Earliest/Latest and real rendering remain outside this companion. The facade's simple rectangle endpoints and checked arithmetic are adequate only under the stated exact-intermediate domain; they are not proofs of all platform geometry implementations.

There is no new browser run and no new browser-defect claim here. Native/WPT acceptance remains the earlier independent gate. The repair's narrow full conditional formal scope is the reviewed claim, not whole sticky layout or CSS correctness.
