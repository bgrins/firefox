This model proves a bounded declaration-index contract for the [sealed capacity candidate](../css-prioritary-declaration-capacity-probe-v1/README.md). The builder appends every longhand to its full vector, but links a prioritary declaration only when its absolute pre-push index is below the sentinel. Counting only declarations for that property does not justify the bound.

For every finite declaration list whose length is at most the sentinel, the modeled linked projection equals an independent full-vector property projection. The streaming theorem also covers an arbitrary prior vector and chain: subsequent indices start at the full prior vector length. No declaration is removed from the vector when linking is refused.

A generic counterexample puts n unrelated declarations before one target declaration. The full projection contains exactly [n], but the linked projection is empty whenever n is at least the sentinel. This applies to both 65535 and 4294967295 without constructing billions of entries during checking. The u32 proposal restores the old u16 boundary and raises the limit; it does not prove unbounded completeness. A target linked first survives arbitrary later unrelated declarations.

Builder.chain is the logical finite sequence of one property's links. SOURCE-MAP.json maps it to the actual head/tail/next update and keeps the unproved concrete-memory refinement explicit. The small wire interpretation distinguishes MAX as the absent head from zero as an end-link: vector index zero remains a valid first declaration, and subsequent increasing indices cannot equal the zero terminator. The model does not execute SmallVec, cast machine integers, prove valid pointer/index access, discover caller declarations or evaluate CSS. The capacity experiment supplies separate exact extracted-source evidence; this Lean result does not replace a native build or browser observation.

Actual run2 compiled all 16 theorem audits and rejected six false claims with `decide` reporting the propositions false. The axiom set is only propext and Quot.sound; there are no sorry or custom axioms. Controls reject per-property-count sufficiency, sentinel-index admission, preservation under arbitrary unrelated insertion, dropping the unlinked vector entry, treating head zero as absent, and deleting an early target after later overflow.
