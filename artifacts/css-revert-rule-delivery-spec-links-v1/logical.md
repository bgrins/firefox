# CSS-LOGICAL-1#logical-property-group

**logical property group** (definition)

**SHA**: hash:3f173e8d160a9ee2ff53020d215b10e49d6afe8ff953bb41fc76cfbab74b5533

## Content

Each set of parallel [flow-relative](CSS-WRITING-MODES-4#flow-relative) properties and [physical](CSS-WRITING-MODES-4#physical) properties (ignoring [shorthand](CSS-CASCADE-5#shorthand-property) properties) related by setting equivalent styles on the various sides or dimensions of a box, forms a **logical property group**. For example, the padding-\* properties form a single [logical property group](CSS-LOGICAL-1#logical-property-group), the margin-\* properties form a separate logical property group, the border-\*-style properties form another logical property group, etc. (Each [longhand property](CSS-CASCADE-5#longhand) can belong to at most one logical property group.)
