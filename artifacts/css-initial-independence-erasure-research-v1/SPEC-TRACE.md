# Independence after simplification

**Question:** Does CSS.registerProperty have to accept every apparently cancelled relative value, and can the current simplified Stylo AST certify that decision?

**Scenario:** Fresh valid custom name, supported non-universal syntax, explicit initial, ordinary complete-input parse, no CSS-wide keyword or substitution reference. The numeric domain includes zero bases and CSS special numeric values. This is a manual trace of freshly captured official drafts: webspec-index is unavailable here, so no exhaustive indexed-route claim is made. All cited section IDs were checked against the captured HTML.

1. [JS registration](https://drafts.css-houdini.org/css-properties-values-api/#the-registerproperty-function) selects a parsed initial before its independence check and inserts only afterwards. The [definition](https://drafts.css-houdini.org/css-properties-values-api/#computationally-independent) asks whether the computed value can be obtained using the property itself and CSS-independent global information. It does not prescribe Stylo's parser flags or Context calls.
2. [Math simplification](https://drafts.csswg.org/css-values-4/#simplify-a-calculation-tree) preserves units when combining same-unit terms and limits evaluation/conversion by available information. [Computed values](https://drafts.csswg.org/css-values-4/#calc-computed-value) subsequently use computed-stage information. These rules do not authorize unrestricted real-number cancellation over zero and nonfinite bases.
3. [Sign](https://drafts.csswg.org/css-values-4/#sign-funcs) distinguishes resolved zero from positive input. The captured local coefficient-only fold is a counterexample to treating arbitrary parser erasure as a sound independence proof; this is already tracked as held fix120. Its separate consumer/prerequisite hold remains in force.
4. [Currentcolor](https://drafts.csswg.org/css-color-4/#resolving-color-values) remains symbolic at computed-value time. Its later dependence on the element's used color does not make that computed representation dependent. [Color light-dark](https://drafts.csswg.org/css-color-5/#light-dark) chooses a branch's computed result; equal independently obtained results do not need the choice to determine that result. Equality of two dependent branches is insufficient.
5. The located WPTs pin ordinary relative rejection, absolute arithmetic, symbolic currentcolor and equal-none image acceptance. They do not decide the exact zero/cancelled relative registration cases. The current source also retains the relative units in these examples, so there is no native simplification proof that settles their registration semantics.

**Verdict: INCONCLUSIVE** for a blanket acceptance/rejection rule over zero and cancelled relative initials. The semantic criterion and the held unsound-fold witness are grounded; exact cancellation-domain correspondence and missing registration-specific tests remain unresolved. This is not a claim that implementations must reject all such values, nor that a reported browser acceptance establishes conformance.
