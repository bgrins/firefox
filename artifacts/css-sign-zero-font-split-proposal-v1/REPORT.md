# Proposed minimal Sign stack

This artifact splits the reviewed four-file native proposal without changing any native postimage. `raw.patch` changes three Rust files and adds an eight-case intermediate-value WPT. `sign.patch` changes only the generic Sign folding gate and adds an eleven-case zero-font WPT. The Sign patch has the raw conversion patch as an explicit semantic prerequisite. Neither patch is accepted or browser-validated by this artifact.

The raw patch retains actual per-unit arithmetic and context/dependency lookups, exposes its uncensored result to both calc mappers, and preserves the old ordinary conversion wrapper's viewport-normalized versus otherwise-finite policy. The raw tests use compound operands to reach the preexisting deferred evaluation path without relying on the Sign gate repair: NaN and positive/negative infinity with a relative length plus an absolute length, in both opacity and width, plus finite mixed-unit controls for both mappers. Expected values are evaluated at font sizes 16, 0, and 16. NaN is infectious within the expression and normalized only at the outer property value; infinity times a zero font basis becomes NaN. The negative-infinity histories are preservation controls even where final normalization masks the intermediate distinction.

The Sign patch retains the two finite zero-font opacity witnesses, length-valued finite witness, absolute and finite mixed-unit controls, and direct relative NaN/infinity histories in both mappers. Delaying a direct contextual leaf requires the raw prerequisite to preserve nonfinite semantics. No remaining-set or other unrelated code is included.

All fourteen original case identities and expressions remain across the two files. Five additional cases cover the prerequisite's width mapper and independent finite controls, yielding nineteen landing cases. The original combined proposal and its 1,032-case controller remain frozen. A future baseline/raw-only/raw-plus-sign comparison must carry all 1,018 existing controls unchanged, giving a proposed total of 1,037 cases. It must not require the later Sign family's failures to disappear in the raw-only phase. Both phases must preserve baseline passing cases and exact retained failure diagnostics, or record a rejected semantic verdict. Calibration failures and infrastructure/source failures remain fatal. No controller was changed here.

The fixture retains the reviewed calibration and assertion ordering. Positive-font initial/reset semantic failures are possible for the raw-only defect, and must be classified using exact per-case semantic assertions after input calibration; the original four-case diagnostic's final-only classifier is unsuitable. Tests collect all three histories before asserting, but a failure still prevents later assertions from being reached.

Artifact checks authenticate explicit HEAD90 preimages, apply raw then Sign in an isolated temporary repository, compare all four native postimages byte-for-byte with reviewed v2, reverse both patches, and confirm owned test removal. JavaScript syntax and inert registration verify the exact eight/eleven rosters. Temporary products are removed. These checks do not compile Gecko, execute a browser, establish individual defect acceptance, or replace the full preservation campaign. No main or nested index, native source, existing fixture, or canonical library was modified.
