# Descendant normal-pass handoff: source-only proposal

This uninstrumented patch is directly against immutable e86b64866cdc5e2260ba9be08c45756fd96e21bb. It does not include or require the pending font-unit membership/admission repair or root-self identity repair. It is not compiled, browser-validated, accepted, or ready to publish.

The isolated child and root-pseudo no-read histories both observe 64px first and settled; the root-read controls observe 46px. In BOTH child histories the trace publishes restored root font size 23 in AnimationOnly, then rejects normal root entry with an empty local hint, normal dirty=false, animation dirty=true. The root-read control succeeds by creating the dependent effect after publication; it does not demonstrate normal task delivery. Full unchanged34 reproduction is separately recorded by root. These observations support testing the missing normal entry; they do not establish that this patch rebuilds the stale endpoint.

## Change

`recalc_style_at` returns the child hint it already computed, without changing propagation, child iteration, or clearing. The only e86 call site is Gecko's `RecalcStyleOnly::process_preorder` (exact revision-wide Servo path search saved in CALLERS.txt); this checkout has no separate Servo caller. The generic function's new result has no Servo-specific side effect.

Each Gecko traversal records a monotone atomic boolean when AnimationOnly returns a fresh `RESTYLE_IF_AFFECTED_BY_WM_OR_ANCESTOR_FONT` child hint. After `driver::traverse_dom` returns, including worker joins and thread-local SequentialTask destruction, glue inserts `RECASCADE_DESCENDANTS` on the actual returned traversal root. No flush, style/metric getter, extra animation membership query, normal dirty-bit write, or removal of the animation-only processing guard is added. The atomic is local to one traversal, starts false, and is read after workers finish; it transports a boolean only, not style memory.

Normal entry accepts that nonempty root hint. `needs_to_recascade_self` does not recognize `RECASCADE_DESCENDANTS`, so an otherwise clean root is traversed without recascading its own animation. `propagate_for_non_animation_restyle` converts it to `recascade_subtree()` for children. Every styled descendant recascades, including through fixed-font/unanimated intermediates and generated-content nodes. Existing normal `process_animations` requests EFFECT_PROPERTIES for animation members even if style values compare equal. Ordinary child and root-pseudo delivery must still be observed separately; pseudo normalization remains the existing Gecko mapping.

The handoff deliberately uses the whole current traversal subtree. If a font publisher is below its traversal root, merely setting root dirty or marking the publisher's immediate children would not connect intervening nodes. Descendant replay supplies that route without parallel writes to ancestors. It does more work than a precise dirty path and must be performance-reviewed. No dirty bits are manufactured above the traversal root: the existing normal traversal is immediately called for this same root by `Servo_TraverseSubtree`, and normal `note_children` plus Gecko's existing post-traversal bookkeeping remain responsible for ordinary descendant/root flags. The patch does not discover dependencies outside that traversal subtree or repair an incorrectly chosen traversal root.

## Explicit boundaries

- No fresh descendant font signal means no extra hint. Normal passes never set the atomic. A signal on an element without styled descendants may cause one harmless normal entry; display:none pruning remains unchanged.
- The producing traversal root gets no new ancestor-font or RECASCADE_SELF hint. Root-self relative animation semantics are unchanged by this handoff; unrelated existing hints may independently require root recascade.
- Existing `RECASCADE_DESCENDANTS` survives `remove_animation_hints` and `clear_state_after_traversing(FinalAnimationTraversal)`, neither of which removes it. However `finish_restyle` currently returns RECASCADE_SELF before returning NEW font hints in FinalAnimationTraversal or when no old style exists. This proposal does not change that behavior or claim new final-pass/initial-style work is covered. StyleNewSubtree's final-only lifecycle requires separate examination if that case becomes relevant.
- The normal pass must actually queue and deliver EFFECT_PROPERTIES, rebuild against restored metrics, and install the expected endpoint. The source route makes these testable obligations; a passing entry model alone does not prove them.
- The three Rust files need a real Gecko typecheck/full native validation. Rustfmt parsing and patch roundtrips are not native compilation.

## Performance alternative and check receipt

Whole-subtree recascade occurs on every qualifying animation font change, not only cancellation. It can recascade fixed-font subtrees with no relevant dependency and is deliberately conservative for this diagnostic. A more selective post-join handoff could insert `RESTYLE_IF_AFFECTED_BY_WM_OR_ANCESTOR_FONT` into each styled traversal-root child and mark only the root's normal dirty-descendant bit. Normal propagation would then cross intermediates without changing the root's self semantics. On bare e86, however, keyframe-only dependencies lack the ordinary computed-style flag checked by conditional recascade: the separately validated font-unit membership/admission repair is what makes those animated consumers eligible. Selective seeding therefore needs that repair (or equivalent explicit consumer logic), plus source/runtime composition validation; it cannot simply replace this route-only handoff and be assumed equivalent. It is a required performance/design comparison before landing, not justification to accept broad invalidation merely because tests pass.
