**Question:** Must observable animated font sizes reflect current font-relative dependencies, and what does that require of repeated native style settlement?

**Scenario:** Connected, rendered standards-mode iframe; applicable paused CSS animations with resolved progress and explicit constant endpoints; no transitions, important override, additive composition, or unresolved target. Root font is an absolute 32px, either literal or animated. The first dependent uses 2rem; descendants use 2em. This trace concerns those acyclic dependencies, not arbitrary CSS animation feedback. Specifications were retrieved on 2026-11-03; QUERY-RECEIPTS.json records snapshots and tool results.

1. [CSSOM getComputedStyle step 5](https://drafts.csswg.org/cssom/#dom-window-getcomputedstyle) selects resolved longhand values for this connected, rendered target. [Resolved values](https://drafts.csswg.org/cssom/#resolved-values) uses the computed value for font-size: it is not one of the listed used-value exceptions. [CSS Fonts](https://drafts.csswg.org/css-fonts-4/#font-size-prop) defines its computed value as “an absolute length”.

2. [CSS Animations model](https://drafts.csswg.org/css-animations-1/#animations) says “CSS Animations affect computed property values.” An applicable animation contributes at the animation cascade origin; ordinary fixed-pixel declarations beneath it do not freeze the animated result. The separate start-time rule permits deferred style resolution, but does not specify that an already applicable effect may expose stale dependency values indefinitely.

3. [Web Animations computed-keyframe algorithm step 2.2](https://drafts.csswg.org/web-animations-1/#calculating-computed-keyframes) calls [compute a property value](https://drafts.csswg.org/web-animations-1/#compute-a-property-value) with the declared value and target element. The [dependency paragraph](https://drafts.csswg.org/web-animations-1/#computing-property-values) explicitly says: “the computed values of dependencies held by value must be calculated first.” This paragraph is normative; the nearby example and the later live-keyframe note are explanatory support, not the sole oracle. [Applying the composited result, steps 1–4](https://drafts.csswg.org/web-animations-1/#applying-the-composited-result) computes the stack from its underlying value and inserts its result into the cascade. Consequently, recomputing an endpoint without applying the resulting effect does not complete the observable-value obligation. This last sentence is an inference connecting those algorithms, not a prescribed Gecko queue operation.

4. [CSS Values font-relative lengths](https://drafts.csswg.org/css-values-4/#font-relative-lengths) makes rem refer to the root’s computed font size. Font-relative units in a font-affecting property on their own reference element use parent metrics, or initial metrics when there is no parent. Thus a non-root child’s font-size:2rem uses the current root font; font-size:2em uses the parent font. Root font-size expressed in rem uses initial metrics, not its own animated output. This is an explicit local rule preventing that self-dependency; it is not a general cycle solver. [CSS Cascade inheritance](https://drafts.csswg.org/css-cascade-5/#inheriting) transmits parent computed values; anonymous layout boxes do not replace the inheritance tree.

**Verdict: REACHED** — the stated acyclic case requires dependencies before computed keyframes and the resulting effect in the computed font-size exposed by CSSOM. The expected sequence 32 → 64 → 128 → 256 → 512 follows by substitution into the unit rules. Its finite depth is not a specification-defined number of whole-document traversals.

In the reviewed sections, no general repeat-until-stable algorithm, fixed pass limit, or fallback for arbitrary cyclic animation dependencies was identified. This bounded search is not proof that every specification lacks such a rule. Historical [CSSWG issue 5125](https://github.com/w3c/csswg-drafts/issues/5125) discusses competing relative-keyframe models; discussion and examples must not replace the current normative dependency paragraph. A proposed broad cycle policy would need its own specification question and observable tests.

For the native repair, the narrow obligation is to process applicable pending effect application plus newly affected font dependencies before returning observable style, preserving provider-before-dependent ordering. An implementation may use invalidation, ordered computation, or repeated passes; this trace does not select one. The existing queue-drain design and depth addendum remain the source mapping: StyleDocument can leave a request queued after its second traversal, while StyleNewSubtree has a distinct final-animation path. Correcting only one entry point is not automatically a general solution. Repeated eligible work needs a decreasing measure for the acyclic case, and separate handling or a justified limit for feedback and animation creation/cancellation. Merely looping while any compositor map is nonempty also includes ineligible/throttled entries and has no termination argument here.

The literal-root depth witness removes root animation startup from that particular chain, strengthening the need for depth-independent dependency processing. It does not prove convergence of arbitrary CSS. The root’s own relative-font exception must remain intact; accidentally recomputing it against its animated output would introduce an implementation feedback loop excluded by the value rule.
