# Pure length scaling API audit

A useful existing primitive is `computed::LengthPercentage::map_lengths`. It is private to its module, preserves pure percentages, copies the calc clamping mode, and calls `CalcNode::map_leaves` to change only `ComputedLeaf::Length`. Both resolved and animated conversions already use it. A narrow `pub(crate)` pure normalization method could reuse this implementation without invoking either general conversion trait. Scalar `CSSPixelLength` exposes `scale_by`; `Zoom::unzoom` supplies the explicit scale operation. No implementation is proposed or compiled here.

Bounded Searchfox queries for zoom/scale traits, scale_by and length mapping did not find a whole registered-value pure scaling operation. This is a bounded search result, not proof that no such API exists anywhere.

The captured generic structures show the remaining recursive work. Registered components and multiplier lists require preserving all non-length payloads and metadata. Transform operations contain length-percentage Translate/TranslateX/TranslateY, Length TranslateZ, mixed Translate3D and Perspective lengths; InterpolateMatrix and AccumulateMatrix recursively contain transform lists. Matrix/Matrix3D carry Number entries, including translations with separate interpretation; blanket numeric scaling is unsound and their compute/use convention needs verification before changing them. Do not use the unrelated computed matrix scale_by_factor, which scales matrix components rather than typed length leaves.

Images require recursion through gradients, cross-fade images, image-set items and light-dark branches that survive computation. Gradient length sites include linear/radial stops and hints, radial circle/ellipse radii and positions, and conic positions (conic stop angles remain unchanged). Colors, percentages, resolutions, URLs and element identities must be copied without resolution. The captured generic enums establish these fields; exact computed pruning of branches, position internals and matrix conversion remain to be audited. These captures are upstream retrievals, not assertions of byte equivalence to current native files.

The minimal plausible next implementation is a dedicated pure length operation rooted at computed registered Value with explicit recursive helpers, reusing LengthPercentage's leaf mapper. It must be applied at all newly computed local storage boundaries and paired with compatible CSSOM export. Inherited/cached canonical copies must not be normalized again. Actual scaling correctness, relative-reference readiness, animations and nested producer invariants remain outside this source-only audit. See the existing normalization model and repair plan. No native mutation, browser/build run, accepted fix or canonical proof coverage is claimed.
