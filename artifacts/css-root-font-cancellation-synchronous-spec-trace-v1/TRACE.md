**Question:** After cancelling a root font animation, must newly created child rem keyframes use restored root 23px at the first synchronous computed-style query?

**Scenario:** The unchanged cancellation fixture first calibrates a literal root font-size of 23px, then a paused root disturbance. It cancels that disturbance, creates a distinct child/pseudo effect with font-size endpoints 1rem and 3rem, pauses it at currentTime 500 of duration 1000, and immediately reads that target’s fontSize. The document and target are rendered; no transition is specified. The same-root pseudo is a pseudo-element target, not an animation of the root element’s own font-size. The literal declarations remain unchanged during cancellation. These facts, rather than equality between two getter histories, define this trace.

1. [Web Animations cancellation §4.5.14](https://drafts.csswg.org/web-animations-1/#canceling-an-animation) resets pending tasks and makes hold/start times unresolved (steps 1.1, 2–3), removing the cancelled effect. This is cancellation of the root disturbance, not the new child animation.
2. [Model liveness §6.13](https://drafts.csswg.org/web-animations-1/#model-liveness) normatively requires: “Changes made to any part of the model cause the entire timing model to be updated and any dependent style.” The subsequent immediate-computed-style example is explicitly nonnormative corroboration, not an independent obligation. Ordinary API calls need not trigger a transition style-change event.
3. [Computed keyframes §5.3.3](https://drafts.csswg.org/web-animations-1/#calculating-computed-keyframes), introductory requirement and step 2.2, computes properties before effect evaluation. [Property computation §5.3.2](https://drafts.csswg.org/web-animations-1/#computing-property-values) resolves dependencies first: they “must be calculated first”. Thus an eager conversion cache cannot substitute an obsolete dependency at observation time. This is an observable requirement, not a mandated native cache algorithm.
4. [CSS Values §6.1.1](https://drafts.csswg.org/css-values-4/#font-relative-lengths) defines rem as “Equal to the computed value of the em unit on the root element.” The em definition refers to computed font-size. The special initial-font rule for root font-size self-dependency does not turn a child or pseudo target into the root element. After removal of the disturbance, the unchanged root declaration supplies 23px.
5. [CSS Fonts font-size definition](https://drafts.csswg.org/css-fonts-4/#font-size-prop) computes an absolute length and interpolates by computed value. With the fixture’s two endpoints and calibrated midpoint, 23px and 69px yield 46px. The prior disturbance’s observed 32px would instead yield the observed 64px; that arithmetic identifies the stale-value signature, not its native cause.
6. [CSSOM getComputedStyle step 5](https://drafts.csswg.org/cssom/#dom-window-getcomputedstyle) supplies resolved values for the rendered connected target; step 6 returns a live object. [Resolved values §9](https://drafts.csswg.org/cssom/#resolved-values) uses the computed value for properties without a special rule, including font-size. This is the observation boundary; no preliminary root getter is required.

**Timing distinction:** [CSS Transitions §3](https://drafts.csswg.org/css-transitions-1/#starting) leaves grouping/timing of style-change events flexible, but prohibits using/displaying cascade-derived results without updating computed values, and requires simultaneous changes to be indistinguishable when updated. The fixture has no transitioning declaration. This flexibility does not override the animation model’s dependent-style update requirement or permit stale keyframe dependencies in the queried result. Cancel events/promises being delivered later does not defer the cancellation’s effect removal.

**Verdict: REACHED** — Under these calibrated conditions, the first child/pseudo rem midpoint query must resolve against restored root 23px and return 46px. A preliminary root read is only a diagnostic control. This establishes the synchronous oracle; it does not identify a native defect location or establish a new accepted bug.
