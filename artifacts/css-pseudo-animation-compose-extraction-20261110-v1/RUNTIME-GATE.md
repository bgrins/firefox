# Runtime acceptance gate for the extraction

No runtime stage below has been executed in this capsule. The parent owns candidate application, build, runs and restoration. Redirect complete outputs to artifacts and compare against an equivalent unmodified baseline; do not classify preexisting expected failures as new regressions.

1. **Compilation and formatting:** format only the two changed native files under repository policy, inspect resulting diff, then build the C++ consumers and generated bindings. A debug build is required for the assertion-sensitive traversal gate; an optimized build alone cannot establish it. Validate the const FFI parameter against the generated header and public alias/access against real translation units.
2. **Value-composition and timing:** run WPT `testing/web-platform/tests/web-animations/animation-model/combining-effects`, `.../animation-model/keyframe-effects`, and `.../interfaces/KeyframeEffect`. These cover replace/add/accumulate, underlying/implicit endpoints, multiple effects, duplicate offsets, fill/direction/easing/iteration and property skips. Run `.../interfaces/Animation/commitStyles.html` separately to preserve endpoint-inclusive behavior. Include the existing nine-case pseudo-underlying fixture; this refactor should retain its 6 PASS / 3 FAIL baseline, and target.html should retain 17 PASS / 7 expected FAIL including the separate unsupported-placeholder case.
3. **Animation class/cascade consumers:** run `testing/web-platform/tests/css/css-animations` and `testing/web-platform/tests/css/css-transitions` under the matching configuration, checking important precedence, transition/animation overlap and property changes. No fresh-mask or CSS-keyframe behavior change is intended.
4. **Rendering state and pending timing:** run the relevant suites under `dom/animation/test` using a debug browser, including compositor, throttling/overflow, pending play/pause and offscreen animation tests. Exercise missing→generated→missing→generated transform pseudo transitions with and without CSSOM reads; check for unexpected transform-layer assertions and behavior divergence. Ordinary non-pseudo animations must be included. A source-level exact overflow block is supporting evidence, not a replacement for executing it.

A complete acceptance requires no new failures in the covered paths and no debug assertion/crash, plus review of changed timing or composition observations. This is the full regression-gate scope proposed for the shared-loop extraction, not a claim to have run every test or to have fixed the pseudo bug. Broader provider-dependent and CSSOM-cache tests become required when a later candidate changes preparation or adds the CSSOM caller.
