## What the general results establish

`markRoot` and `markDesc` deliberately differ: the initial root ignores its table-column-group tag; descendants stop at that tag. Both prune on direct IS_DIRTY, while query admission uses IS_DIRTY OR HAS_DIRTY_CHILDREN. The proofs preserve this distinction.

The exact theorem `allDirty (markRoot t) = rootClosure t` characterizes every direct dirty bit. It does not characterize necessary query readiness: a clean node with HAS_DIRTY_CHILDREN can be eligible behind a dirty barrier. The independent witness constructs precisely that state. Clear-path conditions suffice for selected query readiness; preexisting eligibility can survive even when those conditions fail.

The finite recursive tree gives substantive arbitrary-depth results for marking and barriers. Its structural termination is not a proof that arbitrary native child-list graphs are finite, acyclic, stable, uniquely represented, or free of alias/lifetime hazards. Native stack-to-tree simulation remains reviewed correspondence, not a kernel theorem. World fields are separate values; their noninterference does not derive actual ownership separation.

`forceAll` corresponds to the executed FrameNeedsReflow IS_DIRTY / IntrinsicDirty::None walk after initialization/destruction gates and the valid non-reentrant entry condition. The retained complete native method can return before that walk. It also performs ancestor scheduling and reflow-root work outside the projection. The theorem is not an unconditional postcondition for every call. Under this specialized branch, the actual walk does not prune dirty/table descendants, so it establishes the helper's barrier condition. Ordinary style invalidation evidence supports this producer, but partial completion, initial construction, other publishers, callbacks and reparenting are not closed by that fact.

`selected_query_recovery` supplies the imported Frame's bit from the selected Tree node and returns the arbitrary layout provider's result. The actual same-frame identity, hidden ancestry, forcing traversal, completion, geometry publication and CSS observer correctness are admitted. Completion of that separate Frame is not a joint Tree/world state transition. No desired output freshness is assumed in the theorem, but neither is its native realization established.
