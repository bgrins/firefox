## Interpretation stress tests

The mandatory distinction between legal points and fitting placements is preserved. A legal point beyond capacity does not make the grid feasible. The chosen first-success scan cannot silently enable a later relaxation when an earlier modeled placement exists.

Line counts count supplied current content, grouped by enclosing-block ID; line ordinal labels do not establish validity or uniqueness. This is explicitly a provider boundary. Positive `orphans`/`widows`, correct continuation inventory and complete A/B/C opportunities and a nonempty applicable break-kind set remain admissions, not consequences of `Nat` or the universal Boolean equivalence.

A single decoration list contributes to every candidate prefix. An eventual CSS layout adapter must justify that common active-decoration abstraction for its entire candidate set; it cannot select decorations using the already-chosen expected answer. Candidate-dependent box membership, ordinary margin truncation, floats and changed line layout may require a richer relation. This does not invalidate the present grid theorem.

Forced controls are rejected at an ordinary cut, but a finishing choice does not inspect opportunities. Thus whole-flow exclusion of forced events is essential. `Challenges.lean` makes this boundary concrete: a fitting input with a supplied forced opportunity still finishes. The scope already excludes this as a complete CSS dispatcher.

The emergency region guard is not proved from a CSS opportunity provider. Weak subset/bounds validity admits incompatible region choices on the producer's beyond-capacity example. `graphicSlice` itself does not enforce even that weak validity; this is another explicit caller premise. Positive content index is correctly distinguished from positive geometric offset, including zero-prefix and ordinary-start-decoration controls.

`SliceHistory` describes a supplied finite history already ending at zero. Its coverage/bound theorem is useful and nonvacuous, but cannot establish an emergency algorithm always produces such a history. The independent witness supplies one concrete5-unit history [2,2,1].
