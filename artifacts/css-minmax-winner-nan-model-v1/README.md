# Winner-relative guard: bounded NaN model

Actual isolated Lean run2 passed14 theorem audits and rejected four false controls (71328/f18b15/0). This is an arbitrary-list NaN-preservation theorem under explicit premises, not a native comparator, magnitude-ordering, PartialEq, IEEE or compiler proof. No canonical proof coverage or accepted-fix count is added.

The general theorem takes any leaf type, a single-context functional evaluator, any hazard predicate, a list of children, and a selected winner belonging to that list. Its guard premise says that every hazardous discarded child equals the winner. Its other premise says every nonhazardous discarded child evaluates non-NaN. From these premises, any evaluated child NaN implies winner NaN; membership supplies the converse. Strict min/max aggregation is independently defined and proved NaN exactly when some child is NaN, so the result holds for arbitrary list lengths, either operation and any leaf ordering. The theorem needs no magnitude assumptions for that NaN equivalence.

Singleton and duplicate-only lists preserve NaN universally under the same evaluator. Equality transports evaluation through congruence; equal coefficients alone do not establish equal leaves or contexts. The contextual instance gives each leaf a unit identifier and one of NaN, negative infinity, arbitrary finite integer or positive infinity. An arbitrary unit→basis map supplies either zero or a positive integer basis. The evaluator resolves the relative coefficient before aggregation. Excluding explicit coefficient NaN and enforcing the structural winner guard suffice in this model. A second theorem permits arbitrary before/after unit-basis maps; it does not reuse a positivity fact across mutation. Positive real/noninteger scaling and native finite arithmetic are outside that concrete instance, while the general evaluator theorem remains parametric.

full_result_given_ordering explicitly requires the remaining non-NaN selection correctness as a premise. It joins that premise with the NaN theorem; it does not prove the premise or claim it follows from the guard. The wrong-finite-winner false control demonstrates the gap. The other rejected controls discard a distinct zero-basis infinity, treat equal infinite coefficients in different units as equivalent despite different bases, and ignore a discarded explicit NaN. These controls fail because their propositions are false, not because of syntax or missing imports.
