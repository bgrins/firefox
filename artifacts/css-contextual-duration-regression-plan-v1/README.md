# Animation-only duration regression inputs

This is a static input plan, not an execution owner or completed browser suite. It captures twelve pages: eleven testharness pages and the existing infinite-duration reftest with its exact reference. No native source, installed application, Git/index or canonical state was changed. The first three-case candidate experiment is separate and was still running when these inputs were prepared.

CAPTURE.json identifies exact local branch files and their hashes, including scripts, inherited/per-page metadata and headers, and explicit absent auxiliary paths. Upstream tests and support code were read with Searchfox; capture uses the actual branch bytes rather than silently substituting today's upstream bytes. The accepted-129 landing fixture was read locally because it is branch work. The original three-case probe is authenticated against its immutable manifest. No harness tree is duplicated: only the four referenced script files are included.

SUBSET-MANIFEST.json is generated by the real WPT manifest library. It contains eleven testharness entries and one reftest entry. The reftest must be run with a reftest-capable owner; it cannot be counted as a callback or passed through a testharness-only assessor. Ten testharness pages inertly register 48 exact names without executing callbacks. animation-base-response-001 requires actual DOM named-element bindings before registration; ROSTER.json leaves its roster and the aggregate unknown rather than supplying DOM stand-ins. Source inspection predicts three additional callbacks, hence 51 total, but this is not an observed roster. An original browser discovery must establish exact names, outcomes, endings and any existing failures before a strict candidate comparison.

## New oracle-bearing probes

animation-duration-animated-input-regressions.tentative.html has five callbacks. All use a paused ancestor font animation at 16→24→16→24px and separate the computed CSS property from the effect/output. Assertions happen after collecting the four samples; identity, current time and an independent 25px script transform are calibrated.

1. Literal 1s child duration remains 1000ms and opacity .75 at 750ms, despite animated inherited font. The unrelated script effect stays paused at 250ms with the same frames, duration and output.
2. Contextual child duration follows 1000→1500→1000→1500ms and opacity .75→.5→.75→.5, while the unrelated script effect on that same element remains unchanged.
3. With animation-name:none, the computed contextual duration still changes but no CSS animation is created, and the sole script effect remains unchanged. Passing this observable test does not establish that unnecessary internal tasks were suppressed.
4–5. The same duration/output relationship is checked independently for ::before and ::after. Acquisition must identify the pseudo CSS effect, with animation/effect identity and 750ms time preserved. These are proposed regression expectations, not evidence that the current candidate already covers pseudo traversal.

These ordinary-property expectations follow CSS Animations 2's animation-property/object correspondence and script ownership rules, CSS Animations 1's live property update rule, and inherited font-relative computation. The pseudo cases apply that same rule to generated pseudo elements with their own animations; they do not rely on keyframe-local contextual easing.

## Self-feedback observations, not a fixed-point oracle

animation-duration-self-feedback-observation.tentative.html has two measurement-only callbacks: a font animation whose own duration depends on em, and a pair of font/opacity CSS animations sharing that contextual duration. Each takes eight animation-frame samples and repeat style reads, retaining computed duration, applied durations, font, opacity, progress, state and current time. There is deliberately no assertion of a fixed duration, convergence, equality across repeat reads or a particular interpolation result. Completion is the bounded observation; a timeout, crash or unbounded flush is a scheduling failure requiring investigation, not a manufactured numerical conformance result.

The page retains JSON in #duration-observations. A future observer must retrieve that text before the document closes if it claims measurement results. Ordinary WPT PASS records alone establish only completion and acquisition, not the values in that JSON. No new transport/owner is implemented here. An external browser/process watchdog remains necessary: a JavaScript timeout cannot interrupt a synchronously wedged style flush. These two research callbacks are excluded from normative repair counts and are not proposed as standalone conformance tests.

## Publication guard and remaining gates

The first candidate compares computed animation lists but lacks needs_animations_update's initial existing-or-specified CSS-animation filter. A changed contextual animation-duration with animation-name:none can therefore queue CSS_ANIMATIONS and EFFECT_PROPERTIES. The latter walks all effects on that element. The observable no-CSS case can preserve output while still doing needless work.

Before publication, retain the computed-list inequality but also require new_style.get_ui().specifies_animations() OR self.has_css_animations(context.shared, None), matching the existing early filter. Keep the no-old-style path unchanged. Do not substitute self.has_animations or relevant-effect membership, because that could lose the accepted-129 inactive/reactivation case. This is a recommended guard correction, not an applied source change or tested successor. It does not solve self-feedback: changed computed duration can still alter animated font, which can change duration again.

The first three-case build is an experiment. Later acceptance requires the exact original/candidate broader roster, all original passing controls and full preserved failure/ending signatures, valid reftest completion, real feedback measurements with a watchdog, and the existing restyle-count mochitest dom/animation/test/mozilla/test_restyles.html. That mochitest is a separate selector, not captured into this WPT manifest. Revisit dispatch/flush bounds if feedback samples or restyle counts regress; do not impose an arbitrary iteration cap as a purported semantic fix.
