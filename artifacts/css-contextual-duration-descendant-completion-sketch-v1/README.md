# A selective ancestor frontier is implementable only with dependency admission

There is no justified small queue-loop patch in the currently retained data. A strict-ancestor completion worklist can handle arbitrary finite descendant depth without assuming that the rest of CSS is acyclic, but it needs a conservative dependency certificate that Gecko's present Pending entries and whole-style flags do not provide. Missing same-element timing-source policy blocks a general completion patch. It need not block a restricted descendant algorithm whose inputs are proved independent of its own effects; that admission mechanism is the missing native work.

## Concrete insertion points

The saved branch `ServoStyleSet::StyleDocument` returns immediately when there is no restyle root, then otherwise traverses and admits one compositor follow-up. Late Pending can survive that follow-up with no root. The saved complete `RestyleManager::DoProcessPendingRestyles` owns the script-blocked/non-reentrant style-refresh transaction, post-traversal/frame changes, root clearing, snapshots and container invalidation. A completion scope belongs to that transaction, not to each getter or each invocation of StyleDocument.

Add a separate selective compositor admission at the existing main-thread traversal boundary, before the root-empty return can finish a transaction with certified ready work. It would call the existing explicit-animation-hint path for selected targets, not recursively call PresShell while Servo/pre-traverse/style-refresh guards forbid dispatch. Keep StyleDocument's boolean meaning of required post-traversal/frame processing. A newly admitted root must receive that existing processing before the query publishes style. Do not repeatedly run font/SMIL preparation as if it were a feedback policy.

The tri-state `PreTraverseInSubtree` already checks eligibility, pseudo targets, document membership, cascade updates and removed effects. Its current whole-map selection/removal and forced-full clear are unsuitable as a selective worklist API: a completion-only selector must leave every unselected entry intact, including unrelated Pending and Throttled entries. Preserve existing ordinary/forced-flush semantics separately. Retiring an entry or calling WillComposeStyle means admission/preparation, not completed computation.

## Minimal mechanism sketch, with explicit unimplemented inputs

1. Begin one completion transaction at a fixed animation sample time. Identify a finite dependency-closed set of eligible targets and their current pseudo/effect identities. A certificate must cover both timing inputs and output/property resolution, not merely the changed animation-duration number. Every changing predecessor must be a strict inheritance/flattened-style ancestor whose own dependencies are certified, or an external input fixed for this transaction. Exclude same-element cross-effect inputs, self-feedback, unresolved root-unit/global inputs, container/layout-dependent inputs and variable dependencies not proved safe. A certificate must not be inferred from the fixture name or from the numerical endpoints.
2. Track admitted input generations and whether evaluation for that generation actually completed. Select the shallowest ready frontier: all its changing ancestors have reached their final certified output generations. Multiple predecessor changes coalesce into that final input vector; a dependent is not consumed merely because it was seen previously. Reuse retained computed-style Arcs and owning target references across the boundary, then revalidate document/pseudo/effect identity after operations that may destroy them. Never hold a hash-table entry reference across callback-capable update or traversal operations.
3. Admit explicit animation hints for that frontier, run normal traversal/sequential animation updates, and complete the normal style/post-traversal work. A target becomes settled only after the chosen timing update and corresponding output composition/recascade are known complete for the captured input vector. Current trace WillCompose/removal markers are insufficient for this acknowledgement; a native completion hook or a proved equivalent is required. Inherited descendants whose values change must receive their normal invalidation, even if they had no Pending entry at transaction start.
4. Admit the next ready descendant frontier until that certified component is settled. A finite strict-ancestor relation supplies a rank bound: each eligible target's final input is processed after its ancestors, so arbitrary finite depth is covered without a hard-coded pass count. This is not permission to drain the entire compositor map. Uncertified work remains queued under the existing scheduling contract; failure to certify it must not clear or relabel it as completed.

Rules, membership, geometry-dependent inputs or sample time changing during the transaction invalidate the certificate. Do not silently replenish an iteration budget or repeatedly restart until something happens to stabilize. A mechanism that falls back on such invalidation may be a bounded experiment, but cannot promise full same-query correctness for that case until its fallback policy is specified. Preserve the existing owning shell/document references, AutoAssertNoFlush, frame-destruction scope and snapshot lifetime; the completion scope must not outlive them.

## Why existing bits are insufficient

The tested matching postimage queues CSS_ANIMATIONS and EFFECT_PROPERTIES after comparing old/new computed animation lists; the retained task-to-manager path supplies flags and computed style, not which metric/property/effect produced the changed timing or which input generation was used. The compositor key combines element/pseudo/cascade level, potentially several effects and properties. It cannot establish an acyclic edge or actual evaluation completion.

Public ComputedValueFlags are conservative whole-style dependencies, not timing-input provenance. Their font-metric bits explicitly exclude em/rem; font/writing-mode-relative usage is another aggregate bit. These flags may help reject cases, but they are not a positive certificate that every dependency is a strict ancestor. Computed duration numbers also discard source-unit and variable provenance. Adding per-input dependency recording at computation/cascade time is a larger change than a queue loop; no complete native API for this certificate is asserted here.

Pre-own-effect timing is an alternative policy, not a shortcut to that proof. The existing base-context helper removes all own SMIL/animation/transition levels but keeps current parent primary style. It could make more descendant inputs structurally ordered after policy agreement, while intentionally changing same-element timing behavior. It does not settle parents, separate keyframe inputs, or isolate shared rem/rlh device caches. Do not silently adopt it to make the termination argument work.

## Falsifiers that any proposal must survive

| Proposed shortcut | Counterexample or missing obligation |
| --- | --- |
| Repeat PreTraverse while work exists | Steps self-font duration alternates 500/1000 ms under explicit reevaluation; the mathematical feedback has no fixed point. Actual samples do not establish that every native execution alternates. |
| Consume each compositor key once | Two effects on one element can form font-output to opacity-timing dependence without a feedback edge under the authored composed-input interpretation. That interpretation itself remains a policy question. |
| Queue length or element count is the pass budget | One key contains several properties/effects; intermediate style and variable dependencies are not counted. Later descendants may not initially be Pending. |
| Ancestor ordering alone proves all CSS safe | Root self-rem/rlh timing, own-font timing, and size/container dependencies need separate treatment; mixed ancestor inputs can revisit descendants before their final inputs settle. |
| CSS duration equals applied duration, so evaluation finished | Completed depth-8 record has stage-8 CSS/effect duration 1000 ms and progress 1 while its recorded font remains 16 px. These later sequential reads are not proof of a simultaneous causal state, but disprove using numeric equality alone as an observation of fresh output. |
| Eventual frame recovery satisfies the query | All four actual finite-depth callbacks fail their first read; depth 8 remains old throughout the recorded three-frame window. No native traversal count follows. |

The ranked DAG model proves coverage and completion for fixed pure rules with complete notification and atomic full-batch evaluation. Native frontier acknowledgement, complete invalidation and dependency admission are precisely the missing refinements. Its height+1 result must not be translated into a browser pass cap.
