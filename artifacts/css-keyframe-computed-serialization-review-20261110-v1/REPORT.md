# Computed keyframe conformance oracle review

The eight-callback proposal is suitable for the baseline experiment, with no oracle blocker found. Root authored the proposal; this is independent contract review. Proposal SHA256 is 055df1b6d3cd6f306b9e59460f56260f2688172d265309591622836b99a31408, bound to investigation manifest f45db45c70a132ec9da685d78a802e31ac457a69fd4a410b5a69007307df663c. No browser/native/Git mutation occurred in this review.

The [getKeyframes branch](https://drafts.csswg.org/web-animations-1/#dom-keyframeeffect-getkeyframes) selects computed keyframes for untouched CSS animations and specified keyframes for ordinary WAAPI or replaced CSS keyframes. The [property-value computation](https://drafts.csswg.org/web-animations-1/#computing-property-values) explicitly uses current element computed dependencies without changing that element. Its own animated-font example corroborates the proposed distinction: at current font 15px, authored 1em/2em margins compute to 15px/30px. Evaluating each margin against its own endpoint's 10px/20px font would use the wrong context.

Both endpoints are fully authored, removing generated-base and additive implicit-endpoint ambiguity from this experiment. Relative ordinary lengths and registered <length> values compute to canonical px; unregistered tokens retain em. The typed static registration assertion protects against silently running the typed case without registration. Literal token controls and WAAPI/CSS-setKeyframes controls are separate callbacks, preserving evidence if the computed cases fail. The source-update callback checks fresh current dependency state rather than a stale cached substitution. Explicit pause and half-duration seek avoid timing races; connected ordinary targets avoid missing-pseudo admission questions. Cleanup cancels each animation/removes its target.

The array assertions deliberately check returned property values; they do not claim full frame-object metadata coverage. Existing grouping/offset/composition suites remain required for any native repair. Expected baseline 5 FAIL/3 PASS is provisional until execution. If the animated-font setup assertion fails before its getter assertion, the actual message must distinguish that stage; the runner preserves it rather than treating counts as proof of the predicted defect.

A narrow getter compute route must gate on untouched CSS keyframes, retain the supplied current element/pseudo/parent/container dependency context, and compute each returned property without replacing that context with endpoint-local custom declarations. Rendering's batched Servo_GetComputedKeyframeValues is therefore not an automatically sound substitute. The universal custom branch's no-substitution FIXME likewise means AnimationValue::from_declaration alone is incomplete. Detailed helper design remains deferred behind the bounded baseline, as root requested. No guessed evaluator, native patch, duplicate-bug classification, or count increment is approved here.

Primary clauses and fresh source receipts are retained in css-keyframe-custom-property-contract-20261110-v1; the original diagnostic runtime independently confirms the specified-expression return for relative/custom cases while preserving expected token/WAAPI controls. This review applies that contract to the proposed exact assertions rather than inventing a conformance oracle from Firefox's current outputs.
