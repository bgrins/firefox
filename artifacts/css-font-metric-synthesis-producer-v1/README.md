# Selected synthesis inputs for retained metric consumers

This experimental successor connects the four font-synthesis longhands to the real retained metric provider. It reuses the existing owned declaration preparation and publication path. The observed 13-case fixture explicitly sets font-synthesis:none; the prior provider deliberately stopped on those unprepared declarations. This code supplies that concrete producer. It has not been typechecked in Stylo or run in a browser and does not establish a complete font-metric repair.

The parent cascade is sealed provider 25be8f25; provider custom_properties.rs remains exactly 90acb505. The full patch remains relative to published 5b7204/bb13. PARENT-DELTA.patch isolates this successor. The three existing CSS semantic node identities and recursive eager traversal bodies are unchanged. FontTarget distinguishes a scheduling request for a priority property from a synthesis longhand; it does not add a CSS graph node.

MetricPreparation now retains a LonghandId. Priority callers keep their previous position chains and generated prerequisite checks. Synthesis callers scan the full ordered declaration list with an Option<usize> cursor, filtering exact longhand identity; only priority entry positions interpret the existing u16 sentinel. Local eligibility and rollback logic, retained selected Arc, owned substituted declaration and publication validation are shared. A disallowed variable candidate is skipped without substitution. Only the four synthesis longhands enter this non-priority path. Other non-priority font inputs still return unresolved work.

The Context keeps one synthesis preparation alongside its opaque pending action. A literal/default chain can finish, publish through the unchanged apply_one_longhand, mark the input complete and release the action. It performs no prioritary-property fixup and sets no prioritary ensured bit. The existing seen check in apply_one_longhand prevents later ordinary reapplication of a winning declaration; exhausted excluded chains remain governed by unchanged context flags. A selected variable returns its exact longhand/Arc without substitution. No reference-ready certificate is invented. Eligibility changes invalidate synthesis completion, and already-applied invalidated work is not silently republished or treated as final.

The real provider requests pending synthesis declarations after its metric/orientation prerequisites. Completion is kept separate from both CSS SCC closure and old ensured bits. The existing root loop resumes the waiting custom frame after each actual action publication. The prior pure-AST versus early ATTR preparation boundary remains unchanged. Unprepared features/variations/other font inputs, unresolved selected references, generated work without a completion producer, and true metric wait cycles still lead to explicit experimental suspension/tripwires. Shipping such a tripwire is not proposed.

Fourteen extracted Rust tests pass with debug assertions disabled. They include all prior provider and exact Prepare/Units/Publish-arm tests, plus the four synthesis publications in order, interleaved-longhand/local-rollback selection, repeated exact-Arc waiting without publication, and completion invalidation. Fifteen compiled mutants fail behavioral assertions. The first control run exposed that checking only publication counts could miss a wrong-longhand cursor; the strengthened test checks each published declaration's identity and distinct value. That earlier receipt is retained. Peer review then found that the first prototype incorrectly truncated non-priority scanning at the priority-only u16 sentinel. The corrected cursor and a fixed-allocation 65,535 boundary test cover both a first match at the sentinel and a rollback chain crossing it; restoring the truncation fails that test. An initial boundary-test attempt used an inherited u32 test double and was interrupted before producing a result. The double now matches the frozen native u16 alias, and the allocation is explicitly bounded independently of that type. This was a prototype defect, not an observed Firefox regression.

The extracted harness compiles actual staged/drain/action/provider/completion bodies and actual preparation/publication arms with controlled Stylo/declaration doubles. LonghandId and PrioritaryPropertyId are represented by one test enum with an explicit from_longhand distinction, so this does not prove native type relationships or four Context lifetimes. Parsing, font computation, property application and dictionary/DOM inputs remain doubles. A synthesis variable wait is tested as a wait, not as a completed native reference producer. The test does not establish actual results for any of the 13 browser callbacks.

check.py authenticates parent/source/extraction, unchanged semantic traversal, both two-file zero-fuzz forward/reverse patches, pinned formatting, compiled receipts and scratch absence. Real Stylo compilation is still required. Next concrete work is to let selected prerequisite references progress under the same retained semantic session without replacing its root or inventing edges, while retaining computation versus semantic Pending. Whole-font consumer correspondence, finality/restart after mutations, and genuine readiness-cycle policy remain explicit open obligations.
