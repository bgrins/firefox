This companion addresses the universal run-dispatch gap identified in v1. It is prepared for final verification; only `FREEZE.json` plus successful canonical/relocated receipts establish its frozen status. Independent formal acceptance remains a separate review.

## Main result

For an arbitrary finite original text/glyph buffer satisfying the explicit raw record, shaping, surrogate and range premises, classification updates preserve unrelated storage, shape and metric inputs. Actual-shaped binary run selection, boundary shrinking, ligature scanning, partial-width handling, spacing acquisition and the ordinary unit draw loop produce the same abstract coordinate, ordered draw positions, unit identities and provider trace as an independently grouped raw reference. The contract starts from original raw words and text units; it does not start from a supplied action plan or assume post-update readiness.

The chain is visible in `TextInput.original_input_complete_dispatch`, `Ordinary.complete_raw_dispatch`, `NativeDomain.actual_length_complete_dispatch` and `Identity.simultaneous_raw_geometry_identity`. `NativeDomain.actual_selected_ranges_bounded`, `selected_shrink_bounds` and `scanned_arithmetic_domain` cover the associated bounds/count obligations. See [BRIDGE.md](BRIDGE.md) for providers and the exact arithmetic/native distinction.

The fixed PUA predicate still has its independently specified detailed-category theorem. Exhaustive native ICU/Unicode and decoding checks bind that model to the actual data and implementation. The surrounding styling/shaping/rendering system is not universally verified.

## Separate negative-advance contract

The browser-reachable negative-ligature issue is independent of the PUA classifier repair. V2 preserves the original unsigned arithmetic as an explicit policy and diagnostics, and binds the exact separate signed native candidate. Signed division truncates toward zero; count products cannot exceed the magnitude of the int32 total width, fit signed64 and the exact integer domain of binary64; the final remainder preserves partition totals. Nonnegative behavior is unchanged.

The companion does not claim that legacy unsigned negative behavior refines signed geometry. It also does not infer arbitrary browser clipping/rasterization behavior from the integer theorem. The independent native/font/WPT review is in `negative-review/REPORT.md` and its replay receipt. Root retains responsibility for the separately landable native/WPT patch and final acceptance.

## Limits

This is universal refinement of explicit mathematical algorithms plus finite agreement with complete extracted native functions. It is not a verified compiler, a complete proof of IEEE operations, or a proof of all CSS text shaping/rendering. Shaping partitions, immutable valid storage, external style/font providers and exact-operation/overflow premises are named. The two arithmetic policies and their native variants remain separate. The final internal point of the by-value text-run draw method is a model-state result; actual emitted positions/identities/provider traces are the finite native observations.

Primary PUA/CSS/Unicode17 evidence is retained from the approved scope. Fresh CSS Text/OpenType retrieval for the separate negative-font review encountered an authentication failure; that freshness status is recorded there rather than silently replaced with a current-spec claim. No browser, production-source, WPT, build or Git mutation was performed by this artifact worker.
