# Registered keyframe substitution oracle

Question: should the frozen sixteen midpoint assertions use substituted numeric endpoints and ordinary explicit/default invalid-value behavior?

Scenario: attached HTML elements, two valid document registrations with `<number>` syntax and initial value 0; one inherits and one does not. Attribute and variable values are static. The effect has two endpoints, default linear easing, duration 1000, and paused current time 500. Parent/base values in defaulting cases are 30/42. No additive composition, registration change, relative-unit dependency, or stylesheet keyframe merge is involved.

1. [Web Animations computing property values](https://drafts.csswg.org/web-animations-1/#computing-property-values) resolves each endpoint using the target's computed dependencies before interpolation. The separate calculating-computed-keyframes step applies this to the effect's keyframes.
2. [Registered-property computed values](https://drafts.css-houdini.org/css-properties-values-api-1/#calculation) apply the registration grammar at computed-value time. Registered declarations accept token streams at parse time; a failed number grammar becomes invalid at computed-value time. Numeric literals and successful numeric functions supply numeric computed values. [Animation behavior](https://drafts.css-houdini.org/css-properties-values-api-1/#animation-behavior) says values interpolate “by computed value”.
3. [Attribute substitution](https://drafts.csswg.org/css-values-5/#attr-substitution) resolves the attribute as the requested number, or the supplied fallback for a missing attribute. Thus the three attribute cases and the variable endpoint yield 42, just as the literal and calculation controls do. Number interpolation halfway between 0 and 42 is 21, in either direction. Attr taint does not prohibit numeric interpolation; URL use has separate restrictions.
4. [Explicit defaulting](https://drafts.csswg.org/css-cascade-5/#defaulting-keywords) makes initial select 0, inherit select the parent's 30, and unset select inheritance or initial according to the registration. [Invalid substitution](https://drafts.csswg.org/css-values-5/#invalid-substitution) selects inherited or initial value for non-universal registered properties. Thus invalid and missing-variable endpoints also use 0/30, not the element's existing 42. Halfway from 14 gives 7/22.

**Verdict: REACHED.** The sixteen frozen expected values follow for the stated static scenario. This does not adjudicate dynamic dependency recomputation or fallback-produced CSS-wide keyword implementation issues.

No NOT REACHED claim is made. The inherited invalid-value behavior follows the explicit current Values 5 invalid-substitution rule; a general prose remark about registration initial values is not used to override it.
