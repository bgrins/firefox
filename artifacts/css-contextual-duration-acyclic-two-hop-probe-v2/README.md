A fresh visible same-origin iframe supplies a separate root font basis for each callback. First establish the middle animation at 750 ms and font 28px, then insert/acquire the child; this avoids admitting an already-stale initial child duration. Both CSS animations stay paused, with linear easing and fill both. The animated case has a fixed 1000ms WAAPI root font driver, paused and sought from 0 to 1000.
