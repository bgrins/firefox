# Counter integer sentinel candidate, complete mapped producers

This successor replaces the held one-file candidate with two Rust files and the same23-case landing WPT. V1 remains immutable and must not be treated as compilable: its CounterInteger aliases were not matched by two raw Integer constructors in servo/ports/geckolib/glue.rs. No native source/index or browser/build action occurred. This source correction is not a new accepted fix.

The CSS parser/conversion algorithm is unchanged from v1. Explicit literal MIN is clamped during parsing; boxed math results are clamped after evaluation; inline raw values are preserved. Both glue SetCounterResetListItem and SetCounterSetListItem now construct the wrapper through CounterInteger::from_computed_value. ToComputedValue is already imported in glue. This delegates to Integer::from_computed_value and produces the same inline integer as before, without clamping or inventing a new public raw factory. Wrapper comments now state this compatibility role instead of falsely claiming that omitted reversed reset is the sole possible inline MIN producer.

Raw provenance is genuinely broader than parsed CSS. MappedDeclarationsBuilder forwards HTMLSharedListElement's start−1 (or reversed adjustment/omitted MIN) and HTMLLIElement's value directly. ParseIntValue accepts the full signed32 interval through checked signed HTML integer accumulation. Ordinary ol start=−2147483647 therefore produces MIN with reversed=false through defined arithmetic; li valueMIN likewise supplies raw MIN as SET. The wrapper must preserve these mapped values rather than silently move a valid predecessor by one. Existing native IsContentBasedReset still aliases the ordinary mapped MIN with automatic reset. That separate, unobserved source lead and four prospective exact-rendering cases are recorded in css-counter-html-mapped-sentinel-probe-v1. They are not added to this repair's landing tests or counted as an accepted bug.

Computed-to-specified conversion also preserves arbitrary raw i32 MIN. Consequently, the useful exclusion law is scoped to CSS-authored parser outputs, not all wrapper instances. Discrete animation/copying preserves its supplied computed values; neither numeric identity nor the inverse conversion proves their origin. The new Lean companion models parsed and raw producers separately. It cannot discharge every future/generated constructor's domain automatically. Searchfox discovery across servo (rather than only style/) found the parser plus these two explicit CounterPair construction sites; direct CounterReset::new/CounterSet::new calls are these glue paths. This is bounded source evidence, not a universal generated-code proof.

The landing23, existing30 testharness controls and two reftests are byte-identical to v1. No test asserts the old erroneous computed calcMIN value. Three-path standalone Git patch checks/application/reversal pass against immutable HEAD90 in an owned scratch repository, with exact source/test postimages. Rustfmt using servo/rustfmt.toml and JavaScript syntax pass. Full Stylo/Gecko compilation, normalized comparison and independent source review remain required. The previous one-file source GO does not automatically cover this successor.
