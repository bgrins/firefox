# Initial versus dynamic relative positioning

Release and the shared project baseline return identical90-row observations. Each row compares an offset set before insertion/first layout against an initially zero-offset layout subsequently shifted to the same final computed styles. Inputs span three writing modes, row/column flex and ordinary block parents, fixed80px overflow subjects versus auto-size normal subjects, and zero/±17px block/inline offsets.

Twenty rows differ between fresh and dynamic geometry. Six ordinary horizontal cases independently reproduce lost initial block offsets on successor overflow fragments: row/column flex and block parents at±17px. These are calibrated without the vertical final-size repair. All45 normal-subject controls pass. All rows agree in final computed styles, preserve dimensions and other items, and restore the dynamic zero state exactly. Dynamic translation matches in every row.

Eighty zero-geometry rows calibrate. Ten vertical-rl flex overflow rows fail that absolute calibration because of the separately known final-width defect; four of the20 fresh/dynamic mismatches belong to that group. The16 calibrated mismatches comprise horizontal and vertical-lr block-offset failures plus vertical-rl block-parent block/inline failures. The latter inline cases remain a related review lead rather than a separately counted bug.

CSS Fragmentation4 §5.5 applies relative positioning after fragmentation and per fragment, including overflow-only fragment origins: https://drafts.csswg.org/css-break-4/#transforms . The native helper forwards Default flags to FinishReflowChild, which gates offset application and normal-position caching on ApplyRelativePositioning. Position-only restyle has a different continuation walk, explaining why a later update can correct the initial geometry. The source review and separate repair must preserve predecessor normal versus used coordinates, avoid applying inline offsets twice, and audit caller flags and sticky behavior.

This is a reproduced standalone relative-position lead; no repair is accepted yet. It does not depend on the vertical final-size candidate and will have its own Gecko/WPT commit if accepted. Both browser runs complete with stable source/binary pins; profiles are removed. No native mutation occurs in this probe. The passing earlier zero-first horizontal delta experiment remains retained as a required control.
