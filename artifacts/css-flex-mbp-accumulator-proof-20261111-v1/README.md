The generic free-space theorem still explicitly assumes its independently defined downstream ranges.

The old checked32 rejection is a representability result; it does not predict overflowing C++ as wrap. Seven separate false-claim files must fail with exactly one normal Lean false-proposition diagnostic. These are semantic sensitivity controls, not compiled native mutants.
