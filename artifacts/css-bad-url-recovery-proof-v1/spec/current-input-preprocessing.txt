3.3. Preprocessing the input stream The input stream consists of the filtered code points pushed into it as the input byte stream is decoded. To filter code points from a stream of (unfiltered) code points input : Replace any U+000D CARRIAGE RETURN (CR) code points , U+000C FORM FEED (FF) code points , or pairs of U+000D CARRIAGE RETURN (CR) followed by U+000A LINE FEED (LF) in input by a single U+000A LINE FEED (LF) code point . Replace any U+0000 NULL or surrogate code points in input with U+FFFD REPLACEMENT CHARACTER (�).
