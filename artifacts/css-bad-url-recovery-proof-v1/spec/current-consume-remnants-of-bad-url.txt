4.3.15. Consume the remnants of a bad url This section describes how to consume the remnants of a bad url from a stream of code points , "cleaning up" after the tokenizer realizes that it’s in the middle of a <bad-url-token> rather than a <url-token> . It returns nothing; its sole use is to consume enough of the input stream to reach a recovery point where normal tokenizing can resume. Repeatedly consume the next input code point from the stream: U+0029 RIGHT PARENTHESIS ()) EOF Return. the input stream starts with a valid escape Consume an escaped code point . This allows an escaped right parenthesis ("\)") to be encountered without ending the <bad-url-token> . This is otherwise identical to the "anything else" clause. anything else Do nothing.
