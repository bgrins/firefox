# WEB-ANIMATIONS-1#the-effect-stack

**The effect stack** (heading)

**SHA**: hash:cd72b5821823c7cfde12f892b8f0725078b841004b5824f4701afffaafdf5649

## Content

An **effect stack** is associated with each property [targeted](WEB-ANIMATIONS-1#target-property) by one or more [keyframe effects](WEB-ANIMATIONS-1#keyframe-effect). The [effect stack](WEB-ANIMATIONS-1#effect-stack) establishes the relative composite order of keyframe effects.

The relative **composite order** of any two [keyframe effects](WEB-ANIMATIONS-1#keyframe-effect) *A* and *B* within an [effect stack](WEB-ANIMATIONS-1#effect-stack) is established by comparing their properties as follows:

1.  Sort *A* and *B* by applying the following conditions in turn until the order is resolved,

    1.  If *A* and *B*’s [associated animations](WEB-ANIMATIONS-1#animation-effect-associated-animation) differ by [class](WEB-ANIMATIONS-1#animation-class), sort by any inter-class composite order as defined for the corresponding classes.

    2.  If *A* and *B* are still not sorted, sort by any [class](WEB-ANIMATIONS-1#animation-class)-specific composite order defined by the common class of *A* and *B*’s [associated animations](WEB-ANIMATIONS-1#animation-effect-associated-animation).

    3.  If *A* and *B* are still not sorted, sort by the position of their [associated animations](WEB-ANIMATIONS-1#animation-effect-associated-animation) in the [global animation list](WEB-ANIMATIONS-1#global-animation-list).

[Animation effects](WEB-ANIMATIONS-1#animation-effect) that sort earlier have *lower* composite order.
