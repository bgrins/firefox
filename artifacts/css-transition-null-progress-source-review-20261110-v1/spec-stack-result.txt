# WEB-ANIMATIONS-1#calculating-the-result-of-an-effect-stack

**Calculating the result of an effect stack** (heading)

**SHA**: hash:cd72b5821823c7cfde12f892b8f0725078b841004b5824f4701afffaafdf5649

## Content

In order to calculate the final value of an [effect stack](WEB-ANIMATIONS-1#effect-stack), the [effect values](WEB-ANIMATIONS-1#effect-value) of each [keyframe effect](WEB-ANIMATIONS-1#keyframe-effect) in the stack are combined in composite order.

Each step in the process of evaluating an [effect stack](WEB-ANIMATIONS-1#effect-stack) takes an **underlying value** as input.

For each [keyframe effect](WEB-ANIMATIONS-1#keyframe-effect) in the stack, the appropriate [effect value](WEB-ANIMATIONS-1#effect-value) from the keyframe effect is combined with the [underlying value](WEB-ANIMATIONS-1#underlying-value) to produce a new value. This resulting value becomes the underlying value for combining the next keyframe effect in the stack.

The final value of an [effect stack](WEB-ANIMATIONS-1#effect-stack), called the **composited value**, is simply the result of combining the [effect value](WEB-ANIMATIONS-1#effect-value) of the final (highest composite order) [keyframe effect](WEB-ANIMATIONS-1#keyframe-effect) in the stack with the [underlying value](WEB-ANIMATIONS-1#underlying-value) at that point.
