The earlier Admission model explicitly excludes registered initial values, consumer computation and production scheduling. Its `pending_is_not_invalid` and `wrong_type_ready_does_not_retry` motivate retaining readiness separately from invalid/defaulting. This artifact fills only the fixed keyword/default/cache witness. Importing its unrelated number AST would add no useful dependency, so no new broad admission framework or duplicated expression grammar is introduced.

The graph theorem is conditional on the explicitly modeled selected graph. It proves every positive-length modeled path decreases rank and therefore cannot return to its start. It does not claim that native graph construction always yields these exact edges, or that acyclicity chooses a legal evaluation schedule. Genuine vi/if()/style() cycle policy remains outside the model.
