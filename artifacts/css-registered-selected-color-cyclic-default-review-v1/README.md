# Cyclic invalid-default preservation review

The draft V2 Initial variant repairs the acyclic invalid-substitution path, but it does not by itself cover SCC invalidation. The cascade removes COLOR_SCHEME before checking lowlink, self-reference and the stack suffix. When those checks skip preparation, Context::handle_loop(Custom) still calls the invalid-value handler, which may recompute a contextual initial value.

A minimal source-shaped witness is a non-inheriting registered --c with initial light-dark(red, blue), --c:var(--c), and explicit color-scheme:dark under a light parent. The original coarse edge reaches and applies ColorScheme before the custom SCC default is computed. The reviewed draft clears that edge, skips prepared selection because self_ref is true, and then computes the initial during SCC popping. This can use the earlier scheme. No native result or normative cycle endpoint is asserted here.

A second control uses --c:var(--d) and unregistered --d:var(--c), exercising an unresolved child on the SCC stack as well as the lowlink/backedge path. Require successful registration, record the first --c read before scheme and literal controls, and compare with both ordinary literal light-dark and a valid registered-expression control. Use distinct missing/self/two-variable cases rather than treating an acyclic invalid parse as coverage of SCC invalidation. An independent identifier initial in a color union remains necessary to reveal excessive coarse dependency retention.

A second timing boundary remains even if known custom SCCs retain or classify the initial edge: a cycle can form only after successful singleton preparation visits a non-color edge. Register --c with syntax `<length> | <color>` and a contextual color initial; select `--c:1em`, set `font-size:var(--c)` and a literal dark scheme. The prepared AST is Length and adds no ColorScheme edge. FontUnits then closes the custom/font-size SCC, whose invalid handler recomputes the color initial. The old coarse color edge was visited before SCC popping. A default classifier used only when initial preparation is skipped misses this route. This is also an unexecuted source-shaped discriminator; it is not a normative proof of the final font-size or default color.

The narrow preservation option is to clear/refine the color edge only when singleton preparation succeeds and retain the previous coarse edge otherwise. This preserves the known-before-preparation custom-cycle behavior, but does not by itself cover cycles formed later through unit edges or prove exact selected-default dependency classification inside cycles. A more precise cyclic-default algorithm requires a separate dependency/selection argument. No recommendation here permits partially applying or retrying a cyclic declaration.
