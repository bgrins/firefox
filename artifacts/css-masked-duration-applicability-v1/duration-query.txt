The [animation-duration](CSS-ANIMATIONS-1#propdef-animation-duration) property defines duration of a single animation cycle.

**[\<time \[0s,∞\]>](CSS-VALUES-3#time-value)** 

Specifies the length of time that an animation takes to complete one cycle. A negative [\<time>](CSS-VALUES-3#time-value) is invalid.If the [\<time>](CSS-VALUES-3#time-value) is 0s, like the initial value, the keyframes of the animation have no effect, but the animation itself still occurs instantaneously. Specifically, start and end events are fired; if [animation-fill-mode](CSS-ANIMATIONS-1#propdef-animation-fill-mode) is set to [backwards](CSS-ANIMATIONS-1#valdef-animation-fill-mode-backwards) or [both](CSS-ANIMATIONS-1#valdef-animation-fill-mode-both), the first frame of the animation, as defined by [animation-direction](CSS-ANIMATIONS-1#propdef-animation-direction), will be displayed during the [animation-delay](CSS-ANIMATIONS-1#propdef-animation-delay). After the animation-delay the last frame of the animation, as defined by animation-direction, will be displayed if animation-fill-mode is set to [forwards](CSS-ANIMATIONS-1#valdef-animation-fill-mode-forwards) or both. If animation-fill-mode is set to [none](CSS-ANIMATIONS-1#valdef-animation-fill-mode-none) the animation will have no visible effect.
