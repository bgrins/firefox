**2026-04-28 17:25:16** - Comment #0 by sajidanwar94@gmail.com
This is needed for `sibling-index()` / `sibling- count()`, which is resolvable only at computed-value time. But this is also required today for expressions that have font-based lengths, like:

- `calc(atan2(1em, 16px))` should produce  `45deg`
- `calc(sign(1em - 32px))` should produce `-1`
- `calc(1s * (2em / 16px))` should produce `2s`
- etc.

These are functional in Chrome today (and Safari too probably, but it keeps crashing for me). These don't work in Firefox right now since types other than `<length>` eagerly resolve at parse time.
