# Existing traversal statistics: one prepared action

Prepared only; no browser or native execution. The three files are function expressions for the existing connector execution API. The setup's DOM/font/animation calibration body is copied exactly from the sealed cost probe at 5000 leaves. This is a count experiment, not another timing comparison.

1. Launch the chosen retained archive with `DUMP_STYLE_STATISTICS=1` and `STYLE_STATISTICS_THRESHOLD=0` in its environment **before process startup**, and capture **stdout** (stderr-only is insufficient). Keep the usual archive identity and cleanup checks. Do not disable style sharing/caches. Any nonempty DUMP value enables it, including `0`; threshold defaults to 50 otherwise.
2. Execute/await `setup.js` in a normal blank page with the same persistent window/global for all three calls. Require ready=true and retain calibration output. It creates 5000 pre-styled fixed 13px leaves; root absolute animation is paused at 0 (16px), child relative animation paused at 500 (32px). It creates no measured warmup/action.
3. Record stdout byte offset after setup returns. Execute `action.js` once, synchronously. It performs exactly `rootAnimation.currentTime = 1000; getComputedStyle(target).fontSize` between two clock reads, preserving adjacency and target-first observation. Expected target64px is recorded and checked, never substituted for actual output. The result remains in the page even before cleanup. No root getter occurs in this call.
4. Immediately record new stdout offset/save those bytes and action output **before cleanup or any extra computed-style query**. Preserve all complete `[PERF]` blocks and any incomplete/interleaved bytes. Then execute `cleanup.js` in a finally path. Cleanup records post-state only after the action result was retained, cancels both animations and removes the iframe/global.

Setup/action are now separate connector tasks, unlike the cost loop's adjacent samples. Both animations are paused and the action explicitly seeks; the first-getter read semantics within the action are unchanged, but task boundaries can admit unrelated browser work. Byte-offset isolation is an operational interval, not proof of exclusive attribution. The native blocks contain no PID, document/root identity, phase or traversal flags. Retain a complete log and reject ambiguous/interleaved/truncated attribution; do not silently discard unexpected blocks. If offsets prove too broad, same-thread `window.dump` delimiters outside the critical pair are possible with browser.dom.window.dump.enabled=true and an empty browser.dom.window.dump.file; they are not in these scripts and still cannot exclude unrelated process output.

`driver::traverse_dom` aggregates all worker/main thread traversal statistics after the parallel scope joins and prints `println!("{}", stats)` to stdout for traversals reaching the threshold. This is independent of profiler recording. The output starts `[PERF] perf block start` and ends `[PERF] perf block end`, with comma-separated fields: traversal, elements_traversed, elements_styled, elements_matched, styles_shared, styles_reused, selectors, revalidation_selectors, dependency_selectors, declarations, stylist_rebuilds, traversal_time_ms. The `parallel` label means a pool exists, not proof a worker processed nodes. No profiler configuration or new logging is required. Actual subprocess stdout inheritance must still be verified in the launch.

`elements_traversed` counts recalc visits before restyle-kind selection. `elements_styled` counts compute_style entries, including recascade/animation replacement/cache hits; it is not an exact cascade-call count or unique-element count. Matched/shared/reused distinguish existing resolver/cache outcomes. Selector/declaration fields describe the stylist, not per-action selector execution counts. Traversal time is not the whole getter duration. Logging changes timings: use counts here, not the instrumented elapsedMs as confirmation of the earlier cost medians.

A plausible discriminator is similar large traversal counts but substantially more styled visits under broad subtree recascade than selective font-dependent recascade for the 5000 unrelated fixed leaves. Multiple normal/animation traversal blocks and auxiliary nodes can contribute. No exact N or N+constant total, single block, phase classification, or speedup is asserted before actual output. Correctness still requires first target64px and preserved fixed leaves in post-state.
