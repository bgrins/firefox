# Transition endpoint regression source review

GO for the sealed b2acf5df proposal's bounded red/green experiment. All proposal payloads authenticated. The complete C++ extension, Rust observer, host assertion macros, native correction, selection and retained source evidence were read. The known modified KeyframeEffect header also matches the proposal's source pin: construction and mutator are public, the destructor is virtual/protected, and the test-only subclass can expose protected input keyframes. No compiler, test, native/index/ledger mutation or patch application was performed by this review.

The regression discriminates the stale descriptor independently of numeric correctness. Before replacement it retains the genuine from/to descriptors, verifies their structural source identity and parsed opacity declarations, and retains the to-value Arc. Replacement must produce a nonnull 0.4 from value while clearing its descriptor; the null expectation is nonfatal, allowing the red run to continue. An implementation that updates only the numeric value and synthesized input still fails the descriptor assertion. Unchanged to descriptor/value pointer and 0/1 offsets are separately checked. The old retained from descriptor must still describe 0.2 after releasing the effect, rather than being mutated to impersonate the replacement.

The recomputed input checks exercise the real stored input block: the synthetic replacement resolves to 0.4 and the other endpoint stays 0.8. They do not call UpdateProperties on the effect. With a real 0.1 underlying value, native segment composition distinguishes explicit 0.4→0.8 (0.6 midpoint) from a separately constructed implicit-from segment (0.45 midpoint). Thus absent descriptor is not equated to absent value. This is the intended three-way boundary: implicit value, explicit concrete value, or explicit value with retained declaration identity. It is not a fallback for failed deferred resolution.

The C++ observer arguments are borrowed synchronously while real RefPtr-owned descriptor Arcs remain alive. Rust observes actual public descriptor/context/declaration methods and checks pointer identity within the retained context; it does not construct a surrogate descriptor. Its assert/assert_eq names resolve to the existing host macros, which report GTest failure and return instead of unwinding a normal Rust assertion across FFI. The null check precedes dereference, and the one-element length check precedes indexing. Production segment composition receives genuine owned AnimationValues and consumes the returned strong reference. The references into effect properties are not used after effect release.

Scope remains literal opacity. No custom-property taint/URL preservation, registration changes, real compositor-driven replacement, or current-provider/SCC behavior is proved. The native correction retains the supplied concrete AnimationValue and only releases an obsolete descriptor; it neither manufactures a numeric declaration identity nor mutates externally held old descriptors. Existing guard-return branches of ReplaceTransitionStartValue remain unchanged. The test does not cover every such early-return branch and does not claim a new visible browser defect.

The actual compilation must still validate the added subclass, offset-constructor and Rust/C++ linkage. For the red run, require both selected names, all setup/numeric/input/ownership controls to complete, and only the intended descriptor-null mismatch; an unexpected early failure is not credited as this regression. The green run must execute the same two tests and pass. Because retained-observer assertions occur at the end, their reported GTest failures remain authoritative without a fake completion counter. Use actual TEST_START/TEST_END records, preserving any outer-wrapper parser failure separately.
