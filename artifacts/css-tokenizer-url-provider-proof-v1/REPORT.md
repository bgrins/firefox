# URL and bad-URL provider

## Result and scope

The component proves URL scan and bad-URL recovery relations for arbitrary finite modeled inputs, plus bounds, UTF-8 structural admission, function-observer behavior, and quoted-delegation completion. It retains exact current native source and a fixed 57-case full-source comparison. There is no new confirmed browser bug and no production patch.

The full native refinement remains conditional: `SOURCE-ADMISSION.md` names the codec, integer, allocation, metadata and exact raw-slice boundaries. In particular, the body-loop native metadata bridge is not discharged merely by applying an observer to the consumed prefix. The scope is not silently narrowed to turn that manual source obligation into an accepted theorem.

## Substantive universal results

- Independent parity-labeled close selection equals the native bad-URL shortcut. On admitted UTF-8 units it also equals full CSS escaped-codepoint remnant consumption, including EOF, hex escapes and escaped close.
- Borrowed and owned URL scans agree with a separate classifier/reference scan. Whitespace-end processing has an independent maximal-prefix reference; NUL replacement, escape output, invalid characters and return bounds are included.
- Structural UTF-8 unit shape is preserved through whole-unit copying, partial-copy rejoining, escapes, output and return boundaries. Canonical codec/native unsafe-memory equivalence remains explicit.
- Forward native leading-whitespace counters equal an independent summary and the CRLF-aware line/UTF-16 observer.
- Quoted `url()` exposes a real intermediate cursor difference between native and CSS Syntax. A kernel witness retains it. A decomposition derived from actual modeled Function return supplies the whitespace premise for equality after the subsequent whitespace and string token, including offset, line, UTF-16 column and directive state.
- Generic requested-function observers preserve off/seen states and update only on the function path. The driver-specific URL observer is kept distinct.

The final inventory is generated in `LEAN-INVENTORY.json` and enumerated exactly in `AUDIT-NAMES.json`: 34 modules, 281 theorem reports, with 11 new modules and 96 new reports. Inherited results are counted separately. Only standard Lean axioms are allowed; no `sorry`, custom axiom, `native_decide` or `bv_decide` is admitted.

## Source replay and discrimination

The same fixed 57 inputs are compiled against the complete crate in debug, release, and release with the actual `fast_match_byte` procedural macro. Their full raw traces agree. The independent normalized-scalar oracle compares every token in this fixture domain; seven quoted-function intermediate positions differ intentionally and must match the independently derived exact rollback tuple. Following whitespace/string observations are compared normally.

The Lean driver compares 57 first tokens and 11 delegated strings, including bad-URL raw payload, offset, line, UTF-16 column, pending block and URL observer. SourceURL and source-map URL observations use explicit `none` / `some:<hex>` encoding; every fixed input requires absence, so present-empty cannot masquerade as absent. Arbitrary initial annotation preservation remains a model theorem and a native source-framing obligation, not this finite absence check. Four compiled native mutations challenge escaped-close recovery, single-quote delegation, NUL replacement and newline metadata. Four Lean semantic mutations challenge invalid apostrophe classification, escaped-close selection, CRLF counting and ASCII casefold. Each mutated definition has a compiled counterexample and its unchanged theorem is rejected. Two corrupted native Function positions verify that the comparator cannot hide arbitrary cursor divergence.

Fresh source-only replay and tamper results are supplied in the separate replay receipt directory at handoff. Generated binaries and development output are not part of this source capsule.
