# Nesting specificity source replay package

This directory describes a source-only package for the optimized nesting A companion. Preserve the repository-relative paths in `PATHS-v1.txt`; the companion resolves the Firefox root from its location under `artifacts/`.

## Run

From a compatible Firefox checkout containing the pinned vendored dependencies and installed tool binaries:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 artifacts/css-nesting-specificity-proof-v1/check.py --out /private/tmp/nesting-source-replay-new
```

The output directory must not exist. The checker authenticates all 39 replay inputs, all original/candidate complete source files in `NATIVE-BINDING-v1.json`, 857 vendored dependency files, and the exact Rust/Cargo/Lean executables in `TOOLCHAIN-v1.json`. It executes actual isolated selectors crates (original, optimized candidate and ten deliberately incorrect variants), 29 Lean theorem audits, 133 Lean/native/oracle cases, twelve further native boundaries and six rejected Lean variants. It does not build or launch Firefox. Expected receipt: zero candidate mismatches, 42 original typed specificity mismatches, and two separate family B controls unchanged.

This is a repository-dependent source capsule, not a hermetic standalone distribution: `third_party/rust` and the pinned installed toolchain are prerequisites, not copied into this package. Paths and executable hashes are environment specific. SDK/linker/dynamic-library and Lean standard-library distributions are not independently frozen. Moving the capsule or changing tools requires an explicit new provenance version and replay.

## Scope

The model proves bounded component addition and substitution laws under the stated valid-parent and representable-native-counter premises. The actual crate bridge is a finite test comparison using its existing DummyParser; it is not a proof of all Rust execution, Gecko parsing providers, selector matching, cascade or invalidation. Family B invalid-parent filtering remains separate.

The package contains 39 replay inputs plus their manifest and this documentation. Every original/candidate complete file referenced by `NATIVE-BINDING-v1.json` is included. `PATHS-v1.txt` and `MANIFEST-v1.json` provide package guidance/integrity.

The historical companion `README.md`, `verify.py`, performance runs, specification snapshots, freeze manifests and previous review receipts are deliberately outside this compact source package. They belong to the separately preserved full review artifact and are not required by `check.py`; this document is the source package entrypoint. Historical performance acceptance cannot be regenerated by this source-only replay.
