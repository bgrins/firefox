This scratch model proves a new conditional bridge from the repaired SVGLength flush selector to the existing UnitConversion preservation theorem. The canonical library previously assumed both factor equalities; it did not prove this selector obligation. No canonical source, native source, index, accepted-fix count or coverage registry was changed.

Eighteen theorem audits pass under the pinned Lean4.35.0-rc4 compiler, using the existing UnitConversion object and two threads. Dependencies are limited to propext, Classical.choice and Quot.sound. Four deliberately false claims are rejected: treating equal dependency tiers as unit identity, accepting Style for a percentage dependency, preserving a stale destination with a source-only policy, and assuming correct tier selection itself completes the provider. Replay creates no target directory or compiled products; its temporary negative sources are removed. Imported source/object and native input hashes are unchanged after replay.

The domain has ten distinct public units with codes1–10, matching SVGLength::IsValidUnitType and WebIDL. Both endpoints are assumed to be in that domain. The independent observation requirement assigns viewport-dependent percentage factors to Layout, em/ex font factors to Style, and absolute/unitless factors to none. The implementation-shaped selector separately checks the exact percentage and font predicates on both endpoint codes, prioritizing Layout. selected_le_iff proves that the selected tier is below another tier exactly when that tier covers both requirements. differing_request_minimal adds the actual unequal-unit admission. This is minimality among the three modeled observation tiers for obtaining both factors, not a claim that every numerically correct conversion must refresh them: zero amounts or compensating stale factors can mask a freshness error.

Unit equality remains distinct from dependency equality. In particular em→ex selects Style. Same-unit conversions skip acquisition and preserve representation/current denotation without a provider contract, including stale or zero supplied factors, by reusing the library's identity and sound semantics. This does not prove scalar initialization, notifications or other native side effects are absent on same-unit calls.

ProviderContract explicitly assumes that successful acquisition at a tier supplies current values for every unit whose required tier it covers. Its none case assumes absolute factors are already stable; style and layout cases assume the respective providers actually complete. selected_factors_ready derives the two equalities and repaired_preserves applies UnitConversion.ready_preserves. Conversion success remains a premise, so zero target-factor failure is not converted into success. The Option failure path is an abstract admission/completion boundary, not a new claim about native exceptions or rollback.

A concrete provider instance proves the contract and makes the bridge nonvacuous. With an old200 viewport/new400 viewport, a source-only px→percentage policy stores50% instead of25%; with an old20 font/new40 font, px→em stores2em instead of1em. The repaired model refreshes the required destination in both cases. Its ex=font/2 and absolute factors are a rational witness environment, not an extracted font-metric or native floating-point implementation. A separate incomplete provider selects Layout but returns the old snapshot: conversion still fails preservation and the contract is explicitly false. Thus a call to document FlushPendingNotifications is not proved to establish hidden-subtree readiness or provider completion.

Source correspondence is manual and bound by SOURCE.json/SOURCE.txt and INPUTS.json. Searchfox discovery covered DOMSVGLength::ConvertToSpecifiedUnits, FlushIfNeeded, the unit predicates, validation and WebIDL constants; exact current installed114 bodies are pinned. The native full font predicate also covers internal codes12–21, and parsed sources can carry units outside public1–10, including viewport units22–25. Those extended sources, UNKNOWN defaults and invalid/read-only inputs are excluded from this theorem. The native checks only target validity here; source validity in the public subset is an explicit model admission, not something asserted about every native call.

The bridge assumes stable input unit/identity and coherent sampling against one supplied current context. Owner/document availability, changes during flush, post-flush revalidation, list/scalar lifetime, provider dispatch, actual CSS factor computation, IEEE arithmetic, zero-axis epsilon policy and complete SVG specification refinement remain external. The proof does not bless shared epsilon behavior or establish performance/security effects. Root's separate C++ selector spy can test the source extraction, but does not discharge these provider obligations.
