# Larger conditional-default graph search

The bounded search found no mismatch between the staged DFS and the independent closure oracle across 38,652 traversal cases on four through eight vertices. These cover 6,336 distinct base-graph/eligibility inputs. Both final edge sets and SCC partitions match. This is additional abstract evidence, not a proof of the general DFS algorithm, Stylo implementation, default-value computation or publication order.

The exact algorithms come from sealed cyclic-default-review-v1. The script extracts their function bodies, replaces the two-custom-vertex domain with all non-target vertices, and supplies root and original-neighbor permutations. The target is fixed at n−1 and remains ineligible, matching the original distinguished scheme vertex; other vertices have fixed Boolean eligibility during each execution. The only neighbor-loop adaptation visits supplied original edges in order, followed by any edge introduced by the early-only negative control. Positive default edges are still visited immediately after the node's original outgoing edges, before SCC popping. Dynamic-edge placement is not permuted.

Before larger cases, all 12,288 original three-vertex/sorted-neighbor cases compare generalized and original function outputs exactly. This is a compatibility check, not new coverage beyond the sealed three-vertex result. The separate earlier 98,304 exhaustive neighbor-order receipt remains unchanged.

For each size, six targeted families exercise default-cascade chains, nested SCC chains, a target-inclusive ring, cascading branches, isolated self-cycles and a dense acyclic graph. Every non-target eligibility assignment is tested in those families. Another 1,000 seeded graphs per size use five edge densities, including sparse and dense graphs, with deterministic eligibility flags. Each input has ascending and descending traversal variants plus four seeded root/neighbor permutations; duplicate order pairs are removed within an input. Counts are traversals, not unique algorithms or distinct semantic counterexamples. Duplicate graph/eligibility inputs across families/random generation are separately reported by the unique-input count. The search is deterministic for the saved Python random implementation, with explicit seed formula and fixed case budget.

A concrete eight-vertex chain starts with only vertex 0 cyclic. Its first default edge to target 7 makes all vertices cyclic, enabling six further non-target default edges in the closure. WITNESS.json records the exact matching staged/oracle output and one final SCC. Thus the experiment includes cascading eligibility, rather than only graphs where no new edge is needed. This abstract closure-round account does not imply native traversal pass counts.

Sensitivity is preserved: the sealed early-only rule misses the default edge on the two-node non-self cycle; its differing output is retained in RESULT.json. On a positive-algorithm mismatch, search.py saves the deterministic family/seed, original graph/eligibility/root/neighbor order, exact expected/actual results and a greedy edge/eligibility deletion minimization. That failure path was not exercised because no mismatch was found. The minimizer does not claim minimum vertex count or global minimality. A cooperative 45-second elapsed-time check runs before each larger traversal and stops with an error rather than reporting completion. It is not a hard process deadline for compatibility checks, minimization or one long traversal. The fixed graph/case bounds remain explicit; the actual planned search completed in approximately one second.
