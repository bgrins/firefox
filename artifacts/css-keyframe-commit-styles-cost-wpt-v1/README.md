## Correction to the earlier plan's additive oracle

Both families have a stable retained `--step: 1px`; initial active composition must translate N px. Committing the top writes N px inline. The still-active N additive translations then combine with that new underlying value, so the immediately following computed transform must be 2N px. After cancellation the committed inline N px remains. The earlier cost plan's expectation of N for the still-active postcommit result was incorrect; this HTML explicitly corrects it, preserving genuine additive lower contributions. Matrix coefficients are checked exactly, independently of serialization formatting. These expectations follow the [commitStyles partial-stack write](https://drafts.csswg.org/web-animations-1/#dom-animation-commitstyles) and [additive effect composition](https://drafts.csswg.org/web-animations-1/#effect-composition), not a browser observation from this artifact.
